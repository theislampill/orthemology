## The question this closes

An unknown scoring weight cannot be replaced by its estimate without checking how estimation error affects the actual repair inequalities. This continuation connects four concrete objects in one model:

1. A selector generates actual audit receipts
2. The same selector induces the contract's expected score
3. Exact, time-uniform confidence intervals bound the unknown selector weight
4. An executable rational certificate issues a coherent correction only when the entire interval admits it

The final theorem concerns every real selector parameter, and one fixed public procedure. It does not receive the hidden parameter as a computational argument.

## Exact decision rule

The incoherent input is b=(1/2+epsilon,1/2), with 0≤epsilon≤1/4. A coherent report is c=(q,1−q). Possible fixed, normalised scoring weights occupy [l,u]⊆[0,1]. Write m=(l+u)/2 and d=(u−l)/2.

The unique minimax coherent report and its signed worst-case excess score are

    q*=1/2+m epsilon−d epsilon²
    R=d epsilon−m(1−m)epsilon²−2md epsilon³+d²epsilon⁴.

A report with excess score at most eta for every weight and both truth states exists if and only if R≤eta. Negative eta has a genuine interpretation: guaranteed strict improvement. The code checks the exact rational inequality, not a floating-point approximation or a necessary-only decoding tolerance.

Under valid rational input bounds, rationalCertificate returns some(q*) exactly when the tolerance is feasible. A none result then excludes every real coherent q at that tolerance. Invalid inputs also return none, so that stronger interpretation requires the input-validity hypothesis.

## Actual statistical experiment and computation

The source law is the explicitly constructed infinite product of Bernoulli(alpha) selector draws. Its observed-prefix masses are derived from the product law. Counts are computed from actual finite bit words.

At sample count N=n+1, each tail receives budget

    beta_n=delta/[2(n+1)(n+2)].

Inclusive-tail superuniformity and stochastic monotonicity are proved for the actual finite Bernoulli masses. Rational outward bisection produces the tail brackets. Countable subadditivity and the checked telescoping budget then give simultaneous coverage failure at most delta.

The executable procedure uses only the acquired word, public precision, delta, and rational disturbance/tolerance functions of that word. Every actually issued report is checked. The probability that any issued report, at any time, violates the claimed all-truth expected-score bound is at most delta. It is one time-uniform frequentist guarantee for each true alpha, not a posterior probability conditional on a realised interval and not a simultaneous claim about every parameter on one path.

The initial executable reference enumerates 2^N bit words. ## Contract and evidence scope
