## Portable use

After extracting the archive, run the Python wrapper with explicit paths and the external MANIFEST.json digest from the preservation receipt:

    python3 -B replay.py --expected-manifest-sha256 <digest> --lean-home <Lean-4.19.0-root> --packages-dir <retained-package-root> --retained-root <retained-project-root> --output-dir <new-isolated-output>

The retained-project root contains the named historical project directories listed in the prerequisite bindings. The package root contains mathlib and its peer package directories. The Lean root contains bin/lean, lib/lean and src/lean. Roots may be relocated: active bindings are root-relative. Missing or changed prerequisites fail closed before proof compilation. The wrapper rejects manifest mutation, extra/missing payload files, unsafe paths, stale output and overlap with immutable inputs. It copies exactly the needed non-core retained object bytes into its own closed search directory and places fresh additive outputs first. Original author/reviewer scripts are preserved for inspection but are not executed in their original locations.

Run test_guards.py with the same arguments to exercise the fail-closed wrapper controls. Both commands require a new output directory. All outputs are additive and remain outside the packet and original evidence directories.
