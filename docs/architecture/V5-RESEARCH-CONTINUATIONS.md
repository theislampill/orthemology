# Orthemology v5 research continuations

This additive registry continues the same v5 programme through the **final sixth
return**, after preserving the first five tranches and sixth checkpoint 3 in
their own integration commit. PR28 remains the historical consolidation base.
The [source and review index](../provenance/v5-research-continuations/README.md)
links actual arguments, formal sources and scoped reviews. Seventh is an agenda,
not completed research.

The 42 original families and 26 sixth-final groups are navigation, not an
authoritative theorem catalogue. The
[registry](../../experiments/orthemology-v5-continuations/registry.json) records
source/review identities, claim limits, mathematical form, implementation reach
and isolated suites. The
[successor overlay](../provenance/v5-research-continuations/SIXTH_FINAL_OVERLAY.json)
binds the completed predecessor commit/tree and preserves every prior statement
and evidence status. Its current selectors apply only to their stated scopes.

## Source and evidence ownership

Each suite retains its own module-to-source mapping, import order, declaration
owners and exact dependency pins. Identical Lean bytes share a content-addressed
store; unequal sources with the same module name remain in separate suites.
There is no combined import root. Original notices and statements remain in the
source bytes, including historically accurate comments about earlier uncompiled
states. Current results live in the overlay rather than rewriting those comments.

[SOURCE_MAP](../provenance/v5-research-continuations/SOURCE_MAP.json) distinguishes
exact projections, reviewed prose derivations and items retained only in private
custody. Archive member selectors are not checkout paths or download promises.
Prose derivations add an inherited-evidence notice, reduce original navigation to
text and remove private local locators; their original and derived hashes and
diff digests are recorded. No raw archives, primary-text collection, attached
polyphony PDF, compiled objects, private captures or execution logs are included.

[RESULT_STATUS](../provenance/v5-research-continuations/RESULT_STATUS.json) keeps
source custody, inherited review, fresh checking, repository-candidate disposition
and external warrants separate. A source-integrity pass proves consistency of
the declared records. A kernel-component receipt concerns its exact source closure
and declaration readbacks. Neither establishes empirical validation, normative
warrant, external human peer review, novelty or merged adoption. Ordinary proofs
and conditional arguments cannot receive whole-family kernel status.

[EVIDENCE_BINDINGS](../provenance/v5-research-continuations/EVIDENCE_BINDINGS.json)
binds each scoped statement to its exact source and retained review identities,
and each credited suite to the declaration targets owned by those sources.
Cross-archive sources remain valid when their exact bytes match. These are
explicit integration associations, not machine judgments that every contextual
review proves every statement in a family. Reassigning a suite or review requires
an explicit, reviewed association update; a shared archive alone is insufficient.
The stronger `QUALIFIED` status also requires a source-bound control contract and
terminal control summary, including original drivers, receipt digests and every
required positive/mutation stage. A bare control-success string is insufficient.

## Static action disclosure

For the truthful, integrity-informed, context-bound sender and compulsory-action
game, the final ordinary proof closes the private fixed-codebook frontier for
every finite u>b>=0 and M>=1, including arbitrary real, overlapping, nonuniform
probability rows. With N=b-M+1 and 1<=M<=b, its value is

`max_(1<=q<=u-M+1) floor((q*N+M-1)/u)/q`.

The value is zero for M>=b+1 or b=0. A disjoint-uniform partition attains it.
The shared-random value is `choose(b,M)/choose(u,M)` for 1<=M<=b and zero at the
same boundary; the ratio is not evaluated outside that range. Value evaluation
uses O(u) arithmetic operations; partition construction uses O(M*u^2), with no
claim about bit complexity. The four distinct timing games have values 3/28,
1/4, 3/8 and 1 at (u,b,M)=(8,3,2), and all have value zero when b=0.

This complete private proof depends on the published partition-Kneser theorem.
It remains ordinary reviewed mathematics, not a Lean formalization. The exact
two-message and b=4,M=3 arguments retain their lighter dependencies and rational
certificate checks. The three-module Lean disclosure suite covers the zero-error
subset only. Earlier pending intermediate slices are now scoped predecessors;
the failed three-matroid extension remains a failure. None of these results
authenticates a sender, imposes a moral duty to act, supplies empirical fault
rates, or discharges the strengthened-interface burden against R5.

Completeness, apoautosis and polyphony connections remain proposals. A renamed
winning-region predicate is not a new Gödel-level result; a structured research
continuation is not an empirical demonstration of autonomous apoautosis.

## Reproduction and subsequent checkpoints

See the [replay interface](../../experiments/orthemology-v5-continuations/README.md).
It requires Python 3.11.9, the repository dependency lock, official Linux Lean
4.19.0 and Mathlib `c44e0c8ee63ca166450922a373c7409c5d26b00b`, with each suite's
package revisions. Custom objects are compiled into an absent external directory;
official dependency caches are an explicit trust boundary. The runner verifies
sources before and after, checks exact target types and axiom footprints, and
does not accept author objects or silently select another module variant.

Original positive and intended-failure controls remain separate from the generic
component runner. A missing prerequisite, timeout, invalid probe or reference-only
run is not strict acceptance. Fresh results must be bound to the actual command,
source and terminal receipt. Later checkpoints require fresh input hashes and
statement-specific supersession; existing accepted work is not replayed merely
because a new transport archive arrives.
