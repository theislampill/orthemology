# Orthemic finite existence certificates

This bounded Ninth research artifact gives a total Lean checker for independently submitted finite support-DAG, path, exit and qualifying-component witnesses. For a valid fixed finite rational input, a query has an accepted finite certificate exactly when the original inherited common lawful almost-sure parity policy exists. Completeness also accepts an arbitrary measurable seed policy as its premise. This is an existence interface, not direct certified programme extraction or a new winning-region theorem.

## What is checked

`bodyCheck I c` validates the explicit input and every node, independently of any query. `queryLookup c B s` selects a nonempty exact support/state query; `check` combines them. Shape checks short-circuit before finite-carrier enumeration. Sparse menus have an empty default and reject malformed/duplicate raw keys. All possible positive receipts are covered, not only the selected exit. Paths have reconstructed sources and at most n−1 steps. Components need not be maximal; their actual internal graph, full numerical rows, candidate zero exit and every matching live rival's attained even minimum are checked.

Certificates contain no winning proof, solver invocation, retained-selector equality, or hidden-model oracle. Only the proof of semantic completeness uses classical finite choice and inherited winning-region computations.

## Safe composition API

Use `checkedMerge I c d` for untrusted body admission. It checks both complete original bodies before canonicalization, unions state/pair records at identical support keys, and retains an original literal obligation/component at each collision. It does not union hidden-model supports or component witnesses. `checkedLinkParent I c p` separately checks a new absent-support parent against existing children before adding it. A union of child bodies alone never creates a parent support.

Low-level `merge`, `sortBody` and `linkParent` are structural canonicalizers for already validated inputs. Their preservation theorems explicitly require valid bodies and, for a parent, absence plus local validity. Applying a raw canonicalizer to malformed duplicate support records may discard a duplicate; it is not the untrusted admission API.

`boundCheck actual package B s` additionally compares the actual structured input, including arrays, priorities, menus, codings and declared interpretation fields, before fresh checking. Changed input may remain valid when freshly checked, but a stale bound envelope rejects. Equal hashes or equal labels are not used as input equality proofs.

## Evidence and limits

The controls include the exact three-model reveal example, both required children, independent parent admission, alternative targets/paths, malformed input dimensions, omitted receipts and candidates, wrong child support, same-support duplicate cycles, permission removal, numerical row equality versus support equality, latent priorities, stale bindings, and deliberately weakened checker mutations.

The two-model Bernoulli fixture admits a finite certificate for the inherited history-policy existence result. Finite syntax does not imply autonomous finite-state execution. Unbounded empirical history and externally supplied time must not be confused with finite-state memory. See PROOF_OWNERSHIP.md.

The executable dependency audit follows definitions, opaque bodies and `implemented_by` replacements. It excludes the inherited solver, powerset search, semantic decision and classical choice from checking, and reports trusted runtime primitives. `#eval` and six-module C codegeneration are checked; linked standalone execution is not claimed.

COST_SCOPE.md gives an ordinary polynomial bit-cost argument in explicit input plus certificate size, not a formal complexity theorem or polynomial witness-size claim. No parser/binary refinement, negative completeness, historical proof-carrying novelty, normative authority, occurrence truth, complete worldly model coverage, deployment or physical-safety guarantee is supplied.

## Portable replay

The public packet includes only scientific sources, controls, exact inherited cost closure, dependency identity material, replay scripts and public evidence. Private implementation plans, coordination notes and host-specific failed logs remain outside it.

Run `python replay.py --verify-only` to check the complete source freeze. For a fresh isolated one-lane replay, provide `--lean-bin`, `--mathlib`, optional exact `--mathlib-archive`, and a previously absent `--out` directory. The script uses Lean 4.19.0, Mathlib c44e0c8, `-j1`, no added heartbeat overrides and a 180-second wall bound per module. All eight new modules use the default heartbeat budget; two unchanged inherited source-level settings are documented in DEPENDENCY_TRUST.md. It rebuilds the selected inherited closure and all positive modules/controls, checks actual theorem types/axioms, exercises deliberate mutation rejections and generates C for finite-checker modules. Source-only verification is not proof replay. Optimized Python (`-O`) is refused.
