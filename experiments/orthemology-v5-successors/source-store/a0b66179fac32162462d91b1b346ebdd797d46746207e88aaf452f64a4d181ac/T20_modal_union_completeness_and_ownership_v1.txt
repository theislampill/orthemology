T20 Exact Consequence Boundary for Modal Union Source Certificates
7 October 2026

Scope

This supplements T20_modal_union_component_theorem_v1.txt with an exact completeness converse for its abstract equality-premise language. It classifies what those local modal-crossing premises can force, rather than merely giving another sufficient propagation lemma. It does not classify all metaphysical truths about sources or demonstrate a possible plural reality.

1. Fix the frame before quantifying over interpretations

Fix a frame F consisting of carrier vertices V, world indices W, an admissibility predicate, and a world-indexed crossing relation E. If availability is represented separately, assume the frame's admitted edges have locally available endpoints. Keep this frame fixed throughout the comparison of interpretations.

Let U be the undirected union of the admitted crossing edges, as defined in the preceding paper. Write u ~ v for finite U-path connectivity. This is an equivalence relation.

A pure source interpretation consists of a source set S and an attribution function a : V -> S satisfying the anchored edge law: every admitted E(w,u,v) has a(u)=a(v). The source set and attribution vary across interpretations. No particular attribution function is fixed by the frame.

Define ForcedEqual_F(u,v) to mean that a(u)=a(v) in every such source interpretation. This quantifies only over interpretations of this specified premise language. It adds no fixed source cardinality, named-source equalities or disequalities, surjectivity, global plenitude, or independent metaphysical axioms.

EXACT CONSEQUENCE THEOREM.

ForcedEqual_F(u,v) if and only if u ~ v.

Soundness is the path propagation proved in the preceding paper.

For completeness, use the connected components as the source set: S = V/~. Attribute each carrier v to its component [v]. Endpoints of every admitted crossing lie in the same component, so this is a source interpretation. If u and v are disconnected, [u] and [v] differ. This interpretation separates them, proving that their source equality is not forced by the pure premises.

The same construction separates every disconnected pair simultaneously. It is the free equality interpretation generated by the frame's crossing requirements. It is an abstract logical interpretation, not a claim that its component labels are actual or metaphysically possible original beings.

2. The world-transport version has the same exact boundary

Expand an interpretation to include local source sets Sw, transports t_w : S -> Sw, and local source attributions s_w. Require injective transports, local same-source on admitted edges, and retention of both endpoint attributions through t_w at those edges.

Every expanded interpretation satisfies the anchored edge law. Conversely, every pure source interpretation has a faithful expansion: choose Sw=S in every world, t_w the identity, and s_w=a on available carriers. Thus the expanded and pure languages force exactly the same equalities between anchored vertex sources.

The quantifier order matters. W, admissibility, E and any valid availability frame are fixed first. The source sets, attributions and faithful transports range over the interpretations of that frame. The result does not say that arbitrary already fixed local sorts and transports always admit the component interpretation. For example, a fixed local sort too small for a required injective transport may leave no interpretations at all, making universal consequence vacuous.

It also does not state the false converse for a single fixed a: disconnected carriers can already have the same actual original source. Connectivity characterizes equality forced by this premise language across interpretations, not every equality true in one particular interpretation.

3. Two source values suffice for each separate non-entailment

For one disconnected pair u,v, the separating interpretation need not use a distinct source value for every component. Use two values A and B. Give every vertex in u's component label A and every other vertex label B. No union edge crosses the component boundary, so all edge equalities hold; u and v have different labels.

Consequently, the pairwise completeness converse also holds with any fixed source set having two distinct values, provided no additional constraints prevent this two-color interpretation and the local transports can be chosen faithfully. A fixed singleton source set is different: all labels are equal even in an empty graph. The quotient construction is canonical and simultaneously maximally separating; it does not imply that as many source values as components are necessary for each individual separation test.

No decidability assumption is needed for the mathematical quotient proof. A finite Boolean implementation can compute the component; an unrestricted Boolean construction may require classical decidability. These are proof-engineering choices, not metaphysical principles.

4. Positive and negative certificates

For a fixed nonempty target and anchor v0, the pure premises force every target vertex to have source a(v0) exactly when every target vertex is union-reachable from v0. Paths may pass through vertices outside the target. One co-possible connected world and all-pairs direct contact remain unnecessary.

A positive finite certificate gives paths, with each edge's world witness and its retained-provenance and identity-reflection evidence. A negative finite certificate gives a two-color labeling which respects every declared admitted edge but assigns different colors to the queried endpoints. The latter certifies non-entailment from the declared equality-premise frame.

For an explicitly finite frame, a graph traversal or union-find computation can produce either certificate. Checking a negative certificate requires the complete declared edge set, not just a selected list of favorable edges. For an infinite or symbolic world space, the claim that no edge crosses the cut requires a proof over all admitted worlds; a finite scan cannot establish it.

Even a complete negative certificate for a finite declared frame does not establish metaphysical separation. The declared worlds may be only the supplied evidence, and a further warranted crossing would enlarge the frame and change its consequences. Likewise, a positive certificate verifies the conditional equality reasoning but does not manufacture the actual-world truth of its admissibility or provenance inputs.

5. Limits imposed by richer premises

Additional anchored source equalities can connect components at the level of consequences without an E-edge. They can be represented as additional equality-generating edges if that is the intended expanded language. Independently established source inequalities can make a frame inconsistent when a path connects their carriers. In an inconsistent interpretation class every conclusion is vacuously forced, so the pure iff no longer characterizes it without a consistency restriction and an appropriately revised language.

A global all-other-dependence premise, source-surjectivity conditions, source cardinality bounds or substantive agency axioms may also change the consequence theory. The present completeness theorem should not be described as a completeness theorem for all of T17-T20 metaphysics.

Connectedness forces constancy of the used attribution range, not uniqueness of every member of an unrestricted source set S. Unused source identities remain invisible. To conclude numerical uniqueness of relevant actual originals, the independent coverage premise from the preceding paper remains necessary. This is where conditional active-product availability or another warranted representation rule must enter; graph completeness does not settle idle-original scope.

7. Minimal Lean extension

The soundness development proposed in the preceding paper can be extended with a Setoid on V whose equivalence is undirected union reachability. The quotient map to its components supplies the canonical counterinterpretation. Quotient soundness verifies every edge equality; quotient exactness separates disconnected endpoints. This can be done with Lean's core equivalence and quotient facilities plus either a small finite-path inductive definition or an existing relation-closure import. No large graph framework is intrinsically required.

Suggested theorem boundaries are: anchored edge law from faithful transport; source constancy along union paths; canonical component interpretation; forced equality iff union reachability; target-wide common source iff target vertices share one component in the pure language; and the separate representation/coverage implication for relevant-source uniqueness.

The finite tests from the preceding paper remain useful. Add one disconnected-frame two-color test that preserves all premises, to distinguish exact non-entailment from the two assumption-dropping countermodels. A singleton-source control should explicitly show why unrestricted interpretation or two available values matters to the converse. These additions are small and directly test the exact statement.

No implementation or kernel replay is claimed in this written-theorem pass. The existing T9 status has been reported at its recorded scope, and all metaphysical premise and source-reading boundaries remain visible.
