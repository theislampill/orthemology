## Frozen object

The executable contract is a binary deterministic causal interface of horizon
two. A kernel maps the complete admitted intervention/output history and the
next intervention to the next output. Policies may choose the second
intervention from the first complete observation.

The general finite construction stores the complete admitted history as state,
uses the same conditional output kernel at that state, and appends the next
intervention/output pair. Induction on the horizon gives equality of complete
trajectory laws under every common candidate-independent adaptive policy.

target coordinate is nonidentifiable. This operation does **not** establish

## Complete open-loop versus adaptive profiles

For the frozen deterministic causal contract, all complete open-loop input
sequence trajectories induce the same behavioural partition as all adaptive
policies. This does not license one selected baseline policy, endpoint-only
records, missing trajectories, or noncausal policies. It records a useful
normalisation: adaptivity need not add partition power once every open-loop
sequence has its complete trajectory law.

## Resource firewall

The complete-history state count is a universal upper bound, not a minimum or a
lower bound on rival implementations. Constant-output behaviour can use a much
smaller realiser. Resource discrimination therefore requires the quotient by
future behaviour or a separately proved architecture-class lower bound.
