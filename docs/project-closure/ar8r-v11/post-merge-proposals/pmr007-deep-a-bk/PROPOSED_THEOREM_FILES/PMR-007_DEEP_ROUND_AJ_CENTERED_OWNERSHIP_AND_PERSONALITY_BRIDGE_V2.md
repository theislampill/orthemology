## 2. CIOB-1A — automorphism-orbit obstruction

Let `T_e` be any target set of candidate centers whose value is determined by an
isomorphism-invariant construction using only `A_e`.  Then `T_e` is a union of
`G_e`-orbits.

Consequently:

```text

no neutral-reduct-invariant exact selector can accept s and reject t;

if G_e is transitive on at least two candidate hosts,
no neutral-reduct-invariant unique center exists;

if {s} is an invariant singleton,
s is fixed by every element of G_e.
```

### Proof

For any `g in G_e`, an invariant construction has


after transformation: `g[T_e] = T_e`.

Thus membership is constant on each orbit.  A singleton target is invariant
only when its element has singleton orbit, equivalently when every automorphism
fixes it. ∎

semantics or personality.
