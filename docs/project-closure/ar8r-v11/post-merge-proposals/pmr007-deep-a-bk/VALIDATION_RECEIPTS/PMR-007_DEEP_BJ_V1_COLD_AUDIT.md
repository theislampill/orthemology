## Blocking findings

### BJ-F01 — BA reduction omitted transition-congruence structure

Taking the complete all-action trace as one target recovers BA's state
partition, but BA's exact represented-system factorization also requires the
representation kernel to be stable under every declared transition. V1 must
not claim the set-level decoder theorem alone reproduces the full dynamic
realization theorem.

### BJ-F02 — “one smaller core” was stronger than the result

The quotient-descent theorem is a common deterministic extensional mechanism,
not a reductive common calculus for BA–BI. It supplies one reusable layer while
probability, dynamics, group action, convex geometry, path structure, and
algebraic operations remain separately typed.

### BJ-F03 — anti-unification conflated formal encodability with explanatory reduction

Any finite property can be encoded as a target label, making a vacuous
set-factorization instance. That does not derive the native theorem's invariant
or preserve its operations. V2 must define a substantive reduction as one that
preserves the native typed objects, admissible morphisms, and failure modes
without importing the desired target as an oracle.

### BJ-F04 — target independence was not explicit

If `f` is defined using the answer to the disputed source, metaphysical, or
normative question, fibre constancy merely restates it. The target and its
semantic/authority contract must be independently supplied.

### BJ-F05 — deterministic coarsening was at risk of statistical overreach

TQDC-1D concerns deterministic exact recovery. It does not subsume Blackwell
garbling, likelihood-ratio sufficiency, or stochastic channels. Those need
probability kernels and decision semantics.

### BJ-F06 — subdirect/full-product structure is not explanatory integration

The full-product characterization is exact for attained tuples, but neither a
proper image nor a full image identifies causation, derivation, independent
typing, or the warranted null model. Candidate-G unification requires more.

### BJ-F07 — finite and attained-image scope needed theorem-internal guards

Decoder uniqueness is only on `r(X)`, minimality is only for finite attained
representations, and the result does not assert an effective construction for
arbitrary infinite or inaccessible profiles.

### BJ-F08 — anti-unification executable metadata was incomplete

Two explicit controls lacked a dedicated `pass` field. The mathematical values
were correct, but the admission checker should make every control's disposition
machine explicit.

### BJ-F09 — source, norm, and world nontransfer needed stronger placement

An independently typed target may still lack source authenticity, truth,
proper-function status, recipient warrant, or world adequacy. Exact descent
preserves a target relative to its contract; it does not validate that contract.

### BJ-F10 — ancestry and theorem-origin ceiling must deny multiplicity

TQDC-1A/B are the standard quotient/factorization criterion already present in
profile-fibre and sufficient-statistic families. TQDC-1C is an intersection and
subdirect-image application. The BA–BI mapping creates no new independent
origins for the native results and no general mathematical novelty.

2. Add independent-target and contract guards.
3. State BA's transition congruence, BI's algebra congruence, and every native

4. Define substantive reduction versus answer-encoding.
5. Separate deterministic coarsening from stochastic experiments.
6. Add explicit Candidate-G explanation ceilings.
7. Repair checker metadata and run a partition-based distinct rereview.
