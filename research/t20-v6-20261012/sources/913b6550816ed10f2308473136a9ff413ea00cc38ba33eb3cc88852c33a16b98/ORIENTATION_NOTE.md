# P14 orientation note — prospective applied Orthemology

This note is a research orientation, not an accepted theorem or canonical mapping. The supplied PDF is a prospective application source. P14 asks whether, and under exactly what definitions, it becomes a genuine Orthemology application.

The promising bridge is **structured evidence -> observation/projection -> admissible transformation -> stable policy**, while preserving multidimensional distinctions instead of assuming a scalar total order. The current Orthemology corpus already has ordinary observation/refinement results (notably T03 and V4-Q1/CV-R), scoped fixed-point work (T19, V4-S2, T20, T22), and operational admissibility machinery. P14 must determine which links are exact, which are analogical, and which require new definitions.

Candidate correspondence table (all entries require proof/audit):

| PDF object | Candidate Orthemology reading | Mandatory guard |
|---|---|---|
| `e ∈ E ⊆ R^k` | structured observed/application state | Not automatically an ortheme or canonical Context |
| tuple coordinates | separately observable distinctions | Coordinate semantics must be specified; not automatically independent |
| improvement cone | application comparison/refinement relation | **Do not call it canonical kernel `K`**; Orthemology already uses `K` for the trusted calculus |
| scalarisation `w : E -> R` | candidate observation/projection/quotient | Must prove the exact preservation/loss property; not every scalar map is a CV-R refinement map |
| cognitive loci `F_i` | candidate typed observers/operators | Functional decomposition is a modelling choice, not empirical psychology or canonical Orthemology agent structure |
| admissible responses `S_i` | locally permitted transformations/actions | Must state the governing admissibility relation; not automatically `Adm_Γ` |
| mixed policy `σ_i` | convex policy state | A mixed strategy is not automatically an Orthemology probability law or executable sampler |
| `G_i(e,σ_i,σ_-i)` | joint observation/transition semantics | Requires explicit state/interface typing and dependency semantics |
| equilibrium `σ*` | conditional fixed/stable point | Stability is not truth, correctness, authority, convergence, or self-certification |
| L0-L7 hierarchy | candidate assumption/admissibility DAG | Higher-level conclusions need their added premises; no credit leakage |
| congenial tuples | common admissible comparison/coordination domain | Admission does not imply scalar commensurability or total comparability |

The PDF does **not** by itself advance Girard/SCUU/SCUUAt/OWOU. Any such connection must be separately derived from the current canonical definitions and is expected to remain a non-equivalence unless an actual theorem is supplied.
