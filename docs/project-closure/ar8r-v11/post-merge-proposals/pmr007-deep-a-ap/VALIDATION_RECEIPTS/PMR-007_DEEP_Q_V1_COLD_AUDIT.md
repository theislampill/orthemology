## Blocking findings

### Q-F01 — “total articulability” overstates the finite construction

The proof covers a frozen finite content class and a finite family of lossless bijective encodings. It does not cover all possible contents, incomplete languages, ambiguity, context sensitivity, pragmatic force, or absolute metaphysical articulability.

**Repair:** rename the theorem to **finite exact cross-system articulability** and state the frozen content/language scope everywhere.

### Q-F02 — bijective encoding hides the hard language cases

Bijections exclude polysemy, synonymy, lossy translation, partial expressibility, and context-indexed meaning. The construction is a positive idealized control, not a complete language theory.

**Repair:** state lossless exact encoding as a hard premise and add explicit lossy/ambiguous failure controls.

### Q-F03 — the content object is primitive

The groupoid derives translations from `C` and the encodings but does not explain why `C` exists, is determinate, is world-applicable, or exhausts the intended content domain.

**Repair:** classify the result as **conditional unification given a prior content structure**, not a ground of content determinacy.

### Q-F04 — “concrete actualizer” is too metaphysical

A finite translation transducer executes a table. It is not thereby a metaphysical actualizer of abstract order, a necessary being, or an ultimate bearer.

**Repair:** call it a finite concrete **realizer** and preserve the abstract-order/concrete-actualizer metaphysical bridge as open.

### Q-F05 — personal/impersonal expansion is model-relative

Adding or withholding mentality predicates establishes logical nonentailment only over an intended class containing both expansions. It does not prove the metaphysical possibility of an impersonal semantic realm.

**Repair:** make class closure explicit and preserve the world-level rival as a live architecture rather than an established reality.

### Q-F06 — formal unification versus explanatory unification

The construction genuinely reduces pairwise translation tables and imposes composition laws, but it leaves primitive `C`, each encoding, and applicability. Calling it full explanatory unification would repeat the Candidate G overreach.

**Repair:** classify it as `FORMAL_TRANSLATION_UNIFICATION`; leave metaphysical/explanatory unity open.

### Q-F07 — UG-T4 nonselection ancestry is not proved anew

The symmetry paragraph relies on established equivariant nonselection. The V1 primary checker tests only groupoid laws.

**Repair:** mark the nonselection claim as inherited from `AR8R-T31`/related UG ancestry and do not represent the checker as evidence for it.

### Q-F08 — Track-N source use requires precise authority

The Asfahani file is an English translated-primary-access object based on two editions. Its source predicates do not become neutral conclusions or Arabic-primary verification.

**Repair:** record source hash, translation status, and the source-formal-world firewall explicitly.
