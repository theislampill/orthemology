# AR8R V8 public recovery packet

This additive packet records 42 historical AR8R identities without publishing the private ChatGPT transcript or browser evidence corpus.

- 18 payloads are byte-exact verbatim historical recoveries.
- `AR8R-RC-T366-v1` is a post hoc, historically constrained semantic reconstruction. Its original historical bytes remain unavailable.
- `AR8R-RP-001-v1` is a role-preserving replacement associated with T150. It is not identified with the historical theorem.
- 22 identities remain historical-identity-only records.
- T354 is byte-exactly recovered but audit-blocked: its strict-improvement relation is not reflexive and therefore is not a preorder as written.

The historical duration and segment authority are unchanged. This packet does not claim natural campaign closure, empirical validation, terminology adoption, or owner adoption of either proposal. The full transcript, Activity captures, screenshots, signed links, and unrelated attachments remain local and are not part of this repository.

Run `python scripts/validate_ar8r_recovery.py` to verify counts, hashes, provenance separation, unresolved accounting, and the T354 block.
