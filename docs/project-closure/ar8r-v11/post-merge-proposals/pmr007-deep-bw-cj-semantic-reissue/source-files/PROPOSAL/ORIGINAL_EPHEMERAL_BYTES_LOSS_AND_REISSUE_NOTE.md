# Ephemeral-byte loss and semantic reissue note

The first post-Deep-BV package build completed and passed round-trip verification inside an earlier runtime. During the attempt to surface those files through a separate user-visible execution environment, the active runtime data filesystem reverted to the pre-run baseline. The original theorem, audit, repair, rereview, package, and report bytes from that first build were no longer present.

This reissue therefore follows a fail-closed custody rule:

```text
original ephemeral post-BV bytes preserved: false
semantic results retained in authenticated execution summary: true
fresh consolidated executable recheck: true
exact-byte recovery claimed: false
scientific dispositions changed: false
```

Every theorem packet in this reissue is labeled `SEMANTIC_REISSUE_OR_REGENERATED_CUSTODY_COPY`. The consolidated checker was written and executed after the reset; its source and output are fresh exact bytes and do not purport to be the earlier independent rereview programs.
