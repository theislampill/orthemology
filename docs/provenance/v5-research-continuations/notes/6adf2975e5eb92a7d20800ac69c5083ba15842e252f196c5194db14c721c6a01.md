# Exact two-message fixed-codebook frontier

Candidate for independent review, ordinary finite mathematics; no canonical adoption. The accepted
positive-error v2 packet is unchanged. This argument concerns fixed codebooks
with receiver-private randomness only.

## Theorem

For u>b>=1 and M=2 (including the zero-error b=1 case),

V_fixed(u,b,2) = B(u,b,2)
 = max { t in [0,1] : ceil(t s)+ceil(t(u-s)) <= b for every s=0,...,u }.

Here B is the best disjoint-uniform two-block codebook value. In particular,
V_fixed(7,3,2)=1/3 and V_fixed(11,5,2)=3/8.

The key stronger statement is ordinal: for any two orderings of u objects, if
max_s[ceil(ts)+ceil(t(u-s))]<=b, some b-set C contains at least ceil(tk) of the
first k objects in each ordering, simultaneously for every k.

## Partition equivalence and upper bound

A two-block partition of sizes s,u-s has risk at least t iff the adversary can
put at least ceil(ts) corrupt roots in the first block and ceil(t(u-s)) in the
second, equivalently their sum is at most b. Therefore its minimum over the
positive block sizes is at least t iff this inequality holds for every positive
s. The endpoint constraints s=0,u follow from any internal constraint because
ceil(ts)+ceil(t(u-s))>=ceil(tu). Each block risk is a maximum over finitely many integer allocations; B is a
minimum over finitely many block sizes. Consequently B is attained and the
displayed feasible set is exactly the closed interval [0,B]. Since every partition is an admissible codebook,
V_fixed<=B.

## Chain matroid lemma

Let P_k be the first k objects in one ordering, including P_0=empty and P_u=E.
Put f(k)=floor((1-t)k). The family

I = {D subset E : |D intersect P_k| <= f(k) for all k}

is a matroid (a nested/laminar matroid), with rank

r(A)=min_{0<=k<=u} (|A minus P_k| + f(k)).

For completeness, the exchange and rank claims have short direct proofs.
Downward closure is immediate. If independent I,J have |I|<|J| and no element
of J minus I can be added to I, every such element is in a tight prefix P_k
with |I intersect P_k|=f(k). The largest tight prefix containing any such element
contains all of J minus I. In that prefix J cannot have more elements than I,
and outside it J is a subset of I; contradiction. If there is no tight prefix,
all augmentations are possible. For rank, the displayed expression bounds every
independent subset of A. Choose a maximum independent I subset A. If I=A, use
k=0 to get equality. Otherwise each a in A minus I lies in a tight prefix;
take the largest such prefix P_k. Then A minus P_k=I minus P_k and
|I intersect P_k|=f(k), proving equality.

## Two-ordering lower bound

Construct these matroids from the two orderings, with ranks r_1,r_2. Edmonds'
matroid intersection theorem gives the maximum common independent-set size as

min_{A subset E} [r_1(A)+r_2(E minus A)].

For any A,k,l,

|A minus P^1_k| + |(E minus A) minus P^2_l|
 >= |E minus (P^1_k union P^2_l)| >= max(0,u-k-l).

Consequently

r_1(A)+r_2(E minus A)
 >= min_{k,l} [f(k)+f(l)+max(0,u-k-l)]
 >= min_{s=0,...,u} [f(s)+f(u-s)].

To verify the last inequality, if k+l>=u, decrease k and/or l to a pair summing
to u and use monotonicity of f. If k+l<=u, increase them to such a pair; each
unit increase changes f by at most one, so the increase is at most u-k-l.
Finally,

min_s [f(s)+f(u-s)]
 = u - max_s [ceil(ts)+ceil(t(u-s))] >= u-b.

There is therefore a common independent D of size at least u-b. Keep any u-b
of its elements and set C=E minus D. Then |C|=b and, for either ordering,

|C intersect P_k| >= k-f(k)=ceil(tk).

## From ordinal quotas to arbitrary probability rows

Sort each row p_j in nonincreasing order, breaking ties arbitrarily, and apply
the preceding lemma with t=B. For a sorted row p_(1)>=...>=p_(u)>=0, set
p_(u+1)=0 and a_k=|C intersect P_k|. Summation by parts yields

p(C)=sum_{k=1}^u (p_(k)-p_(k+1)) a_k
 >= t sum_{k=1}^u (p_(k)-p_(k+1)) k
 = t sum_{k=1}^u p_(k)=t.

Thus every pair of arbitrary probability rows has a b-set with both masses at
least B. This proves V_fixed>=B and the claimed equality. No probability grid
or floating-point optimum appears in the argument.

## Scope

The proof uses two-matroid intersection, not a generally valid intersection
formula for three or more matroids. It therefore does not establish disjoint
block optimality for M>=3, and does not yet close (9,4,3).

## Constructive interpretation

For rational rows, compute B by exact enumeration of the two-block integer
allocations, sort the two rows, and use the standard finite matroid-intersection
algorithm with the stated prefix-independence oracles. Its common independent
set supplies an explicit adversarial b-set C. Direct rational summation verifies
both masses. This is an algorithmic certificate for each given rational codebook;
the proof itself covers arbitrary real rows without assuming an effective
representation of those reals. No production implementation is claimed.

## Exact controls and scope-deletion tests

The standard-library regression check verifies 780 partition/ceiling identities
through u=40, 3,784 exact chain-rank subset identities, 34,406 exhaustive
two-ordering instances through u=7, and 2,184 rational-row witness cases through
u=14. These finite checks support the inspected general proof, not continuum
optimality by sampling.

A separate deletion checker catches two invalid modifications. Replacing the
ceiling threshold by floors falsely predicts t=1/2 at u=7,b=3, contradicted by
two uniform rows of risk 3/7. Extending the ordinal-quota conclusion to three
orderings fails at u=9,b=4,t=1/4: the three first-ranked roots must be selected,
but the remaining root cannot meet all three top-five quotas. The explicitly
checked orderings are (0,5,6,7,8,1,2,3,4), (1,3,4,7,8,0,2,5,6), and
(2,3,4,5,6,0,1,7,8). This is only a counterexample to the ordinal proof route,
not to partition optimality for probability rows; uniform distributions on the
three first-five prefixes have risk 2/5.
