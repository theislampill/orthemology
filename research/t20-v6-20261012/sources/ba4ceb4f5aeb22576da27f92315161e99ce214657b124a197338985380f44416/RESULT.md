# Guarded exact support deduction and established minimum derivation results

9 October 2026. Bounded source-sensitive mathematical comparison for the authorised T20 work. This additive report neither integrates an algorithm nor changes a predecessor package or programme status.

## Result

The actual finite guarded tree-cost problem has a structure-preserving reduction to established weighted deduction. Refine an item to its fully scoped judgement and exact support, instantiate only guard-admissible ordered support tuples, and retain each rule occurrence and charge. Knuth's superior-function minimum-derivation result then applies. The support-sensitive guard is part of production admission before the theorem is transported; it is not silently omitted from the old state.

The sharper bound `|J| (|B| + 1)` is also obtained through that reduction. Knuth's finite-valued finalized items can retain witnesses using only earlier-finalized antecedents. Their unfolded trees contain no repeated refined state on a branch, independently of strict cost improvement. Union supports then give at most `|B| + 1` constant-support blocks, each with at most `|J|` nodes.

The result is a documented specialization of existing minimum-derivation machinery, with a source-sensitive state contract and a useful sharper bound. No claim that the precise support-chain formula is novel follows from this bounded inspection. The complete written reduction, including seeds, zero-cost cycles, and tree-cost preservation, is in [TREE_BIJECTION_AND_BOUND.md](../fcd5d082725c2eb1d6094da49e9261fa0f71b5bf99c50145be804ba7729b1d3f/TREE_BIJECTION_AND_BOUND.md).

## What is inherited

The established algorithmic structure includes weighted derivation trees, substituting a cheapest proof of the identical complete item, combining premise costs additively, minimizing among alternative rule instances, and retaining realizing witnesses. The local guarded problem becomes an instance of this structure after exact-support state refinement.

The local synchronous recurrence is a height-indexed Bellman-style evaluation of the refined problem. Knuth's algorithm finalizes one minimum tentative item at a time. They solve the same optimization problem, but their schedules, intermediate tables, and iteration counters are different. In particular, the number of Knuth finalizations is not the reported number of synchronous saturation rounds.

The Lean recurrence package proves correctness and stabilization of its own actual numeric-table update. It does not implement or verify Knuth's priority algorithm. This report adds no Lean development, replay result, extracted compiler, or new kernel-checked transport theorem. Its transfer and bound argument are written mathematics.

## What the exact state contributes

A support-sensitive policy can distinguish two proofs of the same unrefined judgement. A cheaper proof with smaller support need not replace a more expensive one safely. A guard can also distinguish two ordered tuples that have the same union. The admissibility relation therefore has to be fixed and represented before minimum-derivation transport.

An exact obstruction to the union-only representation is the guard accepting `({a}, {b})` and rejecting `({b}, {a})`: both tuples have the same union. The same issue affects a commutative product that has discarded the premise positions. This is an obstruction to that proposed summary, not an impossibility theorem for every provenance semiring, every encoding, or weighted deduction itself.

Once every child retains its exact support and scoped judgement, replacement preserves every input visible to the declared guard. Arbitrary fixed guards, including nonmonotone guards, therefore cause no further obstruction to the refined weighted-deduction theorem. Undeclared proof history, proof shape, price-sensitive guards, changing metadata, or freshly minted identities would require another contract; the present state need not suffice for them.

## Tree cost and hypergraph cost

The source hypergraph literature distinguishes recursively aggregating child values from charging each selected hyperarc only once. To encode the local additive tree recurrence in a set-tail hypergraph, repeated identical premise states need their multiplicities retained as coefficients. A nullary rule can be represented by an edge from an added zero-valued source, if required by that representation. That auxiliary graph encoding need not preserve the original height convention; the grammar reduction does.

The recursive valuation charges repeated uses separately when the witness is unfolded. Summing distinct edges of a shared graph is a different optimization problem. Neither the reduction nor the inspected shortest-hyperpath theorem supplies the missing sharing-aware state needed for the predecessor's DAG-cost boundary.

## The bound and its limits

The generic refined state count is at most `|J| 2^|B|`. The support-chain structure lowers the necessary optimal-tree height to `|J| (|B| + 1)`. It does not lower the number of states, the number of admissible rule tuples, the size of an unfolded witness, or the cost of evaluating one synchronous round to a polynomial quantity.

The first local input already provides the bound for its finite ambient universe and a zero-cost family attaining it. The second local input reports a verified grammar-local `B` bound even with infinite ambient evidence. This report neither originates those local results nor rechecks their Lean implementation. It supplies the external-theorem relationship and explicit semantic transport.
