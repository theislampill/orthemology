## Findings

### BD-F01 — `truth-anchor necessity` overstates the exact theorem

The formal invariance proves that the observable law cannot orient a latent
label.  It does not prove that only one particular kind of truth calibration can
break the symmetry.  An independently warranted asymmetric model restriction,
intervention, semantic convention, or labeled calibration experiment could do
so.  The exact necessity is **some non-swap-invariant orientation-breaking
input**, not necessarily the one source guard proposed in V1.

```text
severity: BLOCKING
repair: restate the general necessity and present calibrated source direction as one sufficient mechanism
```

### BD-F02 — the directional source inequality is not yet a world-truth anchor

`Q_j(1|1)>Q_j(1|0)` refers only to latent and report labels.  Without an
independent semantic map from the report symbol to proposition affirmation and
from the latent coordinate to world truth/falsity, the inequality can orient a
coding convention while leaving world truth unselected.

```text
severity: BLOCKING
repair: type the anchor as a truth-labeled current-domain calibration contract containing root, report semantics, latent/world map, version, and evidence independence
```

### BD-F03 — model-identification and orientation-selection burdens need a sharper split

A source-direction anchor selects between `theta` and `theta^sigma` only after a
separate result has reduced the admissible parameter set to that orbit.  General
finite Bernoulli mixtures may have additional nonidentifiability.  V1 states
this, but the positive theorem and its nonclaim need to be made structurally
prominent.

```text
severity: BLOCKING
repair: define component recovery up to swap as an explicit premise and deny generic identifiability credit
```

### BD-F04 — latent prior and support guards are implicit

The source-reliability interpretation assumes both latent classes remain live.
The observational invariance permits endpoint priors, but component
identification and posterior orientation are meaningful only on the declared
positive-support class.

```text
severity: BLOCKING_SCOPE
repair: declare 0 < pi < 1 for the central identification theorem; retain support-qualified posterior language
```

### BD-F05 — copied-root likelihood control is under-specified in the prose packet

The `3 versus 27` control assumes equal latent prior, one symmetric root with
accuracy `3/4`, observation `1`, and three exact deterministic copies.  Without
those details it can be mistaken for a general evidence claim.

```text
severity: BLOCKING_CLARITY
repair: state the exact hypotheses, observation, and deterministic-copy map
```

### BD-F06 — primary enumeration is not an independent semantic rereview

The primary checker directly instantiates the proof formula on a small rational
grid.  It is useful regression evidence, but not enough for fresh rereview.

```text
severity: BLOCKING_ADMISSION_GATE
repair: after V2 freeze, use a distinct tensor/contraction implementation on arbitrary binary confusion matrices, random rational parameters, posterior orientation, and copied-root controls
```

### BD-F07 — source and tawatur relation must remain one-way

The repository fixtures distinguish source dependence from creed-internal
tawatur warrant.  Dawid–Skene and latent-class identifiability literature supply
statistical ancestry, not the historical Taymiyyan theory.  The candidate must
not imply that tawatur is a latent-class majority model or that its qualitative
conditions reduce to calibration accuracy.

```text
severity: BLOCKING_AUTHORITY
repair: add an explicit source/prior-art firewall and classify the result as a finite statistical control only
```

## Audit conclusion

The label-swap invariance is correct at its declared finite model.  Admission is
blocked until the theorem is repaired to separate latent-code orientation,
world-truth orientation, component recovery, and source-authority claims, and a
distinct rereview is completed.
