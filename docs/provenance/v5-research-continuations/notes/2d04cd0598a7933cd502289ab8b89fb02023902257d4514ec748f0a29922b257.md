## The replacement is valid

The statistical sample counters also persist within their phase. Milestones that depend on the unknown actual model are analysis devices; they do not trigger a controller reset.

For a fixed phase and model, adding the entire rotor vector gives a finite time-homogeneous Markov chain. A closed nonabsorbing strongly connected class contains a positive nonempty cycle through each of its vertices. Returning to the same rotor vector requires a positive multiple of the local menu size in departures from the selected physical state. Every local action therefore occurs on the cycle. Closure includes every supported successor of those actions, so the physical projection is closed under every prescribed action, not only the next rotor choice.

For navigation, a closed class avoiding target, support exit and mismatch sample would have matching candidate/actual rows on every projected allowed pair, no candidate exit, and no path to the candidate target.
