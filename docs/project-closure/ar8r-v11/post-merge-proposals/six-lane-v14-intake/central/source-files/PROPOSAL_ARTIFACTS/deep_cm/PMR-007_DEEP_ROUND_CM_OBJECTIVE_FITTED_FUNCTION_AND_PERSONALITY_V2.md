## 3. Proper-function account distinctions

### Causal role

Causal contribution can be realized impersonally and does not supply a truth aim without another guard.

### Selected effect

An etiological selected effect can be impersonally realized. Selection history alone does not establish objective fittingness or intentional purpose.

### Designed function

A design relation can import a designer’s intention. It does not make the designed system itself a personal subject, and it yields epistemic proper function only when the plan is independently truth-aimed and normatively eligible.

### Learned objective and system-relative success

A learned or installed objective can be perfectly satisfied while differing from the carried truth target. The finite enumeration contains 240 such perfect-success/false-target controls.

### Objective truth-linked functional fit

This package can be impersonally realized once truth and fittingness are independently supplied. It is stronger than success, selected history, and causal role, but still leaves the U/I residual.

### Intentional proper function

A personal intentional account additionally requires intentional uptake, selection because fitting, and de-se ownership. Those are not reduct consequences.

### Fiṭrah-oriented function

A fiṭrah-oriented account is Track-N source-relative. It requires source custody, translation, source proposition, referent, applicability, and world adequacy before it can constrain an actual target. It does not become a neutral theorem by being philosophically richer.
