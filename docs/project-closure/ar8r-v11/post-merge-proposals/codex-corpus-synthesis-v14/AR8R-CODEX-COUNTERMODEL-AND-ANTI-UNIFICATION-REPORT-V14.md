# Countermodel and anti-unification report V14

The eleven controls in `AR8R-CODEX-COUNTERMODELS-V14.yaml` attack stronger
readings of the thin fibre theorem. Each preserves the observed or transported
coordinate while varying a native mechanism the overstrong reading would erase.

The result is not that these domains share nothing. They share a target-relative
distinguishability problem and can reuse fibre, pair-guard, and refinement
lemmas. The negative result is that a common extensional interface does not
identify the mechanisms that generate warrant, independence, temporal
persistence, causal identification, proper function, identity, intentional
hosting, or world truth.

This boundary is productive: it identifies the exact extra coordinates a
future unification must type and validate. It does not prove that no richer
unification is possible.
