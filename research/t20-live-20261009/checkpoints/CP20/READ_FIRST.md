## Portable verification

Extract the ZIP into a fresh directory. From its top-level folder run:

    python3 replay/verify_portable.py --output /absolute/path/to/new-verification-directory

Python3.8+ and the standard library suffice. No network, toolchain, Lean, external source body or repository rebuild is required. The output directory must not already exist and must be outside the package. The replay verifies manifest bytes and JSON, copies the exact unchanged checker inputs into an isolated sibling layout, and runs both Python checkers. It requires author outputs to match byte-for-byte. For the independent result it permits only sorting the four variable_sharing_cross_values records by(a,b,value); all other data must match exactly. It checks two hash seeds and reports byte equality separately from canonical equality. It also checks the exact inherited proof pin and confirms the package was unchanged.
