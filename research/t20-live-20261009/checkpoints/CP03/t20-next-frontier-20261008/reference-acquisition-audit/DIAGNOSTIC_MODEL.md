# Known source with unknown token ownership

This is a written signature-relative re-entry check. It is not a new theorem, a Lean-checked model, a metaphysical possibility proof or a model of a specified human's knowledge. The inspected argument already demands the missing D2 route. Earlier operational token-rival models retain priority.

## Fixed ontic structure

The only dependency edge is dep(actual,g,d). Whole receipt is true exactly of d at actual. There are two actual resources rg and rd. Only rd is received. Intrinsic holds exactly of (g,rg) and (d,rd). One actual received target t has rg as its relevant original resource.

All seven original `FullPremises` hold:

- Occurrence has t.
- Completion chooses rg.
- Realisation chooses g for rg and d for rd.
- SupportTransport is nonvacuously exercised by d and rd; its conclusion holds there.
- ReceiptRepresentation holds exactly for the sole dependency edge.
- ContingencyNeed is nonvacuously exercised by d, absent at alternative; g is necessary.
- ConstitutiveReception holds for d wherever it exists, and its antecedent is false for g.

The conclusion retains the literal g as actual original, necessary and uniformly nonreceived. No source swap across ontic worlds is used.

On the same bearer type, use the anchored-source account with two actual field occurrences a,b. Req(a)={c1}; Req(b)={c1,c2}; Operative equals Req. EntireOrig(g,c1) and EntireOrig(g,c2) are the only provision facts. ActualOriginal and ModeRole hold exactly for g at a and b. Qualified holds for g and ModeDefect nowhere. Then admissibility, inventory soundness/exhaustiveness, use soundness, role applicability, visibility, classification, conformance, actual anchor (g,a), connectedness from a by shared c1, and field CND all hold. g is the unique actual original contributor and complete provider in this nonempty field. These tables stay fixed throughout the epistemic comparison.

## Attacks and limits

The most important objection is that epistemic alternatives cannot be licensed merely by writing down a relation. Correct. This model proves only that the displayed ontic/source-side premises leave the recipient interface unconstrained, and that the additional interface can be nonvacuous. An actual person's knowledge could have discriminating evidence, proper-function grounds or a source-specific constraint absent from these tables. Conversely, the source predicates alone do not prove that such a route exists. The diagnostic neither defeats all knowledge nor demands that every imaginable alternative be excluded.

The second objection is that source identification should require acquaintance. This construction grants the stronger known-fixed-g result outright, so the negative token result does not depend on deciding that dispute. A legitimate description-based route can be used to understand the grant. Acquaintance is neither declared absent by a Boolean nor made necessary by definition.

The third objection is novelty. The inherited token controls already establish the operational analogue, and the DAG already states the D1/D2 failure mode. This written extension gives a compact source-interface readback, not new identification mathematics.

## Positive comparison

If both evidence states instead contain a warranted same-source ownership link for v and the relevant veracity premise, both must make p true. The ideal recipient then knows p. This is ordinary epistemic closure. Its premise can be stated by a description of the qualified source rather than by a name or antecedent acquaintance. Merely changing a data field called authenticated is not the positive evidence: an actual application must provide the route that licenses the resulting epistemic alternatives, as D2 already requires.
