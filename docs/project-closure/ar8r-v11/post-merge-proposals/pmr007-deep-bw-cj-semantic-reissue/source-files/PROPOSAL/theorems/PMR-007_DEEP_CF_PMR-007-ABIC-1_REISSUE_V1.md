## Exact scoped claim

For finite nonempty attribute and bearer sets, a common bearer exists exactly when the total intersection of the bearer sets for all attributes is nonempty. Equivalently, the extended bearer-cover number beta—the minimum number of bearers whose union witnesses every attribute, infinity if any attribute is uninstantiated—equals one. Pairwise overlap and global availability are weaker.

## Proof or construction

Beta=1 means one selected bearer lies in every attribute incidence set, exactly the total-intersection condition. Pairwise-overlap counterexamples use three bearers and three or more attributes with cyclic intersections but empty total intersection.
