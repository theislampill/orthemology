# Representation fidelity: a precise boundary for exporting repair rigidity

Research scope note, 2026-09-30. This is a standard chain-rule calculation and
application guard, not a new theorem of information geometry.

## Result

The new smooth rigidity iff concerns fixed coordinate-additive scores on one
specified categorical simplex. A change of representation is legitimate, but it
must transport the feasible set, truth vectors, disturbances, and loss together.
Merely composing the scalar generator with a nonlinear encoding generally does
not transport the original Bregman divergence.

Let L map the source coordinate domain into an ambient real vector space, let F
be differentiable, and use the convention D_F(x,y)=F(x)-F(y)-dF_y(x-y). The exact
chain rule gives (as a first-order remainder identity; calling the composite
a Bregman divergence additionally requires convexity of F composed with L)

  D_(F∘L)(x,y) = D_F(Lx,Ly)
                 + dF_(Ly)(Lx-Ly-dL_y(x-y)).

For affine L the remainder vanishes. For nonlinear L it generally does not.
An embedding can also turn a flat feasible simplex into a curved image, where
straight tangent rays need not remain feasible. Thus equality of transported
losses is stronger than an informal claim that the new coordinates contain the
same information.

## Exact scalar control

Take L(x)=x² on positive reals and F(z)=z²/2. Both are smooth and L is injective
on that domain. Then

  D_F(Lx,Ly) = (x²-y²)²/2
  D_(F∘L)(x,y) - D_F(Lx,Ly) = y²(x-y)².

At x=2,y=1 the transported loss is 9/2 and the composed-generator loss is 11/2.
The difference is not a numerical approximation. Injectivity and smoothness
alone therefore do not preserve the divergence. This does not prohibit a
nonlinear faithful translation: the correct pulled-back loss is D_F(Lx,Ly),
with the correspondingly transported domain. It may no longer belong to the
same separable Bregman class to which the proved iff applies.

## Consequence for the Orthemology crosswalk

- Linear duplicated occurrences can already alter naive coordinate weights;
  the exact pullback calculation is in the orthability transport review
- Nonlinear encodings can add a further curvature term if one rebuilds a
  Bregman score from the composed potential rather than pulling back the loss
- Before using the rigidity result as an occurrence-language or source-identity
  diagnostic, state the concrete valuation map, admissible forecast set,
  perturbation family, loss transport and fixed cross-context identity
- The theorem can constrain proposed models once those choices are made. It
  does not select a privileged representation or normative authority by itself
