# Complete Boolean phase-controller source: exact scope

## The new endpoint

`FullControllerSource.policy_program_retained_exact` proves that a literal,
executable P02 `Program 1` returns the **exact retained generated phase policy**
on every acquired action/receipt history. The dimensions are fixed at **two
models, two observed states, and two actions**. History length, phase indices,
source-state visits, pair counts, and symbol counts are unbounded natural
numbers. This is not an arbitrary-finite-dimensional controller compiler.

The source is generated from `FullController.Config`. It performs target
normalization, candidate cycling, live-support elimination, four pair-count and
eight symbol-count updates, the exact rational empirical test on the **updated**
history, support-first phase reset, target-exit rejection, and action cycling by
source-state departure visits. Eighteen sufficient statistics are protected
until all next values have been computed. Rejected sampler proposals never enter
this history. The source receives no true-model index, raw sampler word,
physical acquisition clock, or rejection count.

`FullControllerRuntime.actual_policy_call` connects the arity-one program to the
literal numeric parser and explicit stack engine with sufficient fuel.
`FullControllerRuntime.runtime_retained_history_frames` composes it with the
already checked natural-memory compiler and four-bit runtime wrapper. This is
an all-input-tape equality of actual scheduled indexed P02 output with the
explicit retained-policy history machine. The existing wrapper's simulated
environment is still the fixed two-model 1/3-versus-2/3 kernel and initial state
false. It is not a new general rational-row environment compiler. The callable
policy compiler itself accepts any rational kernel on these Boolean carriers.

## Finite premises, not a whole-history bridge

The only policy-extraction certificate is finite:

- `FiniteSelectorSource.Data`: three explicit natural table literals
- 16 cycle cells bind the actual retained `cycleAction` on Boolean menus,
  fallback values, and residues 0/1; `cycle_mod_two` proves the unbounded reduction
- 16 target cells bind the **actual conditional `chooseTarget` result**, including
  absence, rather than an arbitrary qualifying target
- Four cells bind the actual retained `stageActions` sets
- 16 rational coefficient equalities describe both model kernels, plus positive
  row and tolerance denominators

No equality of complete histories, output streams, winning regions, or
probability laws is assumed. The local source component equalities, protected
parallel updates, encoded-history reversal, chronological replay, and exact
retained-policy equality are proved by Lean. Source constructors do not call
`Classical.choose`, `actualTarget`, `stageActions`, or `cycleAction`.

**The finite literal values and their exact retained-selector proofs must still
be supplied.** This packet does not automatically extract opaque classical
choices, and its deliberately varied native-test selector tables carry no
retained-choice certificate. Conditional extraction from these finite bindings
is a stronger result than the earlier disconnected source components, but is
not a claim that a concrete full-controller instantiation of every classical
selector has been supplied.

## Tolerance and success boundaries

The exact equality is to `generatedPhasePolicy` at the supplied rational
`toleranceNumerator / toleranceDenominator`. It is not an equality to the opaque
real tolerance selected inside `ExplicitWinningRecord`. The earlier typed
counterexample showing that two valid tolerances can change a finite-history
decision remains in the unchanged predecessor sources.

The extraction theorem does not add an almost-sure winning conclusion by
itself. Applying the retained success theorem additionally requires the same
positive-separation and initial-winning-region premises as before. Rational
sampling law and receipt completion can be composed using the separately

## Execution representation and resources

The history input is the retained injective base-four sentinel encoding,
newest-first as a list. `EncodedHistoryFoldSource` reverses the encoded digit
sequence and replays completed action/receipt pairs in chronological order.
Sentinel padding is inert. The finite loop bound is the input history numeral;
this simple total construction can grow exponentially in history length.
There is **no practical fuel, latency, wall-clock, memory, or polynomial-time
claim**. Literal P02 natural arithmetic is unbounded, and native resource
exhaustion stays an exception rather than becoming a false result or receipt.
