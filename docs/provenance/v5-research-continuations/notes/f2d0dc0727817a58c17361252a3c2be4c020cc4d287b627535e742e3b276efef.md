## What is actually formalized

### Finite probability experiments and score geometry

`StatisticalRepair` proves a finite-space Hellinger-affinity lower bound for real-valued randomized tests in `[0,1]`, verifies the product Bernoulli mass function, tensors affinity, and proves

    (1 - 4 e²)^n / 4 <= max(error_minus, error_plus)

for `0 <= e <= 1/2`. Its random test is an acceptance probability conditional on the finite bit word; arbitrary parameter-independent private randomization is represented correctly this way.

`RepairObstruction.binary_repair_readout` and `binary_parameter_decoder` prove the explicit weighted-quadratic two-world inequalities, including allowed worsening `eta`. The denominator requires `e>0` in the decoded statement. The two inequalities exactly match the stated losses at truth vertices `(0,1)` and `(1,0)` after coherent output `(q,1-q)` is substituted. Allowing every real q in Lean is stronger than restricting the repair to q in `[0,1]`, so it does not weaken the obstruction.

`RepairTestingBridge` now connects these actual score inequalities, rather than an assumed classifier interface, to the finite Bernoulli lower bound. It proves disjoint successful-repair sets for `alpha_minus=1/2-e`, `alpha_plus=1/2+e`, `0<e<=1/4`, then reduces repair failure to test error. Its randomized result takes one probability measure `K w` on real repairs for each finite bit word w. Both standards use the **same K**. There is no hidden finite-seed limitation. Measurability of the output acceptance sets is proved, and the finite input space can carry its discrete sigma-algebra without an additional kernel regularity restriction.

The stronger square-root expression `[1-sqrt(1-(1-4e²)^n)]/2`, its exponential simplification, the resulting logarithmic sample lower bound, the Hoeffding upper bound, and the adaptive-at-most-n postprocessing representation are ordinary arguments, not claims established by these initial finite Lean statements. Their ordinary algebra and probabilistic reductions were independently reviewed without finding a defect. The exact-rational audit suite also checks the sharper expression without floating-point square roots, via the equivalent squared inequality.

### Generic countability core

`CountableIdentification.countable_positive_exact_identification` requires:

- one common measurable readout, not parameter-indexed readouts
- successful paths included in that readout's theta fiber
- each actual measure dominated by one common **s-finite** reference measure
- measurable parameter singletons

The conclusion is positive-success countability. The measures need not be probability measures and the success sets are not assumed measurable. This is a valid stronger outer-measure statement; a probability interpretation additionally uses measurable success events. The event-restricted variant needs domination only after restriction to a supplied measurable F and uses a finite reference. Its component variant explicitly assumes s-finiteness of the weighted reference sum; it does not establish a particular controller's component representation. The index I need not be countable in the formal statement, which is harmless because the crucial reference s-finiteness remains explicit.

### Applied eventual-repair core

`RestorationCountability.eventual_binary_good_decodes` obtains

    (q_n - 1/2)/e_n -> alpha

from `0<e_n<=1/4`, `e_n->0`, and literal eventual `BinaryGood` inequalities. It does not assume convergence of the repair algorithm. `countable_positive_limit_values` uses measurability of each output coordinate, measurable convergence-to-a sets, uniqueness of real limits, and the s-finite disjoint-positive-measure theorem.

The applied target is exactly positive measure of

    F intersect {eventually BinaryGood alpha e_n q_n}

for alpha in `[0,1]`, under the explicit hypothesis

    forall alpha, (nu alpha).restrict F << mu.restrict F.

This is materially stronger than merely assuming a successful readout. It still does **not** construct the observed path laws, the finite-probe event F, the common controller, or the killed continuations, and it does not prove hdom from an adaptive observation model. Its universal real-indexed measure family can model the original open-interval parameter domain by an arbitrary harmless extension outside that domain. ## Ordinary continuum theorem and T5

### T1 and the role of observed traces

On **observed interaction traces**, the deterministic-N killed-continuation argument is correct. Let lambda_alpha,N be the law of the first N observed rounds. Let K_N(h, .) be the common subprobability continuation kernel that preserves the prefix h and retains exactly paths with no later probe. For every measurable path event A,

    P_alpha(A intersect F_N) = integral K_N(h,A) lambda_alpha,N(dh).

If lambda_alpha,N is dominated by lambda_reference,N and the reference integral is zero, nonnegativity implies K_N(h,A)=0 reference-almost everywhere, hence actual-almost everywhere. Thus actual restriction to F_N is dominated by the reference restriction. If the reference measure of `A intersect F` is zero, it is zero on each `A intersect F_N`; the countable union gives the required dominance on F. No random last probe is treated as a stopping time, and no likelihood ratio for an unused infinite sequence is required.

The raw-oracle counterexample is decisive: let the controller never query an infinite pregenerated Bernoulli(alpha) stack. Then F is the entire raw space. For two different alpha values the raw stack laws are mutually singular, as shown by their almost-sure sample-mean limits. The observed trace can nevertheless be identical. Any formalization must push forward to the observed trace, or explicitly remove unused stack coordinates before asserting domination. The finite-budget I1 pregeneration uses only N bits, so this issue does not invalidate I1.

### T5 needs one direction only

T5's extension is sound under its explicitly shared measurable reference kernels. Prefix domination follows inductively from common controller kernels and actual probe kernels dominated by the reference probe kernel. No strict positivity of actual likelihoods is needed. The shared killed nonprobe continuations then give the integral argument above. A common countable alphabet admits a strictly positive reference distribution; actual zeros cause no problem. Separately countable parameter-specific alphabets with uncountable union do not satisfy this common-alphabet condition.

S-finiteness/finiteness and a **common** reference are substantive. Uncountable counting measure dominates all real point laws but is not s-finite. Exact real parameter-revealing point laws admit no common s-finite reference. These are independently kernel-checked controls, not only prose examples.

T5 extends the continuum countability theorem T1; it does not extend every finite-class consequence that used two-way absolute continuity. Two distinct singular finite-alphabet laws may identify a finite hidden standard after one probe. The draft correctly mentions this boundary. A separate audit theorem witnesses two mutually singular point laws with one finite common dominating reference.

### Sharpness, quantifiers, and finite-class contrast

T2's countable-set sharpness construction is correct as an ideal measurable controller. A strictly positive probability on each element of a countable set exists; picking one candidate and applying its exact repair rule succeeds precisely when the candidate is correct, since shrinking disturbance otherwise forces incompatible limits. The computability qualification is necessary and already present.

T3's finite-class limit-sure versus almost-sure contrast is correct for the positive Bernoulli model. Approximate identification by a sufficiently large finite batch yields simultaneous probability at least 1-delta. A hypothetical policy almost-surely successful under two distinct parameters would have both full-measure finite-probe events and, by pairwise equivalence on that event, both incompatible limiting-readout events of full measure under one law. This contradiction uses **mutual** tail absolute continuity, not countability alone.

The minimax conclusion has the correct order `sup_controller inf_alpha success = 0`. It does not assert existence of one alpha that defeats every conceivable controller; a controller hard-coded to a chosen alpha can succeed at that alpha. Non-atomic-prior integration requires the joint measurability qualification already stated in T1.
