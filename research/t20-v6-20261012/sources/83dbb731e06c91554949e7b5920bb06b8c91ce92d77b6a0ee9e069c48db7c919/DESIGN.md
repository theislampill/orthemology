## Semantic signature

- Agents: rigid A and B, represented as distinct constructor identifiers at every world/intervention.
- Two source-neutral effect coordinates, L and R, of one rigid target token e. The target is a fully specified vector, never 'the effect produced by A/B'. Counterfactual comparisons do not add a world/history index to e.
- Each agent's intrinsic capacity is an explicit set of executable command vectors. Full capacity contains every command in the bounded vector space, not a truth-valued qualification label.
- A will contains the entire source-neutral target plus a chosen executable command/policy. The full intended target and the extent of actually exercised power are recorded separately. A fully specified intention is not automatically a robust complete determinant.
- Intrinsic reason and will evaluation have no edge from a peer's existence, command or product. Their original root status is structural and checked across interventions, not inferred from their names.
- Actual commands produce distinguishable emissions. A production map computes one target state. Contribution is tested both by actual output-path participation and by indispensability under fixed-command peer deletion.
- Entire original provenance requires ownership of all operative original input emissions of the actual target process; it is different from ability to realize an equal qualitative state or counterfactual sufficiency.
- CND is checked by allowing an ownership relation that can violate it, then demanding at most one original owner per fixed contribution/respect. A duplicate-owner negative control must fail. Whether that contribution interface is faithful to the whole source's productive respect remains separately assessed.

Do not assume that individually available wise alternatives are jointly compossible. The main additive agents already possess the union; cooperative underexercise does not by itself demonstrate a missing intrinsic capacity.
