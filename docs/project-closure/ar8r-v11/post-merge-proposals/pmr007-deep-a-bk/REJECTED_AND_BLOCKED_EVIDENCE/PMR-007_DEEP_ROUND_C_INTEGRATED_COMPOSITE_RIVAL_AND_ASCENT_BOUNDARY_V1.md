### Proof

interpretation above.  `o` and `x` are distinct, no object bears all relevant

are not entailed by `P*`. QED.

This is a model-theoretic nonentailment under the declared signature.  It is not
an assertion that the rival is metaphysically true or source-compatible.

## 4. Bridge-by-bridge deletion models

### C-CM1 — underived but contingent order

An order is not generated by the focal process but exists contingently.  This
defeats `underived -> necessary` without an anti-contingency/PSR premise.

### C-CM2 — necessary abstract order without concrete actuality

Modal and semantic structure is necessary and abstract; no concrete bearer or
actualizer follows.  This defeats `necessary order -> externally actual concrete
ground`.

### C-CM3 — concrete actualizer without Creatorhood

A necessary concrete impersonal power actualizes some effects but does not
originate every contingent particular.  This defeats `actualizer -> Creator`.

### C-CM4 — plural necessary actualizers

Two necessary concrete powers realize disjoint effect domains under one
necessary order.  This defeats `Creator-like actualization -> unity` unless a
common-bearer or complete-origin premise is added.

### C-CM5 — unified impersonal control field

One bearer realizes every functional Deep-B role but has no phenomenal or
first-person mentality.  This defeats `functional integration -> intellect or
personality`.

### C-CM6 — spectator intellect

An intellectual subject correctly represents every relevant truth but cannot
select or effect transitions.  This defeats `intellect -> agency/Will/Power`.

### C-CM7 — efficient vicious agent

Knowledge, Will, and Power are co-instantiated and effective, but ends are
vicious.  This defeats `K/W/P -> Wisdom` without independently warranted
fittingness and praiseworthy-end premises.

### C-CM8 — capable but silent ground

A personal agent has communicative capacity but performs no speech act.  This
defeats `capacity for Speech -> actual Speech`.

### C-CM9 — deistic underdetermination

A personal necessary creator exists, but no particular revelation is selected.
This defeats `natural-theology ground -> revelational identification`.
