## Consequential cross-contributions

### 1. Diagnosis, safe action and durable repair have different quantifiers

S6F-11–13's actual restoration argument grants authenticated root identity, a correct fixed target, exact robust diagnosis, complete shared reports and permission. With n=2f+1 root-coupled static report/actuator faults, all truthful reports still permit every fault set of size at most f. A corrupted root can irreversibly enter X. A surviving blocker exists for each fault set, but no observed common choice is certainly safe. The exact first-attempt risk is f/n; after k identified dissenters it is (f-k)/(n-k).

The positive contrast is genuine: if each root implements either the adequate idempotent R or harmless identity, f+1 distinct actual roots restore safely. Identity must preserve future repair routes and every relevant safety coordinate. One common corruptible enforcement gate changes all action supports to {gate,i}; the transversal collapses to one. A FAIL label or checked proof is not that causal guarantee.

**Join to v4:** root/version/source-sidecar services can preserve the required labels and dependencies once supplied. They do not prove a root's report integrity and actuator integrity are the same bounded fault unit, or that its integrity persists until execution. Add these as separate premises for operational application, not as a criticism of the bounded record-view theorem. Root keys for evidence acquisition, action fault units, source ownership and commentary identity are distinct types. The 40/1/1-copy example gives carrier-uniform failure 20/21 versus root-uniform 1/3. Neither seven commentary records nor repeated copies are automatically seven fault-independent actuators.

**Loss warning:** one irreversible damage incident is not one lifetime bad-state visit. S6F-11 explicitly gives bounded incident count and infinite non-target residence. A proof/inquiry planner using the former loss cannot claim the latter restoration property.

### 2. Sidecar cardinality is not action-disclosure capacity

S6F-14 proves the inherited safe-action message threshold b+1, with randomized protocols included under the stated independence assumptions. Its encoder is an informed truthful sender choosing among a pre-agreed action menu. It need not reconstruct the fault set or preserve all responses. v4's 0/1/2-bit commentary service instead preserves a declared deterministic transition/output contract on eight supplied record states. The shared phrase 'minimum bits' does not identify these optimization problems.

The safe-action theorem additionally counts timing, silence, packet identity and the coding dictionary whenever they convey information. Keeping only k while erasing the identities of dissenting roots invalidates reuse of b=f-k. A sidecar application must preserve the actual menu and semantic referent, not merely its numeric size. The source expressly rejects scripture-length, source-truth, human-warrant and real-world authentication inferences.

The new finite 5/14 calculation supplies an exact deletion test of this distinction. It does not turn the T16 record fixture into an actuator model.
