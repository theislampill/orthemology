# Primary-source and pinned-library comparison

## Fixed-point theorem actually invoked

Yitzchak Shmalo, *Combinatorial Proof of Kakutani's Fixed Point Theorem*, arXiv:1811.08454v1 (2018), Definition 2.4 and Theorem 2.5. The inspected theorem concerns a finite-dimensional simplex and upper-semicontinuous correspondences with nonempty compact convex values. F2-01/F2-03 match precisely those hypotheses. F2-04 is a separate direct Cesàro proof for the row-generated construction; it does not purport to prove every Kakutani correspondence. F2-05's countable-cap extension uses its own compactness argument and a chosen linear Markov operator, not the finite-dimensional theorem applied outside its domain. The cited paper's discussion of numerical approximation is not imported as a sampler or convergence guarantee.

The canonical T21/T22 singleton/contraction result is preserved. The irrational-rotation countermodel addresses a stronger all-safe-law existence assertion whose domain is not compact. It does not refute the correctly conditional fixed-point theorem.

## Atomic/trivial measure context

Christopher P. Porter, *Trivial Measures are Not So Trivial*, arXiv:1503.06332, is primary work concerning measures concentrated on countable sets and their computability-theoretic behaviour. It supplies relevant prior context, not a verified identical theorem for every threshold in the P02-L1 index table. This run establishes no theorem-level priority comparison that would warrant novelty. No claim of new mathematical priority is made for support countability, finite parity counting, compact linear fixed points, rational polytope feasibility, or the stated hierarchy application.

## Pinned formal APIs

`PINNED_API_MAP.json` records exact project pins and source paths inspected for the measure, finite sum, compact-subsequence, convex-average and list-permutation primitives. Text inspection is not elaboration/type/axiom evidence. Current-branch searches served only to locate likely paths; current-branch declarations were not substituted for the pin.

Searches for a direct Kakutani/Brouwer/Sperner/Nash API did not identify a suitable fixed-point declaration at the required pin. Absence of these names from an import catalogue is not a proof of absence from every declaration in the library. The finite-row source route instead constructs a stationary point from compactness and Cesàro averages. Riesz–Markov–Kakutani representation results are not treated as a Kakutani fixed-point API.

No external source was copied into this artifact as a newly acquired executable library. Repository dependency pins remain unchanged; no licence/adoption decision is inferred from reading public code.
