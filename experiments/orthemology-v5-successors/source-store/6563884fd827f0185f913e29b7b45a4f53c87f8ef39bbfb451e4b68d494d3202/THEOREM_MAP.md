# Exact formal theorem map

## GroundedSupport

- derivable_mono: availability-set inclusion preserves a finite grounded derivation.
- derivable_rules_mono: adding rules preserves existing finite derivations.
- derivable_sound: truth under an arbitrary interpretation follows only from true available base facts and truth-preserving selected rules.
- exists_minimal_subset: every finite satisfying set contains an inclusion-minimal satisfying subset.
- derivable_after_retraction_iff: exact equivalence between derivability after finite-root removal and a surviving minimal original support.
- survives_disjoint_support: one particular grounded support survives removals disjoint from it.

## GroundedQuotient

- quotient_derivable_iff: exact equivalence between actual-root availability and its carrier-label preimage, with an explicit bounded quotient base relation.
- image_derivation: carrier-root image transports a derivation within the declared label universe.
- minimal_root_support_lifts: every minimal root support is the image of an inclusion-minimal carrier support. No carrier-cardinality optimum is asserted.

## AliasCuts

- hits_mono and image_of_cut: supersets preserve cuts; the image of a label cut is a root cut.
- pullback_of_cut: the root cut's preimage within the finite label universe is a label cut.
- minimal_root_cut_lifts: every minimal root cut is exactly an image of a minimal label cut.
- minimal_root_iff_minimal_archived_image: exact recovery from the complete inclusion-minimal label-cut archive for each arbitrary supplied origin map. The archive can precede learning that map.

## OccurrenceControls

- Testimonial duty derivation without a second jurisdiction premise.
- Historical duty and its properly applicable action survive prospective-grant revocation.
- Prospective issuing power is no longer derivable after that revocation.
- Absent present applicability blocks action while preserving the historical duty derivation.
- Prospective revocation preserves every non-grant primitive root; evidence invalidation preserves the live grant.
- Authorship alone does not derive the duty in the baseline calculus.
- No finite grounded derivation is supplied by the unanchored two-claim cycle; a genuine anchor grounds it.

## CutControls

- Exact unique cardinality-minimum label/root cuts for the four-label and K3,2 families.
- The discarded three-alias cut is inclusion-minimal and maps to the cheaper actual-root cut.
- Finite image cardinality controls. General four-label minimality is written argument plus bounded search, not a named kernel theorem.

## MutationControls

- Each of three explicitly weakened rule systems constructively derives the conclusion rejected by the corresponding baseline control: authorship without veracity; action without current applicability; prospective issuing power without a live grant.
- These claims concern derivability in different specified calculi, not source truth or actual authority.

## Not formalised

The general Python antichain algorithm's refinement to the Lean relation; universal algorithmic time/space bounds; external source authentication; empirical reliability; actual normative jurisdiction; arbitrary nonmonotone rule systems; discovery of root maps; physical history or action; infinite continuation. The finite least-grounded relation is not asserted complete for all true or otherwise warranted propositions.
