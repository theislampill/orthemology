# Closed tests versus a uniform original-source proof

10 October 2026. T20 ACTIVE. This is a direct new consequence of two substantive predecessor results, not a new discovery of the general instance/universal distinction.

## Exact result

Every original polynomial n with a closed HasE typing derivation at the original Church N has a source derivation of the exact scalar identity instance. More strongly, the original fixed candidate c3 applied to n has the literal substituted body of W(originalQ) as its type. This positive metatheorem is inherited from ClosedScalarInstances.closed_scalar_instance_exact.

The new whole-source homogeneous model establishes that no original polynomial proves the universal W(originalQ). Combining these gives the checked closed_instance_rule_not_admissible: even the entire family of these actual derivations cannot be turned, by an admissible metarule of unchanged HasE, into a closed proof of W(originalQ).

The compiled corollary deliberately permits any resulting proof polynomial; failure is not a defect of c3 alone.

## What this changes

Previously the supplied instance family left the universal target open. That exact source-strength boundary is now settled negatively. Testing every closed source-definable Church input would still miss the obstruction to uniform source derivability. The countermodel's extra Church value is a semantic value, not a newly admitted source token, and defeats the universal interpretation while all source-definable instances remain sound.

This supplies a concrete limit for reconstructing a uniform proof from a catalogue of successful tests or instance derivations. It also explains why the separately sound inherited HasC certificate is not interchangeable with a HasE proof.

## Limits

- The inherited full-PER interpretation still validates the universal target. This corollary is not evidence against that intended equality.
- No general claim is made that finite certificates cannot justify uniform results. The inherited HasC example does precisely that in its separately named system.
- There is no executable enumeration, proof-extraction algorithm, complexity bound, or proof that every candidate metaprocedure fails to terminate. The quantified mathematical premise is an external family of derivations.
- We do not identify source-definable instances with all possible typed semantic values.
- This does not decide all type completion, compiler correctness, epistemic warrant, or T20 closure.
