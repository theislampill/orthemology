## Exact contract checked

The evaluator has a common state transition and query rule. A query step reads the next symbol of its parameter oracle and increments the counter; a nonquery step supplies a fixed public default symbol and does not consult that oracle. The state may include an entire private random tape. The measure contract is explicit: the initial-state/seed law is the SAME measure rho in both cases, and each input law is the product rho × oracle-law. The seed is therefore independent of the oracle under each modeled law.

One run bounded by N already determines the whole trajectory from seed plus the first N oracle symbols. If it were to ask at position N, its next counter would violate the bound. Induction therefore proves identical whole runs under any oracle sharing that prefix. This also makes the infinite-horizon event of never asking query N+1 a finite-prefix event. No claim that the last query time is a stopping time is used.

The restricted trace law is factored through that finite input. The reference finite-prefix law has positive mass at EVERY word, so any source finite-prefix law is directly absolutely continuous with respect to it. Product with the common seed, restriction and measurable pushforward preserve that direction. Taking the countable union over N gives domination of finite-query traces.

The reference is the actual full-support iid rival q, whose finite-word masses are products of its singleton masses. It is not merely an auxiliary fair reference dominating two unrelated measures. Therefore a positive source event contained in the finite-query region must have positive mass under the actual rival. Infinite oracle laws themselves need not be absolutely continuous.

Countability and measurability were checked at the actual interfaces: countable Y supports joint measurability from measurable fixed-symbol transitions; S remains an arbitrary measurable state space. SFinite premises are present where product/map identities require them. Probability interpretation additionally requires normalized seed/source laws; the primitive itself correctly states the more general SFinite-measure result. The event transfer theorem even applies to outer-measure sets; applications to probabilistic tail events should still supply their usual measurability.

## Independent boundary controls

### Missing full support

A one-query evaluator stores its first Boolean symbol and never queries again. The source oracle is constantly true. The rival is the genuine iid law with one-symbol measure dirac(false). The bounded observed true-answer event has source mass one and rival mass zero. Its trace set is contained in finiteQueryTrace. This is a kernel-checked counterexample to removing full support, not a failure of a finite grid search.

### Infinite querying

An always-querying evaluator displays every queried symbol. A constant-true source oracle gives the all-true observed event mass one. Under a full-support fair iid rival, every finite all-true prefix has mass 2^(-N), and the whole event has mass zero. The audit proves the counter diverges and no finite query bound exists. Thus full support of all finite words does not license unrestricted whole-trace domination. This counterexample is kernel checked at the actual trace-law level.

### Genuinely countable alphabet

A geometric distribution on the natural numbers has positive mass at every symbol. The generic theorem is instantiated to every finite natural-number word. This tests a countably infinite alphabet, not merely a Boolean relabeling.

### Seed/reference dependence

An independent exact finite control gives both source and rival the same fair seed marginal and same full-support first-symbol marginal. The source joint input is independent; the rival symbol is the seed's complement. The observable equality event has source mass 1/2 and rival mass zero. Appending independent fair oracle tails preserves a full iid oracle marginal while keeping this failure. The theorem excludes the counterexample through its product-law premise. Mere equality of marginals is insufficient; the independent product law or a suitable stronger conditional-support contract must remain explicit.

The source-side independence assumption is sufficient rather than claimed minimal. This audit does not prove a generalized correlated-input theorem.

## Important application ceiling

Trace S includes the full state and query count; if the state contains a private seed, it is a larger trace than the public output alone. Domination of this larger trace can be pushed through a measurable public observable, but that observable and the actual policy-law simulation must be supplied. The primitive does not by itself show that an arbitrary CIRS policy admits this oracle decomposition, that its purported parameter-independent observations really share one seed law, or that the resulting pushforward is its actual controlled process law. Those are the next binding obligations, not premises to erase by calling the abstract evaluator a policy.
