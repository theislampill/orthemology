# Tadmuriyya commentary voice audit

Verified 2026-10-09 UTC. Bounded source-identification task; no intended commentator or exact alleged quotation was supplied.

## Result

The alleged *Sharḥ al-ʿAqīda al-Tadmuriyya* taḥṣīl al-ḥāṣil passage remains **unverified**. The title does not identify one work. Do not attribute an unspecified commentary's wording to Ibn Taymiyya, Ibn ʿUthaymīn, al-Barrāk, Nāṣir al-ʿAql, or Fāliḥ Āl Mahdī.

Two readable later commentaries were checked at their tamānuʿ sections. Both discuss conflicting wills, and neither retrieved HTML text contains either exact string `تحصيل الحاصل` or `تحصيل حاصل`. These are bounded non-hits in specific electronic witnesses, not a claim that every edition or commentary lacks the phrase.

A separate, positively located classical comparator is al-Ṣāwī's *Ḥāshiya* on *Tafsīr al-Jalālayn*, Q21:22. It explicitly places taḥṣīl al-ḥāṣil in the branch where one agent precedes the other. It rejects the simultaneous branch using a different premise, the impossibility of two producers upon one effect. This distinction directly cautions against using taḥṣīl alone as a proof of simultaneous nonduplication.

## Safe downstream use

1. State that the exact alleged Tadmuriyya-commentary quotation is not yet source-bound.
2. Keep Ibn Taymiyya's matn distinct from later elaborations using the witnesses' explicit voice markers.
3. Do not transform a serial taḥṣīl argument into a simultaneous nonduplication theorem without an additional premise.
4. Use the Ṣāwī comparator only with its own correct work/author/verse attribution.
5. A precise future attribution requires the commentator plus edition/lesson or the alleged Arabic quotation; no need to block the independent philosophical analysis on that missing bibliographic identification.
