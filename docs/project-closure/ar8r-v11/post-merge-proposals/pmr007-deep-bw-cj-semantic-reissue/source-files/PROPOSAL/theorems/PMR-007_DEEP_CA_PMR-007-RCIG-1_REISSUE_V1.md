## Exact scoped claim

Fix common resource coordinates, units, measurement rules, realization classes, and a vector budget b. The feasible architecture set consists of architectures having at least one declared realization with coordinatewise cost at most b. The architecture is exactly identified by the resource experiment if and only if this feasible set is a singleton. Incomparable Pareto costs cannot be converted into a unique winner without an independently warranted aggregation rule.

## Proof or construction

The budget evidence is precisely membership in the feasible set. A singleton yields the unique architecture; two feasible architectures produce the same pass evidence. Pareto incomparability is immediate when neither vector dominates the other.
