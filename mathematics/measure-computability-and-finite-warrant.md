# Measure, computability and finite warrant

An infinite object can be uniquely determined and uniformly approximable while an exact question about it remains undecidable. Conversely, a finite representation can support exact decisions that fail for an unrestricted computable representation. The difference lies in the property being asked, the effective input supplied and the evidence a recipient is entitled to use.

This work develops those distinctions for two concrete settings. The first is the atomic mass of a probability law generated by a total synchronous observer. Exact finite-cylinder probabilities yield a sharp arithmetical classification, while a finite-state restriction admits an exact rational algorithm. The second is a compact inverse system with a uniformly computable unique realization. Strict rational comparisons admit complete finite certificates; exact equality does not admit a uniformly complete effective finite-certificate discipline. The positive procedures, the reductions and their boundary controls are given explicitly. [S1–S3]

**Scientific status.** This is a composed ordinary mathematical exposition prepared for independent scientific review. It incorporates three public prose bodies at the exact editions identified in §10. It does not claim a fresh formal build, execution of a checker, empirical validation, owner adoption or priority for the inherited results. A finite calculation is mathematical evidence only for its stated representation and query.

## 1. Two concentration statistics and a separate target question

For a Borel probability measure $`\nu`$ on Cantor space $`2^{\mathbb N}`$, let

```math
\mathrm{At}(\nu)=\{y:\nu(\{y\})>0\},
\qquad
a(\nu)=\sum_{y\in\mathrm{At}(\nu)}\nu(\{y\}),
\qquad
d_{\mathrm{atom}}(\nu)=1-a(\nu).
```

The atom set is countable: for each positive integer *m*, only finitely many points can have mass at least $`1/m`$, and every atom belongs to one of these finite sets. Thus the sum is well-defined and equals the measure of the atom set. The quantity $`d_{\mathrm{atom}}`$ is the mass outside all point atoms. Zero means that the law is purely point-atomic, the property also called a *trivial measure* in the algorithmic-randomness literature; it does not mean that the probability measure is zero. [S1, §1; P1, Definition 2.4]

A different statistic is

```math
d_{\max}(\nu)=1-\sup_y\nu(\{y\}).
```

The two must retain distinct names. For

```math
\nu=\tfrac12\delta_{0^\infty}+\tfrac12\delta_{1^\infty},
```

all mass is atomic, so $`d_{\mathrm{atom}}(\nu)=0`$, whereas $`d_{\max}(\nu)=1/2`$. Both equal one on an atomless law. The tensor treatment explicitly considers the second statistic in its §11; the observer classification below concerns the first. Replacing the sum by a supremum would change its problem and invalidate its reductions. [C2, §11]

Neither statistic alone decides whether an observation preserves a particular target. If a finite observation is coarsened by merging two values carrying opposite target labels, both laws remain purely atomic while target information is lost. Conversely, the existing collective treatment supplies a complete nonatomic trace whose limiting frequency identifies one of two Bernoulli standards almost surely. Its finite prefixes are purely atomic, and its complete law has $`d_{\mathrm{atom}}=1`$. These are compatible facts about different objects and questions. The current work uses the probability statistic without reinterpreting it as cognitive failure, target insufficiency, moment indeterminacy or action authority. [C1, §§2.1, 7.8]

## 2. A total effective observer representation

### 2.1 The admitted input language

Fix a decidable syntax for primitive-recursive integer programs. An index *e* determines an observer by

```math
q_e(x)_n=P_e\bigl(n,\mathrm{enc}(x\upharpoonright(n+1))\bigr)\bmod2.
```

Invalid syntax denotes the constantly zero program. Every index therefore denotes a total productive observer. Its first *n* output bits depend only on the first *n* input bits, so it is synchronous and 1-Lipschitz in the usual prefix metric. Universal evaluation of this syntax is total computable, although it is not primitive recursive as a function of arbitrary program indices. No uniform running-time bound in the requested output length is assumed. [S1, §1]

Let $`\lambda`$ be fair-coin measure and set $`\nu_e=(q_e)_*\lambda`$. For a word $`\sigma`$ of length *n*, its cylinder probability is the exact dyadic rational

```math
p_e(\sigma)
=2^{-n}\#\{u\in\{0,1\}^n:q_e(u)\upharpoonright n=\sigma\}.
```

The expression means evaluation of each of the first *n* output bits using its required finite input prefix. There is no need to evaluate an infinite input. Every such finite enumeration terminates. The classification in §3 concerns this total syntax, not arbitrary partial machine indices accompanied by an unverified productivity promise.

### 2.2 The initial halting subfamily

For a fixed-input machine $`M_e`$, form an observer that emits zero until the machine halts and then copies fresh input bits forever. Each output bit uses only a bounded simulation, so the map from a machine description to the admitted observer syntax is effective. If the machine never halts, the output law is $`\delta_{0^\infty}`$. If it halts, infinitely many independent fair bits remain in the output, so every singleton has probability zero. Hence

```math
d_{\mathrm{atom}}((H_e)_*\lambda)
=\begin{cases}
0,&M_e\text{ never halts},\\
1,&M_e\text{ halts}.
\end{cases}
```

On this indexed subfamily, zero defect is exactly the nonhalting set and positive defect is exactly the halting set: respectively $`\Pi^0_1`$-complete and $`\Sigma^0_1`$-complete under computable many-one reductions. This does not classify the whole observer language. [S1, §2]

### 2.3 What any finite cylinder depth leaves unresolved

**Proposition 1 — Finite-depth agreement with opposite atomicity.** Given any admitted observer and any finite depth *N*, one can effectively construct two admitted observers with exactly the same output laws through depth *N*, one with $`d_{\mathrm{atom}}=0`$ and the other with $`d_{\mathrm{atom}}=1`$.

**Proof.** Both observers follow the supplied observer for the first *N* outputs. Thereafter, the first emits only zero. Its output range has at most $`2^N`$ elements, so all mass is atomic. The second thereafter copies input bits with indices at least *N*. Conditional on any initial input word, these remaining bits are independent and fair. Matching any prescribed infinite output requires matching arbitrarily many of those bits and therefore has probability zero. The modification uses finite branching on the output index and remains within the primitive-recursive synchronous representation. ∎

This is an elementary composition of the finite-prefix and fresh-tail constructions, not a priority claim. It applies to evidence limited to a finite depth of output-cylinder probabilities. The two full program descriptions differ. Reading a complete finite-state machine or proving a global source invariant supplies additional evidence and is not excluded by the proposition. In particular, the finite-state procedure in §4 is consistent with it.

## 3. Exact arithmetical complexity of atomic mass

Here $`\Sigma^0_r`$ and $`\Pi^0_r`$ have their ordinary effective arithmetical-hierarchy meanings, and completeness is by computable many-one reductions. Bounded finite computations do not add unbounded quantifier alternations.

### 3.1 An atomic-mass formula using only finite cylinders

For nonnegative integers *k,n*, put

```math
B_e(k,n)=\sum_{|\sigma|=n}\max\bigl(p_e(\sigma)-2^{-k},0\bigr).
```

These are computable rationals. For fixed *k*, the expression decreases with *n*: splitting a mass *p* into nonnegative children cannot increase the sum of their excesses above a fixed positive threshold. For fixed *n*, it increases with *k*.

**Theorem 2 — Atomic mass from cylinder excesses.**

```math
a(\nu_e)=\sup_k\inf_n B_e(k,n).
```

**Proof.** For an output $`Y\sim\nu_e`$, write $`m_n(Y)=\nu_e([Y\upharpoonright n])`$. Decreasing continuity of the probability measure gives $`m_n(y)\downarrow\nu_e(\{y\})`$. For $`\varepsilon>0`$, define

```math
\phi_\varepsilon(m)=
\begin{cases}
\max(1-\varepsilon/m,0),&m>0,\\
0,&m=0.
\end{cases}
```

The function is continuous on $`[0,1]`$ and bounded by one. Integration over the length-*n* cylinders yields

```math
E\phi_\varepsilon(m_n(Y))
=\sum_{|\sigma|=n}\max(p_e(\sigma)-\varepsilon,0).
```

Bounded convergence then gives

```math
\inf_n B_e(k,n)
=\sum_{y\in\mathrm{At}(\nu_e)}
\max\bigl(\nu_e(\{y\})-2^{-k},0\bigr).
```

Taking the increasing limit in *k* and using monotone convergence on the countable atom set proves the formula. No effective enumeration of the atoms was assumed. ∎ [S1, §3]

For rational *r*, the formula gives the exact strict-cut equivalence

```math
a(\nu_e)>r
\iff
\exists k\,\exists t\in\mathbb Q\quad
\bigl[t>r\ \land\ \forall n\ B_e(k,n)\ge t\bigr].
```

The positive gap $`t-r`$ matters. Requiring merely $`B_e(k,n)>r`$ at every finite stage would permit an infimum equal to *r*. Rational comparisons here are decidable, so the strict lower cut of atomic mass is $`\Sigma^0_2`$.

### 3.2 The complete threshold table

**Theorem 3 — Exact defect thresholds.** For each fixed rational $`0<q<1`$, the admitted observer indices have the following complexities.

| Property | Exact complexity |
|---|---|
| $`d_{\mathrm{atom}}(\nu_e)<q`$ | $`\Sigma^0_2`$-complete |
| $`d_{\mathrm{atom}}(\nu_e)\ge q`$ | $`\Pi^0_2`$-complete |
| $`d_{\mathrm{atom}}(\nu_e)\le q`$ | $`\Pi^0_3`$-complete |
| $`d_{\mathrm{atom}}(\nu_e)>q`$ | $`\Sigma^0_3`$-complete |
| $`d_{\mathrm{atom}}(\nu_e)=q`$ | $`\Pi^0_3`$-complete |

At the endpoints, zero defect is $`\Pi^0_3`$-complete, positive defect is $`\Sigma^0_3`$-complete, defect one is $`\Pi^0_2`$-complete and defect below one is $`\Sigma^0_2`$-complete. Other endpoint and out-of-range comparisons are empty or universal as required by $`0\le d_{\mathrm{atom}}\le1`$. [S1, §4]

**Upper bounds.** Theorem 2 gives $`d_{\mathrm{atom}}<q`$ exactly when $`a>1-q`$, a $`\Sigma^0_2`$ condition. Complementation gives the $`\Pi^0_2`$ condition for $`d_{\mathrm{atom}}\ge q`$. Moreover,

```math
a\ge r\iff\forall m\ge1\ (a>r-2^{-m}).
```

Substitution of the strict-cut formula gives a $`\Pi^0_3`$ condition for $`d_{\mathrm{atom}}\le q`$, and complementation gives $`\Sigma^0_3`$ for the opposite strict inequality. Equality is the conjunction of a $`\Pi^0_3`$ and a $`\Pi^0_2`$ condition. At defect one, it reduces to $`a=0`$, the complement of the $`\Sigma^0_2`$ property $`a>0`$.

**Finite-versus-infinite enumeration.** Let $`W_e`$ be a computably enumerable set with a bounded-stage approximation. An observer $`J_e`$ copies input bit *n* when a new member enters at stage *n*, and otherwise emits zero. If $`W_e`$ is finite, only finitely many random bits appear, so its law has finite support and defect zero. If $`W_e`$ is infinite, matching any fixed output requires matching arbitrarily many independent copied bits, so its defect is one. Thus FIN reduces to defect below any $`0<q\le1`$, and INF to defect at least that threshold.

For clarity, the standard completeness of this intermediate construction can be seen directly. For a $`\Sigma^0_2`$ predicate $`\exists s\forall t\ R(e,s,t)`$ with primitive-recursive *R*, let $`r_u`$ be the least $`s\le u`$ passing all tests $`R(e,s,t)`$ with $`t\le u`$, or let $`r_u=u+1`$ if there is none. The sequence is nondecreasing: a candidate once rejected stays rejected. A permanently passing candidate bounds it, giving finitely many changes; with no such candidate it tends to infinity and changes infinitely often. Enumerate one new element at every change. The resulting set is finite exactly when the given $`\Sigma^0_2`$ predicate holds. This proves the required hardness for FIN and, by complementation, INF. Membership of FIN in $`\Sigma^0_2`$ follows by asserting a stage after which no new element enters; INF has the complementary $`\Pi^0_2`$ definition.

**The full zero-defect reduction.** Apply the same construction uniformly to each row of an array $`W_{e,i}`$. On input prefix $`1^i0`$, an observer emits that prefix as a tag and then runs $`J_{e,i}`$ on the untouched fair tail. The exceptional input $`1^\infty`$ is emitted as itself and has probability zero. The tag probabilities are $`2^{-i-1}`$, and the output cylinders for different tags are disjoint. Consequently,

```math
d_{\mathrm{atom}}(\nu_e)
=\sum_{i\ge0}2^{-i-1}\mathbf1_{\{W_{e,i}\text{ is infinite}\}}.
```

Given a $`\Pi^0_3`$ predicate $`\forall i\exists s\forall t\ R(e,i,s,t)`$, use the preceding least-surviving-candidate construction in row *i*. Each output-bit computation needs only a finite input prefix and bounded simulation, so the resulting observer is admitted without a totality promise. Its defect is zero exactly when every row is finite, exactly the original $`\Pi^0_3`$ predicate. This proves zero-defect hardness; complementation proves positive-defect hardness.

**Rational shifts.** To move the boundary to fixed rational $`0\le q<1`$, construct a disjoint tagged mixture with total diffuse weight *q* and remaining weight $`1-q`$ carrying $`\nu_e`$. The resulting defect is

```math
q+(1-q)d_{\mathrm{atom}}(\nu_e).
```

A fixed-length fair-bit selector suffices for dyadic *q*. For other rational *q*, read successive fair bits until their binary interval is wholly below or wholly above *q*, emitting the bits read as a tag. Stopping words are prefix-free and have total probability one. The undecided boundary input has probability zero and is emitted productively. On each stopping word, the unused tail is still independent and fair; run a fresh-bit copier on the below branch and the original observer on the above branch. Exact rational endpoint comparisons require bounded integer arithmetic. The resulting observer is again primitive-recursive and synchronous, and the prefix-free tags prevent collisions among components. Its total diffuse mass is exactly the displayed expression.

Thus defect at most *q* and defect equal to *q* hold exactly when the original defect was zero, and defect above *q* holds exactly when it was positive. Together with the upper bounds, this proves all remaining entries. ∎

The result is about index sets in the declared total language. For promised uniform names with computable cylinder probabilities, each finite sum in Theorem 2 is a computable real. If rational approximants $`b_j`$ satisfy $`|b_j-B_e(k,n)|\le2^{-j}`$, then $`B_e(k,n)\ge t`$ is equivalent to $`\forall j\ (b_j+2^{-j}\ge t)`$. The added universal precision quantifier merges with the existing universal stage quantifier, giving the same upper bounds relative to valid names. A raw numbering of partial descriptions additionally requires analysis of validity and totality; its index-set classification cannot be inherited silently. Likewise, neither finite-prefix sampling nor an unbounded search that has not succeeded certifies the hierarchy claims. [S1, §6]

## 4. The finite-state class has an exact positive procedure

Consider a finite synchronous Mealy machine with states *S*, initial state $`s_0`$, transition $`\delta:S\times\{0,1\}\to S`$ and output $`o:S\times\{0,1\}\to\{0,1\}`$, driven by independent fair bits.

### 4.1 Finding the states with input-insensitive output

Start with $`E_0=S\times S`$ and repeatedly delete a pair $`(s,t)`$ unless, for every pair of input bits *b,c*,

```math
o(s,b)=o(t,c)
\quad\text{and}\quad
(\delta(s,b),\delta(t,c))\in E_r.
```

Equivalently these conditions define $`E_{r+1}`$ from $`E_r`$. The decreasing sequence stabilizes after finitely many deletions; call its final relation *E*. Put

```math
D=\{s:(s,s)\in E\}.
```

A state belongs to *D* exactly when every input stream produces the same output stream. One direction follows by induction on finite prefix length from the fixed-point condition. For the other, a pair with identical outputs on all pairs of infinite inputs must have equal first outputs and successors with the same property, so all such pairs survive every deletion. Equivalently, every deleted pair has a finite distinguishing input pair. The set *D* is transition-closed. Its fixed output from each state is eventually periodic: one may follow the all-zero input through finitely many states. [S1, §5]

### 4.2 Atomic mass equals a reachability probability

**Theorem 4 — Finite-state atomicity.**

```math
a(\nu)=\Pr_{s_0}(\text{eventually hit }D),
\qquad
d_{\mathrm{atom}}(\nu)=\Pr_{s_0}(\text{never hit }D).
```

**Proof.** Every finite hitting input word produces a finite output prefix followed by one fixed tail. These outputs form a countable set. Each has positive probability, because the corresponding finite input cylinder has positive probability and its subsequent output is fixed.

For each state outside *D*, deletion of its diagonal pair supplies two equally long input words with different output words. Pad them when necessary and choose a common length *L* for the finitely many such states. At least one of those two words disagrees with any specified length-*L* target output. Its input probability is $`2^{-L}`$. Hence, from any state outside *D*, the probability of matching a prescribed target block while remaining outside *D* is at most $`1-2^{-L}`$. Repeated conditioning on successive finite blocks gives a bound $`(1-2^{-L})^j`$ for *j* blocks. It tends to zero. Every fixed infinite output therefore has probability zero on runs that never hit *D*.

Since the full atom set is countable, runs avoiding *D* contribute no mass to it. Runs hitting *D* contribute all their mass to atoms, proving both identities. ∎

### 4.3 Exact rational computation

The theorem gives a terminating algorithm on the full finite machine description:

1. Compute *E* by finite relation deletion and extract *D*.
2. In the directed transition graph, find the states *Z* from which *D* is unreachable.
3. Set $`h=1`$ on *D* and $`h=0`$ on *Z*.
4. For every remaining state, solve

```math
h(s)=\tfrac12h(\delta(s,0))+\tfrac12h(\delta(s,1)).
```

5. Return $`1-h(s_0)`$ as the exact defect and compare that rational number with the requested rational threshold.

The remaining linear system is nonsingular. Every remaining state has a finite path to *D*. Finiteness supplies a common finite upper bound on the length of a suitable exit path and a positive lower bound on its probability. The probability of staying forever in the remaining subgraph is therefore zero. Its transition submatrix has powers tending to zero, so $`I-Q`$ is invertible. Rational Gaussian elimination computes the unique solution exactly. This is a decidability result, with no asserted optimal complexity bound.

For example, take initial state *s* and states *z,c* with the following transitions and outputs.

| State | Input 0: next state, output | Input 1: next state, output |
|---|---|---|
| *s* | *z*, 0 | *c*, 0 |
| *z* | *z*, 0 | *z*, 0 |
| *c* | *c*, 0 | *c*, 1 |

Here $`D=\{z\}`$, $`h(z)=1`$, $`h(c)=0`$, and $`h(s)=1/2`$. Half the mass produces $`0^\infty`$; the other half has a fair infinite tail after its initial zero. The exact diffuse defect is $`1/2`$. This worked instance illustrates the procedure; it is not a newly executed test.

Unbounded computable control state changes the representation class. It can implement the simulations in §3, so the exact finite-state decision theorem does not extend to every total computable observer.

## 5. Compact survivors and finite robust answers

The previous decision theorem obtains strength by restricting the representation. A different positive result restricts the query and states the effective evidence interface explicitly.

**Theorem 5 — Finite witness for an open answer region.** Let $`K_0\supseteq K_1\supseteq\cdots`$ be nonempty compact subsets of a Hausdorff space, and put $`S=\bigcap_nK_n`$. If *U* is open and contains *S*, some finite stage satisfies $`K_N\subseteq U`$.

**Proof.** The nested compact sets have a nonempty intersection. If no $`K_n`$ lies in *U*, then the nonempty sets $`K_n\setminus U`$ are closed subsets of compact $`K_0`$. They are nested, hence have the finite-intersection property and a common point. That point belongs to *S* and lies outside *U*, a contradiction. ∎ [S2, §1]

The theorem applies to the actual finite-extension images at a fixed coordinate, or to the actual images of a fixed finite block of observations. If the declared answer is the same throughout an ambient open neighbourhood of every surviving realization, a finite range warrants that answer for every compatible realization. The realization itself need not be unique.

For a continuous real observable *g*, strict regions $`\{g<\tau\}`$ and $`\{g>\tau\}`$ are open. Equality is not covered merely because it is true on the final survivor. The ambient topology matters: continuity only on *S* does not make the relevant answer region open around *S*.

### 5.1 The effective search and its premises

For an algorithm, assume a computable metric presentation, uniformly supplied upper-compact names for the sets $`K_n`$, and an effectively open name for *U*. Concretely, the compact names must semidecide whether a supplied finite family of basic open balls covers $`K_n`$, and the open name enumerates basic balls making up *U*. These are part of the input, not consequences of set-theoretic compactness. [S2, §1; S3, C17–C18]

Dovetail the containment searches for all *n*. Within each search, enumerate finite subfamilies of balls already listed for *U* and run the cover semidecision for $`K_n`$. If any such check succeeds, output *n* with that finite cover. Soundness follows because the cover lies in *U*. Completeness on the promised robust instances follows from Theorem 5 and compactness: a stage wholly in *U* has a finite subcover drawn from its enumerated balls, and its cover check eventually succeeds. Running the searches by dovetailing is necessary; waiting forever on an earlier false containment would not be a complete search.

If *g* is computable and continuous in the represented sense, its strict rational sublevel and superlevel regions supply the needed effective open names. A separately supplied numerical convergence rate or an advance lower bound on the query gap is unnecessary. The conclusion is termination on the stated promise domain. The search does not decide those promises for arbitrary proposed descriptions. The existing effective-compactness literature gives the same finite-cover interface and computability of an effectively compact singleton; no new abstract compactness principle is claimed here. [P2, §2.6]

The tensor reconstruction theorem already uses an effective compact representing fibre together with uniform moment names and a determinacy promise. Its computed law and its promise conditions retain their own proof. The present theorem explains a related query-level consequence and also covers nonunique survivors when the requested answer is constant on a suitable open neighbourhood. It does not rederive or weaken the moment theorem's input requirements. [C2, §10.1]

## 6. A uniformly computable realization and complete strict certificates

Let *P* be a well-formed unary P02-L1 program, with natural output and the inherited bounded-loop semantics. Define its bit stream and inverse system by

```math
b_P(i)=\mathrm{Eval}(P,i)\bmod2,
\qquad X_i=[0,1],
\qquad f_{P,i}(x)=\frac{x+b_P(i)}2.
```

The evaluation used here is the unary evaluator with argument *i*. A different wrapper with an incompatible arity contract cannot be substituted for it. Every finite evaluation terminates mathematically, although a particular implementation may refuse a resource limit. [S2, §2; S3, C06, C12]

### 6.1 Existence, uniqueness and the exact finite range

**Theorem 6 — A unique computable compatible realization.** The system has the unique realization

```math
x_{P,i}=\sum_{r\ge0}b_P(i+r)2^{-r-1}.
```

Each coordinate is uniformly computable with error at most $`2^{-n}`$ after its first *n* terms. At coordinate zero, the depth-*n* finite-extension image is exactly

```math
K_{0,n}=\left[\frac{V_n}{2^n},\frac{V_n+1}{2^n}\right],
\qquad V_0=0,
\qquad V_{n+1}=2V_n+b_P(n).
```

**Proof.** The series is nonnegative and bounded by one. Splitting off its first term proves compatibility, $`x_{P,i}=(b_P(i)+x_{P,i+1})/2`$. For any compatible realization *z*, unwinding *n* equations gives

```math
z_i=\sum_{r\lt{}n}b_P(i+r)2^{-r-1}+2^{-n}z_{i+n}.
```

Both remaining tail coordinates lie in $`[0,1]`$, so the distance between *z* and the displayed realization at coordinate *i* is at most $`2^{-n}`$ for every *n*. It is therefore zero. The same formula proves the approximation bound and the exact image interval: the finite extension's last free coordinate ranges through all of $`[0,1]`$. Writing the integer prefix value as

```math
V_n=\sum_{k\lt{}n}b_P(k)2^{n-1-k}
```

gives the recurrence. ∎ [S2, §2; S3, §1]

This is inverse composition: adding a depth composes the next map on the right. For bits 0,1, the map is $`f_0(f_1(x))=(1+x)/4`$, not $`(2+x)/4`$. The distinction is detectable by a nonconstant prefix and cannot be checked by all-zero examples alone.

### 6.2 The finite certificate service

Fix a threshold $`\tau=p/d`$ with integer *p* and positive integer *d*. Let $`x_P=x_{P,0}`$. A finite witness consists of a depth *n* and the correctly replayed prefix calculation. The exact integer tests are

```math
\begin{aligned}
\text{Below:}&\quad (V_n+1)d\lt{}p2^n,\\
\text{Above:}&\quad V_nd>p2^n.
\end{aligned}
```

**Theorem 7 — Sound and complete finite witnesses for strict comparisons.** A successful Below test implies $`x_P<\tau`$, and a successful Above test implies $`x_P>\tau`$. Every true strict comparison eventually has its corresponding successful test. At equality neither test ever succeeds.

**Proof.** Soundness follows from Theorem 6's enclosing interval. If $`x_P<\tau`$, choose *n* with $`2^{-n}<\tau-x_P`$. The interval's upper endpoint is at most $`x_P+2^{-n}`$, hence is strictly below *τ*. The Above case follows by the corresponding lower-endpoint bound. At equality the point belongs to every interval, excluding both strict endpoint tests. ∎ [S2, §2; S3, §1]

To search for a strict answer, compute successively $`b_P(0),b_P(1),\ldots`$, update $`V_n`$ and apply the chosen test. The unknown positive gap is used only in the termination proof; it need not be supplied. An implementation that exhausts a resource budget has refused this search. It has not proved equality or disproved the requested strict inequality.

The verifier must also bind the calculation to the independently expected request: the literal program or its explicitly declared identity normal form, threshold, scalar interpretation, model and version, recipient, comparison and governing release rule. It must reject malformed syntax, a zero denominator, inconsistent prefix length, non-bit prefix entries, a claimed *V* different from replay, or a stale bound field. Exact binding proves that the calculation concerns the expected record. It does not prove the record's worldly truth or authority. [S2, §2; S3, C07–C12]

## 7. Complete effective equality certification is obstructed

The preceding realization is computable with a fixed geometric error bound. That does not make exact zero uniformly semidecidable. The target reduction can be written inside the actual bounded-loop program fragment instead of assuming a black-box simulation oracle.

### 7.1 The source machine premise and the admitted AST construction

Use nonempty finite valid two-counter instruction tables. Each instruction is a halt instruction H, an increment $`I(r,t)`$, or a conditional decrement $`D(r,t_{\mathrm{zero}},t_{\mathrm{nonzero}})`$, with $`r\in\{0,1\}`$ and in-range targets. Both counters and the initial program counter start at zero. A stage *t* means the instruction in the configuration after *t* transitions, so an initial H has stage zero. [S3, §2]

The recursion-theoretic premise is the standard one for this source machine class: its halting set is computably enumerable and undecidable. Consequently its nonhalting set is not computably enumerable, since simultaneous enumeration of halting and nonhalting would decide which holds. This premise is inherited computability background; no new formalization of two-counter universality is claimed. The following complete construction establishes the reduction into the target language actually used here.

Use distinct natural-number registers with these roles.

| Register | Role |
|---|---|
| 0 | Unary input *n*, never written |
| 1 | Output bit |
| 2 | Current program counter |
| 3 | Snapshotted program counter |
| 4, 5 | Source counters |
| 6 | Latched halt bit |
| 7 | Bounded-loop index |
| 8 | Previous halt bit |

Construct a finite unary P02-L1 AST with output register 1. Initialize registers 1, 2, 4, 5 and 6 to zero. Execute a bounded loop of length $`n+1`$ using register 7. On each iteration:

1. Copy register 6 into register 8.
2. If register 6 is zero, copy register 2 into register 3 and execute a finite sequence of cases, one for each source instruction index *j*. Every case tests register 3 against the constant *j*.
3. The matching H case sets register 6 to one. An I case increments the selected source counter and assigns its target to the program counter. A D case tests the selected counter: at zero it assigns the zero target; otherwise it subtracts one using truncated natural subtraction and assigns the nonzero target.
4. Assign $`\mathrm{sub}(\text{register }6,\text{register }8)`$ to output register 1.

All operations expand into the existing finite `set`, `seq`, `if`, bounded `loop`, register, constant, addition, comparison and truncated-subtraction constructors. The source table only determines finitely many case branches and numerals. Validity of that table is decidable, and the table-to-AST map is effective. No new primitive instruction, unbounded loop or external execution oracle is introduced. [S3, §2]

**Invariant and first-halting correctness.** Before iteration $`t+1`$, either the halt bit is zero and the program counter and counters are the source configuration after *t* transitions, or the halt bit is one and H has already been reached. In the first case exactly one instruction case runs. Its test uses the unchanged snapshot, so assigning a new program counter cannot activate a second case in the same iteration. In the second case no instruction case runs. The halt bit changes at most once, from zero to one, and the output at the end of the iteration is one exactly when that change occurs.

After $`n+1`$ iterations, the program therefore outputs one exactly when the first H stage is *n*. Initial H produces $`1,0,0,\ldots`$; an initial increment leading to H produces $`0,1,0,\ldots`$; a self-looping increment with no H produces only zeros. These controls fix the indexing and the one-step simulation semantics. Every finite evaluation terminates irrespective of whether the source machine ever halts.

For the resulting admitted unary program $`P_M`$,

```math
x_{P_M}=
\begin{cases}
0,&M\text{ never halts},\\
2^{-t-1},&M\text{ first reaches H at stage }t.
\end{cases}
```

Every one of these inverse systems retains compactness, continuity, unique realization, exact contraction factor $`1/2`$ and the uniform $`2^{-n}`$ approximation bound.

### 7.2 The certificate impossibility and its positive exceptions

**Theorem 8 — No uniformly complete effective finite equality discipline.** Let *C* be any effectively enumerable class of finite certificates, and let $`A(P,c)`$ be computably enumerable acceptance. It is impossible that acceptance is sound for $`x_P=0`$ over every admitted *P* and complete for every true zero instance in the family $`P_M`$.

**Proof.** Given *M*, effectively construct $`P_M`$. Enumerate candidate certificates and dovetail their acceptance computations. Soundness ensures that an acceptance implies $`x_{P_M}=0`$, hence nonhalting. Completeness ensures that a nonhalting machine eventually has an accepted certificate. This semidecides nonhalting, contradicting the stated source-machine premise. ∎ [S2, §3; S3, §§2–3]

The certificate may be an invariant, induction argument, arithmetic derivation or global finite proof. The argument does not restrict it to an observation prefix. A constantly zero program has a direct finite equality proof. A source table with a self-looping increment and no H has a finite nonhalting invariant, also yielding a genuine equality proof. A verifier accepting a finite list of sound exceptional instances is possible but incomplete. An unsupported asserted law is not such a proof; a noncomputable acceptance oracle lies outside the effective premise.

The simpler observer reduction in §2.2 similarly excludes an effective sound finite-certificate discipline complete for zero diffuse defect on the entire admitted observer language. The stronger threshold classification does not require reading this impossibility as a ban on restricted fragments. The original finite invariant certificates remain sound incomplete services at their own stated scope. [S1, §6]

### 8.2 General compactness controls

**C13 — A robust answer without a unique state.** Let $`X_i=\{0,1\}\times[0,1]`$ and $`f_i(c,x)=(c,x/2)`$. There are two compatible realizations, with fixed first coordinate zero or one and second coordinate zero. With observable $`g(c,x)=x`$, depth three gives values in $`[0,1/8]`$ and certifies $`g<1/4`$ for both. This is a general compact-query example, not an input to a scalar-only unary certificate format.

**C14 — One unique coordinate need not make the entire realization unique.** Take $`X_0`$ to be a singleton and $`X_i=\{0,1\}`$ for $`i\ge1`$. Let $`f_0`$ be constant and all later maps be identities. Coordinate zero is fixed, but the full inverse system has two realizations. A coordinate-zero certificate cannot be promoted to full-state uniqueness.

**C15 — Continuity only on survivors is insufficient.** Take $`K_n=[0,2^{-n}]`$, $`S=\{0\}`$, and $`q(x)=1`$ exactly at zero. Its restriction to *S* is continuous. Every finite range also contains positive points, so no such range makes *q* constant. A separate global proof can establish that the survivor is zero; the control excludes the unsupported ambient-open inference.

**C16 — Closedness does not replace compactness.** In $`\mathbb R`$, let $`K_n=\{0\}\cup[n+1,\infty)`$ and $`U=(-1,1)`$. The sets are nonempty, closed and nested, and their intersection is $`\{0\}\subset U`$. None lies inside *U*. The extra points escape to infinity. This is a set-theoretic counterexample, not an effective-search claim.

**C17 — Existence does not supply effective names.** Fix a noncomputable $`\alpha\in[0,1]`$ and make every bonding map the constant *α*. The system is compact, continuous and uniquely realized, and every positive-depth coordinate range is $`\{\alpha\}`$. These existence statements provide no computable name for the map or the point. A purported effective solver using only them would have to compute *α*. This missing-input example differs from §6, where both the maps and the unique state are uniformly computable.

**C18 — Search need not receive a separate convergence rate.** Let $`r_n`$ be a computable nonincreasing sequence of positive rationals, promised to tend to zero, and let $`K_n=[0,r_n]`$. For rational $`\tau>0`$, compute endpoints until $`r_n<\tau`$. The promise ensures termination. A separately supplied numerical modulus is unnecessary; the promise itself has not been made decidable for arbitrary proposed programs.

## 9. The effective access distinction

The results supply three concrete positive interfaces with different conclusions.

| Supplied representation and premises | Complete positive service | Remaining boundary |
|---|---|---|
| Full finite synchronous Mealy machine under fair independent inputs | Exact rational diffuse defect and every rational threshold decision | Does not extend to unbounded computable state. |
| Uniform upper-compact ranges, an effective open answer region, and containment of all survivors in that region | A finite containment witness found by dovetailing cover checks | Does not decide validity of the names or the robustness promise. |
| Admitted unary generator, its exact bit interpretation and a fixed strict rational query | A finite replayed dyadic witness for every true strict comparison | Does not certify equality by absence of a strict witness. |

For an arbitrary admitted first-halting generator, evaluating its first three bits may establish 000 without settling whether its source ever halts. That finite prefix nevertheless proves $`x_P\in[0,1/8]`$ and therefore $`x_P<1/4`$. A later first halting bit can make the scalar positive while preserving that conclusion. Under a previously admitted rule requiring precisely this strict bound, the mathematical evidence is sufficient now. A rule demanding exact zero requires an additional genuine global equality proof or continued withholding. These are different fixed queries; changing the rule is not a step of the proof. [S2, §4; S3, §6]

The hierarchy theorem, the finite-state procedure and the compact-query theorem therefore coexist without contradiction. Exact finite observations, a complete source description, effective approximation, robust finite warrant and uniformly complete exact decision are distinct capabilities. The source identity and request-binding controls preserve which capability was actually supplied. No empirical probability, interpretation of harm, collective acquisition advantage, communication-cost improvement or physical intervention permission follows from the scalar construction.
