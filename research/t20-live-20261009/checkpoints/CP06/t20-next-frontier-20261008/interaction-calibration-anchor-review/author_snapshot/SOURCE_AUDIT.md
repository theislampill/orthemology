## Negative mappings retained

- Deterministic unattenuated endpoint union -> full stochastic response: fails without the declared response model. Added AB support can be Boolean-absorbed by A yet visible under independent routes; under shared bearer gates it remains invisible.
- Independent route product -> physical incidence architecture: not injective. A single gate per route with the stipulated product-dependent success probability gives the same endpoint law.
- AB anchoring -> every A occurrence: fails if support-dependent calibration is allowed. The exact unary-pair versus recalibrated singleton countermodel retains the AB response.
- Own-input endpoint preservation -> coordinatewise calibration: false. The continuous strictly own-monotone cross-talk construction preserves every own endpoint while restoring multiplicity ambiguity.
- Exact log contrast -> direct boundary log arithmetic: invalid when lower-support factors vanish. Only the isolated contrast has the finite extensions used in the proof.
- Fixed inventory -> fresh latent inventory mixture: invalid. A log of an average does not become the sum of fixed-support log factors; the A/B mixture produces a nonzero AB contrast without any AB route.
- Attenuation mask -> issued-root change with guards: invalid. Guards are evaluated on issued profiles and need not change under attenuation.
- Exact population functions -> finite empirical frequencies: invalid. The written uniqueness theorem is not a sampling theorem. The appendix's Cauchy probability oracle is an explicit additional computational input contract.
- Rank-one characterization -> halting approximate zero test: invalid. The appendix instead uses nonzero half-integer cuts under an explicitly promised positive integer multiplicity. It does not thereby decide absence.
- Four isolated values -> full absolute calibration maps: invalid. Reciprocal scaling preserves a finite rank-one interaction panel; unsampled function values are unobserved. The main full-law calibration recovery remains separately scoped.
- Anonymous histogram -> numerical route identity, source ownership, actual productive adequacy or source-level perfections: unsupported. No proof here supplies the required interpretation or intervention admissibility.
