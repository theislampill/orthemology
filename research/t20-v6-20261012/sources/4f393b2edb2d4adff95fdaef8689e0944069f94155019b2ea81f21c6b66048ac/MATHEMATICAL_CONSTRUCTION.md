## 1. Concrete untyped carrier

Let T be the set of finite closed terms generated by six constants I, K, S, a0, a1, ν and binary application. Application is total as a syntactic constructor. Write it left-associatively. There are thirteen reduction schemas, closed under every term context:

    I x       → x
    K x y     → x
    S f g x   → f x (g x)
    ν f a0    → a0
    ν f a1    → a1
    ν f I     → f I
    ν f K     → f K
    ν f (K x) → f (K x)
    ν f S     → f S
    ν f (S x) → f (S x)
    ν f (S x y) → f (S x y)
    ν f ν     → f ν
    ν f (ν x) → f (ν x).

The displayed x,y,f,g are rule metavariables, not extra carrier constants. Let ≈ be the reflexive/symmetric/transitive compatible conversion generated by these rules. Inert atoms have no application reduction. The source constants zero and one map to a0 and a1; source I/K/S map to the corresponding constants; source application maps to application. ν is exclusively a semantic value. No source constant or conversion generator is added.

The function weak-head forms are exactly I, K, K x, S, S x, S x y, ν, ν x, with arbitrary closed arguments. Define

    At(t) :⇔ t ≈ a0 or t ≈ a1
    Fn(t) :⇔ t ≈ v for some function weak-head form v.

Both predicates are conversion-saturated by definition.

### Confluence and distinct tags

This is an orthogonal first-order term-rewriting system. Each rule is left-linear. Distinct root left-hand-side patterns cannot unify: the SKI heads are different, and the ν cases have mutually exclusive rigid atom/partial-function spines in the final argument. At a proper nonvariable position of any left-hand side there is only a constant or an unsaturated spine, so no reduction left-hand side overlaps there. Overlaps at metavariable positions are allowed in the definition of orthogonality.

The confluence theorem for orthogonal first-order TRSs therefore applies, without a termination premise. Every reduct of a0 is a0; every reduct of a1 is a1; every reduct of a function weak-head form retains the same function-head/arity shape, with only its arguments reducing. Thus a0 is not convertible to a1, At and Fn are disjoint, and a term convertible to a value has a common reduct of the same value tag.

Reference for the mathematical confluence theorem: Oliveira and Ayala-Rincon, *Formalizing the Confluence of Orthogonal Rewriting Systems* (2013), https://arxiv.org/pdf/1303.7335, pp. 145–148. That paper explicitly states that technical parts of its PVS orthogonality development were axiomatized. It is not being presented as a kernel certificate for this construction.

### Application strictness, with no standardisation assumption

If At(t a) or Fn(t a), then Fn(t).

By confluence, t a reduces to a common reduct of the asserted weak-head value; this reduct is still an atom or a function weak-head form. Consider that finite reduction from t a. Before its first root contraction, all steps occur within the left or right subterm. If there is a root contraction, the left subterm immediately before it must be I, K x, S x y, or ν f. Each is a function weak-head form, and the accumulated left-subterm steps exhibit a reduction from t to it. If there is no root contraction, the final application itself is a function weak-head form, necessarily K x, S x, S x y, or ν x; its left subterm is a function weak-head form reached from t. (An application cannot literally be the atom a0 or a1.) This proves Fn(t). No normalisation or head-completeness theorem is assumed.

The ν reduction rules and compatibility also give

    At(a) ⇒ ν f a ≈ a
    Fn(a) ⇒ ν f a ≈ f a.

For the function case, convert a to a displayed function weak-head form v, use the corresponding ν rule, and convert f v back to f a.

## 2. The entire universe, defined before interpreting source types

A saturated PER is a symmetric, transitive relation R on T such that R(x,y), x≈x′ and y≈y′ imply R(x′,y′). Its support is {x | R(x,x)}. Let top(x,y) always hold.

Define U to contain **all** saturated PERs satisfying at least one of these three conditions:

1. R=top;
2. every supported x satisfies At(x);
3. every supported x satisfies Fn(x).

The empty PER is allowed (vacuously by either homogeneous alternative). This definition mentions neither source syntax nor its interpretation. It is a set of relations on the explicitly defined set T, so quantification over U is not an equation recursively defining a universe. It is not a finite menu of selected test types. In particular, every later source-definable relation is required to lie in this very U.

### Arbitrary intersection closure

For any indexed family of members of U, its intersection is a saturated PER. If every factor is top, the intersection is top, including an empty family. Otherwise choose a non-top factor. That factor has atom-only or function-only support, and the intersection's support is a subset of it. Thus the intersection is in U. This uses ordinary classical reasoning on sets, not an effective enumeration of PERs.

### Dependent Pi closure

Take A∈U and B(x)∈U for every A-supported x, with B(x)=B(y) whenever A(x,y). Define

    Pi(A,B)(f,g) :⇔ ∀ x y, A(x,y) ⇒ B(x)(f x,g y).

This is a saturated PER. For symmetry, transport B(y) back to B(x) and use symmetry in B(x). For transitivity, insert the middle value g x and use A(x,x); for saturation, use application compatibility. These are exactly the extensional dependent-Pi arguments in the inspected FullPER proof.

If B(x)=top for every A-supported x, Pi(A,B)=top. Otherwise choose a supported x with B(x)≠top. A supported f in Pi satisfies B(x)(f x,f x). Hence At(f x) or Fn(f x), because B(x)∈U and is non-top. Application strictness gives Fn(f). The whole Pi relation therefore has function-only support. This proves Pi(A,B)∈U, including empty domains and empty fibers. No totality of the computational reduction relation is needed.

### Dependent Sigma closure, including universal first carrier

Use the unchanged erased source projections first(z)=z K and second(z)=z (K I). Define

    Sigma(A,B)(z,w) :⇔ A(first z,first w)
                            and B(first z)(second z,second w).

This is a saturated PER: symmetry and transitivity use B's transport along the first-coordinate PER relation; saturation uses projection compatibility and transport from first z to a convertible first z′.

If A≠top, every supported z has At(first z) or Fn(first z), so application strictness gives Fn(z). If A=top, extensionality forces B(x)=B(y) for **every** x,y∈T. If this constant fiber is top, Sigma(A,B)=top. Otherwise every supported z has second z in the proper homogeneous fiber; strictness again gives Fn(z). Thus Sigma(A,B)∈U in all cases. No represented-pair side condition is imposed or required by the actual source rules.

This explicitly discharges the proposed dangerous universal-first-carrier case; merely asserting that every pair is syntactically a function would not have discharged it.

### Identity closure

Given A∈U and related endpoints p,q, the identity relation is the product of the I-conversion class with itself; when A(p,q) fails it is empty. Since I is a function weak-head form, this relation belongs to U in either case.

## 4. A genuine nonparametric member of the interpreted Church N

The actual N is All α. (α→α)→α→α. Let P be an arbitrary member of U, let f,g be related at P→P, and let a,b be P-related.

- If P=top, its conclusion P(ν f a,ν g b) is immediate, even for stuck/diverging terms.
- If P has atom-only support, both a and b satisfy At. The atom ν law gives ν f a≈a and ν g b≈b, so P-relatedness follows by saturation from P(a,b).
- If P has function-only support, the function ν law gives ν f a≈f a and ν g b≈g b. The arrow premise gives P(f a,g b), and saturation finishes.

Consequently ν is self-related at the full interpretation of N, with its quantifier ranging over every member of U.     ν f a0 ≈ a0.
