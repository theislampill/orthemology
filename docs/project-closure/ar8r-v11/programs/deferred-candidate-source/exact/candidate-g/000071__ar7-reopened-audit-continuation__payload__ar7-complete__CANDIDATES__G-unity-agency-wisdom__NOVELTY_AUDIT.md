# Novelty audit — Candidate G

## Exact neighbors

- Philip Kitcher, explanatory unification by few reusable argument patterns;
- David Mark Kovacs, metaphysically explanatory unification;
- Sam Cowling, ideological versus ontological parsimony;
- James H. McIntyre, brute-fact parsimony and ontology/ideology exchange;
- cybernetic and belief–desire–intention architectures;
- theistic simplicity debate surrounding Swinburne.

## Comparison

The carrier-boxing theorem is an exact, useful formalization of an established idea: exchanging plural ontology for one bearer plus primitive ideology does not automatically improve explanation. The functional rational-source architecture has established control-theoretic and agent-theoretic analogues. The four-domain orthability application is a distinctive synthesis, but no current proof shows that an impersonal architecture cannot match it or that the synthesis is substantial enough for priority.
