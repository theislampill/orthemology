## 2. Typed levels of unity

Let:

```text
World, Role, Token, Part : Type
Bears       : World -> Token -> Role -> Prop
ExistsAt    : World -> Token -> Prop
Transport   : Edge -> Token -> Token
SameBearer  : World -> Token -> World -> Token -> Prop
PartOf      : World -> Part -> Token -> Prop
Grounds     : World -> Token -> Token -> Prop
ActsFor     : World -> Token -> End -> Action -> Prop
```

For a frozen role set `R*`, define:

```text
WorldCommon(w,x) := ExistsAt(w,x) and forall r in R*, Bears(w,x,r)
WorldSingleton(w) := exists exactly one x, WorldCommon(w,x)
RoleSection(s) := forall w, WorldCommon(w,s(w))
TransportCoherent(s) := every declared edge transports s(w) to s(v)
LineageUnique := exists exactly one transport-coherent RoleSection
NumericalUnity(s) := forall w v, SameBearer(w,s(w),v,s(v))
MereologicalSimplicity(w,x) := no proper-part decomposition under the declared
                               mereology
ReasonIntegration(w,x) := the fittingness/apprehension/uptake/because-of/
                          realization package is bearer- and episode-local
CreatorScope(w,x) := x originates/actualizes every member of the declared
                     created domain under the declared Creator bridge
```

`SameBearer` is not defined as “lies in the same transport orbit.” Doing so
would hide `B_ID` in the definition and manufacture the desired conclusion.

## 4. Proof decomposition

The proof obligations decompose rather than collapse:

1. `U1–U3` may establish a unique coherent role section by the existing
   holonomy/section family.
2. `U4` converts the section from a counterpart/lineage object into one
   numerically identical bearer **relative to the supplied identity semantics**.
3. `U5` blocks a trivial aggregate relabelling of a plurality.
4. `U6` blocks the quantifier shift from global role availability to bearer-
   local co-instantiation.
5. `U7` blocks the shift from co-instantiation to reason-mediated personal or
   wise agency.
6. `U8` blocks the shift from bearer unity to universal Creatorhood.
7. `U9` blocks the shift from a source role bundle to actual-world or revealed
   identification.

No earlier step supplies a later step.

## 5. Countermodels and deletion tests

### SB-CM53 — worldwise singleton swap

Two worlds each contain exactly one role carrier, `a0` and `a1`. They are
counterpart tokens and are not numerically identical. World-local uniqueness
holds; de re numerical unity fails.

### SB-CM54 — coherent lineage without identity

Flat transports select `{a0,a1}` as one path-independent lineage. `B_ID` is
withheld. The coherent section exists and is unique, but the tokens remain
numerically distinct under counterpart semantics.

### SB-CM55 — nontrivial holonomy

A triangular frame has role-preserving transports with one swap around the
cycle. Every world has an eligible carrier and every edge has a bijection, but
no anchor-fixed coherent section exists.

### SB-CM56 — aggregate laundering

A system token `S={p_K,p_W,p_P}` is declared one carrier because each role is
available in one proper part. At the coarse system type, `S` satisfies a weak
existential role predicate; at bearer-local granularity no part bears all
roles. Deleting `U5` and `U6` launders the plural realization into “one bearer.”

### SB-CM57 — one substrate, unintegrated powers

One substrate instantiates three powers, but each operates independently and no
reason-mediated episode links apprehension, selection, and realization. One
carrier does not establish integrated personality or Wisdom.

### SB-CM58 — numerically persistent bearer with role drift

The same bearer exists across all declared worlds, but the universal-actualizer
or role-bundle predicate fails in one world. Necessary existence of the bearer
does not entail necessary possession of the target role.

### SB-CM59 — common root, globally distributed attributes

A unique transported root exists in every world while Will, Power, and
Knowledge are borne by coordinated nonroot realizers. This is the surviving R5
shape already represented in Frontier Round 17.

### SB-CM60 — one role bearer under rival property ontologies

The same bearer-role incidence reduct is given nominalist, trope, conceptualist,
immanent-realist, powers, and real-pattern interpretations. Numerical bearer
unity does not choose a theory of properties.

### SB-CM61 — unique common bearer without simplicity

Exactly one bearer carries every registered role, but it has proper parts or
internally distinct powers under the declared mereology. Common bearer does not
entail simplicity.

### SB-CM62 — source co-reference without world identity

One source object bears the role bundle. Two admissible source/world maps send
it to distinct world bearers. Source co-reference does not supply `B_ID` or a
singleton world-referent fibre.

### SB-CM63 — one bearer without Creator scope

One numerically persistent integrated bearer exists, but actualizes only a
proper subdomain. Personality or unity does not establish universal
Creatorhood.

## 7. Source and school ceiling

The translated Aṣfahāniyyah locus on attributes returning to their locus can
supply a **source-relative locality constraint**. It does not prove a neutral
identity theory, transworld persistence, simplicity, general property realism,
or the numerical identity of a revealed referent.

One located Ibn Taymiyyah passage is not an unqualified Atharī consensus. The
repository’s `B_ID` remains a project bridge parameter unless exact source and
world arguments independently fix it.
