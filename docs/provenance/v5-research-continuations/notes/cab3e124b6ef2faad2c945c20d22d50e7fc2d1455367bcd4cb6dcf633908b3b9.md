# Exact rational sparse-cluster policy

Run a decision from a real finite binary prefix:

    python -B reference.py --word 0000000000000001 --epsilon 1/16 --mode uniform_critical

The result is an exact JSON report and a finite index-search certificate. With those arguments it selects the second centre and the critical left report. Use strict_width with an explicit --delta for arbitrary distributions inside the documented protected intervals. The default mode is strict_width with delta0; it does not silently assume a continuous or critical-uniform prior.

Large-index inspection uses a truthful count summary:

    python -B reference.py --summary 1000000 0 --epsilon 1/4 --delta 1/16

A summary does not acquire or authenticate receipts. It is exactly equivalent to the word policy when the supplied counts come from that prefix.

Read DESIGN_AND_CONTRACT.md and EFFECTIVE_WITNESS_THEOREM.md before using the statistical guarantee. The implemented support is rational2^(-(i+1)^2), distinct from the real exp-square example. The program uses exact integer/rational arithmetic and needs no normalizer approximation or exact-real oracle. The declared modes have different component-law promises.
