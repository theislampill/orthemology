# Provenance policy

Allowed classes: `ADMITTED_POST_MERGE_SCOPED_RESULT`, `POST_MERGE_RESEARCH_CANDIDATE`, `BLOCKED_FORMAL_DEFECT`, `INFRASTRUCTURE_OR_CONTROL`, `NOT_REPOSITORY_READY`, and `OWNER_ADOPTION_PENDING`.

No post-merge object is an exact historical recovery. Repository presence would not establish source truth, world truth, external review, empirical validation, or owner adoption. Same-model staged review is not external independence.
