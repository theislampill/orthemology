## 3. Formal bearer-integration setting

Let `A` be a finite nonempty set of attribute coordinates and `B` a finite nonempty set of candidate bearers. Write:

\[
Real(a,b)
\]

when bearer `b` realizes attribute coordinate `a` under its complete local guard package.

Define:

\[
Local(A,B):=\forall a\in A\;\exists b\in B\;Real(a,b),
\]

\[
Common(A,B):=\exists b\in B\;\forall a\in A\;Real(a,b).
\]

For each attribute `a`, let

\[
E_a=\{b\in B:Real(a,b)\}.
\]

Then:

\[
Common(A,B)\iff \bigcap_{a\in A}E_a\ne\varnothing.
\]

This is an elementary set-intersection criterion. Its central role is diagnostic: local attribute proofs constrain the individual `E_a`; unity requires an additional global intersection fact.

## 4. CBA-1A — local availability does not establish one bearer

\[
Local(A,B)\not\models Common(A,B).
\]

A minimal witness has attributes `{K,W}` and bearers `{u,v}`:

```text
Real(K,u)
Real(W,v)
no other Real facts
```

Each attribute is realized, but no bearer realizes both.

This generalizes the W/P/K warning without transferring independent theorem credit.

## 5. CBA-1B — pairwise co-instantiation still need not yield global unity

For three attributes, even every pair can share a bearer while the full intersection is empty:

```text
E_K = {u,v}
E_W = {v,w}
E_P = {u,w}
```

Every pairwise intersection is nonempty, but:

\[
E_K\cap E_W\cap E_P=\varnothing.
\]

Thus pairwise coordination or pairwise common realization is insufficient for one bearer of the entire package.

## 6. CBA-1C — the bearer-import theorem

Suppose each local qiyās rule is written with the **same pre-fixed constant** `d`:

\[
Guard_a(d)\to Real(a,d)
\]

for every `a`, and every `Guard_a(d)` holds. Then `Common(A,B)` follows with witness `d`.

But the common-bearer fact is not produced by the attribute rule. It enters through the typing decision that every rule has the numerically same target `d`.

If the applications instead use independently introduced targets `d_a`, the local conclusions do not identify them. Therefore an integrated ascent must choose one of three honest routes:

```text
1. SOURCE-FIXED BEARER:
   one bearer is independently fixed by a source premise;

2. INDEPENDENT UNITY/IDENTITY BRIDGE:
   the d_a are proved identical or jointly realized;

3. PLURAL REALIZATION:
   the attribute conclusions remain distributed.
```

Calling all targets “the Necessary Being” or “the Creator” is not itself an identity proof if those labels are doing the disputed work.

## 7. Qiyās al-awlā does not supply the missing unity guard

The M4 local rule transports one eligible perfection to one already fixed target under six guards. Add a seventh integration coordinate:

```text
CB — common-bearer identity across the separately admitted attribute rules.
```

`CB` is not one of the inherited qiyās guards and is not entailed by them. Deleting `CB` leaves the distributed and pairwise-only countermodels above.

This does not deny source-relative unity predication. It locates its authority correctly: if Track N independently identifies one Creator and applies all guarded rules to Him, the common bearer is source-fixed. That is a conditional school-internal architecture, not a neutral derivation of unity from the attribute rules.

## 8. Speech remains a multi-bridge chain

Even with a common bearer of Life, Knowledge, Will, and Power, the existing speech packet allows none of these silent migrations:

```text

actual speech -> every act praiseworthy;
capacity -> authorized Divine Name;
speech occurrence -> identified revelation;
created expression -> uncreated content.
```

Each requires its own source, qualification, occurrence, naming, or content bridge. Common bearer integration is necessary for a unified package but not sufficient for the later Speech/revelation nodes.

## 9. Strongest rival architecture

The strongest current plural rival has:

```text
one impersonal order coordinating several bearers;
K, W, P, Life, or articulability distributed across those bearers;
pairwise or system-level coordination;
no one bearer possessing the complete package.
```

It can satisfy every local existential attribute claim and substantial coordination while failing `Common`. It remains formally consistent with the neutral packet. If Track-N source premises are accepted, it becomes source-incompatible at the personal Creator and Speech nodes; that is source-relative exclusion, not neutral contradiction.
