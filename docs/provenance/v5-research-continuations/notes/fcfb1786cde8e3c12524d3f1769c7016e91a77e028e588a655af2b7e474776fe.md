# When integrity information and shared randomness arrive

Sixth-tranche ordinary mathematical supplement, pending separate review. It keeps
the accepted action problem's semantics and changes the explicitly declared
order of observations. No world deployment, ethical obligation or new general
game-theoretic novelty is asserted.

## Fixed context

Condition on the common report view. There are u possible action roots and a
residual corruption budget 0<=b<u. The known faulty roots have already been
excluded. There are M>=1 message values. A receiver must choose one root; choosing
a corrupt root is damage. Fresh, unrevealed receiver coins have a common law independent of any earlier
corruption choice conditional on the current public transcript. Schedule4
explicitly allows the later corruption choice to depend on the already revealed
root; there is no independence claim about that revealed outcome. Protocols and
their conditional action laws are common knowledge and measurable.
The sender cooperates and knows whichever corruption set the schedule says is
already available. Messages, source identity, action binding, target, permissions
and the causal effect contract are held fixed and reliable.

Let F(u,b,M) be the accepted fixed-codebook private-random minimax value. For a
fixed codebook p_1,...,p_M, its value is max_C min_m p_m(C), where |C|<=b.
This note does not solve F at parameters still open in the research ledger.

## Four schedules and their exact values

### 1. Corruption committed before a shared random codebook

C is fixed first. The sender and receiver then see a fresh shared seed Z,
independent of C, which selects their common codebook as a measurable function of Z. The sender knows C and Z,
chooses m, and the receiver draws its action using any remaining private coins.
The accepted positive-error theorem gives

S(u,b,M) = choose(b,M)/choose(u,M) for 1<=M<=b,
and S(u,b,M)=0 when M>=b+1.

Its loss is max_C E_Z[min_m p_(Z,m)(C)]. The placement of the expectation is part
of the resource contract. The sender sees Z before choosing its message.

### 2. Corruption chosen after the public codebook, before the message

Z is public before the adversary chooses C. The sender then learns that C and
chooses its message; receiver-private action coins remain unavailable to both.
The exact value is F(u,b,M).

For every realised codebook, max_C min_m p_(Z,m)(C) is at least the infimum F.
Hence its expectation is at least F. Conversely, using a fixed codebook whose
value approaches F gives the reverse inequality. In this finite-dimensional
setting the infimum is attained: the product of M finite probability simplexes
is compact and max_C min_m is continuous, since there are finitely many C and m.
Thus a constant optimal codebook attains F exactly.

The adversary can choose a maximizing C measurably: enumerate the finite fault
sets and select the first maximizer. This is a new schedule, not a covert
reinterpretation of the static-before-seed theorem.

### 3. Corruption chosen after the complete message, before the private draw

The adversary sees the public seed and full message before choosing any b-set C.
The sender cannot change its message after that choice. The receiver's draw is
fresh and conditionally independent of C; there are no further observations.
The exact value is b/u, independent of M.

For each public transcript the receiver has some probability row p. The b largest
coordinates have total at least b/u, so the adversary can achieve at least this
loss. A uniform receiver row achieves b/u against every allowed C, without any
message. Randomized communication cannot improve the lower bound because it
holds after every realised public transcript.

This theorem does not cover a sender who receives and exploits the later private
seed or a new causal constraint on which fault sets remain possible. Either would
change the stipulated resource.

### 4. Corruption chosen after the actual root is revealed

If b>=1 and the adversary can corrupt the selected root before its intervention
lands, damage has value one. If b=0, the value is zero. The adversary includes the
selected root; no message capacity or pre-action coin can prevent that under this
unrestricted schedule. A protected commitment or an independently noncorruptible
actuator changes the causal contract and can defeat this particular adversary.

## Strict comparisons and identity

At u=8,b=3,M=2, the reviewed fixed value is1/4, whereas the corruption-before-shared-randomness
schedule in item1 has value3/28. Item2 returns to1/4; item3 has value3/8; item4 has
value1. These are four different information/adversary contracts, not conflicting
answers to one unspecified question. These values reoptimise the protocol for
each schedule. They are not the performance of one unchanged implementation.
For example, transplanting the random two-root menu from item1 into item2 gives
loss one when b=3: the adversary corrupts both revealed menu roots. The optimal
item2 value1/4 instead uses the fixed two four-root lottery codebook. None of
these values is a Bayesian posterior that a source is reliable.

The first schedule is more accurately described as **corruption-before-shared-
randomness**; the seed must not have been exposed when C was chosen. Keeping the
same root labels or the same packet bytes does not preserve this causal timing.
The root-count variable still counts actual integrity units, not copied carriers.

## Why this matters to the source and restoration crosswalk

A correct statement of the target does not fix intervention integrity. A truthful
statement about an action root at one time need not certify it after an allowed
change of fault status. Likewise, common randomness helps only under its actual
visibility and commitment conditions. The relevant communication therefore needs
a current context and an adequate period of integrity, or a protection mechanism
whose own support is included in the fault model.

This does not show that an omniscient source is uncertain about a future act, or
that a source with broader causal power cannot protect an actuator. Those would
be different source/causal resources requiring explicit warrant. The schedules
here specify limited knowledge access and intervention powers; an application
must not silently change them at the theological interface.

The positive consequence is practical: preserving a warranted shared-random menu,
a committed fault contract and the timing of execution can preserve a provable
risk advantage. Preserving only diagnostic agreement or carrier identity cannot.
Abort can avoid damage but changes the compulsory-restoration objective; none of
these minimax calculations supplies a moral permission to take the risk.
