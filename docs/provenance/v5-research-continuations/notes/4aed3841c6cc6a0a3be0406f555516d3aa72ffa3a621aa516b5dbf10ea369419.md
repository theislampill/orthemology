## Statement and proof assessment

The central equivalence says that a fixed deterministic decoder offers a safe message against every corruption set of size at most b exactly when its actual image contains more than b roots. This is the right quantity. Label count alone is insufficient when labels copy one root. Necessity chooses the image itself as the corruption set when its size is at most b; sufficiency uses finite-set cardinality to prevent every image element fitting in the adversary's set.

The message lower bound follows because image size cannot exceed the finite message type's cardinality. An injective adequately sized menu attains the sufficient condition. The support lemma chooses one representative from each nonempty output support, reducing a surely safe support code to a safe deterministic decoder. It therefore proves a necessary cardinal bound, not a measure-theoretic theorem about almost-sure safety. Its universal avoidance of every support root must be justified by the intended finite-output probability semantics when applied.

The four controls check distinct failure modes: an injective two-root menu succeeds at budget one; duplicate labels fail; equality between menu size and budget fails; and a support containing a corrupt root cannot certify sure safety. These are meaningful semantic controls, not independent witnesses that the source possesses the required integrity information.

The residual-budget lemma proves only disjoint-union cardinal accounting. Recognition of known corrupt dissenters, a static shared reporting/actuation budget, the remaining root universe, and conditioning on a fixed observation are premises of application. The type system does not infer them from the name of a set.
