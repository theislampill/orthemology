Status: PASS_SCOPED_ORDINARY_PD_EXPTIME_COMPLETENESS. The frozen author source is accepted at the interface stated below. ## Claim inspected

EXPTIME-hardness of attained almost-sure reachability for explicit finite rational posterior-deterministic joint kernels with an explicit mixed initial belief, visible absorbing target, five receipt symbols, and transition probabilities in {0,1/2,1}. Combining this with the separately reviewed EXPTIME hidden-parity upper bound closes that encoding's complexity interval. The upper theorem is a dependency, not re-proved here.

## Primary-source comparison

The checker mechanism has direct ancestry in CDHR2007 §5: one initial private tape cell, public machine-transition choices, and rejection of false symbol reports. Inspection of its transition families shows that all rows after initial selection already resolve successors uniquely from the old state, action and observation; the initial selection row is the exception. CDH2010 §4 supplies the polynomial-space clock and bounded-horizon transfer from adversarial choices to positive random choices. Moving that initial selection into the supplied mixed belief is therefore a precise restriction-preserving adaptation. FGKPV2026 v2 Definition3.1 matches this PD interface, while Theorem3.3 concerns value approximation. No qualitative hardness theorem was located in that version. This does not establish absence from the literature or historical novelty. See SOURCE_REGISTER.json for exact primary URLs and hashes.

## Independent proof checks

- Input size: the checked cell and head each range over m cells; only one tape symbol and one control are stored in each hidden state. The explicit tuple table, action table and uniform prior have polynomial size. The exponential clock is encoded in polynomially many checked tape cells, not in an exponentially expanded state counter.
- Honest invariant: before a first false read, every initial checker remains present; each tracks its own true symbol and the common control/head. Every honest action/receipt prefix has the same likelihood under every checker. The equal posterior weights are a consequence of the kernel, not an assumption about policy memory.
- Cheating: at a positive honest prefix, the checker at the current head has positive conditional probability. A false claim sends that branch irreversibly to rejection. Learning by failed probes cannot help attained almost-sure reachability.
- Randomization: full action/receipt histories give one common behavioural action distribution when the seed is independent of the initial checker. Choosing any positive-probability action at each reachable prefix preserves positivity of every finite selected path. There is no need for a uniform lower bound on action probabilities. A false claim or rejecting terminal path would contradict the original AS property.
- Alternation: every universal branch has positive probability. The source clock ensures every legal branch is finite. Consequently the extracted pure choices cannot leave an infinite branch or a rejecting branch; they define an accepting alternating-machine strategy.
- PD: each existential or failed-check row is deterministic. The two nonterminal universal branches have different receipts. Terminal branches sharing a receipt share the same absorbing successor. Thus every old-state/action/receipt row has at most one successor, including unreachable tuple states.
- Information: the five receipts suffice. Control and head are reconstructible from the input, truthful action history and public branch bits. Forgetting a terminal branch bit is harmless because simulation has ended. The checker index remains hidden on every honest nonterminal prefix.
- Target/parity: the accepting sink is visibly absorbing. Priority2 there and priority1 elsewhere give a pathwise reachability/min-even-parity equivalence.

## Rejected overgeneralizations

1. A pure known initial state cannot secretly choose the checker under one receipt while retaining PD. With a known initial state the PD property permits exact state tracking, giving the ordinary fully observed reachability problem.
2. Suppressing the public universal bit can create two different successors under one receipt and can destroy an accepting policy.
3. Omitting an initially possible checker, revealing the checker for free, or dropping local symbol validation permits a rejecting machine to win.
4. The clock cannot be discarded. A public universal loop-or-accept state is almost-surely accepting after fair randomization, although an adversary can loop forever. Its kernel is still PD. The exact finite avoidance probability is 2^(-n), so this is a genuine infinite-horizon distinction.
5. The earlier compact-menu hidden-model PSPACE result is not contradicted. The explicit PD descriptor state can encode the entire vector of checker symbols and is exponential in the compact PD input. Its local fixed-point graph is not a polynomial-size explicit hidden-model instance.
6. No value1/attainment identification, fixed-error approximation lower bound, autonomous finite-memory theorem, or hidden-parity finite-odd-cost conclusion follows here.

## Exact upper/lower interface match

The retained embedding begins with a known finite mixed belief b and uses its strictly positive support as the fixed initial tags. It has no fabricated initial receipt, uses the same rational joint observation/next-state kernel, remembers action/receipt histories, and permits a common independent private seed. The reduction's uniform checker belief is exactly such an input. Its five-receipt kernel satisfies the same at-most-one-successor condition on every row. All source actions are enabled, so the embedding's support-consistency menu causes no extra restriction on feasible histories.

The parity lift preserves the actual hidden state/action priority at each physical action index. Assigning priority2 on TOP and priority1 elsewhere is action-independent and gives precisely the absorbing reachability event. Positive prior mass on every checker converts mixture probability1 to probability1 for every checker under the same policy, before existential quantification. No limit-sure value, finite-controller restriction or observation-compatible replacement is invoked.

The descriptor has at most (N+1)^k times a linear receipt factor, where N is the source state count and k its initial support size. The retained 2^k polynomial explicit-family procedure is therefore singly exponential in the explicit PD input. The newly accepted lower bound uses a polynomial-size PD input. The resulting EXPTIME-completeness claim is thus for the same ordinary encoding.

Known-state initialization is a different interface. A known current state remains known after every action/receipt because of PD. The resulting reachability problem is the ordinary fully observed MDP problem and has a polynomial-time decision procedure. A hidden checker-selection boot row cannot be inserted while preserving the required PD property.

## Separate observation-convention corollary

For the reviewed reduction, a deterministic state-label presentation costs only a constant factor. Replace every nonterminal physical state q by copies (q,last) with last in {E,U0,U1}; retain one accepting ACC-labelled sink and one rejecting REJ-labelled sink. From an old copy, follow the original joint row and store its emitted nonterminal receipt in the next copy. Terminal outcomes use their corresponding sink. Label each copied state by last. Initialize every checker in its E copy with the same uniform weights.

The initial E label is common and contains no checker information. Reading or stripping it adds no action and preserves all path probabilities. Given an old copy, action and next label, the original PD property selects at most one next physical state, hence at most one copy. The target remains globally visible and absorbing. There are 3(N−2)+2 states in a nontrivial instance, which is at most a fivefold bound. This label-consistent construction deliberately avoids artificial nonterminal ACC-labelled states that a careless full Cartesian duplication would introduce. The accepted complexity corollary therefore also applies to the deterministic state-observation convention with an explicit mixed initial distribution.
