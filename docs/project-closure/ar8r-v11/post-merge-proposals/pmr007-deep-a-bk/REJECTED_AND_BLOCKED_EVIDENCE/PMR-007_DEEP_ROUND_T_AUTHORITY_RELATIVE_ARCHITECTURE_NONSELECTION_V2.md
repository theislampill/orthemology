## 2. Registered-profile nonselection theorem

Let `P` map a model to `P_REG_O_TO_S`, and let `L` be any target coordinate on
which two attained expansions differ. If

```text
P(M1) = P(M2)
and
L(M1) != L(M2),
```

then no deterministic exact certifier `c` satisfying `L = c ∘ P` exists on
that attained class.

The frozen class contains personal/source and impersonal expansions with the
same `P_REG_O_TO_S` value and different values for common-bearer unity,
personality, Wisdom, Speech, and revelational identification. Therefore:

> The registered neutral profile does not warrant a unique integrated-personal
> architecture.

This is a direct application of the existing profile/fibre factorization
family. It receives zero general mathematical novelty credit.
