## 1. Frozen source, not a toy SKI typing system

The source is exactly `OrthemologyV2.Term`: `i`, `k`, `s`, `zero`, `one`, application.
The markers are inert constants. `Step` has the three I/K/S contractions and
both compatible application-context rules. `Red` is its reflexive transitive
closure; `OrthemologyV3.Conv` is generated by reflexivity, a Step, symmetry and
transitivity. There is no extensionality or eta equation.

Source types are exactly `TypeCode.var n`, `bottom`, `arrow A B`, `all B`.
Type variables use de Bruijn indices; `rename`, `substitute`, `upSub`,
`singleSub` and `instantiateType` are the unchanged canonical operations.
`FiniteDerives` has all seven original rules:

* I:A→A, K:A→B→A, S:(A→B→C)→(A→B)→A→C;
* application;
* universal introduction from ONE finite derivation of the same runtime term;
* universal elimination at a syntactic TypeCode;
* forward compatible multi-step reduction.

There are no term-variable hypotheses in FiniteDerives, no marker typing rules,
and no inverse-conversion typing rule. The separate canonical `Cert` checker
also imposes a finite type-depth condition. That checker condition is not
silently added to the FiniteDerives theorem or confused with type inference.
Exact preimages are in `formal/vendor/FiniteBridge.lean` and the original packet.

## 2. Curry target and the generalisation side condition

`P01F.LTerm` has de Bruijn variables, zero, one, application and lambda. There is
no runtime type abstraction/application: System F is Curry-style. The type syntax
is literally the source TypeCode; bottom is a rigid type symbol in this syntax,
not an assertion that its interpretation is the canonical empty Code.

A target context Γ:Nat→TypeCode assigns types to term variables. `Has Γ t A`
has exactly variable, lambda, application, allI and allE rules. In particular,
**reduction is not included as a typing constructor**.

The allI rule is

    Has (n ↦ rename succ (Γ n)) t B
    --------------------------------
    Has Γ t (all B).

Thus the freshly generalised type variable cannot occur in the old assumptions.
The shifted premise is essential; holding Γ fixed would make generalisation
unsound. AllE concludes `Has Γ t (instantiateType B X)`.

A total Nat-indexed context is a convenient metatheoretic presentation of open
terms; every finite term uses only finitely many entries. Closed translations
are typable under every Γ, so this presentation neither admits new source
assumptions nor strengthens FiniteDerives.

## 3. Precise translation

Types translate identically. Terms translate as follows (numbers are de Bruijn
term indices):

    ⟦I⟧ = λ.0
    ⟦K⟧ = λ.λ.1
    ⟦S⟧ = λ.λ.λ.((2 0)(1 0))
    ⟦zero⟧ = zero;  ⟦one⟧ = one
    ⟦f x⟧ = ⟦f⟧ ⟦x⟧.

Every translation is closed. Therefore target term renaming or simultaneous
term substitution leaves it unchanged. The type-substitution square is exact
syntactic equality because the translator reuses the canonical operation:

    ⟦substitute σ A⟧ = substitute (n ↦ ⟦σ n⟧) ⟦A⟧.

The closed-source term-substitution square is not advertised as an open-source
binder theorem; the separate P01Polynomials module supplies open tracker
substitution for U11.

## 4. Substitution proofs, including both binders

`P01TypeAlgebra` proves identity/composition for type renaming and substitution,
renaming–substitution interchange, and the up/single-substitution equations.
Under all, a substitution is lifted with index0 fixed and old images renamed by
succ. In particular

    substitute (upSub σ) (rename succ A)
      = rename succ (substitute σ A),
    instantiateType (rename succ A) X = A,
    substitute σ (instantiateType B X)
      = instantiateType (substitute (upSub σ) B) (substitute σ X).

Each proof is structural induction on A or B. The binder cases reduce to equality
of Nat-indexed substitutions; index0 and successor cases are handled separately.
`P01LambdaSyntax` supplies the analogous term equations using lifted runtime
substitutions, and proves compatible beta reduction stable under substitution.

Type substitution for target typing changes *both* Γ and A. Its allI case uses
the first displayed up/shift identity. Its allE case uses the instantiation
identity. Term renaming and weakening preserve typing by typing induction.
For simultaneous term substitution, assume every image σ(n) has Γ(n) in Δ.
The lambda case lifts σ with the new variable and weakens the old images.
The allI case type-renames all image typings into shifted Δ; runtime σ itself
is unchanged. The allE case reuses the induction hypothesis and instantiates.
These cases exhaust the target rules. Single substitution follows by choosing
image0=a and image(n+1)=var n.

## 5. The previously missing lambda-generation argument

A Curry typing derivation of a lambda may end in allI/allE, not lambda
introduction. Merely inverting its last rule is therefore insufficient.

Define an auxiliary `LamView Γ b A` with only two constructors:

    Has (A :: Γ) b B  ⇒ LamView Γ b (A→B)
    LamView (shiftContext Γ) b B ⇒ LamView Γ b (all B).

This is a proved view, not an assumption and not a replacement typing system.
First prove LamView stable under type substitution using target type
substitution for the arrow case and the up/shift equation for the all case.
A view at an all type necessarily uses the all constructor. Instantiate its
premise using singleSub X; the shifted Γ then becomes Γ exactly. This proves
view-level universal elimination without adding an allE constructor.

Now induct over `Has Γ t A`, assuming t=λb. Variable and application conclusions
are impossible by syntax. The lambda case gives an arrow view; allI gives an all
view; allE uses the view-level instantiation just proved. Finally, a view at an
arrow must have the arrow constructor. Hence

    Has Γ (λb) (A→B) ⇒ Has (A::Γ) b B.

This closes the inversion needed by subject reduction rather than assuming it
as a new premise.

## 6. Subject reduction without circular typing

Induct on `Has Γ t A`, then inspect a compatible beta step t→u.
For an application, a root step has a lambda function. Lambda generation gives
the body typing; single substitution gives the contractum typing. Left/right
steps use the corresponding induction hypothesis. Under a lambda, use the body
hypothesis. Under an allI/allE typing rule, runtime reduction is the same step;
apply the premise induction hypothesis then rebuild the type rule. A variable
cannot step. Thus

    Has Γ t A ∧ Beta t u ⇒ Has Γ u A.

Induction on the target finite reduction path gives the multi-step result.
This theorem is not proved by adding a conversion or reduction typing rule.

## 7. Nonempty simulation, finite paths and infinite paths

`BPositive a b` means ∃m, Beta a m ∧ BStar m b. Root source contractions have
respectively one, two and three beta steps. Translating an I step substitutes its
argument for variable0. K uses two lambdas and does not inspect the discarded
argument. S substitutes f, g, x and yields the exact translated duplicated-x
contractum. Closedness removes otherwise necessary shifts of these arguments.

Both source context rules lift the **same positive** witness into the matching
application side. Thus a reduction inside a K-discarded argument is represented
by a real target reduction in that argument; it is not erased by scheduling a
root contraction first. Every source Step, not only root steps or tested terms,
has a positive target path.

Finite Red paths concatenate these paths. For a source chain indexed by Nat,
`chain_simulation` gives a positive target path at every link. Choosing finite
witness lists and concatenating them gives an infinite target chain: each list
has length≥1, so cumulative lengths exceed every natural bound. This ordinary
concatenation observation is not needed as an additional axiom in the formal
SN proof: `positive_simulation_reflects_SN` directly inducts on target
accessibility and consumes the first positive step plus its finite tail.
Consequently

    SN_beta(⟦t⟧) ⇒ SN_source(t).

`SN_no_chain` rules out any source chain from the resulting accessibility proof.
The formal chain result deliberately distinguishes positive *paths* from an
incorrect one-source-step/one-target-step correspondence.

## 8. Typing preservation covers the actual complete fragment

Induct on FiniteDerives, strengthening the conclusion to every Γ. I/K/S use
one/two/three lambda introductions and the appropriate variables/applications.
Application is homomorphic. allI instantiates the hypothesis at shifted Γ;
allE uses canonical type instantiation. The forward-reduce source rule uses
finite simulation and the now-proved target subject-reduction theorem.
The final statement is

    FiniteDerives t A ⇒ ∀Γ, Has Γ ⟦t⟧ A.

A target System-F SN theorem can be supplied to the positive-reflection theorem
as an independent cross-check. This packet **does not claim a newly mechanised
SN theorem for all target System-F terms**. No such theorem is smuggled in as an

## 9. Independent source reducibility, confluence and exact completeness

`P01Candidates` mechanises the preserved ordinary candidate argument in new
candidate source. Candidates are SN-contained, downward Step-closed and closed
under the specified neutral expansion. They are NOT canonical conversion-
saturated Codes. Function candidates and intersections are formed internally;
K expansion explicitly requires SN of its discarded argument, and S expansion
covers both occurrences of the argument. Bottom is interpreted by the SN
candidate for this proof only. Type substitution and all seven typing rules give

    FiniteDerives t A ⇒ StronglyNormalising t.

`P01Confluence` proves source confluence by compatible parallel reduction and
complete developments, including head-shape inversions, parallel diamond and
strip/closure lemmas. It never reflects target beta equality. Accessibility gives
a source normal form; confluence makes it unique as a literal Term. More strongly,
for arbitrary t,u and normal n,m reached by source Red,

    Conv t u ⇔ n=m.

Finite typing supplies the existence/termination premise for normalisation. This
is conversion decision on supplied finitely typed inputs, not a decision
procedure for finding an arbitrary System-F typing, and not a proof that an
untyped or dependent frontend normalisation budget always suffices.

`P01Omega` proves the old Ω reduct-shape invariant with new source. Every reachable
shape still has a step, hence Ω has no normal reduct. If a finitely typed u were
Conv-equivalent to Ω, confluence would join Ω to u and then to u's normal form,
a contradiction. Thus Ω has **no** finitely typed representative modulo Conv.
The K t Ω example remains separate: it can convert to t despite failing SN.

Finally, I and S K K remain distinct source normal forms, while their translations
beta-convert. Target-conversion reflection is false; source-conversion
preservation, source normal-form completeness and Ω nonrepresentability survive.
No accepted source equality is changed.
