# Causal stochastic migration with an implementable information interface

**Status:** isolated research return at repository commit `03e2604dfcef278b01c60d19b05370fcec4194b6`, tree `3d06e80277ce39286c94307e0f14b215bc94ed83`. This is a sufficient constructive contract and an ordinary mathematical proof, supported by exact finite probes. It is not canonical adoption, a complete migration decision procedure, or a kernel-checked measure theorem. Source owners and hashes remain in `source_identity.json`.

## 1. Result and the gap it closes

A source controller's almost-sure eventual target persistence transfers to a destination when:

1. the destination can reconstruct the information actually used by that controller and implement its translated actions without consulting hidden source state;
2. initial laws and every subsequent full transition law admit relation-supported couplings, with the correct two marginals;
3. destination badness reflects to source badness on the relation; and
4. destination eligibility, public warrant and safety obligations are independently satisfied.

The result permits history-dependent and unbounded-memory policies. A finite relation certificate does not turn such a policy into a finite-memory controller. Support-only continuation conditions do not supply the missing probability law, and a per-hidden-state matching action does not supply an executable information interface.

## 2. Finite plant and information model

Let A have hidden finite state set X, finite actions A, observation map o_A:X→O_A, and finite nonempty kernel menus D_A(x,a). Each d in D_A(x,a) is a probability distribution P_A^d(·|x,a). Let B analogously have Y, actions B, o_B, and D_B. Menus are choices of an adversarial disturbance after the controller chooses its action. A singleton menu is the ordinary stochastic case. Every distribution sums to one, including unwanted outcomes.

Stochastic observations can be represented by adjoining the latest emitted observation to the hidden plant state. Its joint transition kernel, including correlations with the plant and provenance roots, must be used. This does not authorize replacing shared-root observations by independent copies.

A source behavioral policy σ assigns a distribution on actions to each finite source observation/action history. It can retain the complete history. Its current action is sampled freshly from that kernel after the current history is fixed; future action coins are not pre-sampled into memory exposed to the adversary. A source adversary may use the complete source state/action history and randomized history-dependent choices from D_A. This strong adversary class is important in §5. Every source action used by σ must have the source's separately established authority and eligibility.

The destination interface has:

- a finite **public mode** set Z;
- a relation R⊆X×Y×Z;
- an initial public mode z₀(o_B(y));
- an information reconstruction η:Z×O_B→O_A;
- an abstract-action menu M(z,o)⊆A;
- a public action translator τ(z,o,a)∈B;
- a public mode update u(z,o,b,o')∈Z.

The destination remembers its privately sampled virtual source actions a, even if several a translate to the same executed b. Those virtual actions are controller information, not automatically public evidence. In contrast, z must be reconstructible from the actual public destination observation/action trace. Thus u cannot distinguish two privately different a that yield the same b. The checker retains a in its lookup syntax for convenience but rejects inconsistent updates on a common (z,o,b,o'). If virtual actions are instead publicly logged, that is an explicit enlargement of the action/observation model.

For histories generated by the interface, σ must put all its mass in M(z,o). This is a policy-conformance premise, not something the local plant checker proves for an arbitrary program.

### SR0. The implementability boundary

Fix an available information map I on possible controller histories and a prescribed next-action kernel K(h). An implementation depending only on I exists exactly when K is constant on each fibre of I. Necessity follows because an implemented kernel has the form k(I(h)); sufficiency defines k on each nonempty fibre. The same statement applies to a prescribed memory-update kernel.

Consequently, `for every hidden pair there exists a suitable destination action` is too weak: distinct hidden pairs in one information fibre may require different actions. A public translator is one sufficient uniform witness. Full reconstruction of o_A is stronger than necessary for a particular policy: one may use a coarser source readout if the chosen policy's action and memory updates factor through its history. That sufficiency must be proved; the observation map cannot be coarsened silently.

## 3. The local certificate

For every (x,y,z)∈R, put o=o_B(y). Require:

**R1, information.** η(z,o)=o_A(x).

**R2, meaning and permission.** Bad_B(y) implies Bad_A(x); Safe_A(x) implies Safe_B(y). For every a∈M(z,o), a is eligible at x, b=τ(z,o,a) is eligible at y, and the actual public destination warrant J_B(z,o,b) holds. Any task-specific readout preservation is an additional explicitly supplied relation. Eligibility or warrant is not inferred from a coupling.

**R3, full step coupling.** For every a∈M(z,o), b=τ(z,o,a), and every d_B∈D_B(y,b), there exist d_A∈D_A(x,a) and a probability distribution κ_{x,y,z,a,d_B} on X×Y such that

- Σ_{y'}κ(x',y')=P_A^{d_A}(x'|x,a) for every x';
- Σ_{x'}κ(x',y')=P_B^{d_B}(y'|y,b) for every y';
- κ(x',y')>0 implies (x',y',u(z,o,b,o_B(y')))∈R.

The existential source kernel can depend on the whole related triple and on d_B. The implemented action and public mode update cannot. The checker searches for one source kernel. Allowing a convex mixture of source kernels would be a valid weaker certificate against the randomized source adversary, but is not implemented here.

**R4, full initial coupling.** There is a probability distribution κ₀ with marginals μ_A, μ_B, supported on pairs (x,y) satisfying (x,y,z₀(o_B(y)))∈R. If controller memory or a migration memento is already populated, it belongs in the initial interface contract too. Matching only the current plant output does not justify resetting learned information.

These are rational transportation feasibility problems when the inputs are rational. For each fixed candidate d_A, R3 is a full unit-flow problem. A success witness lists every positive joint mass; a failed candidate is not rescued by normalizing only the favourable relation-supported outcomes.

## 4. Destination controller construction

At initialization, read o=o_B(y), set z=z₀(o), and start the virtual source history with η(z,o), together with any explicitly matched source-controller initial memory.

At each step:

1. sample a from σ on the remembered virtual source history;
2. execute b=τ(z,o,a), retaining a in controller memory;
3. receive o'=o_B(y'), set z'=u(z,o,b,o');
4. append a and η(z',o') to the virtual source history.

This algorithm never samples or observes the proof's hidden source state x. The κ witnesses are used to prove correctness, not as a hidden-state oracle in the implementation. If σ has an M-state realization with fixed initial memory, deterministic memory updates from its observation/action history, and fresh current-action draws, the destination needs at most |Z|M memory states, apart from the convention for storing the current observation. More general randomized-memory realizations need an explicit proof that their conditional action kernel remains σ even under the declared adversary’s memory exposure. Equality of their unexposed plant laws is insufficient: exposed memory must not reveal pre-sampled future action coins. The finite plant/interface checker does not establish this controller-implementation equivalence. If σ requires an unbounded count, so can the destination. An unbounded external clock is additional memory.

## 5. SR1: exact path-law gluing and restoration transfer

**Theorem.** Assume R1–R4, source-policy conformance and the stated source adversary class. If σ ensures source coBüchi acceptance almost surely against every source adversary, then the constructed destination controller ensures destination coBüchi acceptance almost surely against every destination adversary. Source sure safety also transfers, under the safety-reflection premise. Destination permission is supplied by R2 at every reachable interface state.

Here coBüchi means that only finitely many actual states are bad. It is neither a finite-entry certificate into a publicly recognized invariant core nor a deterministic bound on the last bad time.

### Proof, first with singleton kernel menus

Construct joint finite histories recursively. Initially use κ₀. At a related triple and a joint past, choose a with σ on the source observation/action history, set b=τ(z,o_B(y),a), and choose (x',y') with the specified κ. Update z publicly.

By R1 and induction, the source observation/action history used in this definition equals the destination's reconstructed virtual history. Thus the very same action kernel is legal on both sides; it is not secretly conditioned on hidden x or on future success.

For a joint cylinder, its mass is the product of its initial coupling mass, its successive policy probabilities and its successive coupling probabilities. All factors are nonnegative and each extension sums to the old cylinder mass. These cylinder laws are consistent probability laws.

Summing extensions over y' gives exactly P_A(x'|x,a). Since the policy probability depends only on the source observation/action history, summing over all destination histories leaves exactly the source controlled finite-history law. Independently, summing over x' gives P_B(y'|y,b). The virtual source history and mode are available from the destination history together with its own retained virtual actions, so summing out source histories leaves exactly the constructed destination controller's finite-history law. No destination branch has been discarded.

These consistent finite-alphabet cylinder laws define a unique probability measure on infinite joint histories. Even for unbounded-memory behavioral σ, each step records only finite-alphabet states, actions and modes; memory is represented by finite histories, not by an additional unconstrained infinite alphabet. One elementary route is the cylinder-algebra extension: finite additivity follows from consistency, and a decreasing sequence of nonempty finite-alphabet cylinder sets cannot have empty intersection by compactness of the product of finite discrete alphabets. Hence the cylinder probability is continuous at the empty set and extends to the generated sigma-algebra. Uniqueness follows because cylinders generate it. This is the finite-alphabet instance of the standard kernel-extension construction, not an inference from a finite probe horizon.

R holds at every time with joint probability one, because it holds initially and every positive transition preserves it. Countable intersection then gives

`{destination bad infinitely often} ⊆ {source bad infinitely often}`

up to a null set. The marginals are the actual controller laws just established. Therefore

`P_B(Bad_B infinitely often) ≤ P_A(Bad_A infinitely often)`.

The right side is zero under the source hypothesis. This proves almost-sure restoration.

### Adversarial kernel menus

Fix any destination adversary. It is enough to allow the strongest nonanticipating version that sees the entire destination state history and the controller's past/current virtual actions and memory; weaker observation-restricted adversaries are included. In the joint construction it chooses d_B first, according to that adversary, and then the certificate supplies d_A and κ. Its destination marginal is still exactly the chosen adversary's law.

For the source marginal, the selected d_A can depend on latent destination history. At a source finite state/action history h and the already selected current action a, condition the joint past on that positive-probability event and let λ_d(h,a) be the conditional probability that the certificate selected source kernel d. Then

`P(X_{t+1}=x' | h,a) = Σ_d λ_d(h,a) P_A^d(x'|x_t,a)`.

This is an allowed randomized source adversary. All these conditional probabilities are ordinary ratios on finite sets at each time; define arbitrary legal choices on zero-probability histories. No future event is conditioned on. The source action kernel remains σ because it was chosen before either disturbance and depends only on source observation/action history. Thus the source marginal is a law covered by the robust source hypothesis, and the same event inclusion proves the result.

If the source adversary were restricted to an observation filtration, this marginally induced adversary might be too informative. That alternative theorem requires a further adversary-information compatibility condition. The proof does not silently assume it.

### Sure safety and authority

If the destination had a supported unsafe finite history, its finite cylinder would have positive probability under some legal disturbance choices. Exact marginal gluing and Safe_A⇒Safe_B would produce a source unsafe history of positive probability, contradicting source sure safety. Therefore safety holds on every supported destination history. The same finite-prefix lifting establishes that every reachable destination state is covered by R2's local eligibility and genuinely public warrant. The checker verifies the supplied J_B entries, not their empirical or normative truth. ∎

## 6. Sharp negative controls and non-necessity

**S1: a support witness can lose all the probability.** Source b has transitions b→b and b→g with probabilities 1/2 each; g absorbs and is good. Destination B remains B forever and is bad. R={(b,B),(g,G)}, with G absorbing good. Every destination edge has a source support match, and badness reflects. Source restoration is almost sure; destination restoration fails surely. At (b,B), any exact source marginal sends 1/2 to g, while the destination marginal places all mass on B and (g,B)∉R. No full R-coupling exists. Conditioning on the b→b branch would erase half the source law at every step.

**S2: information can be the whole obstruction.** A hidden bit h is fixed, initially fair. At every round the controller guesses 0 or 1; next state stores the same h and the new guess, and badness is `guess≠h`. The source observes h; the destination always observes the same symbol. Corresponding physical kernels are identical under equal guesses, so each hidden pair admits an exact coupling for each action. The source policy always guesses h and is safe from badness after one step. A destination policy has the same law of action sequences under either h; the disjoint events `eventually all guesses 0` and `eventually all guesses 1` cannot both have probability one. Public reconstruction or policy-factorization fails. An oracle translator choosing a different guess from each hidden pair is not an implementation.

**S3: probability preservation does not supply permission.** The positive many-to-one fixture becomes invalid when its destination public warrant for `do` at `unclear` is removed. All six full couplings continue to exist. The checker rejects the authority contract independently.

**S4: privately divergent mode updates are not public evidence.** Duplicate an abstract source action without changing its kernel; translate both copies to the same destination action, but update z to different modes depending on the private copy. Plant couplings and observation identities may all hold. Such a z cannot be read from the public destination history. A red-first regression test exposed this issue, and the checker now rejects it. A controller-private mode is possible in a different theorem, but J_B would need a separate public state and proof.

**S5: this contract is sufficient, not necessary.** Two one-action geometric-exit systems with exit rates 1/2 and 1/3 both restore almost surely, although the identity relation does not couple their one-step laws. Also, a policy that never uses a source observation distinction can migrate despite failure of full-observation reconstruction. One can prove a policy-specific coarsening or use a different relation; rejection alone is not impossibility of every restorative migration.

**S6: one initial match cannot stand in for two complete initial laws.** Coupling source mass one at b to a destination law with half its mass at an unrelated G is impossible for the fixture's R, even if (b,B) is a correct individual match. R4 quantifies over all initial mass. A changed prior or migrated memento must be declared.

## 7. Executable certificate and evidence

`stochastic_refinement.py` checks R1–R4 for finite dictionaries with exact integer/Fraction probabilities and returns source-kernel indices, full step couplings, and the initial coupling. It rejects floating-point and Boolean probabilities, missing kernel menus, observation mismatches, bad/safety-reflection failures, missing eligibility or warrant, and mode updates depending on a private virtual-action distinction. It is a research checker over supplied finite typed structures, not a hardened parser for untrusted files.

`test_stochastic_refinement.py` has eight focused tests. With the earlier restoration/migration/correlation tests, 28 tests pass. `probe_stochastic_refinement.py` separately propagates a genuinely history-dependent randomized policy through (i) the source alone, (ii) the destination implementation alone, and (iii) the joint coupling, then compares exact finite cylinder marginals through nine transitions. At the last level it checks 1,534 joint/source cylinders and 1,023 destination cylinders. It also constructs 250 seeded two-public-mode quotients with hidden source clones and two disturbance choices, rechecks all 12,088 returned step couplings' marginals and relation support, and rejects 250 independent warrant deletions. There were zero mismatches. These finite probes support the implementation, not the unbounded measure theorem by induction from data.

Reproduce from this directory:

```sh
python -m unittest test_restoration test_migration test_correlation test_stochastic_refinement
python probe_stochastic_refinement.py
```

## 8. Actual literature relationship

Probabilistic simulation and controller refinement are established methods. Haesaert, Soudjani and Abate's Definition 6 uses coupled transition laws and an initial lifting; its interface may depend on both model states. Theorems 1–2 then refine controllers. Those full-state interface arguments do not automatically make a hidden-state-dependent action executable by our observation-restricted destination. Our R1/public-transducer clauses are explicit sufficient information restrictions, while R2 adds this programme's independent permission/meaning obligations. Their approximate finite-horizon result also cannot simply be read as exact infinite-horizon almost-sure persistence. [Author preprint, §§3–4](https://arxiv.org/pdf/1605.09557), [published article](https://doi.org/10.1137/16M1079397).

Partial observation has also been addressed directly using belief models and label-based approximate stochastic simulation. That is close methodological ancestry, not an unoccupied problem class; our finite raw-plant interface is a restricted alternative with exact kernels and an explicit public/private information boundary. [Haesaert et al., 2018, paper record and abstract](https://authors.library.caltech.edu/records/8652e-1ns11). The kernel-extension step is standard; a recent formalization concerns that general theorem, not this migration proof. [Marion, *A Formalization of the Ionescu–Tulcea Theorem in Mathlib*](https://arxiv.org/abs/2506.18616).

## 9. What remains open after this return

The checker is complete only for its supplied relation, translator, public modes, finite kernel menus and pure matching-kernel witnesses. It does not synthesize those interfaces, infer the actual source standard, establish source coBüchi winning, or choose an authorized model of provenance. Source adversaries with restricted information, approximate couplings with recovery after relation exits, and automatic policy-sufficient readout minimization need separate contracts. In particular, a summable probability of **leaving** R gives only a finite number of departures almost surely; one departure could be permanently destructive. Eventual target transfer then requires an actual recovery/invariant argument, not Borel–Cantelli alone.
