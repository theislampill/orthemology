## 1. Central question

Deep I showed that effective-realizer existence does not select one realizer under neutral symmetry. This round asks whether a non-haecceitistic dependency structure can supply the required asymmetry.

Let a directed edge

```text
u -> v
```

mean that `v`'s efficacy in the declared actualization domain is derivative from or borrowed through `u`. The direction is upstream source to downstream dependent. The graph is not a mere communication, temporal-precedence, or correlation graph.

## 2. Finite dependency setting

Let `D=(V,E)` be a finite directed acyclic graph. Define:

```text
u <= v:
u reaches v, allowing u=v;

Root(r):
no proper predecessor reaches r;

Up(v):
{u : u <= v};

UpstreamDirected(D):
for every v,w in V, Up(v) intersects Up(w).
```

A root represents an underived actualizer only relative to the complete declared efficacy-dependence graph.

## 3. UCA-1 — common-ancestry unity theorem

For a finite DAG `D`, the following are equivalent:

1. `D` is upstream-directed;
2. `D` has exactly one root;
3. there is one root `r` that reaches every vertex.

### Proof

Every vertex of a finite DAG has a root ancestor. If `D` is upstream-directed and `r,s` are roots, they have a common ancestor `u`. Since no proper vertex can precede a root, `u=r=s`; hence the root is unique. Every vertex has some root ancestor, so the unique root reaches every vertex. Conversely, if one root reaches every vertex, that root belongs to `Up(v)∩Up(w)` for every pair. QED.

## 4. Automorphism consequence

The unique root is fixed by every automorphism of the dependency graph. Thus a complete, finite, well-founded, upstream-directed efficacy graph supplies the symmetry breaker absent in Deep I.

This is structural selection, not yet personal agency, metaphysical necessity, or explanatory completeness.

## 6. Mandatory countermodels

### J-CM1 — plural roots

Two root powers actualize disjoint effect domains. The graph is a DAG but not upstream-directed. Unity fails.

### J-CM2 — downstream merger hides plural roots

Two roots feed one merger node, which then feeds every observed effect. All observed effects share a common upstream node, but the full graph has two roots. Common ancestry restricted to outputs does not establish one underived source.

### J-CM3 — directed cycle

A cycle is upstream-directed because every vertex reaches every other, but it has no root. Acyclicity or well-foundedness is load-bearing.

### J-CM4 — infinite descending chain

Every finite truncation has an apparent source, while the infinite graph has no underived root. Finiteness can be replaced only by an independently defended well-foundedness condition.

### J-CM5 — incomplete dependency registry

An omitted root actualizer supplies one hidden effect lineage. The registered graph has one root; the real graph has two. Graph completeness is a certification burden.

### J-CM6 — unique efficacy root, separate abstract order

One concrete root supplies every efficacy lineage, while modal/semantic/normative order remains a numerically distinct abstract primitive. Efficacy unity does not establish one common order–actuality bearer.

### J-CM7 — unique root but incomplete Creatorhood

The unique root supplies all registered effects while a contingent particular outside the registered domain remains unoriginated. Declared-domain actualizer unity does not establish complete Creatorhood.

### J-CM8 — unique root, no mentality or Wisdom

An impersonal powers field is the unique root. It supplies one actualizer without intellect, personality, agency, fitting ends, Wisdom, or Speech.

## 8. Nonclaims

The theorem does not show that the actual world has a finite or well-founded complete dependency graph, that the edge relation is source-authenticated, that one root is metaphysically necessary, that it originates all contingent reality, or that it is intellectual, personal, agentic, wise, or speaking.
