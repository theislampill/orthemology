# AR8R research flywheel crosswalk

The flywheel is a dependency graph, not a claim that every topic forms one
theory. Source custody constrains language and version; language constrains
communication; communication constrains provenance; provenance disciplines
representation learning and theorem-family credit; representation and causal
restoration tests separate visible alignment from target change; proper-function
work asks whether the route as well as the output is adequate; Candidate N and
the source lanes supply typed premise candidates to Track T; Candidate G and R5
challenge premature unity; and failed transcendental bridges return narrower
questions to source, language, representation, and countermodel work.

The recovered PMR-007 proposal adds a typed daee-temporal loop: version custody
constrains eligible actions; warranted-output and certificate-object structure
constrains local protocols; temporal fixed points separate event-local closure
from future persistence; and provenance-root transversals pressure-test static
restorative portfolios. Those results return model-completeness, causal,
authorization, and dynamic-robustness burdens to the originating lanes.

The exact PMR-001/PMR-002–006 sources also restore three edges that compact
summaries can easily lose: fiṭrah/reminder loci type a state-sensitive daee
restoration target; Candidate 1's finite query problem constrains later
provenance-root oracle extensions and their credit; and TAC/SAC carrier,
episode, lineage, and acquisition-root distinctions constrain what copied or
synchronized communication can establish. PMR-FAMILY-01 prevents the same
Speech/hearing/seeing proof skeleton from receiving three independent origins.

Every edge has an anti-laundering direction. Source custody is not translation
truth. Receipt is not warrant. Similarity is not identity. Restoration is not
proper function. A source-role taxonomy is not world truth. A common carrier is
not explanatory unity. Articulability is not mentality or divine Speech. A
renamed application is not a new theorem origin.

The corresponding YAML names each owner, contribution, and forbidden transfer.
Its purpose is to keep successive research waves mutually productive without
allowing vocabulary resemblance to move proof, novelty, source, metaphysical,
or authorization credit across lanes.
