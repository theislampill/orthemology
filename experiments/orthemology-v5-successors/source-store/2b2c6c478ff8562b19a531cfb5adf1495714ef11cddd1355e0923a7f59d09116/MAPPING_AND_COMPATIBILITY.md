# Exact composition and acceptance contract

Status: proposed design; implementation and verification not attempted.
Finite tables and all symbol meanings are in `DESIGN.md`.

## 1. Literal identity and sort map

| Input/output role | Joint value | Binding required |
|---|---|---|
| A received target | `x : B` | `targetReceived x`; whole reception and actual existence both true |
| A original resource | `rg : R` | actual, nonreceived, relevant to x |
| A intrinsic bearer | `g : B` | intrinsic g rg, actual existence, whole nonreceipt |
| B necessary bearer | the same `g : B` | no new existential choice or reassignment |
| C essential/uniform original | the same `g : B` | broad EssentialNonreceipt and inherited binary UniformRoot |
| Field source S | literally `B` | g/h/x and all effects available as source candidates |
| Field anchor | `(g,a)` | x is produced at a; cx is required and operative at a |
| Qualification/classification/conformance | all fixed at `g` | no premise on h or x substituted for a g-premise |
| Common complete provider | the same `g` | all four field contribution tokens have EntireOrig g |
| Outside original | `h`, resource `rh`, effect `z`, occurrence `o` | h differs from g and x; h is necessary and original, actual only outside the field in the productive relations |
| Created agent | `x` | received in w0/w1, absent w2, intrinsic rx, actual agency at k |
| Veracity Source | literally `B` | full package fixed at g; no automatic all-source quantifier |
| Veracity Occasion | literally `W` | w0 is the same actual point; all three occasions explicitly interpreted |
| True source-owned assertion | `(w0,g,u,present)` | g owns u; content true because l exists at w0 |
| False created assertion | `(w0,x,v,absent)` | x owns v; g supports v; g does not assert its false content |
| Primitive resource vs contribution | separate `R` and `C` | rg is intrinsic to g; rx is intrinsic to x; cx maps to rx and x without collapsing these roles |

The A/B/C generic existential theorem by itself does not designate g: it can
also return an outside witness for z. At canonical target x prove that any
`OriginalWitness framework x resource bearer` has resource=rg and bearer=g.
Then apply the existing A bridge at that target and the retained B/C steps to
this same g. Also instantiate the unmodified generic `abc_same_witness` theorem
as a separate API check; do not mistake its existential output for the anchor
identity certificate.

## 5. Obstructions and excluded strengthening

No interface contradiction is presently identified at the proposed finite
tables. The following stronger demands would be illegitimate or impossible:

- Requiring a false g-owned token or incomplete qualified g-role while keeping
  all good-source premises contradicts the checked component theorems.
- Inferring Qualified(g), Classification(g), or Package(g) from A/B/C alone
  would need new substantive bridges. They are independently interpreted here.
- Treating g's productive support of v as g's assertion would make its false
  content contradict Package(g); ownership must not be transported by support.
- Giving h an incoming requisite at k while retaining field CND and complete
  g coverage would force h=g. This model instead makes the outside boundary
  explicit and predecessor-closed; it does not hide that incoming branch.
- Claiming all necessary originals equal g is false here: h is a distinct
  necessary original. No field theorem has that global conclusion.
- Demanding a proof that the finite W is metaphysically exhaustive, that the
  contribution decomposition is correct of reality, or that every source
  doctrine has been included exceeds this consistency test.
- The optional strict-ancestry certificate proves a model-specific compatible
  interpretation. General incidence-to-Sixth refinement remains OPEN.

The three frozen component interfaces can therefore be tested together as
specified without weakening a selected premise, changing a theorem, or using
disconnected copies of their principal witness. This is a design conclusion
awaiting the planned mechanical checks, not a claim that those checks passed.
