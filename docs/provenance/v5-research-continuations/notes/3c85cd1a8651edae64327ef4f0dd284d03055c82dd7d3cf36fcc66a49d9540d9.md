# Exact integer confidence budget

This is a conditional arithmetic evaluator for the independently reviewed ordinary controller-cost tail theorem. It is not a winning-region checker, controller extractor, empirical model certificate or end-to-end Lean proof.

## Input and theorem boundary

Supply positive integer state/action/model counts s,a,m, a rational positive lower bound p<=1 on positive transition probabilities, a genuine rational positive empirical separation margin eta, and a rational failure budget0<delta<1. The actual policy, hard menus, winning initial state and stochastic law must separately satisfy the accepted controller theorem.

Let q=sa, D=s a^s, r=p^D, and c=min(eta,1)^2/2. The formal raw-tape theorem supplies coefficient

    A0=2qs/[1-exp(-c)].

The elementary inequality exp(c)>=1+c gives A0<=A=2qs(1+c)/c. Also lambda=-log(1-r/2)>=r/2. The accepted ordinary stopped-cost theorem then yields

    P(C>T) <= A exp(-cN) + 2^(J_N) exp(-lambda T/D),
    J_N=q(N+m-1)+2m(N+m+1).

These are the only probabilistic premises of this arithmetic layer. It does not prove them anew or infer their semantic applicability from integer data.

## Integer-only witnesses

Choose nonnegative integer k and ell with

    2^k >= 2A/delta,    2^ell >= 2/delta.

Choose positive integer N and nonnegative integer T with

    cN >= k,    rT >= 2D(J_N+ell).

Because exp(1)>2, the first tail term is at most A*2^(-k)<=delta/2. The second is at most

    2^(J_N) exp(-J_N-ell) <= 2^(-ell) <= delta/2.

Thus P(C>T)<=delta. All witness inequalities are rational/integer comparisons. No floating-point logarithm, exponential, underflow-sensitive subtraction or exact-real comparison oracle is used. The evaluator selects the least dyadic upper-log witnesses and rounds N,T upwards; it makes no optimality claim.

## Executable boundary

src/exact_budget.py returns exact Python integers and Fractions. Its verifier recomputes the arithmetic construction and checks the displayed rational witness inequalities. No external input is executed. Floating-point parameters and Boolean values in integer count fields are rejected. An explicit work guard can refuse an excessively large exact probability power; that is an implementation resource limit, not a mathematical counterexample.

The returned record labels the result CONDITIONAL_PARAMETER_BOUND_ONLY and lists the semantic premises it has not checked. The example budget is deliberately conservative and may be many orders of magnitude above realised cost. It is a proof-derived upper bound, not a performance prediction.

Run the complete local test suite with:

    python3 -m unittest discover -s tests

Core behaviour tests were written before implementation; their missing-feature failures are retained separately from the successful run. Additional grid and mutation controls were added after the core implementation. No canonical repository file was modified.

## Formal arithmetic endpoint

IntegerBudget.confidence_from_witnesses checks the two-term arithmetic implication in Lean4.19.0 against pinned Mathlib. The probability-tail bound remains an explicit real inequality premise. Its integer exponents, dyadic inequalities and rounded time witness imply the real upper bound delta. This does not formalise the entire controller-cost proof or certify that user-supplied integers describe a winning stochastic controller.

The Python evaluator and Lean arithmetic theorem implement the same displayed witness specification. Their correspondence is source-reviewed and testable; there is no extracted Python or verified Python interpreter claim.

## Exact coefficient successor

ExactBudgetEnvelope additionally proves both envelope inequalities used by the evaluator: b/(1-exp(-c)) <= b(1+c)/c for b>=0,c>0, and -log(1-r/2)>=r/2 for r<=1. confidence_from_exact_tail composes those with the integer dyadic witnesses. Its tail premise therefore has the original exact exponential coefficient and logarithmic progress rate. This removes two ordinary arithmetic steps from that particular interface, while leaving the stochastic controller-tail theorem explicitly conditional.
