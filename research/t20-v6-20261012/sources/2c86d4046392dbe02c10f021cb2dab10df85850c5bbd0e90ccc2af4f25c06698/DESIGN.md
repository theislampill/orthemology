## Discriminating questions

1. Does adding genuine productive work necessarily change the complete created output, or is this true only for nonabsorbing production laws? Majmu 20:175 uses even qualitative comparison (`mithl`), so origin-essentiality alone cannot support or rebut it.
2. Does individuation of intrinsic act tokens entail individuation of their external effects? Minhaj V03L0272 explicitly makes this move. The inference needs a production-map condition distinct from the intrinsic-token identity theorem.
3. Can full created histories and every input-intervention outcome be identical while actual productive derivations differ? Derive contribution from executed transition rules rather than attach arbitrary owner predicates.
4. Can an interaction be explained by the original agents without a third original or reciprocal efficient receipt? Test a nonentity rule, a created mechanism, and an intrinsic relational state separately.
5. What does conservation establish when all created side effects are accounted for, and when does it silently count an uncreated intrinsic act as a created emission?

## Executable semantics

- Typed intrinsic acts belong to rigid original roots; created event keys do not contain origin labels.
- Guarded production rules yield events and derivation supports. Policies with direct coalescence, independently enabled productions, and priority selection will be compared. These are distinct operational factorizations, not distinct labels on one evaluator.
- A created history contains all created event tokens and their states. Derivation records are a distinct explanatory sort. A provenance-sensitive history is an additional interpretation, never the default identity criterion.
- Root interventions change which intrinsic acts are issued while preserving the remaining act object. Rule deletions are separate mechanism interventions and cannot be assumed available to metaphysical agents.
- Commutative finite monoids diagnose absorption, cancellation and reversible interaction beyond addition/OR. Enumeration is exhaustive only at the stated finite signature. General conditional proofs supply the scope beyond enumeration.
- Coalescence-resource accounting tests whether a created mechanism adds omitted output, external receipt, or a prior joint-production regress. No claim that a mathematical function supplies its own metaphysical explanation.
