## Result

Under seven explicit conditions, the computer verifies that the actual received target has a relevant actual original resource instantiated by one and the same actual bearer, and that this bearer necessarily exists and is essentially nonreceived in its whole existence.

The conditions are: actual received-target occurrence, positive original completion, bearer realisation, same-respect support transport, an explicit binary-receipt representation, contingency-as-need, and generic constitutive reception. Their truth of reality remains philosophical/application work. The theorem does not say that a computer has proved those premises or God's existence.

The original-resource predicate is exactly actual resource plus nonreceipt in the specified existential respect. Resources and bearers have independent types. An original resource is not defined as an existing original bearer. The new A bridge derives bearer nonreceipt by contradiction: receipt of the bearer would, by support transport, make the same intrinsic resource received.

B and C are calls to the inherited SourceIdentity theorems, not newly discovered deductions. The same g selected by A is retained throughout. A does not require the binary receipt representation or modal principles; the representation is needed for this explicit reuse of the inherited binary interface.

## What the tests discriminate

- Removing completion, realisation or support separately leaves the other major assumptions true but no actual original bearer. Each uses a genuinely infinite Nat ancestry with supplier n+1, no self-edges and strict transitivity. These failures do not depend on forbidden causal cycles or a finite truncation.
- Removing contingency-as-need leaves a real actual original bearer which can be absent elsewhere. All other major assumptions hold; no bearer is necessary.
- Removing generic constitution leaves necessary actual bearers which switch supplier/receiver roles between worlds. Each world's relation is acyclic, but no bearer is a uniform root.
- The full positive two-world model has a necessary original source and a contingent received effect. Both need and intrinsic-resource transport are nonvacuously exercised. The joint premise set is therefore inhabited relative to Lean's ordinary logical foundations.
- Essential nonreceipt conditional on existence does not require necessity. This elementary premise-minimality observation does not remove necessity from the compound necessary-and-uniform conclusion.

Counterinterpretations certify logical independence at this exact signature, not metaphysical possibility. In particular, the full-bearer realisation and general contingency premises are sufficient formulations, not claimed globally minimal quantifiers. Their witness instances perform the relevant steps.
