# Finite bad-visit cost of the actual generated coBüchi controller

## 1. Result and exact scope

Fix the fifth-tranche finite observed-state rational-family input and its **literal** `generatedPhasePolicy P menu priority B0 s0 fallback fallbackAction (empiricalReject P ε)` with Unit seed and Dirac seed law. Assume `B0.Nonempty`, `s0 ∈ winningRegion P menu priority B0`, and that the actual tolerance satisfies the source hypotheses:

- ε > 0
- for every θ,σ in B0 and unequal full row e, some receipt coordinate y has `ε < |Pσ(e,y)-Pθ(e,y)|`

In particular this includes the separately accepted `ExplicitController.policy` and `winningRecord`, with their original `Classical.choose` tolerance and target choices. It also applies to every choice satisfying those finite certificates, not just a convenient choice made for a test. No controller alteration, counter reset, policy extraction, or assumed fair policy is used.

Let `Bad σ e` be an arbitrary model-specific predicate and set `priority σ e = if Bad σ e then 1 else 2`. The minimum-priority convention is essential. For σ∈B0, let e_t be the actual executed state/action pair at time t and let

`C = Σ(t≥0) 1[Bad σ e_t]`.

**Theorem.** For this very controller, `Eσ[C]` is finite. In fact `Eσ[C^d]` is finite for every positive integer d. These assertions concern actual action visits, including the first action and excluding any artificial default history label.

The complete stochastic/cost theorem below is an ordinary source-bound mathematical proof. Five Lean modules formalize its exact coBüchi/count interface, actual finite-prefix phase bound, actual empirical-test margin consequences, non-stopping shell transfer, and exact stack-to-history cost-moment law identity. They do **not** constitute an end-to-end Lean proof of the hitting-time and stopped-cost estimates.

### Explicit first-moment bound

Write `s=|State|`, `a=|Action|`, `m=|B0|`, `q=sa`. The supplied initial state and fallback action ensure s,a≥1; m≥1 is assumed. Let p be the minimum strictly positive probability among the finitely many true-model rows. Normalization gives `0<p≤1`. A minimum over the entire finite family is an admissible common replacement.

Put `D=s a^s`, `r=p^D`. For the chosen ε and true σ, let Δ be the minimum, over unequal candidate/true rows, of their maximum absolute coordinate gap. If unequal rows exist, choose `η=min(ε,Δ−ε)/2`. Otherwise choose `η=ε/2`. Then η>0, η<ε, and every unequal row has a coordinate with gap strictly greater than ε+η. Neither every coordinate nor every positive coordinate gap need exceed ε.

Suppose constants `A≥1`, `c>0` certify the all-deterministic-prefix tape bound

`P(G_nᶜ) ≤ A exp(−cn)` for every n≥1,

where G_n is defined in §2. Define `z=exp(−c/2)` and

`J_n = 2m(n+m+1)(q(n+m)+1)`.

Then

`E C ≤ sqrt(2) D sqrt(A)/r · Σ(n≥1) J_n z^(n−1)`

and therefore

`E C ≤ 2 sqrt(2) m D sqrt(A)/r · [ q z(1+z)/(1−z)^3 + (q(2m+3)+1) z/(1−z)^2 + (m+2)(q(m+1)+1)/(1−z) ]`.

The usual two-sided Hoeffding inequality supplies the particular ordinary instance

`c=2η²`, `A=2qs/(1−exp(−2η²))`.

A weaker formally certified exponential tape rate can be substituted without changing any controller or subsequent proof step. Constants are intentionally very loose. This is a per-input theorem, not a bound independent of small transition probabilities, state/action cardinalities, or row-separation margins.

## 2. Raw tapes, deterministic prefixes, and the non-stopping cutoff

Work first under the accepted product stack law for the fixed true model σ and Unit seed. For each pair e and receipt y, let F(e,y,l) be the empirical frequency in the first l cells of e's raw tape. Those l deterministic tape cells are iid with the actual row; the receipt indicator is Bernoulli with mean Pσ(e,y).

For n≥1 define

`G_n = { for every e,y and every l≥n: |F(e,y,l)−Pσ(e,y)|<η }`.

A union bound over q pairs, s coordinates and the countable deterministic indices l gives

`P(G_nᶜ) ≤ 2qs Σ(l≥n) exp(−2η² l) = A exp(−cn)`.

The G_n increase. Their union has probability one, either by this bound or by the already accepted simultaneous tape convergence theorem. Let `K=min{n≥1:G_n}` on that full-measure union and choose any value on its null complement. K is a measurable last-error cutoff. It is **not** a stopping time. We never condition future samples, phase durations or a cost bound on K or G_n.

Primary source for the only external probabilistic inequality is Hoeffding, *Probability Inequalities for Sums of Bounded Random Variables*, JASA 58(301), 1963, Theorem 2, DOI https://doi.org/10.1080/01621459.1963.10500830. Everything after that inequality is proved below by finite graph, conditioning, and elementary moment arguments. No historical novelty is claimed for these tools or for multi-environment MDP analysis.

## 3. A real observed stopping time, with inclusive cost

Let H_t be the complete observed pair/receipt history after exactly t completed transitions, so e_t is chosen from H_t. Counts and frequencies are exactly the source's `actionCount` and `historyFrequency`. The retained sequential-consumption theorem identifies each observed frequency with the raw prefix at the count actually consumed. This is a pathwise identity, not an iid assertion conditional on that random count.

Define the analysis stopping time

`τ_n = inf { t≥1 : there are e,y with count_e(H_t)≥n and |freq_e,y(H_t)−Pσ(e,y)|≥η }`,

with inf ∅=∞. Its event at t depends only on H_t, so it is a stopping time in the fixed-σ full-history filtration. It uses the hidden true row for analysis and is **not** an online stopping rule implemented by the common controller.

Define `C_n = Σ(0≤t<τ_n) 1[Bad σ e_t]`. Thus, if τ_n is finite, the action e_(τ_n−1) whose receipt first detects the violation **is included**. No subsequent action is charged. On G_n, the pathwise prefix identity gives τ_n=∞ and C_n=C.

For every t<τ_n, H_t is accurate at all acquired counts ≥n. The next transition may detect a violation; all bounds below include this final transition and do not assume its post-transition statistics remain accurate.

## 4. Source-derived barrier and segment budgets

Fix a support B containing σ. The exact `cycleAction` enumeration contains a σ-candidate index j in `[n,n+|B|−1]`. This is a statement about `Fintype.equivFin` and modular arithmetic, not a different candidate schedule.

Whenever the phase index equals j and the next completed history remains before τ_n, its active test counts satisfy `count>j≥n`. Their true deviations are <η<ε, so the true-candidate test is false. The source's `run_true_candidate_no_increment` uses the actual qualifying component closure to exclude a true-candidate component exit. Hence that phase cannot increment. On unchanged support the only possibilities are increments 0 or1, so the barrier cannot be skipped. A proper support change resets the phase to0 before every other guard.

Consequently, at every action time t<τ_n,

`index_t < n+|B0|`.

This precise actual-run consequence, including resets and literal test arguments, is kernel-checked in `generated_index_bounded_of_accurate`. An increment on the detecting transition is irrelevant because no next action is charged.

Actual support contains σ and only shrinks. There are at most m distinct support epochs. In each epoch the phase begins at0 and is nondecreasing until reset, and no phase index below n+m can occur in more than one episode. A conservative bound is `m(n+m+1)` phase episodes. Within an episode normalization changes navigation (`none`) into one selected operating component (`some E`) at most once. A retained component cannot change without ending the phase/support episode. Therefore at most

`H_n = 2m(n+m+1)`

navigation/operating segments begin before τ_n.

## 5. Frozen-menu chains retain the real source counters

During one segment fix its support B, candidate θ and active pair set F: the stage-safe pair set in navigation or the chosen E in operation. The active action menu at state u is M_u. For unused states assign a singleton dummy residue; such states are not reached before a terminal event. For used states M_u is nonempty by the actual region/component invariant.

The policy's action at u is the exact finite cyclic enumeration indexed by the **global number of departures from u**, reduced modulo |M_u|. Include one such residue for every state in the augmented state. At segment entry these are arbitrary residues determined by the entire old history. They are not reset to0, and there is no physical-clock replacement.

The number of augmented states is at most

`s ∏u max(1,|M_u|) ≤ s a^s = D`.

Freeze the segment's menu and let a transition follow the actual true row Pσ. A positive augmented edge has probability at least p. Kill the frozen chain when support changes; also kill on target entry in navigation or component exit in operation. Row-test rejection is not part of this frozen chain; when present in the actual run it only terminates an interval earlier.

The actual finite-history law supplies the next-row kernel even after arbitrary finite stopping histories. Explicitly, for a positive compatible history the accepted cylinder product factorization gives the next-receipt conditional probability Pσ(e,y) by dividing the extended cylinder probability by the current cylinder probability. For a stopping time, partition `{T<∞}` over the countably many `(T,H_T)` values and apply this same calculation. No assertion about unused tapes conditional on K, G_n, or a bare random sample count is made.

## 6. Every dangerous frozen mode has uniform progress

Call a row e mismatching when `Pθ(e,·)≠Pσ(e,·)`. Progress is execution of a mismatching row or a terminal event of the current segment.

First note a graph fact about a closed strongly connected class of the augmented chain. If its projection contains a physical state u, it contains every active action at u: take a positive-length closed walk through an augmented vertex with state u and repeat it. Returning to the same residue entails a positive multiple of |M_u| departures from u, which traverse every cyclic action. Closure projects all true positive successors back into the projected set. This is finite graph reasoning; it does not postulate probabilistic fairness.

### Navigation

Suppose an augmented closed class avoids every progress event. Every projected row then matches θ and σ. Every true positive successor stays in the class and preserves B; equality of rows gives the same properties under θ. Source-wise cyclic coverage contains all active stage actions at projected source states. The accepted fixed-point target-or-exit property, equivalently `fair_recurrent_hits_target`, says this nonempty fair closed projection cannot avoid all θ-target states while having no proper-support exit. But such target entry is terminal. Contradiction.

### Mismatching operation

Suppose some row in the selected E mismatches. A closed class avoiding progress would project to a nonempty set of E-pairs that matches on every used row, includes all retained actions at each projected state, and is closed under candidate successors. The candidate's accepted E certificate is strongly connected for those successors (`NoExit` identifies them with the internal graph). Candidate reachability from any projected state therefore forces every E-state into the projection, and cyclic coverage forces every E-pair. This contradicts the assumed mismatching row. So no such closed class exists.

### Fully matching operation

If every row in E matches, the qualifying certificate for live σ supplies an even minimum on E. At priorities 1 and2 this means **every pair of E is good**. This is the kernel-checked `qualifying_matching_all_good`. The whole segment has zero bad cost.

This safe segment need not be absorbing: the source scans stale rows outside E and may reject later. We skip its zero-cost time but retain any later episode/segment it initiates in the budget. We never bound its physical duration.

### Uniform bound

A finite directed graph in which no reachable closed class avoids progress has a positive path from every nonterminal vertex to progress. Removing repetitions gives a path of at most D transitions when the final mismatch execution/terminal edge is included. Its conditional probability is at least `p^D=r`, uniformly over all finite segment-entry histories and all starting residues. Extra empirical rejection or τ_n stopping can only end a waiting interval earlier. Repeating after blocks of D transitions yields

`P(L>kD | history at an interval's finite start) ≤ (1−r)^k`

for an interval length L until the next progress/segment termination/analysis stop. Thus L is stochastically dominated by D·Geom(r), with geometric support {1,2,...}.

## 7. A deterministic budget of charged waiting intervals

Consider a mismatching execution within a segment before the detecting transition. Once any mismatching pair's **cumulative** count reaches n+m, it is ≥n and greater than the current phase index. Some coordinate has gap >ε+η; observed accuracy and the triangle inequality imply candidate deviation >ε. The exact empirical test therefore rejects on that completed transition unless a support-change or exit guard already ends the segment. This is `mismatch_test_true_of_accurate` plus the checked phase bound.

Hence each pair can produce at most n+m−1 nonterminating mismatch executions in one segment. At most one additional mismatch execution is its final transition, possibly the τ_n-detecting transition where accuracy is no longer available. The coarse total budget `q(n+m)` suffices. Add one interval for termination not already counted as a mismatch. Each dangerous segment is therefore covered by at most `q(n+m)+1` charged intervals.

Enumerate dangerous intervals in chronological order, skipping fully matching zero-cost segments. All finite interval starts are stopping times: σ, the selected menu, row-equality classification, counters, test outcomes and phase/support guards determine them from actual histories. Infinite starts contribute padded length0. The enumeration contains at most

`J_n=H_n(q(n+m)+1)`

intervals. Their lengths L_i satisfy `C_n ≤ Σ(i≤J_n)L_i`. Their conditional geometric bound is uniform. Independence between different intervals is neither claimed nor needed.

## 8. Stopped moments

For G~Geom(r), `E G²=(2−r)/r²≤2/r²`. Conditional geometric domination at each finite start and zero padding give `E L_i²≤2D²/r²`. The deterministic inequality `(Σ_i L_i)²≤J_n Σ_i L_i²` yields

`E C_n² ≤ 2D² J_n²/r²`.

More generally `E G^k≤k!/r^k`. One direct justification is `g^k≤k! binom(g+k−1,k)` and summing the geometric generating series; k≥1. Applying `(Σ_i L_i)^k≤J_n^(k−1)Σ_i L_i^k` gives

`E C_n^k ≤ k!(D J_n/r)^k`.

No conditional bound given G_n is used here. The stopped controller is bounded under the original true-model law.

## 9. Shell transfer and explicit constants

The disjoint measurable events `{K=n}`, n≥1, cover up to a null set. On each of them C=C_n. For n≥2, `{K=n}⊆G_(n−1)ᶜ`; for n=1 its probability is at most1. Cauchy–Schwarz therefore gives

`E[C·1(K=n)] ≤ sqrt(E C_n²) sqrt(P(K=n)) ≤ sqrt(2)D J_n/r · sqrt(A) z^(n−1)`.

The final bound includes n=1 because A≥1. Summing by Tonelli proves the first series bound. Set j=n−1; then

`J_n/(2m)=q j² + (q(2m+3)+1)j + (m+2)(q(m+1)+1)`.

Use `Σz^j=1/(1−z)`, `Σjz^j=z/(1−z)²`, `Σj²z^j=z(1+z)/(1−z)³` to obtain the displayed closed form. `ShellCostTransfer.shell_cost_transfer` formalizes the ENNReal Cauchy–Schwarz/Tonelli step without assuming the cost finite or the shells independent/stopping.

For any positive integer d, use the stopped 2d-th moment instead:

`E C^d ≤ sqrt((2d)!)(D/r)^d sqrt(A) Σ(n≥1) J_n^d z^(n−1) <∞`.

The remaining series is polynomial times geometric. This establishes every finite integer moment, without asserting an exponential moment of C or a bound on physical time of the last bad visit.

## 11. Existence characterization

Within exactly this finite observed-state hidden-model interface and coBüchi encoding, the following have the same region:

1. membership in the accepted computed winning region
2. existence of a common lawful almost-sure coBüchi policy in the accepted seeded class
3. existence of a common lawful policy with finite expected total bad visits under every live model
4. existence of a deterministic history policy whose bad count has every finite integer moment under every live model

The predecessor proves 1⇔2. This theorem proves 1⇒4⇒3. Finite expected nonnegative count implies a.s. finite count and therefore coBüchi, so 3⇒2; that count/parity implication is kernel-checked in `ActualBadCount`. All forward witnesses are fixed before σ is quantified. Since B0 is finite, arbitrary finite priors over B0 preserve these finiteness assertions by a finite mixture.

This is an existence equivalence; an arbitrary a.s.-winning policy need not itself have finite expected bad cost.

## 12. Negative controls and nonclaims

- A one-state, two-action system admits the following different a.s.-coBüchi policy: draw T with `P(T=n)=1/((n+1)(n+2))`, take the bad action for T rounds, then good forever. T is finite a.s. but `E T=Σ(k≥1)1/(k+1)=∞`. The actual generated controller can select the good target immediately. Thus a.s. success alone is insufficient; our proof uses the source's quantitative structure.
- In a winning general-parity component with priorities0 and1, the priority1 action may recur forever. The coBüchi target-all-good implication fails. A kernel-checked finite countercontrol records this boundary.
- A sole-action two-state chain remains in its bad start with probability1−p and enters an absorbing good state with probability p. It is an admitted singleton-model controller instance with expected bad count1/p. A transition-probability-independent bound is impossible.
- This result does not establish finite physical stabilization time in expectation, finite controller memory, an executable extraction of Classical.choice, a sharp/minimax cost, or robustness uniformly as the row margin or positive probabilities vanish.
- All graph and moment reasoning is for static hidden models with fully observed physical states. No general POMDP/hidden-state theorem is asserted.
