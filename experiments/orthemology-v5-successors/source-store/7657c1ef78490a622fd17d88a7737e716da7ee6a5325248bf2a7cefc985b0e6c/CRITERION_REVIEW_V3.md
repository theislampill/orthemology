## Resolution of V2 finding F3

The original transition installed an exact payload under a hard-coded checker. The new `RuleState` instead has an installed rule, rule version and rule history, separately from draft contents and draft revision. `InstallCommand` binds expected rule and version, new rule, actor, destination, target, authorization epoch, operation and time bounds. The current grant must specifically allow `install-criterion`.

Rule identity is a constructor in a two-term language, interpreted by explicit definitions. NORMALIZED_LF means equality after stripping trailing LF; EXACT means byte equality. No arbitrary function or executable payload receives trust merely because it carries the string C1. The fixed evaluator itself remains trusted implementation support.

The code update changes exactly rule, rule version and rule history. The Lean frame theorem preserves source, draft, draft revision, standard, destination, epoch, grant, revocation, clock and unrelated state. The entire State remains unchanged on rejection. Independent full-record comparisons agree with the claimed frame.

For every finite source, appending LF changes its sequence while normalization erases the difference. The generic Lean lemma supplies a false-acceptance witness for C0 and proves EXACT's universal adequacy. After a valid normalized-to-exact installation, the previously accepted extra-LF candidate is rejected while the exact source remains accepted. The actual pinned-source test additionally rejects a first-byte mutation before and after. These are interpreter decisions, not merely metadata assertions.

A bad existing draft remains bad and untouched after successful criterion installation. The extension expressly distinguishes that successful rule repair from restoration of the draft. A separate `replace-derived` grant is needed to repair bytes, and the two operation scopes reject one another's grants. The current code does not claim a formally verified composed deployment that automatically performs both operations.

The remedy remains authorized by the retained exact-recovery standard and current model grant. It therefore fills the operational-instance gap while leaving Candidate E's stronger full-basis existence burden unchanged.
