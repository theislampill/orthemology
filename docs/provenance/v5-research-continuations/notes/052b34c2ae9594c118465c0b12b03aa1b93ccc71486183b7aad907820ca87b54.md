# Positive-error action disclosure: fixed codebooks and shared randomness

Sixth-tranche bounded mathematical continuation of the reviewed restoration
architecture and action-sufficient disclosure supplement. Ordinary proofs; no
canonical adoption, production deployment or claim of new general mathematical
novelty. The fixed-codebook frontier is not fully classified below.

## 1. Two distinct communication contracts

There are u roots, at most b corrupt, with 0<=b<u. Root identity, governing-rule
diagnosis, target and action binding are already fixed. In the inherited model,
u=n-k and b=f-k; n=2f+1, so u=2b+k+1. A cooperative informed sender knows the
corruption set C and communicates one of M distinguishable messages before the
receiver's compulsory first repair attempt. A corrupt-root attempt is unsafe.
No further observation, probe, message or safe fallback precedes it.

A positive-error message labels a lottery or an action choice; it need not and
must not assert that every possible selected root is intact. Cooperation means
the sender chooses the best available message under the specified risk contract.
If every message is instead required to certify certain safety, a positive-error
protocol does not meet that stronger specification. Aborting is not a free
option: it changes the eventual-action requirement or counts as failure.

### Fixed codebook, receiver-private randomness

For each message m the receiver has a fixed probability distribution p_m on the
u roots. Its private draw is not revealed to the sender before the message.
The sender's optimal conditional loss is min_m p_m(C), where
p_m(C)=sum_{i in C} p_m(i). A randomized sender cannot improve this minimum.

Define

V_fixed(u,b,M) = inf_{p_1,...,p_M} max_{|C|<=b} min_m p_m(C).

Because the masses are nonnegative, the maximum may be restricted to |C|=b.
All protocol seeds are generated after the common report view is fixed, or
have a law independent of C conditional on that view. Sender and receiver private
seeds are independent apart from an explicitly declared shared seed. Otherwise,
conditioning a report on a correlated seed could introduce an uncounted integrity
channel. All other distinguishable channels, including timing and silence, must
be counted in M. Independent private randomness supplied later to the receiver is
already part of p_m.

### Shared randomness visible to the informed sender

Let Z be a pre-shared random seed independent of the static C. Both parties see
Z. At seed z, the receiver has distributions p_{m,z}, and the sender can choose
m using both C and z. Define

V_shared(u,b,M) = inf_protocol max_{|C|<=b} E_Z[min_m p_{m,Z}(C)].

The adversary commits to C before Z is realized; it need not be unknown to the
sender. Receiver-private randomness may remain after conditioning on Z. This
is a strictly stronger resource class than one fixed codebook. The earlier
zero-error threshold agrees across these classes; their positive-error curves
can differ sharply. A common random menu is an additional protocol resource,
not something obtained by copying a report or assuming source omniscience.

## 2. The proposed fixed-codebook formula is not generally optimal

The M-1 singleton choices plus uniform remainder construction gives

V_fixed <= (b-M+1)/(u-M+1), for 1<=M<=b+1.

It is valid but not always optimal. Take u=8,b=3,M=2. Partition the roots into
two blocks of four, with one message decoding to the uniform lottery on each
block. Any three corrupt roots split between the blocks. If they split 0/3,
the sender chooses the clean block and risk is zero. If they split 1/2, the
sender chooses the one-corrupt block and risk is 1/4. Thus worst-case risk is
exactly 1/4, strictly less than the proposed 2/7.

This is inside the original restoration parameters: f=4,k=1 gives u=8,b=3.
Overlapping support is unnecessary for the counterexample. Nothing here proves
that overlap cannot improve the best disjoint-block construction in other cases.

## 3. A general fixed-codebook lower bound

**Theorem F1.** For 1<=M<=b+1,

V_fixed(u,b,M) >= (b-M+1)/u.

### Proof

Fix arbitrary distributions p_1,...,p_M and write N=b-M+1, t=N/u. If N=0 the
claim is immediate. For N>0 consider the nonempty compact polytope

P = {x in [0,1]^u : sum_i p_m(i)x_i >= t for every m}.

The uniform vector x_i=t is feasible and has sum_i x_i=N. Minimize sum_i x_i on
P and choose an optimal vertex x*. It has at most M strictly fractional
coordinates: if there were more, the active distribution inequalities impose
at most M linear equations on those coordinates, leaving a nonzero direction
for a sufficiently small positive and negative feasible perturbation, contrary
to extremality. Bound constraints on coordinates already equal to0 or1 are held
fixed; inactive inequalities retain slack under a small enough perturbation.

Let z be the number of coordinates equal to1, and r the number strictly between
0 and1. If r=0, then z<=N<=b. If r>0, the strictly positive fractional mass and
sum_i x*_i<=N imply z<=N-1; therefore z+r<=N-1+M=b. Round every positive
coordinate upward to1. The resulting subset C has size at most b and, by
nonnegativity, p_m(C)>=t for every m. Padding C to size b cannot reduce a mass.
Hence max_C min_m p_m(C)>=t for this arbitrary codebook, proving the theorem. ∎

This uses a standard finite linear-programming vertex argument. The probability
simplex is continuous; no finite probability grid is being passed off as a
proof of the lower bound.

## 4. An exact infinite family for fixed codebooks

**Theorem F2.** Let N=b-M+1>=0 and d=gcd(u,N). If d>=M, then

V_fixed(u,b,M)=N/u.

For N=0, M=b+1 and the zero-error protocol already proves the claim. For N>0,
put q=u/d. Partition u roots into M nonempty blocks whose sizes s_j are positive
multiples of q. This is possible because d>=M. For example, use M-1 blocks of
size q and one of size (d-M+1)q. Let message j select uniformly in its block.

Set t=N/u. Each threshold t s_j is an integer, and their sum is N. To make every
block's corruption fraction strictly exceed t requires at least t s_j+1 corrupt
roots in every block, totaling N+M=b+1. A b-root corruption set cannot do that.
Thus at least one message has risk at most t. Conversely, choose t s_j corrupt
roots in each block and pad to b; every block initially has fraction t, so worst
risk is at least t. The codebook attains t; F1 proves global optimality. ∎

Examples:

- u=8,b=3,M=2: d=2, blocks4+4, exact risk1/4
- u=9,b=4,M=2: d=3, blocks3+6, exact risk1/3, below singleton bound3/8
- M=1: the formula reduces to b/u, achieved by one uniform distribution
- M=b+1: the exact value is0, agreeing with the zero-error threshold

For an arbitrary block partition, its exact worst-case risk is

max_{0<=c_j<=s_j, sum c_j=b} min_j c_j/s_j.

This provides additional constructive upper bounds by finite integer allocation.
It includes singleton-menu constructions and can outperform equal blocks. The
best partition is not established here as globally optimal among all overlapping
or nonuniform codebooks. In the remaining parameter cases, the rigorous interval
provided here is F1 below and the best supplied constructive upper bound above. For example, this packet
proves 4/11 <= V_fixed(11,5,2) <= 3/8 via blocks3+8, but does not close that gap.
Similarly, blocks1+4+4 give 2/9 <= V_fixed(9,4,3) <= 1/4 without establishing
that the upper value is optimal.

### The exact last positive-error boundary M=b

**Theorem F3.** For 1<=b<u,

V_fixed(u,b,b)=1/(u-b+1).

The M-1 singleton plus uniform remainder construction attains this value. For
the lower bound, prove by induction on M that for any M distributions on u>M
roots, some subset of at most M roots has mass at least t=1/(u-M+1) under every
distribution. This subset is the adversary's corruption set, not a proposed
receiver action.

For M=1, a largest-mass root has mass at least1/u. For M>1, first suppose one
distribution p_j assigns some root r mass at least t. Include r and delete that
already satisfied distribution. For every remaining distribution p, let a=p(r).
If a<1, normalize p on the u-1 remaining roots by dividing by1-a. If a=1, the
original distribution is already satisfied by r; install any auxiliary residual
distribution for the induction. The induction on M-1,u-1 has the same threshold
1/((u-1)-(M-1)+1)=t, and returns at most M-1 additional roots. For a<1, their
union with r has original mass at least a+(1-a)t>=t; the a=1 case is immediate.

In the other case, every coordinate of every distribution is strictly below t.
Any M-root subset then has mass strictly greater than

1-(u-M)t=t

under every distribution, since its complement has u-M>=1 coordinates, each
strictly less than t. Thus such a subset is an adversarial witness. This finishes
the induction and the lower bound. ∎

This completely identifies the last nonzero point of the fixed-codebook curve,
even when the arithmetic condition in F2 fails. It does not close the remaining
intermediate cases 1<M<b. The rational controls implement the induction itself,
including mass-one residuals, rather than merely checking candidate optima.

## 5. Complete frontier with shared randomness

**Theorem S1.** If 1<=M<=b, then

V_shared(u,b,M) = binom(b,M)/binom(u,M).

For M>=b+1 the value is0; use only b+1 messages if more are available. These
statements include arbitrary receiver-private randomization and randomized
message selection. For b=0, one message already suffices with zero risk.

### Constructive upper bound

Use Z to select an M-element subset T of roots uniformly, with a pre-agreed
ordering and message labels. The sender sees C and T. If T has an intact member,
it sends that member's label. If all T are corrupt, every available label fails.
For any fixed C of size b, the failure probability is

P(T subset C)=binom(b,M)/binom(u,M).

Smaller C only reduce this probability. If M=b+1, T cannot be entirely corrupt,
so failure is zero. The decoder can be deterministic once Z and the message are
fixed. The sender does not claim an unsafe root to be safe in the failure case:
the labels are action choices under a positive-error contract.

### Lower bound against every shared-random protocol

For analysis, average the adversary uniformly over the b-element subsets C,
independently of Z. Fix z. Let p_1,...,p_M be its receiver distributions, including
any private randomness. Since each p_m(C) lies in [0,1],

min_m p_m(C) >= product_m p_m(C).

Draw independent representative roots R_m from p_m solely for the proof.
Then product_m p_m(C) is the probability that all representatives belong to C.
Conditional on the representatives, their set has r<=M distinct roots. A uniform
b-set contains that set with probability

binom(b,r)/binom(u,r).

For M<=b<u this ratio is nonincreasing in r, so it is at least
binom(b,M)/binom(u,M). Average over representatives and then z. The mean loss
against the uniform static adversary is at least the claimed value. Therefore
some single fixed C has expected loss at least that value. We have not allowed
the adversary to observe the realized seed before choosing C.

An encoder that randomizes its message cannot beat the minimum conditional
message risk. Thus the bound covers that randomization too. Together with the
uniform random-menu construction, this proves equality. ∎

### A strict resource separation

At u=8,b=3,M=2,

V_fixed=1/4, while V_shared=binom(3,2)/binom(8,2)=3/28.

Both protocols communicate one of two labels, but only the second gives the
informed sender access to the random menu before it selects the label. Treating
a mixture of codebooks as one fixed pair of averaged decoder distributions loses
that informed conditioning and is invalid. Sharing random information can change
what an agent is able to do with its integrity knowledge, even though neither
protocol changes the true target or increases the number of acquisition roots.

## 6. Agency, source and identity crosswalk

The gain is operationally substantive: information about C, control over a
bounded message, common reference to the chosen roots, and the opportunity to
condition the message on Z jointly alter attainable action risk. Bare possession
of knowledge and bare power, without this coordination, do not supply the
protocol. It does not follow that one metaphysical bearer must own every role.

The source must actually have appropriate integrity knowledge and act according
to the protocol; capacity for disclosure does not establish a disclosure
occurrence. Correct source attribution alone does not establish truthful
integrity information. The common dictionary, root labels, current version,
message fidelity, recipient authority and causal repair effects remain separately
warranted premises. Numerical identity between sender and recipient is unnecessary.
Copies of one carrier neither add distinct message actions nor manufacture the
shared-random conditioning relation.

No binomial expression here is a posterior credibility assigned to a real
source. The uniform adversary is a lower-proof device; the achieved upper bound
is frequentist risk over explicitly supplied random menus for every fixed C.
No independence among actual root failures is assumed. What is required is that
C be fixed before and independent of the protocol seed. If the adversary sees T
and then selects C with M<=b, it can corrupt every offered root and force loss1.
Likewise, a new source-corruption or common-gate failure must enter the fault
model; calling the encoder trusted is an additional premise, not a theorem.

Objective norm-fixing determines which action effects count as repair and which
loss is relevant. These bounds do not authenticate that target or import a
prediction-loss theorem into destructive-action loss. This continuation adds a strengthened informed-sender/shared-random interface;
it does not assume that the original R5 architecture already supplies that
resource. The specified roles can still be realized separately, and no
one-bearer necessity or defeat of the retained R5 control is established.
The result establishes no actual world, divine attribute, revelational identification,
policy adoption or repair of a human noetic structure.

## 7. Evidence and remaining classification

The rigorous outputs are the counterexample, F1, F2, the M=b boundary F3, and
complete S1. The general
fixed-codebook value outside the F2 family and the F3 boundary remains open in this packet. In particular, no theorem excludes gains from overlapping supports
or nonuniform lotteries over the best block construction.

Exploratory mixed-integer programming supports some small-instance values, but
floating-point solver status is not a proof certificate and is not used to assert
those optima here. A separate exact-arithmetic checker verifies the constructive
risks, the arithmetic-family equality, random-menu risks and the representative
product identity on bounded cases. The general proofs above control their stated
scope. Prior restoration v1 remains unchanged.
