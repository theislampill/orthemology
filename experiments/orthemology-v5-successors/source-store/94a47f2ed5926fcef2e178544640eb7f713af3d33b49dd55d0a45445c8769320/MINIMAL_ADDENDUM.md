# From compact completion to finite recipient warrant

## Scope

This ordinary mathematical addendum delimits the finite evidence supplied by the compact-continuous inverse-limit correction. It does not introduce a new calculus or checker. The represented state, the question asked of it, the recipient's evidence access and the governing release rule must be specified separately.

## 1. Robust answers have finite witnesses

Let `K_0⊇K_1⊇...` be nonempty compact subsets of a Hausdorff space, and let `S=⋂_n K_n`. If U is open and contains S, then some finite K_N is contained in U. Otherwise the closed subsets `K_n\U` of compact K_0 would have the finite-intersection property and a common point outside U, contradicting S⊆U.

Apply this to finite-extension images at one fixed coordinate, or to the actual compact images of a fixed finite observation block. If a specified answer is constant throughout an ambient open neighbourhood of all survivors, a finite range already warrants it for every compatible realization. Full state uniqueness is unnecessary. Continuity only on the survivor set is insufficient.

For a continuous real observable g and threshold τ, the answer regions `{g<τ}` and `{g>τ}` are open. Equality is not covered by this argument. An effective upper-compact presentation of the ranges and effectively open answer regions make the finite containment search terminate on robust instances. These are substantive represented-input assumptions. A numerical convergence rate need not be separately supplied; ordinary compactness alone supplies no effective names or algorithm.

## 2. One family separates the state from its exact query

Let P be any well-formed unary P02-L1 program. Its bounded-loop syntax makes every finite evaluation total. Set

`b_P(i)=Eval(P,i) mod 2`, `X_i=[0,1]`, `f_(P,i)(x)=(x+b_P(i))/2`.

Every input is therefore a valid compact-continuous inverse system. Its unique realization has

`x_(P,i)=Σ_(r≥0) b_P(i+r)2^−(r+1)`.

Compatibility follows by splitting the series. Uniqueness follows because unwinding n compatibility equations bounds the difference between any two candidate values at coordinate i by `2^-n`. The state is uniformly computable, with that explicit error bound and contraction rate.

For coordinate zero, finite inverse composition has the exact interval

`K_(0,n)=[V_n/2^n,(V_n+1)/2^n]`,

where `V_0=0` and `V_(n+1)=2V_n+b_P(n)`. Extending depth composes the next map on the right. Thus a receiver who replays the finite coefficients can establish a strict comparison to `τ=p/d`, d>0, by checking

- Below: `(V_n+1)d < p2^n`
- Above: `V_n d > p2^n`

These checks are sound and **exactly complete for their respective strict claims**: if x_P is on either strict side, choose n with `2^-n<|x_P−τ|`. The corresponding endpoint lies on that side. The gap need not be provided to the search. At equality neither strict witness exists; prolonged search or resource exhaustion is not an equality answer.

The program, threshold, scalar interpretation, model/version, recipient and release rule must remain bound to the independently expected request. Exact equality checks preserve that declared binding; they do not establish its worldly truth or authority.

## 3. Global finite proofs remain eligible, but cannot be uniformly complete

A finite two-counter instruction table can be translated effectively into a unary P02-L1 program that simulates exactly n+1 current instructions and outputs 1 iff its latched halt bit first changes on the last iteration. The construction uses only finite instruction cases, snapshotted program counters and bounded loops. Hence its bit is 1 exactly at the first halting stage n.

For this admitted family, x_P is zero exactly when the source machine never halts; if it halts at t, x_P equals `2^−(t+1)`. All the compactness, uniqueness, computability and known-rate facts above still hold.

If a sound computably enumerable verifier of arbitrary finite certificates were complete for x_P=0 throughout this family, enumerating accepted certificates would semidecide nonhalting. Thus no such uniformly complete verifier exists. This is not a ban on global proofs: a constant-zero program or a verified nonhalting invariant can have a finite equality proof. The obstruction concerns effective completeness across the whole family, not the availability of proofs for individual inputs.

## 4. The recipient consequence

A verified prefix 000 gives the interval [0,1/8], sufficient to release `x_P<1/4` under an independently admitted rule requiring that strict bound. It does not, by its interval calculation alone, warrant x_P=0: a later 1 preserves the prefix while making the scalar positive. If the rule demands exact zero, an additional genuine global proof is needed; the strict bound does not change that rule.

This is the precise interface between infinite determination and finite warrant. It supplies a positive use and a matched boundary countercontrol for the same representation. It supplies no new collective acquisition, communication-cost advantage, physical intervention authority or empirical interpretation of x_P.
