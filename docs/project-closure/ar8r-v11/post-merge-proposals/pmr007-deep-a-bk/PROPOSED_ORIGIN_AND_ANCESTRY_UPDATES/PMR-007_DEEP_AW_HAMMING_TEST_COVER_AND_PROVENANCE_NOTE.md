## Mathematical ancestry

The exact substitution and erasure thresholds are the classical finite-code
Hamming-distance criteria:

```text
minimum distance >= 2f+1  <=> correction of f unmarked substitutions;
minimum distance >= f+1   <=> correction of f marked erasures.
```

Selecting roots so every hypothesis pair is separated with the required
multiplicity is a pair-separation multicover.  At `f=0` it is the Test Cover
problem already used in Deep AS.  Round AW is therefore a provenance-root
application and cross-lane integration, not an independent coding theorem.
