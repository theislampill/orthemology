# Posterior deterministic reachability from a fixed hidden tape checker

Ordinary candidate reduction, 2026-10-01. This is submitted for independent mathematical and prior-art review. It must not be credited merely because general POMDP reachability is EXPTIME-hard. The construction below proves the required posterior-deterministic restriction directly. No historical novelty is asserted.

## Claim and source problem

Almost-sure reachability in finite rational posterior-deterministic POMDPs with an explicitly supplied mixed initial belief is EXPTIME-hard, already for an observable absorbing target and a constant observation alphabet. Together with the retained EXPTIME upper bound for attained hidden parity, this would give EXPTIME-completeness for that initial-belief interface, including the visible absorbing-target special case.

The reduction starts from a binary-branching polynomial-space alternating Turing machine in the standard clock-bounded normal form: every computation reaches acceptance or rejection within an exponential number of steps, regardless of existential and universal branch choices. Acceptance of this normal form is EXPTIME-hard. Chatterjee, Doyen and Henzinger, *Qualitative Analysis of Partially-observable Markov Decision Processes* (2010), section4, explicitly describes the polynomial-space clock transformation and the EXPTIME-complete bounded source problem. Primary manuscript: https://lsv.ens-paris-saclay.fr/~doyen/papers/Qualitative_Analysis_of_Partially-observable_MDP.pdf. We use that source fact, not an unexamined claim that their whole POMDP reduction is posterior-deterministic.

The clock is part of the simulated machine's polynomially many tape cells and transition program. An exponential counter value is represented by polynomially many bits. No exponential computation tree or horizon table is written into the POMDP input. Equivalently one can reduce from a fixed polynomial-space alternating decider with a clock transformation applied uniformly to its input instances. The space bound m is polynomial in the original input length.

## Source ancestry and precise adaptation

The hidden single-cell checker is classical, not a new construction. Chatterjee, Doyen, Henzinger and Raskin, *Algorithms for omega-regular games with imperfect information* (LMCS 3(3:4), 2007), section 5, explicitly chooses one private tape cell initially, retains its index and symbol, publicly exposes the selected machine transition at universal steps, and sends false claims to a rejecting sink. Primary source: https://digicoll.lib.berkeley.edu/record/137173/files/EECS-2006-89.pdf ; journal manuscript https://arxiv.org/abs/0706.2619. The initial hidden-choice row has multiple successors under one observation. The post-initial transition families expose sufficient public transition information to determine each successor from the previous hidden state.

Our construction is a streamlined adaptation of that checker. It puts the initial checker choice directly in the explicitly supplied initial belief, eliminating the non-PD initial row. It also uses the clock-bounded source and probabilistic universal-choice argument described by CDH2010. The direct proof below checks a constant-observation variant rather than assuming that every feature of either published reduction survives automatically. This is a restriction-preserving complexity corollary of classical constructions; historical priority for the exact corollary has not been exhausted.

## 1. Machine interface

Let the machine have nonterminal controls Q, tape alphabet Gamma, m cells, known initial contents tau_0(1),...,tau_0(m), initial control q0 and initial head h0. Each q is existential or universal. For each q and read symbol gamma there are two transitions indexed by b in{0,1}; deterministic transitions may be duplicated. A transition specifies a written symbol, next control and head movement. Terminal outcomes are Accept and Reject. A move beyond the declared tape bound is rejecting.

The machine's complete configuration contains the whole tape, control and head. Its actual read symbol is the current head cell. Existential transitions are chosen by the accepting player; both universal successors must accept. The clock guarantee eliminates infinite-play ambiguity.

## 2. Polynomial POMDP construction

The nonterminal hidden states are

    (i, sigma, q, h),

where i is one checked cell, sigma is its stored symbol, q is the common machine control and h the common head position. Add two absorbing states TOP and BOTTOM. There are at most m^2 |Gamma| |Q|+2 states. Actions are pairs (gamma,b) in Gamma×{0,1}. The observations are E,U0,U1,ACC,REJ.

The initial belief assigns probability1/m to each

    (i,tau_0(i),q0,h0),     1<=i<=m.

The checked index is selected only by this initial belief. It is never resampled. All these weights are strictly positive rational numbers. If the machine is initially terminal, handle that trivially by a one-state accepting/rejecting POMDP instead; otherwise q0 belongs to Q.

At state (i,sigma,q,h), action (gamma,b) is processed as follows.

1. If i=h and sigma!=gamma, transition to BOTTOM with observation REJ and probability1. This checker detects a false claim about its own cell.
2. Otherwise, if q is existential, apply machine transition b on the claimed gamma deterministically. If q is universal, choose c=0 or1 with probability1/2 and apply transition c on gamma; the action's b is ignored.
3. Update sigma to the written symbol exactly when i=h; otherwise leave it unchanged. Keep i fixed. Update q and h according to the selected machine transition.
4. First check the tape bounds: an out-of-bounds next head always uses BOTTOM and REJ, even if the proposed next control is accepting. For an in-bounds move, if the next control accepts, use TOP and observation ACC; if it rejects, use BOTTOM and REJ. Otherwise use the resulting tuple and observation E for an existential step, or Uc for a universal step.

TOP loops under every action with observation ACC. BOTTOM loops under every action with observation REJ. Duplicate transition contributions are added. The target is{TOP} and is observable: ACC occurs exactly on entry to or residence in TOP.

The complete joint table T(observation,next_state|state,action) is explicitly writable in polynomial time and size. Its probabilities are0,1/2,1 after merging duplicate outcomes. The uniform initial belief has a polynomial binary encoding. All actions remain available; malformed simulation choices are handled by rejecting transitions.

## 3. Posterior determinism

Fix one old hidden state and action. A failed read check has one possible successor. An existential step has one successor. In a universal step, nonterminal branch0 and branch1 carry distinct observations U0 and U1. If multiple branches emit ACC, all of them go to the single TOP state; if multiple branches emit REJ, all go to the single BOTTOM state. No other state emits either terminal observation.

Therefore for every fixed old state, action and observation, there is at most one positive-probability next state. This is precisely posterior determinism for the joint transition/observation kernel. It is not merely deterministic dynamics after revealing the hidden checked cell. That index remains unobserved.

A tempting alternative initial transition from one known state to all checkers under one common observation would violate this property. The reduction uses the mixed initial belief allowed by the decision problem. With a known initial state, posterior determinism instead permits exact state tracking, so this initial-belief distinction is essential.

## 4. Completeness

Suppose the alternating machine accepts. A POMDP policy stores or reconstructs the full simulated configuration from the known input and the public history. It claims the actual symbol under the head. At an existential control it chooses an accepting machine branch; at a universal control it observes which branch nature selected. Nonterminal universal observations identify that branch, and terminal observations make further reconstruction irrelevant.

Every checker agrees with every truthful read. Each tuple tracks its own correct cell and the same q,h. Every possible branch sequence therefore simulates an accepting computation and reaches TOP within the clock bound. This holds for every initially selected checker, hence almost-surely under the initial belief. The policy may use unbounded or exponential memory; no small-memory assertion is needed for this reduction.

## 5. Soundness and why the hidden checker cannot be learned safely

Consider an almost-surely winning policy, allowing independent randomisation and full observed history. Before any false read claim, all checked indices induce exactly the same honest observation probabilities: an existential step is deterministic and a universal nonterminal bit is fair. All originally possible checkers remain possible with positive probability on every honest feasible prefix.

If the policy makes a first false read claim with positive probability at such a prefix, then the initially selected checker equal to that head position has positive conditional probability. It detects the false claim and enters the absorbing BOTTOM state. This creates a positive failure probability, contradicting almost-sure success. Thus no such first false claim can have positive probability. The same argument rules out using deliberate false claims as a safe probe to discover the checker: the affected checker is irreversibly lost.

For precision with randomized policies, take their common behavioural action distribution at each positive observed prefix. Choose one positive-probability action at every honest reachable prefix. Every finite path generated by these choices and positive universal branch outcomes has positive probability in the original policy, since it is a finite product of positive conditional probabilities. Consequently the resulting pure history policy can neither make a false first claim nor reach a rejecting machine outcome on any universal branch: either event would be a positive failure event of the original policy for at least one initially positive checker. This extraction does not assume a uniform positive lower bound on all chosen action probabilities.

The extracted policy therefore induces legal existential machine choices. Every universal branch halts by the source clock guarantee. None may reject, so all accept. This is a winning strategy for the alternating machine. Equivalently, a pure-policy reduction can use the classical Borel-objective derandomisation theorem, but no such citation is required by the finite positive-path extraction above.

The control cannot infer a checked index along truthful histories because their observations are checker-independent. Numerical posterior reweighting does not create a loophole: each checker has the same likelihood on those prefixes. The proof does not assume that a failing probe's counterfactual branch will actually be observed before declaring it invalid; its positive probability alone defeats almost-sure winning.

## 6. Consequences if the candidate passes review

The reduction establishes EXPTIME-hardness with mixed initial belief and visible absorbing reachability. Assign priority2 to TOP and priority1 elsewhere. Because TOP is absorbing, minimum-even parity is equivalent pathwise to reaching TOP. Thus the lower bound applies to the retained hidden-parity problem. Combining with the already reviewed EXPTIME upper bound would close the previous PSPACE-hard/EXPTIME interval as EXPTIME-complete.

This does not improve value-approximation bounds, cover known-state initialisation, show finite expected lifetime odd-priority cost for general parity, or establish a formal complexity theorem in Lean. The lower-bound source is classical; any new contribution here is the carefully checked restriction-preserving application, subject to a wider historical comparison.

## 7. Adversarial finite checks

An independent review checker builds the explicit joint kernel from small clock-bounded machines and compares two independent decisions: direct perfect-information alternating acceptance on full configurations, and finite-horizon sure reachability in the constructed mixed-belief model. The horizon is valid for these finite acyclic fixtures. It is not a substitute for the ordinary reduction proof or a general belief-support algorithm for infinite-horizon almost-sure reachability.

Required countercontrols are: omit a checker from the initial support; reveal the checker for free; omit local read validation; suppress the universal-branch observation; replace the mixed initial belief with an unobserved checker-selection transition from a known state; allow out-of-bounds accepting moves; and remove the bounded-halting clock. Without the clock, a public universal state with one self-loop branch and one accepting branch is almost-surely accepting under fair randomisation although an adversary can loop forever. These test the actual hypotheses rather than simply counting successful examples.
