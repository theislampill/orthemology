## Exact ordinary countermodels

1. **An almost-sure finite cost need not be integrable.** In a finite observed fair-coin system, a deterministic history policy can wait for the first one, recording its index N, then perform 2^N bad actions and switch permanently to a good action. Here P(N=n)=2^-n, every run outside the all-zero null tape eventually uses only good actions, and E[2^N]=sum(n>=1) 1=infinity. This is a counterexample to inference from qualitative coBüchi alone, not a counterexample to the particular accepted phase controller.

2. **Adaptive sample-count conditioning changes the law.** Let two bits be independent fair coins and select N=1 if the first bit is one, otherwise N=2. The conditional empirical means are 1 given N=1 and 1/4 given N=2. Neither is the original mean 1/2. The valid raw-prefix identity does not license a conditional iid assertion.

3. **A last-error cutoff is not generally a stopping time.** For a two-observation error process, let K be one plus the last error position, using K=1 if there are no errors. Prefix [0] has completions [0,0] and [0,1] with different membership in {K<=1}; that event is not determined after the first observation. In the proposed cost proof, the analysis stopping time instead detects an already acquired deviation. Its predicate can depend on the fixed true model for analysis without becoming an executable hidden-model detector.

4. **No probability-independent hitting bound.** A two-state rational chain that leaves a bad state with probability p=2^-k has mean departure time 2^k. Finiteness for each fixed positive p is compatible with arbitrarily large expectation across inputs.

5. **No general parity-to-odd-count implication.** A recurrent component whose minimum priority is 2 may retain and visit priority 3 forever. Only the 1=bad, 2=good coBüchi specialization licenses elimination of all bad pairs from a fully matching qualifying component.

6. **Action and acquisition clocks differ.** Pair rejection (00 -> one; 01 or 10 -> zero; 11 -> retry) gives accepted probability 1/3 and mean 8/3 acquired bits. Each finite pair horizon has a nonzero pending mass 4^-K. The endless 11 tape never accepts. Giving every first-bit wait tick a bad label makes bad physical ticks recur forever, even when every accepted abstract action is good. A receipt-only result must not be presented as a physical-clock coBüchi result.

7. **Mean acquisition cost cannot be multiplied without the right conditional contract.** Read a fair bit B and then consume 100 additional unused bits only when B=1. Then E B=1/2, E L=51, and E(BL)=101/2 > (E B)(E L)=51/2. An original state/action cost is predictable before its receipt; a receipt-dependent cost is a different object.

8. **Source counters cannot be replaced by physical time.** On deterministic alternation between states 0 and 1, cycling two actions by t mod 2 never uses action 1 at state 0. Cycling by the number of departures from each source uses both actions. A finite-state reduction must retain each source counter's residue, with its actual entry offset.
