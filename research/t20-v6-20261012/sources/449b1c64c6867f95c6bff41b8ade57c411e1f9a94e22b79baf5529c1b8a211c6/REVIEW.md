## Independently checked result

`exists_primrec_rational_shift` says: for every fixed family F jointly primitive recursive in parameter e, observation n, and finite word, and every fixed natural a,b with 0<b and a≤b, there is a single ternary LOOP program p. Its concrete specialization map `parameterIndex p` is primitive recursive in e, and every specialized numeric index has pointwise output exactly the unary-tag shift of `output (F e)`. Its actual fair-source pushforward measure has defect a/b+(1−a/b)d_base.

`exists_primrec_pi3_threshold_reduction` composes this with the existing jointly PR `pi3PrefixValue R`. For each fixed jointly PR four-place predicate R and fixed a<b, it supplies an actual primitive-recursive numeric map f such that defect=fixed threshold iff ∀i∃s∀t R, defect≤threshold iff the same, and defect>threshold iff ∃i∀s∃t ¬R. The existing Pi3 law supplies the zero/positive-defect alternatives. The strict a<b assumption is essential; the affine transform at one loses the base information.

The quantifiers are important: this is an existential program for each fixed F (and fixed rational threshold), followed by a concrete PR numeric specialization map. It does not establish a uniform PR interpreter of arbitrary numeric programs, a PR compiler taking arbitrary F as data, uniform extraction of p from its logical PR proof, or a displayed literal numeric value for p. None of these stronger claims is needed for the stated fixed-matrix lower reduction.
