AR8R-T134 — State-sensitive access is necessary for Blackwell improvement but not sufficient for a fixed target
Theorem

For a fixed base transcript H, if an added signal D is generated by a state-independent kernel from H, then it cannot improve any decision problem relative to H alone.

If the conditional-independence/garbling condition fails in a finite experiment, the augmented experiment can be strictly more informative for some decision problem. It need not improve a particular registered target or query problem.
Countermodel to target sufficiency

Let the hidden state be (u,v) in {0,1}^2; the registered target is q(u,v)=u. Let the new signal reveal v exactly. The signal is state-sensitive and makes the full experiment more informative, yet it provides no information about u; the query requirement for determining q is unchanged.
Consequence

new state-sensitive access

is a necessary escape from internal-garbling nonaugmentation, but target relevance is a second, independent condition. For Candidate 1, a new source or side channel must separate threshold-positive from threshold-negative matchings—not merely distinguish hidden inputs in an irrelevant coordinate.
