## 1. Typed lineage object

Let `L=(V,E)` be a finite DAG. Every vertex denotes one declared actualizer unit at a fixed granularity. An edge `u→v` means that `v`'s efficacy in one fixed explanatory respect is derivatively inherited from or borrowed through `u`.

The admitted graph theorem requires:

```text
HOMOGENEITY:
all edges express the same composable efficacy-lineage relation;

VERTEX COVERAGE:
all actualizer units relevant to the declared domain are represented;

RELATION COMPLETENESS:
all lineage relations capable of changing root status are represented;

ACYCLICITY:
no same-respect efficacy lineage is circular in the declared model.
```

For reachability `u≤v`, let `Up(v)={u:u≤v}`. A root has no proper predecessor. `L` is upstream-directed when `Up(v)∩Up(w)≠∅` for every `v,w∈V`.

## 2. UCA-1 — exact unique-lineage-root theorem

For a finite DAG, the following are equivalent:

1. `L` is upstream-directed;
2. `L` has exactly one root;
3. one root reaches every vertex.

### Proof

Every vertex in a finite DAG has a root ancestor. If `r` and `s` are roots and upstream directedness holds, some `u` precedes both. A root has no proper ancestor, so `u=r=s`. Hence the root is unique. Every vertex's root ancestor is therefore that root, so it reaches every vertex. The converse is immediate: a universal root belongs to every pair of upstream sets. QED.

The unique root is fixed by every automorphism of the complete typed lineage graph. It is therefore a non-idle structural symmetry breaker of the kind Deep I required.
