## 1. Exact inherited burden

Candidate G's derivational-unification parity theorem establishes that moving
freely recombinable primitive coordinates into one bearer does not reduce
explanatory freedom.  Genuine unification requires shared derivation,
cross-profile restriction, cross-domain counterfactual dependence, primitive
reduction, or novel excluded configurations.  Its principal unresolved burden
is rival parity: an impersonal or distributed architecture may realize the same
integrated graph at equal cost.

Deep Round B separates two questions:

1. can a model exhibit genuine derivational unification rather than
   carrier-boxing?;
2. does that achievement discriminate a personal ground from matched
   impersonal or distributed realizers?

## 2. A positive non-boxed architecture

Let the independently variable primitive profile be

```text
Theta = {(t,e): t,e in {0,1}}
```

where `t` is a truth/norm coordinate supplied independently for this model and
`e` is an efficacy coordinate.  Define the joint explanandum profile

```text
F(t,e) = <M,A,S,N,R>
       = <t,e,t,t,t AND e>.
```

Thus:

```text
M = S = N;
R = A AND N.
```

Every coordinate has both marginal values, so the product of the five marginal
spaces has 32 profiles.  The image of `F` has only four.  Twenty-eight joint
configurations are excluded.  A `t` intervention jointly changes modal,
semantic, and normative coordinates, and can change realization; an `e`
intervention changes actuality and can change realization.  This is a genuine
cross-profile restriction and shared derivation under Candidate G's criterion.
It is not merely one bearer containing five independent facts.

The construction is intentionally weak.  It does not explain the primitive
truth/norm coordinate `t`, identify its bearer, or show that its norm is
proper-functional, teleological, or wise.

## 3. DURP-1 — realization-parity theorem

### Typed explanatory structures

For an architecture `H`, retain:

```text
Theta_H: admissible primitive profiles;
F_H: primitive profile -> <M,A,S,N,R>;
I_H: allowed primitive interventions and their output effects;
C_H: declared primitive and derivational cost data.
```

A **functional explanatory isomorphism** between `H` and `H'` is a bijection on
primitive profiles that preserves `F`, allowed interventions, and declared cost.
Bearer labels not appearing in these structures are idle.

### Theorem

If a personal, impersonal, or distributed realization of an architecture are
functionally explanatorily isomorphic in the above sense, then no premise or
observation expressible only in `<Theta,F,I,C>` discriminates among those
realization classes.  Genuine derivational unification may therefore defeat a
carrier-boxed rival while leaving personal-versus-impersonal-versus-distributed
realization undecided.

### Proof

Let `phi:Theta_H -> Theta_H'` be the isomorphism.  Every admissible primitive
profile in `H` has exactly the same output profile under `H'`, and every allowed
intervention has the same cross-domain effect.  Cost data are equal by
hypothesis.  Therefore every formula, prediction, exclusion, and intervention
contrast definable from `<Theta,F,I,C>` has the same value in both structures.
A realization label absent from the structure cannot be recovered from it.
QED.

This is an immediate explanatory-structure isomorphism result and a strict
application of Candidate G's parity theorem.  No general mathematical novelty
is claimed.

### B-CM3 — distributed exact computation

subject.  It defeats unified-output-to-one-subject.

### B-CM4 — gerrymandered single primitive

A single 32-valued primitive encodes an arbitrary five-bit output and a lookup
table returns it.  Counting named primitive coordinates says "one", but the
state-space and intervention freedom remain five bits.  Coordinate count alone
is not explanatory compression.

### B-CM5 — reversed direction

A hidden label is reconstructed from the already obtained output profile.  It
fits the same observed correlations while explaining nothing about why the
outputs coordinate.  Fit and compression are not sufficient without direction.

### B-CM6 — thick brute totality

The entire coordinated profile is primitive.  It can cover every observed case
but declines derivation.  It remains consistent unless brute stopping points
are independently penalized.

### B-CM7 — holistic powers monism

A nonmental concrete powers whole realizes the same laws.  It is a stronger R5
rival than a mere list of plural primitives because it has genuine
cross-profile restrictions.

### B-CM8 — idle personal tag

Adding `Personal=true` to H-IMP without changing any primitive, derivation,
prediction, or intervention yields no added explanatory credit and no evidence
for the tag.
