## Anti-false-unity rule

A proposed cross-domain reduction is not substantive merely because every
finite native result can be recoded as a target predicate. It must preserve the
native typed objects, admissible transformations, load-bearing invariant, and
failure class without importing the answer.

This rule applies both to theorem-family deduplication and Candidate-G
unification. A one-name or one-carrier packaging of independently stipulated
coordinates remains carrier-boxing unless it derives constraints not freely
available in the matched rival.
