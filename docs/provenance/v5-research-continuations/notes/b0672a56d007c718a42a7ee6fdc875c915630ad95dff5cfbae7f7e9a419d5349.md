## The model

Fix one epsilon in (0,1/4] for an entire run. The two possible hidden standards are

  alpha_false = 1/2 - epsilon,
  alpha_true  = 1/2 + epsilon.

The disturbed binary forecast is (1/2+epsilon,1/2). There are two available repair
actions. Action a outputs the coherent pair (q_a,1-q_a), where
q_a=1/2+alpha_a*epsilon. Its target is not a hand-labelled good/bad matrix: it is
the actual two weighted-quadratic score inequalities `BinaryGood` from the
statistical repair bridge. Lean proves action a succeeds under hidden theta if
and only if a=theta.

After every repair action, a fresh Boolean observation has Bernoulli(alpha_theta)
law. Every repair is permitted by this constructed model. There is no separate
prohibited probing action. The data-to-standard relation is part of the model
specification; an application must independently authenticate that relation and
the action permissions.

## The actual shared controller and probability space

`ProductObservationLaw.lean` proves coordinate marginal laws and independence
from finite-cylinder identities of Mathlib's actual infinite product measure.
`GeneratedBinaryExperiment.lean` constructs the normalised Bernoulli mass and an
independent stack for each action. The selector uses the original canonical
prefix-likelihood policy. It reads only already acquired stack entries; neither
the true theta nor unacquired observations are inputs to `selectedRepair`.

Each support contains one action. Thus every support block is exactly one repair
step; this instance has no block-to-physical-action flattening obligation.

The final theorem `generated_experiment_eventually_repairs` concludes, for each
true theta under its generated probability law, that all sufficiently late
issued repairs satisfy the actual BinaryGood inequalities almost surely. Its
only explicit inputs are epsilon with its bounds, theta identifying the law,
and the fixed initial tie choice. The target relation, law normalisation,
independence, identical marginals, and selector maximisation are proved inside
the dependency chain rather than assumed as an unconnected interface.

This is a mathematical policy over real likelihoods. It is not a Python-to-Lean
execution refinement, a physical sampler, or a uniform effective comparison
algorithm for arbitrary real epsilon. Rational instances admit exact likelihood
comparison; deployment would still require its own implementation and sensor
binding evidence.

## Quantitative relation to the negative experiment

For the same two Bernoulli alternatives, the one-step Hellinger affinity is

  rho = sqrt(1 - 4 epsilon²).

The controlled-restoration budget therefore yields the ordinary expected
wrong-repair bound

  E[wrong repairs] <= 1 / (1 - rho)
                    = (1 + sqrt(1 - 4 epsilon²)) / (4 epsilon²)
                    <= 1 / (2 epsilon²).

The root's separate finite-sample theorem proves that any repair rule after N
Bernoulli samples has worst-case failure at least (1-4epsilon²)^N/4. These are
different performance quantities: a finite-confidence sample requirement and
a cumulative bad-action expectation must not be identified. Their common
inverse-square scale makes the information bottleneck concrete while the
positive controller continues to obtain evidence through permitted repair
steps. The displayed expected-action comparison is an ordinary application of
the Hellinger budget until separately linked to this generated path law; the
almost-sure eventual score theorem itself is kernel checked.

## What this composition does not show

- Epsilon is fixed within each run. Varying it across this family changes the
  two hidden standards. This is not a theorem about a drifting true standard or
  a shrinking within-run epsilon schedule
- Early mistakes are allowed. Almost-sure eventual success is not zero risk at
  every step, a finite deterministic learning deadline or a known final error
- The continuum no-go has a different acquisition contract: continued querying
  is target-bad and success must eventually stop it. This positive model permits
  observations after ordinary repair actions. There is no contradiction
- The known observation-to-score coupling and action permissions are supplied
  modelling commitments, not conclusions about moral or epistemic authority
