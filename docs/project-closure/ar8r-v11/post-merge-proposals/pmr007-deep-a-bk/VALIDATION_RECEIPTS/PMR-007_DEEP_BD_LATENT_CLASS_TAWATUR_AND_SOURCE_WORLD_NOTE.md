# PMR-007 Deep BD — latent-class, source-world, and tawatur ancestry note

## Statistical ancestry

Dawid and Skene's 1979 observer-error model estimates individual reporting
error rates when the true response is latent.  It is the direct model-family
ancestor for finite source-report channels and latent truth labels used here.
It does not by itself supply world-truth orientation or a source-theological
warrant rule.

General latent-class identifiability theory distinguishes strict
identifiability from identifiability up to a permutation of latent labels.
Label swapping leaves the observable distribution unchanged.  Guarded results
using Kruskal-rank or related conditions can identify selected finite latent
models up to label permutation; exceptional parameter sets and additional
nonidentifiability remain possible.  Deep BD therefore makes recovery up to the
single swap orbit an explicit premise of its positive anchor theorem.
