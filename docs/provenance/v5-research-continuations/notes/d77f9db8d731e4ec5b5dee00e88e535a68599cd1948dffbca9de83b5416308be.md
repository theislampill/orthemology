## What is genuinely established

The model couples a root's reporting and actuation integrity under one fixed corruption budget. Its repetition code exactly diagnoses the hidden faulty module despite up to f corrupted reports. A corrupt root can nevertheless truthfully report the module and later perform a destructive action. Thus diagnosis is not integrity identification. The target is the whole corrected binary rule, not one lucky output, and X is explicitly an absorbing unsafe non-target state.

The no-safe-policy proof does not use a mobile adversary. On a unanimous report every root is faulty in some admissible static scenario. Any deterministic policy that eventually attempts an intervention has a first chosen root, and one such scenario makes that attempt destructive. Randomization cannot make both safety and eventual attempt almost sure. If p is the first-root distribution, a static corruption set containing the f largest masses has total mass at least f/n. Uniform root choice attains that value. The almost-sure eventual-attempt policy class is explicit; perpetual waiting is safe but not restorative.

The sharper conditional frontier is correct. Once k mismatches are seen, those roots consume k units of the shared budget. Every remaining root is potentially corrupt if k<f; all agreeing roots are safe when k=f. Uniform choice among n−k agreeing roots has worst-case damage probability (f−k)/(n−k). For a lower bound, uniformly mix the adversary over all maximal compatible corrupt sets: each agreeing root has exactly that inclusion frequency, and a known-corrupt root has frequency one. No action mixture can improve the displayed bound. This proof covers arbitrary real probability distributions, not just the finite lattice tests.

This explains the initially surprising comparison between unanimity and disagreement without claiming that disagreement is generally desirable. Its force depends on a shared reporting/actuation fault budget. Independently corruptible actuator roots or drifting fault sets require a different inference. The packet includes those deletion controls.

## Positive result and its trust cost

The fail-silent architecture genuinely changes the causal failure model. Each action is either the same adequate idempotent repair or the identity. Every f+1 distinct-root batch includes a good action, and subsequent actions cannot undo it. No integrity diagnosis or trusted response receipt is required. The harmlessness premise concerns all safety- and future-repair-relevant state, not just a displayed return value.

The containment-gate analysis closes an important loophole. If every action depends on one corruptible shared gate, every support contains that gate and the cut number is one. Declaring the gate trusted is permissible as an explicit premise, but it does not derive independence. Source correctness, philosophical unity and possession of a proof file cannot substitute for the gate's actual non-bypassability, atomicity or preservation properties.

The result does not make a finite loss theorem certify the wrong target. One damage-event loss can remain bounded while the system stays outside the true target forever. Conversely the fail-silent bound counts post-acquisition non-target action visits and has moments bounded by (f+1)^d for nonnegative moment orders. This bound comes from the finite architecture, not from the separately accepted empirical-controller theorem.
