# Source notices and dependencies

No third-party library source or dependency stack is vendored in this update. The authored Python controls use the standard library and import separately held predecessor compiler files identified by their original bindings. Those imports are not silently made available by this archive. Earlier archives, including their licenses and copyright notices, remain unchanged.

Original authored reports/scripts and their existing notices are copied exactly; this preservation adds no license grant or authorship claim. Source ledgers retain the declared classical Set Cover/AND-OR, fibre, parity and inversion ancestry and external-reading limits. Raw external source bodies are not embedded.
