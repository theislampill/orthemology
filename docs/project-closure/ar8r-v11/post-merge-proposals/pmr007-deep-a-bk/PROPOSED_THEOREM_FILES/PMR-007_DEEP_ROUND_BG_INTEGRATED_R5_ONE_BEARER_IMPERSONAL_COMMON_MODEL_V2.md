## 2. Scoped nonentailment theorem


`CreatorClass` is a scoped target predicate requiring agentive and intentional
origination, not a synonym for causal actualization.

predicates. Therefore none of them is definable from, or entailed by, the
complete declared neutral reduct relative to the intended expansion class.

This is a signature-relative nonentailment result. It is not a claim that every
metaphysically admissible model class is closed under those expansions.
