# Independent audit: common full-path observation boundary

Scope: CommonObservationBoundary.lean and CommonObservationFiniteActions.lean, freshly copied and compiled with their SelfVerifyingSupport dependency. The result is classical filter/absolute-continuity reasoning. No historical novelty or replacement for policy-law CIRS necessity is claimed.

## Result and exact meaning

No blocking mathematical or specification defect found. A NONZERO reference measure mu must satisfy mu << nu_theta for every candidate's COMPLETE path law. Each candidate's eventual success therefore also holds mu-almost everywhere. Finite target multiplicity lets these events be intersected, and lets their eventual time thresholds be combined. One resulting observed action is accepted by every target.

The same-law specialization and constant-action converse are correct at this abstract target-set level. The latter does not establish an admissible physical policy when action availability or dynamics impose additional restrictions; those must be represented by the action domain/targets or proved separately. One shared output map X is essential, rather than a different parameter-informed policy for each target.

The finite-action successor is also correct for an arbitrary target family. If no action were universally accepted, choose one rejecting target for each action. This is a finite obstruction indexed by the finite action set; applying the original theorem to that subfamily yields a contradiction. Thus either finite target multiplicity OR finite action alphabet suffices.

The support-kernel equivalence correctly says that, when every rival agrees on every candidate action, self-verifying support is exactly support contained in every target. It does not assert that the support is nonempty. A separate control uses empty support with disjoint targets to prevent silently deriving an accepted action from that equivalence alone.

## Accepted independent controls

1. Reversed domination: the two Dirac laws on Bool are both dominated by counting measure, and X(omega,n)=omega succeeds at its own singleton target under each law. The targets have empty intersection. Being jointly dominated by a third measure is therefore the wrong direction
2. Zero reference: if mu=0, almost-everywhere success is vacuous even for disjoint targets. The NeZero condition is load-bearing
3. Infinite targets and infinite actions: under the same genuine Dirac probability law, X(omega,n)=n eventually meets every fixed tail target {a | theta<=a}, but no action meets all tails. This realizes the author's infinite-target counterexample under an actual nonzero law
4. Finite-action rescue: an independently written proof confirms the successor for arbitrary target indexing
5. Empty self-verifying support: the support-kernel statement needs a nonempty support premise before it can yield a common action
6. Finite-prefix domination is insufficient even with a CONSISTENT reference family. One path law is the all-true Dirac oracle and the other is fair iid. Projections of the same all-true Dirac reference are dominated by both laws at every finite prefix, but no nonzero reference can be dominated by both full path laws
7. For the preceding counterexample, a detector outputs true until it has seen a false symbol, then outputs false. It is measurably defined and depends only on observations strictly before its current time. It succeeds eventually at the appropriate singleton target under each law, despite the empty target intersection. The fair law eventually sees a false symbol because its all-true event has mass zero

These principal controls are Lean proofs, not numerical illustrations. The fair-iid null-event lemma is reused from the separately sealed generic-query audit, whose source and object identities are recorded.
