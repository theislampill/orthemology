## Inspect and reproduce

Run these commands from the repository root:

```bash
python -B scripts/validate_v5_successors.py
python -B scripts/replay_v5_successors.py --list
python -B scripts/replay_v5_successors.py --check --suite t11-substitution
python -B scripts/replay_v5_successors.py --project --suite t11-substitution --out ../successor-projection
```

Choose a fresh absent projection directory outside the checkout. Checking and
projection do not execute research code. Execution requires the exact tools,
external inputs and original control stages declared by the selected suite.
The [toolchain record](../../docs/provenance/v5-successors/TOOLCHAINS.json)
distinguishes repository Python 3.11.9, source-specific Python environments,
official Lean 4.19.0 and package pins. Original driver argument conventions are
part of the suite contract.

Every suite preserves its own module-to-source mapping. Equal source bytes may
share storage; equal filenames do not justify sharing different objects or
proof closures. Negative fixtures stay outside accepted proof roots. Read the
[control dispositions](../../docs/provenance/v5-successors/CONTROL_DISPOSITIONS.json)
and [verification record](../../docs/provenance/v5-successors/INTEGRATION_VERIFICATION.json)
for actual terminal outcomes, retained failures and fresh versus reused evidence.
A timeout is not a successful rejection, and a successful finite computation
does not establish a universal theorem.

Raw archives, original DOCX/PDF files, private transcripts, local locators,
third-party primary-text collections, participant-level observations, compiled
objects and full execution logs remain outside Git. The
[source map](../../docs/provenance/v5-successors/SOURCE_MAP.json) and
[public projection record](../../docs/provenance/v5-successors/PUBLIC_PROJECTION.json)
bind original identities to the exact public text and reviewed derivations.
