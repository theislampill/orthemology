# Orthemology v5 research continuations

This additive candidate continues the same v5 programme through **sixth-tranche
checkpoint 3**. It incorporates the first five research tranches and the supplied
sixth checkpoints; it is not a final sixth return. PR28's consolidation remains
the historical base. The [source and review index](../provenance/v5-research-continuations/README.md)
is the entry point to the actual proof texts, formal sources and scoped reviews.

The 42 intake family labels are navigation aids. They neither enumerate every
theorem nor replace the statements in the supplied sources. The
[registry](../../experiments/orthemology-v5-continuations/registry.json) records
an origin archive, source/review identities, claim boundary, mathematical form,
implementation reach and applicable suites for each family.

## Source and evidence ownership

Each suite retains its own module-to-source mapping, import order, declaration
owners and exact dependency pins. Identical Lean bytes share a content-addressed
store; unequal sources with the same module name remain in separate suites.
There is no combined import root. Original notices and statements remain in the
source bytes, including historically accurate comments about earlier uncompiled
states. Current results live in the overlay rather than rewriting those comments.

[SOURCE_MAP](../provenance/v5-research-continuations/SOURCE_MAP.json) distinguishes
exact projections, reviewed prose derivations and items retained only in private
custody. Archive member selectors are not checkout paths or download promises.
Prose derivations add an inherited-evidence notice, reduce original navigation to
text and remove private local locators; their original and derived hashes and
diff digests are recorded. No raw archives, primary-text collection, attached
polyphony PDF, compiled objects, private captures or execution logs are included.

[RESULT_STATUS](../provenance/v5-research-continuations/RESULT_STATUS.json) keeps
source custody, inherited review, fresh checking, repository-candidate disposition
and external warrants separate. A source-integrity pass proves consistency of
the declared records. A kernel-component receipt concerns its exact source closure
and declaration readbacks. Neither establishes empirical validation, normative
warrant, external human peer review, novelty or merged adoption. Ordinary proofs
and conditional arguments cannot receive whole-family kernel status.

[EVIDENCE_BINDINGS](../provenance/v5-research-continuations/EVIDENCE_BINDINGS.json)
binds each scoped statement to its exact source and retained review identities,
and each credited suite to the declaration targets owned by those sources.
Cross-archive sources remain valid when their exact bytes match. These are
explicit integration associations, not machine judgments that every contextual
review proves every statement in a family. Reassigning a suite or review requires
an explicit, reviewed association update; a shared archive alone is insufficient.
The stronger `QUALIFIED` status also requires a source-bound control contract and
terminal control summary, including original drivers, receipt digests and every
required positive/mutation stage. A bare control-success string is insufficient.

## Finite observed-state control

The global iff concerns a fixed **finite hidden model family**, exact rational
transition rows, fully observed evolving state, specified action menus and hidden
model-relative priorities. The common policy is fixed **before** quantifying the
true model. The source endpoint is
`HiddenParity.Sufficiency.computed_region_iff_common_parity_policy`.
Its mathematical policy witness is distinct from an executable controller.
It is not a theorem for arbitrary hidden-state POMDPs, uncertain sensors or every
governing framework.

The SCC successor proves the specified decision-region identity and public-region
connection. Its inner graph algorithm does not make every compact representation
polynomial. Preserve the separate compact-menu PSPACE, expanded-table polynomial,
mixed-belief PD EXPTIME and fixed-k XP statements. The full complexity reduction
retains ordinary-proof status where the source says so.

The explicit policy record connects the actual mathematical policy and seed-law
fields to that construction. Empty support, lawfulness, seed compatibility and
the quantifier order remain part of the source contracts and controls.

## Sixth-checkpoint cost and runtime frontier

The strongest total bad-count tail theorem is **ordinary reviewed mathematics
with formal components**. It counts executed logical state/action pairs,
including action zero, for the specified generated coBüchi controller. The affine
tail is an assumption in the formal tail-to-moments consequence. Checkpoint 3
supplies actual positive-history slice bounds but not end-to-end chronological
aggregation of those slices. General parity does not imply finite odd-visit
cost; a bad-count bound is not a last-error, wall-clock or deadline bound.

Runtime **candidate v5** is the reviewed source/compiler/history/guard successor.
The complete general phase/support/target controller has not been supplied as a
P02 policy implementation. The environment simulator is model-indexed; its
hidden true-model index must not be passed to the common policy. Logical receipt
laws, raw physical streams, information available from clocks and nonatomic defect
have distinct contracts. Finite Python traces corroborate specified source bytes;
they are not universal host-refinement proofs.

Rational-reference candidate 3, integer-budget candidate v3 and nonconvexity
candidate v2 retain their exact identities and predecessor failures in the
[supersession ledger](../provenance/v5-research-continuations/SUPERSESSION.json).
An uncapped mathematical rule is separate from guarded adapters. An exact budget
certificate is conditional on semantic inputs, not a certificate of winningness
or physical model truth. Infinite expected errors do not imply almost-sure
infinitely many actual errors.

## Earlier and philosophical branches

The first-tranche type, dependent, observer, compiler, computability and operational
sources remain separately indexed. The second and third tranches retain geometry,
information, restoration, recursive, measure and indexed-semantics branches.
Fourth-tranche recovery texts retain their ordinary/recovery status; later
descendants do not retroactively supply missing historical objects.

Sourcehood-to-Knowledge arguments use substantive premises. The original-giver,
cognitive, intrinsic-determination and complete-coverage premises are not inferred
from compilation. Current Track T and R5 retain their world-directed existence,
coverage, unity and necessity burdens. School-neutral argument and Athari
interpretation remain distinct. The noninferential Knowledge clarification
separates our argument for Knowledge from a supposed process of learning in its
subject. No necessary-being deduction, completed attribute ladder, objective norm
authority or defeated rival follows from a finite formal model.

Completeness, apoautosis and polyphony connections remain proposals. A renamed
winning-region predicate is not a new Gödel-level result; a structured research
continuation is not an empirical demonstration of autonomous apoautosis.

The [obligation crosswalk](../provenance/v5-research-continuations/OBLIGATION_CROSSWALK.json)
preserves U01–U14, CV-R/CV-C/CV-O and the exact qualified criticism IDs. In
particular, a different finite fixed-point theorem does not close U08's general
Kakutani obligations. T354, Candidate E/G, PMR007, Ten Advances and Connes-specific
statuses remain with their existing owners. Occurrence-centred core definitions,
terminology/verdict ownership, multi-actor and application branches remain intact.

## Reproduction and subsequent checkpoints

See the [replay interface](../../experiments/orthemology-v5-continuations/README.md).
It requires Python 3.11.9, the repository dependency lock, official Linux Lean
4.19.0 and Mathlib `c44e0c8ee63ca166450922a373c7409c5d26b00b`, with each suite's
package revisions. Custom objects are compiled into an absent external directory;
official dependency caches are an explicit trust boundary. The runner verifies
sources before and after, checks exact target types and axiom footprints, and
does not accept author objects or silently select another module variant.

Original positive and intended-failure controls remain separate from the generic
component runner. A missing prerequisite, timeout, invalid probe or reference-only
run is not strict acceptance. Fresh results must be bound to the actual command,
source and terminal receipt. Later checkpoints require fresh input hashes and
statement-specific supersession; existing accepted work is not replayed merely
because a new transport archive arrives.

[Decision 0037](../decisions/0037-v5-research-continuation-registry.md) records this
candidate architecture. Licence, release, DOI, identity, terminology adoption,
publication and remote Git actions remain separate owner decisions.
