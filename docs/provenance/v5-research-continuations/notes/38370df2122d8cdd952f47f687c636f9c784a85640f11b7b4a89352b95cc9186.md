# Model specification for the sixth necessary ground inquiry

These are tests of conditional inferences. They do not certify metaphysical possibility, establish consciousness from behaviour, or substitute finite worlds for objective orthability.

## Tests fixed before implementation

1. An actual original-giver rule can force source Knowledge at the actual world while leaving it absent in another world in which the same necessary source has no cognitive recipient. Thus applying the rule at every represented world is insufficient for essential standing Knowledge when its recipient antecedent can fail.
2. Possible production of cognition plus worldwise original-giver priority entails possible source Knowledge, not present source Knowledge. All worlds share the same intrinsic response law, and no external cognitive supplier is present.
3. Capacity for cognition is a different predicate from actual cognition. A model may have unborrowed productive capacity, dependent recipient Knowledge, and no source cognition unless the actual-cognitive priority premise is added.
4. An always-cognitive source can have different contingent acts and know different obtaining states across alternatives. Standing Knowledge does not imply that each effect, act, or contingent content is necessary.
5. A terminal knower under a pedagogical or cognitive-transfer relation need not be terminal under productive origination. The relations may have different roots. Equating the roots needs an additional identity or absolute-unborrowed bridge.
6. An intrinsic determination condition that fixes standing cognition wherever the source's nature is present excludes test 1. It is sufficient because it supplies the otherwise missing modal condition, not because independence secretly contained it.
7. Mere overall superiority does not entail superiority in the cognitive respect. A source may exceed a recipient in productive range and fall below it in actual cognition.

The checker must report each declared model in a JSON-serializable form, calculate the relevant predicates, verify the positive conditionals on all two-world Boolean assignments, and include deliberately false controls. It must distinguish actual sourcehood, source existence, actuality of cognition, standing type possession, and token/content invariance.

No retained source formula will be changed. The fifth exact Lean model remains the authoritative executable witness for the imported SourceIdentity and ProductiveCompleteness predicates. The new checker tests additional modal and relation-typing transitions only.
