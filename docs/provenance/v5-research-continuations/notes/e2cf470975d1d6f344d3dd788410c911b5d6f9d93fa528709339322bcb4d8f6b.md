# Critical uniform smoothing is finite precisely on the sparse side

Separate ordinary successor, version1,2026-10-01. This resolves the whole-cluster uniform critical case left outside the distribution-free width theorem. It does not contradict its absolutely continuous edge-strip counterexample.

## 1. Statement

Fix0<e<=1/16. Let the same half-separated centres a_i<=1/2, weights a_i/Z and spacing S be given. Let nu_i be UNIFORM on[(1-e)a_i,(1+e)a_i]. Thus the relative half-width equals the literal tolerance, d=e. All actual-process, compulsory reporting, complete-word and independent-seed quantifiers are unchanged.

A common measurable coherent policy has finite expected lifetime literal count iff S<infinity. The universal lower bound exp(-1)S/(9Z) remains valid. One explicit policy below has

    E count <=30000S/Z+128/e^2+(32/e^2)M_head,

where H is any finite cutoff with a_i<=1/8 for i>=H and M_head is the finite inverse-variance moment of the first H components, as defined in WIDTH_BOUNDARY.md. The entire theorem uses the real parameter drawn once from the stated absolutely continuous prior.

## 2. Two overlapping accepted intervals

For one tail centre0<a<=1/8, define

    l=(1-e)a, u=(1+e)a,
    s=e a(1-e^2), h=2e^2a^2, W=4ea^2,
    qL=1/2+s-h, qR=1/2+s+h.

Both reports are coherent. The following accepted intervals include their boundaries:

    qL accepts every alpha in[l,u-W],
    qR accepts every alpha in[l+W,u].                 (8)

These overlap since W<=ea/2. Exact endpoint calculations verify(8). At the critical shifted centre q*=1/2+s, both relevant endpoint excesses equal s^2. Moving down or up by h gives

    D0(l,e,qL)=s^2-h-2sh+h^2,
    D1(u,e,qR)=s^2-h+2sh+h^2,
    D1(u-W,e,qL)=s^2+h-2sh+h^2-We(1-e),
    D0(l+W,e,qR)=s^2+h+2sh+h^2-We(1+e).

Now s^2<=e^2a^2, h=2e^2a^2, h^2<=(3/4)e^2a^2, and2sh+h^2<=e^2a^2. For the latter it is enough that4ea+4e^2a^2<=1, which follows from e<=1/16 and a<=1/8. Also We(1-e)>=(15/4)e^2a^2 and We(1+e)>=4e^2a^2. All four displayed excesses are therefore nonpositive. Monotonicity in alpha proves(8). This is an exact algebraic argument; no small-a approximation is used.

## 3. Local observation rule and error cost

If the global cluster selector chooses this tail index, report qL when H_n<=a and qR when H_n>a. For a true alpha in the central overlap[l+W,u-W], either report is accepted. Failure can occur only in the lower strip[l,l+W] or the upper strip[u-W,u]. Endpoints included in both descriptions have zero measure under the uniform law and do not affect the upper bound.

For a true alpha in the lower strip,

    alpha<=a(1-e/2),

so the wrong local choice requires H_n>a, a deviation of at least ea/2. For the upper strip,

    alpha>=a(1+e/2),

and the wrong local choice requires H_n<=a, again a deviation of at least ea/2. In both cases alpha(1-alpha)<=alpha<=(1+e)a<=(5/4)a.

Use the inherited centered MGF bound with t=e/8 or t=-e/8. Its exponent is at most

    -n e^2a/16+n(5/4)e^2a/64
      =-11n e^2a/256<=-n e^2a/32.

Thus the local wrong-choice probability, for each parameter in either relevant strip, is at most exp(-n e^2a/32). Summing n>=1 gives at most32/(e^2a).

The two strips have total uniform component mass

    2W/(2ea)=4a.

Consequently their conditional integrated lifetime error is at most128/e^2. Multiplication by the component weight a/Z and summation over all tail components gives a total local contribution at most128/e^2, since sum_i a_i/Z=1.

## 4. The single actual common policy

Use the same clipped-log global selector J_n. If J_n<H, use the empirical report. If J_n>=H, use qL_(J_n) or qR_(J_n) according to the comparison H_n<=a_(J_n).

For a true parameter in cluster i, failure is charged to

1. Global cluster misclassification J_n!=i
2. If i<H, empirical literal failure
3. If i>=H, the local two-report error at the true cluster index

This is a proof decomposition only. The IMPLEMENTED MATHEMATICAL RULE uses J_n, never the true i. The global classification analysis needs d<=1/16 and therefore applies here with d=e. It contributes at most30000S/Z. The finite head contributes32M_head/e^2, and the local tail cost is bounded in section3. This proves the upper statement without assuming independent errors across stages or separate policies chosen after the true cluster is revealed.

The universal necessity is exactly the earlier all-zero adjacent-cluster proof with d=e<=1/16. Thus S<infinity is necessary as well as sufficient for this uniform-whole-cluster prior.

## 5. What the comparison establishes

At the SAME critical relative width d=e and SAME centres/weights:

- Uniform mass throughout each whole cluster has finite budget iff S is finite
- Balanced mass concentrated into the two O(ea_i^2)-wide edge strips can force every policy's budget to infinity, even when S is finite

Both priors can be absolutely continuous and have no endpoint atoms. Fine mass placement within clusters therefore matters exactly at the critical width. The distribution-free guarantee requires d<e, while a specified benign critical shape can remain finite. This is a shape-sensitive boundary, not a blanket statement that smoothing at critical width is either always safe or always impossible.
