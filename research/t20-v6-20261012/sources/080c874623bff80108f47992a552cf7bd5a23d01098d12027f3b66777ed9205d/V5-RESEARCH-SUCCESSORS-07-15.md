## Reading the evidence

Each result has its own input contract, assumptions, conclusion, limitations,
source/review associations, declaration targets and applicable original
obligations. The [evidence bindings](../../PUBLIC_BOUNDARIES.md#recovered-reference-025)
bind the complete statement and receipts, rather than a title or file basename.

| Field | What it records |
| --- | --- |
| Custody | Exact bytes, reviewed public derivation, or private custody only |
| Inherited evidence | What the supplied source-specific review actually established |
| Fresh evidence | Not run, blocked, inconclusive, failed, finite execution, formal components, or a qualified declared suite |
| Research disposition | Candidate, deferred, rejected, or historical at the stated scope |
| Implementation reach | The particular finite witness, reference implementation, restricted checker or formal component supplied |
| External warrants | Separate adoption, normative, empirical, specialist and external-review burdens |

`QUALIFIED_DECLARED_SUITE` concerns the exact declared suite and its checked
targets. A narrower component result can cite that same receipt while retaining
component status. It does not acquire the suite's scope as a new whole-result
claim. A successful proof of a named counterexample has exit zero; an actual
mutation rejection has its own terminal exit and diagnostic. Resource limits
receive no rejection credit. Repeated modules, readbacks and repair retries do
not create independent scientific evidence.

## Sources and replay

The [source map](../../PUBLIC_BOUNDARIES.md#recovered-reference-034) preserves every
selected original alias and nested archive relationship. Equal public bytes
can share storage; unequal modules with the same name have isolated suite
projections and builds. Original archive-member selectors and external source
locks describe custody or prescribed inputs, not files promised to exist in
this checkout. The [publication allowlist](../../PUBLIC_BOUNDARIES.md#recovered-reference-031)
and [source-use record](../../PUBLIC_BOUNDARIES.md#recovered-reference-035) distinguish
original text from reviewed derivations. Original notices and mathematical
equations remain part of the source contract.

Raw archives, original DOCX/PDF inputs, private transcripts and local locators,
third-party primary-text collections, participant-level data, compiled objects
and full execution logs are excluded from Git. Public receipts carry scoped
identities and outcomes; private originals remain available to their owner for
exact comparison.

The replay interface separates descriptor checking, projection and execution:

```bash
python -B scripts/validate_v5_successors.py
python -B scripts/replay_v5_successors.py --list
python -B scripts/replay_v5_successors.py --check --suite t11-substitution
python -B scripts/replay_v5_successors.py --project --suite t11-substitution --out ../successor-projection
```

Use an absent output directory outside the checkout. Projection executes no
research driver. Execution additionally requires the suite's explicit tool and
input bindings. The repository environment remains Python 3.11.9; packages
prescribing Python 3.12 have separate environments and exact dependency pins.
Formal suites use official Lean 4.19.0 and their declared package revisions.
Fresh custom objects, exact inherited objects and trusted external caches have
separate evidence. Changed derived proof source requires a fresh build.

Reviewed original drivers retain their argument meanings and original positive,
mutation, type-readback and proof-closure stages. A wrapper's successful exit
does not substitute for its child terminals. Where the original driver runs
mutations internally, an explicitly recorded trace observes those actual child
calls; reading the resulting evidence does not execute the mutation again.
