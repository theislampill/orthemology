# Exact posterior-only continuation via a paired tensor lift

10 October 2026 UTC. Candidate ordinary proof for independent investigation. Prior ownership and independent review pending; no novelty or verified implementation claim.

## Declared finite model

A finite hidden state has n coordinates. Fix a finite, explicitly supplied alphabet of admitted observation/action symbols, including the empty word in the observations. An admitted symbol a has a nonnegative matrix M_a, belonging to a justified substochastic instrument. A belief r is a probability vector. For every word w=a1...ak in the full free monoid Sigma*, put M_w=M_ak...M_a1 and M_empty=I. A restricted history-dependent admission policy is not implicit; it must be represented separately, for example by an explicitly supplied finite controller product. Its probability is p_w(r)=1^T M_w r. If positive, the target posterior is C M_w r / p_w(r), where C is a fixed column-stochastic target marginal. An impossible word returns an explicit undefined-observation status, not a made-up posterior.

The target can be a static latent variable preserved by the instrument, or a fixed readout C of the current, time-indexed latent state; these interpretations cannot silently be exchanged. An externally varying C_t is outside this theorem unless represented in an enlarged fixed-state model. This candidate addresses the represented finite filter, not actual psychological states or HasE identity.

The inherited full predictive observable closure already preserves both event probabilities and target joint numerators. The narrower question here asks exactly when two initial beliefs have the same conditional target output under every common observation word, including equal feasibility, without asking for equal word probabilities.

## Finite tensor condition

For each row c of C define the two-slot covector O_c = c tensor 1^T - 1^T tensor c. For each admitted symbol put T_a=M_a tensor M_a. Let W be the row span generated by the O_c and closed under right multiplication by every T_a. This is a finite linear subspace of dimension at most n^2. It can be generated by successive span closure with exact rational linear algebra when the finite matrices, target readout C, and compared states r,s are all rational.

For positive-probability w in both beliefs,

q_w(r)=q_w(s)

if and only if, for every c,

(c M_w r)(1^T M_w s) - (1^T M_w r)(c M_w s)=0.

This is precisely O_c (M_w tensor M_w) (r tensor s)=0. Hence equality for every feasible word follows exactly from annihilation of W by r tensor s, provided word feasibility agrees. If one or both word probabilities vanish, nonnegativity forces the corresponding unnormalised state vector to vanish. Its cross products are then zero automatically. Thus adding these words does not strengthen the tensor equations and cannot replace the feasibility guard.

Consequently the exact iff is:

1. r and s have the same feasible-word language;
2. every covector in W annihilates r tensor s.

The forward implication uses equality of feasible conditional outputs, plus zero cross products on jointly impossible words. The reverse uses the defining generators for every word, followed by division only when both probabilities are positive. Span closure is only an algebraic finite method of checking the universal cross-product condition.

## Feasibility is separately finite

For nonnegative M, support updates as S -> {j : exists i in S with M[j,i]>0}. Word feasibility means the resulting support is nonempty. This deterministic finite subset automaton allows comparison of any two initial supports by reachability of a pair with exactly one empty component. No probabilities or arbitrary choices at zero-probability events are needed.

If r and s have the same positive support, feasibility agrees automatically under every word. Full-support pairs are an important instance. The later normalised posteriors after a common feasible word also have the same support.

## Important scope tests

- This is a finite test of pairwise posterior-only equivalence, not a construction of a minimal single-belief linear representation. The paired tensor is bilinear in two states; one must not call its dimension the minimal memory of a filter.
- Event probability equality is deliberately absent. A target independent of a hidden sensor-quality coordinate can retain the same target posterior under every sensor observation while two initial quality distributions predict different observation frequencies.
- Without the feasibility guard, two states with the same target value but different likelihood of an impossible event can pass every cross-product test. Returning a posterior for the impossible branch would change the semantics.
- All O_c are antisymmetric under swapping tensor slots, and each M tensor M preserves that subspace. A dimension bound n(n-1)/2 is therefore available in characteristic zero. This is an optional algebraic simplification, not needed for the proof or a claim of optimal search complexity.
- Finite dimension does not by itself give a practical algorithm for arbitrary undecidable real coefficients. Rational inputs provide the declared exact-arithmetic implementation scope.

This candidate is a potentially faithful use of tensor operations to test a nonlinear normalised continuation question. It must still be compared with retained project results and independently checked before receiving new result credit.

## Concrete fixed binary-audit quotient

For a joint law of binary target Theta and a single fixed audit D, suppose both audit outcomes have positive probability. The allowed observations only reveal/re-read this same D. Let t=P(D=1), q_d=P(Theta=1|D=d), and q=P(Theta=1). The complete posterior-only signature is (q,q_0,q_1): contradictory rereads are impossible and repeated matching rereads leave the state unchanged.

If q_0 differs from q_1, total probability gives t=(q-q_0)/(q_1-q_0). Consequently this signature reconstructs the entire joint law. If q_0=q_1=q, target and audit are independent; any t in (0,1) has the same signature at fixed q. Thus the posterior-only quotient collapses audit-marginal fibres on the independence locus but is injective elsewhere. Equal audit-event probabilities are unnecessary on that locus, and required to retain full predictive equivalence.

This classification concerns the fixed audit's instrument. Adding a new target-sensitive audit can refine it. It is not a licence to ignore the source of future observations or to treat fresh independent verifier samples as rereads.
