# Distribution-wrapper revision 2

Only the public replay wrapper, its boundary controls, README and distribution manifest change. All accepted scientific sources, imported sources, frozen source manifest and independent-review artifacts retain their original bytes.

The first public wrapper was not accepted for distribution. This successor rejects protected/existing output destinations, unlisted or unsafe inventory entries, substituted dependency manifests and unbounded compiler hangs. Failed stages preserve their output and cannot produce a successful receipt. No new scientific result is claimed by this wrapper revision.
