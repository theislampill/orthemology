Read PARTICULAR_POWERS_AND_MODAL_WARRANT.md for the primary-source analysis and LOCUS_AND_INCREMENT_NOTES.md for the locus-sensitive terminology. This second public projection removes repeated source exposition while preserving the accepted argument and its limits. It adds no research result.

Full source PDFs, raw captures, source extractions, inspection images, private coordination and internal instructions are excluded. External evidence paths are documentary references, not missing package members.

Run python verify_public.py from the extracted directory. The standard-library verifier checks the closed inventory, hashes, public byte-range map, independent review bindings and declared cumulative source arithmetic. It requires no network or original checkout. Attribution completeness and source interpretation are human judgments; the verifier cannot establish them.
