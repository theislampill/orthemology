## 2. Source and formal objects

Let `H0` be the finite family of live proper-function or norm-source standards
in Deep CQ. A source interpretation `D` supplies a translated predicate
`P_D(h)` on standards and hence an attained candidate family

```text
H_D = {h in H0 : P_D(h)}.
```

`H_D` can be empty, singleton, or plural. A source label does not make it
singleton.

The **source-relative** contract has nine coordinates:

```text
N1 Track-N regime acceptance;
N2 exact textual custody;
N3 version identity;
N4 translation fidelity;
N5 attribution and source-bearer fidelity;
N6 predicate preservation;
N7 formal-target linkage;
N8 target-bearer/context applicability;
N9 authorized use in the declared Track-N argument.
```

The **world-directed extension** adds:

```text
W1 truth of the source proposition;
W2 actual-world referent and world adequacy.
```

These are project custody coordinates. The supplied source materials do not
jointly state this list as one historical theorem.

## 3. FSRA-1A — source-relative restriction

If `N1` through `N9` hold and `H_D` is nonempty, then `H_D` is an authorized
standard-family restriction **inside the declared Track-N argument**.

This is a typed use rule, not a neutral proof that the source proposition is
true. If `H_D` is empty, the interpretation/argument is inconsistent at this
interface. If `H_D` has more than one member, norm-source uncertainty remains.

A unique source-selected standard requires:

```text
|H_D| = 1
```

or a separate uniqueness premise. It is not obtained from custody alone.

## 4. FSRA-1B — world-directed use

The Track-N restriction may be used as an actual-world standard family only if
`W1` and `W2` are additionally warranted. Thus:

```text
source-relative interpretive validity
!=
actual-world truth and applicability.
```

Deleting either world-extension guard leaves a model in which the source
argument is internally well typed while the actual target family remains open.

## 5. FSRA-1C — restoration monotonicity after justified restriction

Suppose `H_D` is a nonempty subset of `H0`, and every target region,
eligibility contract, and transition map is inherited without reinterpretation.
Then Deep CQ gives:

```text
V_H0 subseteq V_HD
W_H0 subseteq W_HD.
```

The proof is the standard uncertainty-family monotonicity: fewer standards
weaken target intersection, enlarge common eligibility, and weaken the
universal successor condition.

This result says what a justified source restriction would do to the finite
controller problem. It does not justify the restriction.

## 6. Exact countermodels

### CR-CM-EMPTY — source inconsistency

Every custody coordinate may be syntactically populated while no live standard
satisfies the translated predicate. `H_D` is empty; no target is thereby
selected.

### CR-CM-NONSINGLETON — source underdetermination

All source-relative guards can hold while two distinct standards satisfy the
translated predicate. The source package narrows `H0` but does not determine one
proper-function theory.

### CR-CM-WORLD — source/world nonmigration

The source text, version, translation, bearer, predicate map, and formal target
can all be accepted inside Track N while source truth or actual-world referent
adequacy is left open. No neutral or world-directed conclusion follows.

### CR-CM-REINTERPRET — inheritance failure

A translated application can change the target region or action semantics.
Then `H_D subset H0` as a set of names is insufficient for Deep CQ monotonicity;
the inherited-object guard is load-bearing.

### CR-CM-NEUTRAL-PARITY — source/neutral realization parity

A source-relative fiṭrah realization and an impersonal selected-effect or
powers-based truth tracker can share accuracy, reliability, corrigibility, and
causal-guidance profiles while differing in source relation, design, and
proper-function ontology. The neutral profile does not select Track N.
