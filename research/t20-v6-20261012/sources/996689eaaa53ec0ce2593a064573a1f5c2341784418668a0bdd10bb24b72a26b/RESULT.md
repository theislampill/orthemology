A time reparametrisation gives endpoint competitors of arbitrarily small finite action with this behaviour. The inherited whole-law CV-R diffuse-mass defect is one at both endpoints and therefore does not register this particular change.

This is a new-to-this-synthesis **application and interface qualification** of inherited theorems and elementary measure theory. ## 3. Exact specialisation of the Gaussian dynamics

Use the inherited report's parameters beta=0, tau=1, initial b=0 and s=0. The unique solution keeps b=0 and has

    s'(t)=(s(t)+2)(1-s(t)),     s(0)=0,
    s(t)=2(exp(3t)-1)/(2exp(3t)+1).

For t>0, 0<s(t)<1. If Y and G are independent standard Gaussians, put

    mu_t = Law(Y, sqrt(s(t)) G),
    mu_0 = Law(Y,0).

The entire Y-marginal is exactly standard Gaussian at every time. The target is the independent bivariate standard Gaussian pi. For t>0,

    E(t)=KL(mu_t || pi)=(s(t)-1-log(s(t)))/2,
    D(t)=(s(t)+2)(1-s(t))^2/(2s(t)),
    E'(t)=-D(t)<0.

These are direct specialisations of the existing full-law theorem, not merely a Gaussian parameter fit. The initial KL is infinite. Consequently this endpoint example does not refute a theorem restricted to positive-density, finite-initial-energy states. In original time D(t)=1/(2t)+O(1), so total action at the initial boundary diverges even though the geometric curve length is finite. On the unit interval r in [0,1], the reparametrised curve t=epsilon r^2 has action 2epsilon+O(epsilon^2). This is an admissible finite-action endpoint competitor preserving the entire marginal; it is not the original unit-time KL-gradient equation and is not claimed geodesically minimal.

## 4. A fixed semantic repertoire

On X=R^2, for each real a != 0 define the Borel predicate

    A_a = {(y,z): z != a}.

Neither its indexing set nor its meaning changes with time. Its universal intersection is the Borel set

    H = intersection_(a != 0) A_a = {(y,z): z=0}.

For the initial law, mu_0(A_a)=1 for every a != 0, and mu_0(H)=1. For any t>0, the Z marginal is a nondegenerate Gaussian. It assigns zero mass to each singleton, so mu_t(A_a)=1 for every a != 0. But mu_t(H)=0.

Consequently all pointwise almost-sure predicate certificates agree throughout this correction while the probability of their universal conjunction jumps from one to zero. The intersection is explicitly measurable; no unjustified closure of sigma algebras under arbitrary intersections is used. A countable subfamily has intersection of probability one for every t and cannot reproduce this example. In particular, separate finite program or formula occurrences over a countable alphabet cannot enumerate this whole indexed repertoire. An object-language universal quantifier may range over an uncountable semantic domain, but that requires its own specified interpretation; no such compiler-to-predicate transport is inferred here.

This is an instance of the CV-R quantifier distinction in the actual later correction dynamics. The full-event defect d(mu)=1-sum_x mu({x}) is already one for mu_0: its continuous Y marginal gives zero mass to every point of R^2. It stays one for every t>0. Thus d(mu) is an upper envelope over the full measurable repertoire, not the failure probability of this particular fixed repertoire. Calling its unchanged value a certificate of this repertoire's preservation would change the theorem's meaning.

Conditionally on Y=y, the initial Z-law is a point mass at zero; the positive-time conditional law is N(0,s(t)). Their conditional diffuse-mass defects are zero and one respectively. This conditional interpretation is exact for the stated regular conditional probabilities. It must not be identified with the already saturated whole-law defect or with the old finite positive-coarse-atom increment formula: each singleton Y fibre has zero marginal mass, and a disintegration integral is a different interface.

## 5. Tensor recovery and computability do not erase the boundary

All mixed polynomial moments of mu_t are continuous at zero. Explicitly,

    E[Y^m Z^n] = E[Y^m] E[G^n] s(t)^(n/2),

with odd Gaussian moments zero; when n is positive and even the last factor is an integer power of s. The family is moment-determinate, including the singular endpoint. The variance s alone identifies the law in this promised family. Thus neither moment indeterminacy nor failure of finite parametric identification explains the conjunction change.

The observable 1_H is bounded and Borel but discontinuous at every point of H. The map

    s -> mu_s(H) = 1 if s=0, and 0 if s>0

is discontinuous on [0,1]. There is no continuous decoder of this event mass from the ordinary covariance parameter, or from its continuously varying complete moment name on this family. In the usual real-name computational representation there is no uniform algorithm producing arbitrarily accurate event-mass values from a name of s: such an algorithm with error below 1/3 would decide whether an arbitrary nonnegative named real is exactly zero. Run that algorithm on the all-zero approximation name of zero. The finite set of precision queries it reads before returning an error-below-1/3 answer is also compatible with a sufficiently small positive input whose name agrees on those queries. This contradicts the two separated outputs. This argument does not require every possible finite name transcript for zero to admit that perturbation. This argument concerns the uniform represented-input problem; at a specified symbolic initial condition s=0 the event mass is of course known exactly.

The countable capped inverse theorem does not apply to these Gaussian probability laws as indexed atomic laws. Its stronger l1/total-variation representation is precisely one way to make all bounded, effectively represented discrete queries stable, subject to its own computability assumptions. The current example illustrates why moving to a continuous full-law geometric representation requires restating which measurable semantic queries the representation supports. Exact parameter identification is not a uniform computable oracle for every measurable event.

## 6. Positive repair conditions

### 6.1 Preservation of all initial almost-sure events

For two probabilities mu and nu on the same measurable space, the following are equivalent:

- every measurable H with mu(H)=1 also has nu(H)=1;
- nu is absolutely continuous with respect to mu.

Proof: apply the first statement to complements of mu-null measurable sets. The converse is the definition of absolute continuity applied to H^c.

Therefore a correction transition nu << mu preserves every already established measurable universal conjunction whose initial mass is one. This conclusion concerns the conjunction itself, not an interchange of arbitrary intersections and probability. Pure positive Bayesian reweighting with finite, nonzero normalisation has this property; indeed strictly positive weights almost everywhere yield equivalent measures. A finite succession of such updates retains the property by transitivity. Merely taking a weak limit of such states need not preserve it, so an infinite-time conclusion requires a separately justified limit condition.

This is a sufficient and exact all-event condition, not a requirement that every useful epistemic correction must obey it. Legitimate correction can overturn a previously represented certainty. The point is that an interface promising preservation must prove the required preservation, rather than obtaining it from energy descent or positivity alone.

### 6.2 Quantitative control for a declared obligation

For any fixed measurable H,

    |nu(H)-mu(H)| <= TV(nu,mu),

using TV as sup_A |nu(A)-mu(A)|. Thus a total-variation error bound transfers to that event-mass query. A bound in W_2 or the stated marginal-preserving action does not give such a uniform estimate in this domain, by Sections 3-4.

For a fixed repertoire of allowed measurable conjunctions C, the exact present-query pseudometric is sup_(H in C)|nu(H)-mu(H)|. It can be weaker than total variation and need not preserve other queries or future corrections. No minimal dynamically closed sidecar is supplied merely by writing that pseudometric. If the application needs future audit or revision operations, its query class must first be closed under the actual pullbacks/updates or supported by a proved continuation theorem.

### 6.3 Constrained geometry must carry the right constraint

The Gaussian example preserves the entire Y-marginal but fails the H constraint. Adding preservation of mu(H)=1 would exclude every nondegenerate mu_t in this particular Gaussian family. That is a genuine incompatibility between two specified requirements, not an implementation bug that can be fixed by smaller time steps. Choosing which requirement expresses the intended correction depends on the application. A name such as noetic improvement cannot decide it.
