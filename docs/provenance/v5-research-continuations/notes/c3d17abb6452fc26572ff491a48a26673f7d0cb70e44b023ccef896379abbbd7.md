# Finite endpoint issuance obstructs uniform exact repair safety

Independent ordinary proof notes for the stated Bernoulli audit interface. This is not a kernel theorem, empirical source authentication, or a claim about arbitrary norm-sensing mechanisms.

## Interface and exact good-report set

Fix epsilon in (0,1/4]. The baseline is (1/2+epsilon,1/2), and a coherent report is (q,1-q), q in [0,1]. Under the selector-induced expected score with parameter alpha, the two truth losses at the coherent report are q^2 and (1-q)^2. Define G_alpha by the simultaneous inequalities

    q^2 <= 1/4+alpha*epsilon*(1+epsilon)
    (1-q)^2 <= 1/4-alpha*epsilon*(1-epsilon).

A single procedure observes iid Bernoulli(alpha) bits and private randomness whose law is independent of alpha and which is independent of the observation source. The common rule, seed distribution, baseline and epsilon are fixed across parameters. Its first issuance of a real report has an extended stopping index N in the bit filtration, and its report Q on {N<infinity} depends only on the seed and acquired prefix through N. Assume all seed/prefix decisions, the stopping events and issued reports are measurable. Reports outside [0,1] count as incorrect. Direct parameter oracles, extra parameter-dependent signals and infinitely many acquisitions before a purported finite index are outside this interface.

For alpha>0, the second inequality forces q>1/2. The first and the elementary inequality sqrt(1/4+x)<=1/2+x give

    G_alpha subset (1/2,1/2+alpha*epsilon*(1+epsilon)].

These punctured intervals decrease to the empty set as alpha decreases to zero. Thus every fixed finite measure on reports assigns G_alpha mass tending to zero. An atom at exactly 1/2 does not help, because that point is excluded for every positive alpha.

## Coupling of finite issuance

Couple the same private seed R at alpha=0 and alpha>0. The endpoint stream is identically zero. Let N0(R) and Q0(R) denote its stopping index and first report. On the event N0=n<infinity, if the first n bits of the alpha stream are zero, causality forces its entire pre-issuance run, first issuance index and report to agree with the endpoint run.

The conditional matching probability is (1-alpha)^n. Summing over actual finite issuance indices n<=K gives the sharper bound

    P_alpha(first issued report is unsafe)
      >= sum_(n=0)^K (1-alpha)^n P_0(N0=n and Q0 not in G_alpha)
      >= (1-alpha)^K P_0(N0<=K and Q0 not in G_alpha).

This uses only the n bits actually acquired before matching issuance; an equivalent latent-K-prefix event is not an instruction to perform extra probes. In particular, for any integer K,

    P_alpha(first issued report is unsafe)
      >= P_0(N0<=K)
          -P_0(N0<=K and Q0 in G_alpha)
          -[1-(1-alpha)^K].

For fixed K the middle term tends to zero by the punctured-interval bound, and the final term tends to zero. Taking the lower limit as alpha decreases to zero, then K to infinity, gives

    liminf P_alpha(first issued report is unsafe)
      >= P_0(N0<infinity).                         (1)

Unsafe means that a finite report is actually issued and lies outside G_alpha. Non-issuance is not counted as an unsafe output.

If N0 is finite almost surely, the right side is one and the unsafe probability tends to one. Thus an all-issued safety requirement with a uniform failure allowance delta<1 is incompatible with almost-sure finite first issuance at the endpoint. More generally that requirement forces P_0(N0<infinity)<=delta.

No finite expected stopping time is assumed. For example P(N0=2^k)=2^(-k), k>=1, is finite almost surely and has infinite mean; truncation still proves the result.

## Stopped-law total variation

When N0 is finite almost surely, include a cemetery symbol for non-issuance under any parameter. Under the coupling,

    TV(law_alpha(Q),law_0(Q))
      <= P_0(N0>K)+1-(1-alpha)^K.

Choose K first and alpha second to obtain convergence to zero. This is stopped-output convergence. The raw infinite Bernoulli(alpha) and Bernoulli(0) stream laws instead have total variation distance one for every alpha>0, because only the latter assigns mass one to the all-zero infinite stream.

If endpoint issuance is only partial, full stopped-law convergence can fail: on a branch that waits forever for the first one, the endpoint never issues while every positive-alpha run eventually does. Formula (1) remains valid because it uses only finite endpoint prefixes; it must not be proved by asserting full stopped-law convergence in that partial case.

## The other endpoint

Let q1=1/2+epsilon and C=epsilon*(1-epsilon)/(1-2epsilon), which is finite because epsilon<=1/4. For alpha<1, the first good-report inequality gives q<q1. The second and concavity of the square root give

    q >= q1-C*(1-alpha).

Hence G_alpha is contained in a shrinking punctured interval immediately below q1. Coupling the same seed with all-one prefixes gives the analogous bound

    liminf_(alpha increases to 1) P_alpha(first issued report unsafe)
      >= P_1(N1<infinity).

Both endpoint obstructions concern a fixed positive baseline perturbation. The conclusion under positive parameters still follows if finite issuance on the all-zero counterfactual path is separately imposed. The closed family is what makes such endpoint liveness part of an all-parameter requirement. A zero perturbation would already be coherent and does not satisfy these conclusions.

## Controls and adjacent achievable goals

The partial-issuance lower bound can be attained by a trivial abstaining procedure: issue q=1/2 with probability p and otherwise never issue. Its unsafe probability is p for every positive alpha, while it issues with probability p at alpha=0. This shows why the conclusion is p rather than an automatic one when endpoint issuance is partial.

Eventual correctness is different. Issue q_n=1/2+epsilon*S_n/n after each observation. For interior alpha, q_n converges almost surely to q_alpha=1/2+epsilon*alpha. Both expected loss excesses at q_alpha equal -alpha*(1-alpha)*epsilon^2<0, so continuity gives eventual exact repair almost surely. At either endpoint, every empirical report equals the unique exact coherent repair. Thus finite first issuance and eventual correctness coexist, while uniform all-issued safety fails.

For positive alpha, every all-zero observed prefix produces q_n=1/2 and is unsafe. The expected number of these initial unsafe reports is (1-alpha)/alpha. Consequently no parameter-uniform expected error-count bound follows over this continuum, despite pointwise eventual correctness and zero errors at alpha=0. This does not contradict finite-model controlled-law results or a compact interior restriction.
