# Finite sidecars become actual source data and deterministic correction programs

11 October 2026 UTC. Additive, bounded T20 source-transport result. No protected edits, rule adoption, integration, theological-warrant revision, or programme closure. Author kernel verification is recorded separately from independent review.

## Result

The finite sidecar can be more than an external label beside proof-irrelevant identity. **Arbitrary finite deterministic correction tables compile into actual original Has programs, and therefore into the unchanged HasE and HasJ grammars.** Each program consumes ordinary Sigma data carrying a retained coarse natural and a local natural tag, with a fixed identity-proof slot. It returns one Sigma package containing the branch output, next coarse value and next tag. Exact finite branch histories and final data observations are proved on the literal composed source polynomials, without decoding and re-encoding between corrections.

There is also a source-observable minimum. Within a fixed coarse fibre, n classes required to be distinguished by actual typed natural-valued source observers need at least n ordinary tags, even if their identity-proof terms vary arbitrarily. n tags suffice. Across finitely many fibres, one common alphabet of size M exists exactly when each required fibre count is at most M. The same tag may be reused at another retained coarse value. This is the source realisation of the finite labelling step, not a new proof of D1's partition-refinement theorem.

**This does not implement D1's full stochastic contract.** The constructed correction has a deterministic output branch and deterministic next state. There is no sampler, random-source semantics, probability law, arbitrary-real probability representation, action-menu enforcement, or automatic interpretation of human warrant. Those boundaries are part of the result.

## 2. Exact source representation and program

The definitions are literal types in the existing calculus:

- `Evidence = Id_Raw(I,I)`
- `Labelled = Sigma N Evidence`
- `State = Sigma N Labelled`
- `Reply = Sigma N State`

Thus a state is the ordinary data package `(coarse, (tag, evidence))`; a reply is `(branch, nextState)`. The canonical encoding uses numeral data and the same I proof in every proof field. The proof slot certifies only its displayed trivial identity. It does not authenticate, endorse or causally connect the coarse value, tag or purported provenance.

`lookupPR` recursively branches on zero and decrements the query with the existing predecessor description. `tablePR` nests two such finite lookups. The resulting table has exact natural output values and an explicit fallback. A source mixed substitution sends its two natural arguments to the first projection and nested tag projection of the actual State variable. Bracket abstraction then gives a closed source arrow.

`controller_hasE` and `controller_hasJ` are literal inclusions of `controller_has : Has [] controller (State -> Reply)`. The controller therefore requires neither Joint Sigma elimination nor Joint dependent induction. No substitute typing calculus or general compiler completeness is assumed. The compiler itself is inherited; the finite table description and its use on these source records are the new additive layer.

## 3. What the operational theorems establish

`Represents p z k` says that the two ordinary projections of raw source evaluation p observe exactly the natural counts z and k. It accepts noncanonical source inputs whenever they have those observations; it is not limited to bare numeral syntax.

- `tablePR_denote` proves exact table lookup, including fallback behavior.
- `tableObserver_has` is the original-source typed observer `State -> N`.
- `tableObserver_observes` proves its exact count at represented inputs.
- `controller_observes` proves the exact joint branch and next-state observation from the same input state.
- `finite_controller_observes` specializes this to arbitrary finite rectangular rows, under `z < Z` and `k < M`.
- `runSource_typed` proves that literal compositions return a typed State and typed numeric branch terms.
- `runSource_observes` proves every finite branch history and final retained state agrees with the table execution.
- `runSource_branch_identities` additionally supplies actual HasJ identities of the returned branch terms to their exact numeral outputs. This uses the inherited closed-typed-natural extraction/canonicity result, not a general semantic-to-source completeness rule.

The action sequence in these history theorems is supplied as a finite list of deterministic tables. They do not construct or verify an adaptive policy, make all actions legal, or interpret action costs. Finite numeric labels, costs or menu indicators can be read with the generic table observer, but their meaning and an action-enforcement interface are separate obligations.

The source carriers are N, not Fin. The finite bounds are external application premises. `ClosedRectangle` and `runCodes_bounded` explicitly require each selected table to preserve the rectangle before concluding that a finite execution remains inside it. Arbitrary nonrectangular represented code sets similarly require the application to justify closure on its actual represented codes. The program's total fallback does not turn an out-of-domain state into a faithful represented state. `ClosedRectangle` bounds only the two next-state coordinates. Branch output remains arbitrary N; interpreting it as a member of a specified finite outcome set also requires an explicit range/coding premise.

## 4. Exact observational separation and minimum

`encoded_identity_iff` proves:

    there exists an actual HasJ identity of encoded (z,k) and encoded (z',k')
    iff z=z' and k=k'.

Actual typed coarse/tag projections witness the negative direction. Source identity cannot hide a differing natural observation. The positive direction uses literal equal data. In particular, labels reused at different coarse values remain separated.

`proofPacker` is an actual original-source arrow from Evidence to State. `withEvidence z k e` is its literal application. Its numeric projections give z and k for every e, and `proof_slot_cannot_separate` derives actual HasJ identity between `withEvidence z k e` and `withEvidence z k f` whenever e and f are typed at Evidence. This combines the existing proof-uniqueness theorem with source arrow congruence. External inspection of the proof syntax or derivation tree remains possible; it is outside these typed observers.

`ObservablyDifferent` requires an actual source arrow `State -> N`, exact observations at its two outputs, and unequal counts. Under that requirement:

- `finite_fibre_lower_bound` proves n <= M for n required source-observable classes encoded with M ordinary tags in one fixed coarse fibre, even with arbitrary varying typed proofs.
- `finite_fibre_attains` realizes n distinguishable classes with n tags and an actual projection observer.
- `common_alphabet_exact` states the finite-family existence/minimum equivalence: there is a common M-valued tag assignment with these source-observable distinctions iff every fibre count is <= M.

For a nonempty finite family this is equivalent to M >= max fibre count. D2 owns the separate fixed-length binary ceiling. No bit-vector source implementation is claimed here.

The minimum is relative to this declared observation requirement and the fixed `(coarse, tag, Evidence)` architecture. It is not a minimum over arbitrary source encodings, free external archives, alternative carriers, weaker query families, all cognitive warrant, or real-world provenance. Applying D2's particular P* requires the application's already-justified class assignment and its declared contract. The present code does not discover P* or show that every D1 distinction has a deterministic source witness.

## 5. Checked controls

The six-module replay checks a concrete declared operational example with four accepted support/price classes and two rejected classes:

- All four accepted classes give the same current verdict.
- One typed cost observer and one typed withdrawal observer jointly distinguish all four.
- Withdrawal returns the expected branch and next coarse/tag pair.
- A two-withdrawal source trace has actual HasJ identities to both expected branch numerals.
- Reusing tag 0 across coarse values 0 and 1 is source-distinguishable.
- Two tags cannot carry four stipulated source-observable classes, even with separately chosen proof terms.
- A common four-tag alphabet realizes fibre counts four and two.
- Empty tables and out-of-range rows/columns use the exact explicit default; an empty action sequence leaves the source input and code state unchanged.
- A deliberately escaping correction is still well typed at `State -> Reply` but fails the declared 1x1 closure condition. A second call then takes the fallback path. This directly rejects an inference from source N typing to finite-state safety.

These are mathematical/operational controls, not assignments of probabilities or actual warrant to a person's reasoning. No metaphysical or theological premise is changed or weakened.

## 6. Full D1–D3 boundary

A finite deterministic correction is a special case of a finite transition contract, but the full D1 input also contains required labels, enabled menus, costs and a joint outcome/next-block kernel. The present source programs represent and compute finite deterministic numeric tables. They do not establish that those tables are the warranted quotient of any particular application.

For a stochastic extension, encoding a selected branch as ordinary data would preserve the computation conditional on that selection. It would not reproduce the joint law. A rational sampler needs separately specified randomness and a proved sampling semantics; arbitrary real probabilities need still more representation assumptions. None is introduced here. Therefore no new D3 law-preservation, Bellman-value or almost-sure reachability claim follows from this packet alone.
