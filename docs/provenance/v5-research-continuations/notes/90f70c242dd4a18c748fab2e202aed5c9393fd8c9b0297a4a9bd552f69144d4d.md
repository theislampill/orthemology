# Qualitative global policy design and remaining proof map

This is an ordinary design map, not a proved sufficiency claim. Every bridge below must be implemented against the actual history policy and transition rows before a full converse is claimed.

## Concrete policy
The controller computes its memory from the entire observed action/state history. It maintains exact live support B, a phase counter k, and navigation versus a selected target component E. Candidate theta is the k-th cyclic element of B. All menus use the actual bottom-up winningRegion and regionAllowed.

While navigating, cycle all safe actions at the current observed state. If the current state belongs to the candidate's computed target, choose a qualifying component containing it and switch to cycling that component. Use global per-state departure counts, not the physical clock and not an assumed fresh phase counter.

After each observed transition, a proper support change resets the phase counter and navigation on the computed child region. Otherwise a detected row mismatch increments the phase counter and restarts navigation. During target operation, an observed state outside that component also rejects the phase. Such an exit is impossible for the candidate under its retained rows, but can occur under a nonmatching true model. Rejection is checked during navigation as well as operation.

Tests use global per-pair empirical prefixes reconstructed from observed histories. Fix a tolerance below half every nonzero row-coordinate separation in the finite initial model family. Permit rejection from a pair only when its observed count exceeds the phase counter k. The policy does not use the true model.

All nonempty branches remain in the current region or in the actual computed proper-child region by the literal all-branch license. Thus the hard-menu Lawful condition is proved before probability arguments.

## Eventual support and phase reasoning
Finite support descent and supported observations imply an eventually constant nonempty support containing the true model. Its current states remain in that support's computed region.

If the phase counter is unbounded, every live candidate, including the true model, is selected at arbitrarily late phase indices. On the raw convergence event, all true-row empirical deviations occur below one finite random count. Once k exceeds that count, no true-candidate row test can reject. Its operating component cannot be exited. An infinite navigation of that true candidate contradicts fair recurrent closure plus the region target-or-exit paths; hence it reaches a target and stays in its phase. This contradicts unbounded phase indices.

Therefore the support and phase eventually stabilize. If navigation remained forever, fairness holds on the safe menu. A recurrent used row mismatch would eventually reject by convergence and the fixed finite count gate. If all recurrent rows match the candidate, actual recurrent closure transfers to candidate closure; fair propagation along candidate target-or-exit paths forces a target or a support exit, contradiction. Thus operation eventually stabilizes on a qualifying component.

Within that component, a recurrent row mismatch would again force rejection. If all recurrent rows match the candidate, actual recurrent closure plus per-state action cycling implies the recurrent pair set is the whole candidate component. The true live model therefore matches every full row there, and the target qualification gives its even recurrent minimum. Finite-prefix parity invariance yields global success.
