# Source-bound target (2026-10-02)

This additive verification targets accepted Theorems A–C from the digest-bound
`unknown-root-attribution-accepted-v1` source; that source is unchanged. It is
not a new scientific result and does not widen the physical/observation contract.

Universe: an arbitrary finite label type with m labels. An admissible map has
exactly one alias class A of c labels, c ≥ 1. Class labels map to the distinguished
root `none`; every outside label i maps to `some i`. Actual roots are the image
of all labels. This is an explicit root-image representation, not label counting.
It is equivalent by root renaming to the accepted representative-index encoding.

Target A: for all B ≥ 1, c ≥ 1 with c ≤ m, and all P,R, universal root-image
intersection cardinality > B over every c-subset A iff |P ∩ R| ≥ B+c.
Empty P∩R and forced bridges must be included. No min-cardinality formula is
assumed; derive the formula/decomposition and construct violating A.

Target B: for B ≥ 1, c ≥ 1, B < m-c+1 and k=B+c-1, actual-world availability
against every admissible A and ≤ B actual faulty roots iff every k-label T has
some allowed path disjoint from T. Derive maximal-taint realizability and the
pullback cardinality, rather than postulating the desired label-fault envelope.

Target C: for arbitrary fixed path and quorum families F,G (not necessarily
uniform), requiring every allowed P,R to satisfy Target A and requiring both
actual-world availability predicates, existence iff m ≥ 3k+1. Prove lower bound
for arbitrary families and upper bound by all (m-k)-subsets. Families remain
outside all map/fault quantifiers and cannot adapt to new attribution evidence.

Non-targets: Theorems D/E, operational temporal refinements, covering-search
optimum and randomized caps. Their existing accepted ordinary proof status does
not become full kernel coverage merely because A–C are deepened. No new root
oracle, adaptive family redesign, or v2 physical premise is introduced.

Method: generic Finset proofs under ordinary Lean logical axioms. Finite regression
examples and hypothesis-deletion countermodels are controls only, not substitutes
for the all-parameter proofs. No custom axioms, sorry, native_decide, unsafe proof
code, or hypotheses equivalent to the target cardinal result are admitted.
