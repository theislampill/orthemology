# Proper-function and ontology adjudication after Deep BV

This is a program adjudication, not a theorem identity.

## Function-fixing accounts

```text
frequency:
  describes prevalence, not correctness or truth aim;

causal/systemic/organizational role:
  fixes contribution relative to a system description, not objective fittingness;

selected effect:
  depends on selection history and can select nontruth or harmful effects;

designed function:
  is conditional on an independently truth-aimed and eligible design plan;

learned objective/success surface:
  may be optimized perfectly under a false, destructive, or mis-specified target;

truth-linked epistemic function:
  requires an independently warranted truth orientation and environment relation;

Plantinga-style package:
  is conditional on design, truth aim, proper environment, and successful operation;

fiṭrah-oriented function:
  is a Track-N source-relative account until source/world/applicability bridges close;

primitive or holistic norm source:
  remains an impersonal Candidate-E/R5 stopping point.
```

## Ontology matrix disposition

The current neutral evidence does not uniquely choose among:

- nominalist practice-relative norm descriptions;
- conceptualist or one-intellect nonpersonal grounding;
- immanent realist norm properties;
- powers/dispositional realization;
- property dualism;
- impersonal teleology;
- personal-agentive teleology.

Deep CD shows that target orientation needs a certified symmetry-breaking anchor. Deep CG then strengthens the rival: one nonpersonal intellectual ground can carry COMMON content grounding, functional common-bearer structure, fittingness orientation, truth and authority registers, causal guidance, articulability, actuality, and efficacy while personal target predicates remain variable.

## Transcendental contribution

The adjudication narrows the bridge rather than closing it:

```text
truth calibration or target authority
does not entail
proper function;

proper function
would not by itself entail
one personal ground or Wisdom;

source-relative fiṭrah
can supply a school-internal function architecture
but does not migrate into neutral entailment without independent bridges.
```
