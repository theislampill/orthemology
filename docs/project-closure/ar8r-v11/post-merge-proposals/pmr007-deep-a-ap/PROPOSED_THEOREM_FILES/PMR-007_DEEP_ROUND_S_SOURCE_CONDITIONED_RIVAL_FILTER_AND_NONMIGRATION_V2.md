## 1. Typed source contract

Let `L_T` be the neutral Track-T language. Let `Σ_N` contain source-attributed predicates such as Creator, one, knowing, able, living, volition, speaking, hearing, seeing, actual Speech, and uncreated Speech. A Track-N source contract is a tuple

```text
C_N = <b, P_N, Auth, Ident>
```

where `b` is the referent to which the translated source co-predicates `P_N`, `Auth` is H12 source authentication, and `Ident` is H16 identification of that source referent with the neutral ground under assessment.

The accessible Asfahani translation provides translated-primary access to a passage that co-predicates Creator, necessity, oneness, knowledge, ability, life, volition, speech, hearing, and sight of one referent; it separately classifies volition and speech as true attributes without treating `al-murid` and `al-mutakallim` as unqualified Divine Names; and it presents the Qur'an as uncreated Speech subsisting in and spoken by Allah. It also explicitly criticizes an argument whose conclusion yields only some necessary existence but not the Creator. This source status is not Arabic-primary verification.

## 2. Source-relative rival-filter theorem

For a finite declared rival family `R`, let `D(r)` be the set of source predicates in `Σ_N` that rival `r` withholds. For `S ⊆ Σ_N`, define:

```text
Filter_N(S,R) := for every r in R, S intersects D(r).
```

Then:

> `Filter_N(S,R)` holds exactly when `S` is a transversal of the finite defect hypergraph `{D(r): r in R}`.

This is the standard hitting-set equivalence. It receives zero general mathematical novelty credit.

Under `Auth ∧ Ident`, a filtered rival is incompatible with the **source-expanded** model class because it fails at least one authenticated predicate attributed to the identified referent. If either guard is absent, no source-relative exclusion of the neutral rival follows.

## 4. Bearer-laundering control

Global availability of Knowledge, Ability/Power, Volition, and Speech across several bearers does not satisfy a source contract that co-predicates them of one referent. In the three-bearer four-role assignment class, many assignments realize all roles globally while no bearer realizes all four. Source-local binding blocks that laundering only within the source-expanded signature; it is not an independent Track-T common-bearer proof.

## 5. Nonmigration theorem

Let two models have the same `L_T` reduct but differ in their `Σ_N` source expansion. Every `L_T` sentence has the same truth value in both reducts. Therefore, a distinction produced only by `Σ_N` predicates cannot be re-described as a neutral `L_T` entailment without an additional bridge.

This is the exact Track-N to Track-T nonmigration result. It sharpens B12 and B16 rather than closing them:

```text
B12: source predicate attribution remains conditional on H12;
B16: neutral ground identification remains conditional on H16.
```
