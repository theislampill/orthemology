# Read first

This package closes the classical-versus-executable numeric-table gap under explicit executable grammar/enumeration/equality/guard-decision inputs. Begin with RESULT.md.

- Executable.lean: computational candidate enumeration, rational update, and equality with the frozen recurrence
- FiniteTable.lean: materialized finite tables, exact row membership, all-round correspondence, inherited global minima and stopping/stability
- Controls.lean and Main.lean: actual runtime evaluations; these are not proof-oracle theorems
- replay.sh and check-mutations.sh: fresh kernel compilation, runtime controls, and expected rejection checks

It returns exact prices, not proof-tree certificates. Witness existence and the height/minimum mathematics are inherited. No Python correspondence, performance, source/semantic warrant, integration, adoption, owner closure, or historical-duration claim. Predecessors are unchanged.
