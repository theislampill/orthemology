## 1. Scope-corrected setting

Let `B` be a **previously specified finite Boolean algebra of registered
extensional contents**. Let `T` be a finite created token algebra with Boolean
operations, and let

\[
\sigma:T\to B
\]

be a previously specified Boolean-algebra homomorphism.

`T` is `B`-articulating when `sigma` is surjective. This says only that every
content already in `B` has at least one created token realization.

## 2. FTASA-1A — finite impersonal construction

Every finite Boolean algebra `B` admits a finite created token algebra `T` and a
surjective homomorphism `sigma:T->B`. The construction may be implemented by a
finite table with every mentality, personality, agency, intentionality, Wisdom,
speech-capacity, and actual-Speech predicate false.

This proves a finite algebraic realization. It does not derive `B`, `sigma`, or
the distinctions they encode.

## 3. FTASA-1B — semantic quotient characterization

Define

\[
t\sim_\sigma u\iff\sigma(t)=\sigma(u).
\]

Because `sigma` is a homomorphism, `~_sigma` is a congruence and

\[
\boxed{T/{\sim_\sigma}\cong\operatorname{im}(\sigma)}.
\]

If `sigma` is surjective,

\[
\boxed{T/{\sim_\sigma}\cong B}.
\]

The quotient identifies created expressions only relative to the supplied
semantic map. It does not make the quotient uncreated, mental, divine, or
world-complete.

## 4. FTASA-1C — guarded translation

For a second created token algebra `T'` with semantic map `sigma'`, a translation
`tau:T->T'` preserves the full registered Boolean content only under the guard

\[
\sigma'\circ\tau=\sigma.
\]

A query-relative or nonhomomorphic translation can preserve less. This guard is
a formal contract, not an empirical claim about Arabic, English, natural
language, or any supplied translation.

## 5. FTASA-1D — source, world, version, and personality nonidentification

Fix `T`, `B`, `sigma`, and all Boolean operations. The same algebraic object can
be extended with:

```text

different versions and recipient-applicability states;

```

Therefore none of those coordinates factors through the finite algebraic
reduct without an additional bridge or model-class restriction.
