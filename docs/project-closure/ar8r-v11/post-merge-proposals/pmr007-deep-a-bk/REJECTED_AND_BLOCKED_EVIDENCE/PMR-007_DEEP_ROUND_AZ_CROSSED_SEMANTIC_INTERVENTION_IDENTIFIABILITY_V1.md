## 1. Candidate finite setting

Let

```text
F — surface form, token, code, or presentation;
C — interpreted content under one frozen semantic contract;
Y — system response, judgment, or action.
```

For a finite declared class, assume a deterministic potential-response table

\[
y:F\times C\to Y.
\]

The candidate experiment independently crosses forms and contents.

Define:

```text
FORM-INVARIANT:
  y(f,c)=y(f',c) for all f,f',c;

CONTENT-SENSITIVE:
  for some c!=c' and some f, y(f,c)!=y(f,c');

CONTENT-MEDIATED AT THE DECLARED TABLE:
  FORM-INVARIANT and CONTENT-SENSITIVE.
```

## 2. Candidate characterization

When every form-content cell is interventionally available and the response
table is stable, the complete crossed intervention table exactly decides the
above content-mediation predicate.

When only the diagonal support `F=C` is observed, content mediation and form
mediation need not be distinguishable.  The two tables

```text
y(f,c)=c;
y(f,c)=f
```

agree on the diagonal and disagree off it.

## 3. Intended use

The crossed design can test whether a daee/agent/learner tracks a declared
content across paraphrases, modalities, or codes rather than one surface form.
It does not by itself establish intrinsic semanticity, first-person uptake,
personality, proper function, Wisdom, or world truth.
