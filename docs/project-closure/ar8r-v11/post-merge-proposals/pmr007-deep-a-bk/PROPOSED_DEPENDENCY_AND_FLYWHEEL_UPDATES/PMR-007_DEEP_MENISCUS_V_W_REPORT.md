# PMR-007 deep-meniscus block V–W report

Deep V repaired Fable Round 1 burden B06 at the level of **diagnosis**, not
explanation.  Profile certifiability and frozen-root warrant completeness are
separate Boolean coordinates; their pair is the coarsest exact diagnostic for
those two predicates on the declared finite episode class.  A one-bit release
gate can decide joint success, but it collapses profile-only, warrant-only, and
joint failure.  The mixed states are incomparable under the coordinatewise
order, so a runtime that ranks them adds a policy or loss assignment.  An
independently supplied world-target coordinate remains separately variable.

Deep W then repaired the arbitrary side-by-side product by requiring valid
profile, warrant, and world-bridge objects to map to the same full declared
contract key:

```text
(target identity,
 target version,
 recipient scope,
 analysis version,
 referent identity,
 semantic-contract digest).
```

The finite pullback has the ordinary universal property, and every one of the
six key coordinates receives an independent erasure witness.  This is a useful
target-local integration interface.  It does **not** validate the components,
warrant the key, authenticate the source, identify the referent, establish the
world target, create a numerical bearer, or supply an intentional subject.

The combined result is therefore:

```text
profile certification
  != warrant completeness
  != world-target adequacy;

joint release
  != diagnostic completeness;

product compatibility
  != explanatory or derivational unity;

full-key agreement
  != target-key authority;

contract-aligned pullback
  != one bearer, one subject, source truth, or world truth.
```

The work materially narrows the common-core burden: there is now a precise
finite diagnostic product and a target-indexed compatibility construction.

architecture explains and constrains the target, semantic, warrant, source, and
world coordinates rather than merely transporting or joining records that
already contain them.
