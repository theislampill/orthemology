# Actual tagged-row measure bridge

This is an isolated, qualified research successor at Orthemology main `03e2604dfcef278b01c60d19b05370fcec4194b6`. It changes no canonical campaign status.

## Checked chain

1. PrefixTail proves the exact probability of a prescribed finite prefix together with any finite tail pattern, then derives full tail disintegration by uniqueness of finite-dimensional distributions
2. TaggedRows defines the actual unary selector, its echoed tag and the row observer on the untouched tail. The all-true input branch stays defined; only its measure-zero contribution is omitted from the countable mixture law
3. TaggedMass proves prefix tags preserve positive-singleton mass and that actual tagged output has zero defect exactly when every row has zero defect
4. Pi3Law composes the already-qualified least-surviving-candidate rows. Its actual fair-Cantor law has defect zero iff `forall i, exists s, forall t, R(a,i,s,t)`; positive defect iff the complementary quantifier pattern holds

The off-by-one convention is explicit: tag i is i true bits followed by false; tail starts at i+1; the first row output occupies position i+1. Every mixture weight is positive and the weights sum to one.

## Claim ceiling

These are mathematical semantics of an actual measurable observer, not a replacement abstract mixture. However, the top-level theorem permits any supplied decidable matrix family. It does not by itself prove an effective numeric-index translator, primitive-recursive compiler completeness, the final byte-code representation, or Pi3-completeness of an index set. Those obligations belong to the separately tracked compiler lane.

On Cantor space ordinary atoms correspond to points. In general measurable-space extensions, use the precise positive-singleton terminology.
