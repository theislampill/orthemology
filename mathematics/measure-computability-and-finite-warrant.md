# Measure, computability and finite warrant

An infinite object can be uniquely determined and uniformly approximable while an exact question about it remains undecidable. Conversely, a finite representation can support exact decisions that fail for an unrestricted computable representation. The difference lies in the property being asked, the effective input supplied and the evidence a recipient is entitled to use.

This work develops those distinctions for two concrete settings. The first is the atomic mass of a probability law generated by a total synchronous observer. Exact finite-cylinder probabilities yield a sharp arithmetical classification, while a finite-state restriction admits an exact rational algorithm. The second is a compact inverse system with a uniformly computable unique realization. Strict rational comparisons admit complete finite certificates; exact equality does not admit a uniformly complete effective finite-certificate discipline. The positive procedures, the reductions and their boundary controls are given explicitly. [S1–S3]

**Scientific status.** This is a composed ordinary mathematical exposition prepared for independent scientific review. It incorporates three public prose bodies at the exact editions identified in §10. It does not claim a fresh formal build, execution of a checker, empirical validation, owner adoption or priority for the inherited results. A finite calculation is mathematical evidence only for its stated representation and query.

## 1. Two concentration statistics and a separate target question

For a Borel probability measure $`\nu`$ on Cantor space $`2^{\mathbb N}`$, let

```math
\mathrm{At}(\nu)=\{y:\nu(\{y\})>0\},
\qquad
a(\nu)=\sum_{y\in\mathrm{At}(\nu)}\nu(\{y\}),
\qquad
d_{\mathrm{atom}}(\nu)=1-a(\nu).
```

The atom set is countable: for each positive integer *m*, only finitely many points can have mass at least $`1/m`$, and every atom belongs to one of these finite sets. Thus the sum is well-defined and equals the measure of the atom set. The quantity $`d_{\mathrm{atom}}`$ is the mass outside all point atoms. Zero means that the law is purely point-atomic, the property also called a *trivial measure* in the algorithmic-randomness literature; it does not mean that the probability measure is zero. [S1, §1; P1, Definition 2.4]

A different statistic is

```math
d_{\max}(\nu)=1-\sup_y\nu(\{y\}).
```

The two must retain distinct names. For

```math
\nu=\tfrac12\delta_{0^\infty}+\tfrac12\delta_{1^\infty},
```

all mass is atomic, so $`d_{\mathrm{atom}}(\nu)=0`$, whereas $`d_{\max}(\nu)=1/2`$. Both equal one on an atomless law. The tensor treatment explicitly considers the second statistic in its §11; the observer classification below concerns the first. Replacing the sum by a supremum would change its problem and invalidate its reductions. [C2, §11]

Neither statistic alone decides whether an observation preserves a particular target. If a finite observation is coarsened by merging two values carrying opposite target labels, both laws remain purely atomic while target information is lost. Conversely, the existing collective treatment supplies a complete nonatomic trace whose limiting frequency identifies one of two Bernoulli standards almost surely. Its finite prefixes are purely atomic, and its complete law has $`d_{\mathrm{atom}}=1`$. These are compatible facts about different objects and questions. The current work uses the probability statistic without reinterpreting it as cognitive failure, target insufficiency, moment indeterminacy or action authority. [C1, §§2.1, 7.8]

## 2. A total effective observer representation

### 2.1 The admitted input language

Fix a decidable syntax for primitive-recursive integer programs. An index *e* determines an observer by

```math
q_e(x)_n=P_e\bigl(n,\mathrm{enc}(x\upharpoonright(n+1))\bigr)\bmod2.
```

Invalid syntax denotes the constantly zero program. Every index therefore denotes a total productive observer. Its first *n* output bits depend only on the first *n* input bits, so it is synchronous and 1-Lipschitz in the usual prefix metric. Universal evaluation of this syntax is total computable, although it is not primitive recursive as a function of arbitrary program indices. No uniform running-time bound in the requested output length is assumed. [S1, §1]

Let $`\lambda`$ be fair-coin measure and set $`\nu_e=(q_e)_*\lambda`$. For a word $`\sigma`$ of length *n*, its cylinder probability is the exact dyadic rational

```math
p_e(\sigma)
=2^{-n}\#\{u\in\{0,1\}^n:q_e(u)\upharpoonright n=\sigma\}.
```

The expression means evaluation of each of the first *n* output bits using its required finite input prefix. There is no need to evaluate an infinite input. Every such finite enumeration terminates. The classification in §3 concerns this total syntax, not arbitrary partial machine indices accompanied by an unverified productivity promise.

### 2.2 The initial halting subfamily

For a fixed-input machine $`M_e`$, form an observer that emits zero until the machine halts and then copies fresh input bits forever. Each output bit uses only a bounded simulation, so the map from a machine description to the admitted observer syntax is effective. If the machine never halts, the output law is $`\delta_{0^\infty}`$. If it halts, infinitely many independent fair bits remain in the output, so every singleton has probability zero. Hence

```math
d_{\mathrm{atom}}((H_e)_*\lambda)
=\begin{cases}
0,&M_e\text{ never halts},\\
1,&M_e\text{ halts}.
\end{cases}
```

On this indexed subfamily, zero defect is exactly the nonhalting set and positive defect is exactly the halting set: respectively $`\Pi^0_1`$-complete and $`\Sigma^0_1`$-complete under computable many-one reductions. This does not classify the whole observer language. [S1, §2]

### 2.3 What any finite cylinder depth leaves unresolved

**Proposition 1 — Finite-depth agreement with opposite atomicity.** Given any admitted observer and any finite depth *N*, one can effectively construct two admitted observers with exactly the same output laws through depth *N*, one with $`d_{\mathrm{atom}}=0`$ and the other with $`d_{\mathrm{atom}}=1`$.

**Proof.** Both observers follow the supplied observer for the first *N* outputs. Thereafter, the first emits only zero. Its output range has at most $`2^N`$ elements, so all mass is atomic. The second thereafter copies input bits with indices at least *N*. Conditional on any initial input word, these remaining bits are independent and fair. Matching any prescribed infinite output requires matching arbitrarily many of those bits and therefore has probability zero. The modification uses finite branching on the output index and remains within the primitive-recursive synchronous representation. ∎

This is an elementary composition of the finite-prefix and fresh-tail constructions, not a priority claim. It applies to evidence limited to a finite depth of output-cylinder probabilities. The two full program descriptions differ. Reading a complete finite-state machine or proving a global source invariant supplies additional evidence and is not excluded by the proposition. In particular, the finite-state procedure in §4 is consistent with it.

For the fair Cantor law itself, truncate after N bits and fill the remaining coordinates with zero. The resulting finite-support law agrees with the fair law on every prefix through N, but its atomic defect is zero while the fair law's defect is one. Their full event-supremum total variation distance is exactly one. Finite-prefix equality therefore provides no nontrivial full-law total variation bound. [N250-186]

The ambiguity is not confined to the endpoints. For any 0≤r≤1, mix r times fair Cantor with 1−r times its N-bit truncation law. Every prefix law through N is unchanged, while the atomic defect is exactly r. Thus the full interval of defects is compatible with those same finite-prefix data. This law-level interpolation does not assert an effective program presentation for every real r. [N250-240]


## 3. Exact arithmetical complexity of atomic mass

### 3.1 An atomic-mass formula using only finite cylinders

For nonnegative integers *k,n*, put

```math
B_e(k,n)=\sum_{|\sigma|=n}\max\bigl(p_e(\sigma)-2^{-k},0\bigr).
```

These are computable rationals. For fixed *k*, the expression decreases with *n*: splitting a mass *p* into nonnegative children cannot increase the sum of their excesses above a fixed positive threshold. For fixed *n*, it increases with *k*.

**Theorem 2 — Atomic mass from cylinder excesses.**

```math
a(\nu_e)=\sup_k\inf_n B_e(k,n).
```

**Proof.** For an output $`Y\sim\nu_e`$, write $`m_n(Y)=\nu_e([Y\upharpoonright n])`$. Decreasing continuity of the probability measure gives $`m_n(y)\downarrow\nu_e(\{y\})`$. For $`\varepsilon>0`$, define

```math
\phi_\varepsilon(m)=
\begin{cases}
\max(1-\varepsilon/m,0),&m>0,\\
0,&m=0.
\end{cases}
```

The function is continuous on $`[0,1]`$ and bounded by one. Integration over the length-*n* cylinders yields

```math
E\phi_\varepsilon(m_n(Y))
=\sum_{|\sigma|=n}\max(p_e(\sigma)-\varepsilon,0).
```

Bounded convergence then gives

```math
\inf_n B_e(k,n)
=\sum_{y\in\mathrm{At}(\nu_e)}
\max\bigl(\nu_e(\{y\})-2^{-k},0\bigr).
```

Taking the increasing limit in *k* and using monotone convergence on the countable atom set proves the formula. No effective enumeration of the atoms was assumed. ∎ [S1, §3]

For rational *r*, the formula gives the exact strict-cut equivalence

```math
a(\nu_e)>r
\iff
\exists k\,\exists t\in\mathbb Q\quad
\bigl[t>r\ \land\ \forall n\ B_e(k,n)\ge t\bigr].
```

The positive gap $`t-r`$ matters. Requiring merely $`B_e(k,n)>r`$ at every finite stage would permit an infimum equal to *r*. Rational comparisons here are decidable, so the strict lower cut of atomic mass is $`\Sigma^0_2`$.

The heavy events therefore decrease with N to the event that the singleton mass is at least 2^(-k); increasing k exhausts the positive-singleton support. Consequently a(ν_e)=sup_k inf_N H_e(k,N). ## 4. The finite-state class has an exact positive procedure

Consider a finite synchronous Mealy machine with states *S*, initial state $`s_0`$, transition $`\delta:S\times\{0,1\}\to S`$ and output $`o:S\times\{0,1\}\to\{0,1\}`$, driven by independent fair bits.

### 4.1 Finding the states with input-insensitive output

Start with $`E_0=S\times S`$ and repeatedly delete a pair $`(s,t)`$ unless, for every pair of input bits *b,c*,

```math
o(s,b)=o(t,c)
\quad\text{and}\quad
(\delta(s,b),\delta(t,c))\in E_r.
```

Equivalently these conditions define $`E_{r+1}`$ from $`E_r`$. The decreasing sequence stabilizes after finitely many deletions; call its final relation *E*. Put

```math
D=\{s:(s,s)\in E\}.
```

A state belongs to *D* exactly when every input stream produces the same output stream. One direction follows by induction on finite prefix length from the fixed-point condition. For the other, a pair with identical outputs on all pairs of infinite inputs must have equal first outputs and successors with the same property, so all such pairs survive every deletion. Equivalently, every deleted pair has a finite distinguishing input pair. The set *D* is transition-closed. Its fixed output from each state is eventually periodic: one may follow the all-zero input through finitely many states. [S1, §5]

A finite refinement bound follows from the partial-equivalence structure, not merely from the number of ordered state pairs. For a decreasing deterministic iteration of partial equivalence relations from the universal relation on a nonempty m-state set, complete each relation on two tagged copies of the states: equal tagged points are related, and so are any points whose underlying states were related. Each inactive state contributes two singleton classes; each active equivalence class contributes one. The quotient starts with one class and has at most 2m. A proper refinement increases its class count, since the fine quotient surjects onto the coarse one and a lost related pair separates its opposite-tag representatives. Thus there are at most 2m−1 strict steps. Once consecutive stages agree, the fixed update makes every later stage agree.

The concrete Mealy recurrence above satisfies those partial-equivalence and deterministic-update premises. Consequently E_(2m)=E_(2m−1), and E_(2m−1) is the intersection of all finite approximants. At depth n the relation compares all independently chosen pairs of length-n input words, not merely identical inputs in both runs. Every state outside D therefore has two distinguishing words of length 2m−1, so the common block length in the atomicity proof below may be chosen as L=2m−1. Two- and three-state controls exclude a general m-round replacement; this does not assert universal optimality or a running-time bound. [C250-068] [C250-103] [C250-109]

The small-control qualification can be sharpened to a uniform statement about the distinguishing horizon, without claiming optimal running time. The completion potential is exactly 2(m−|dom R|)+c(R), where c(R) counts equivalence classes in the active domain. This includes the empty-domain case. The 2m−1 distinguishing horizon is attained for every positive state count: for m≥2, use a base state that can wait or enter an input-insensitive countdown chain. From the distinguished chain state all length 2m−2 input words give the same output, while two continuations differ at length 2m−1. For m=1, the input-copying machine already separates at one tick. Thus the horizon cannot be uniformly reduced for this class; this is not an optimal running-time claim. The literal guarded update R intersect refine(R) gives exactly the same approximants from the universal relation, because those approximants decrease, so the horizon and witnesses apply to that guarded iteration too. ### 4.2 Atomic mass equals a reachability probability

**Theorem 4 — Finite-state atomicity.**

```math
a(\nu)=\Pr_{s_0}(\text{eventually hit }D),
\qquad
d_{\mathrm{atom}}(\nu)=\Pr_{s_0}(\text{never hit }D).
```

**Proof.** Every finite hitting input word produces a finite output prefix followed by one fixed tail. These outputs form a countable set. Each has positive probability, because the corresponding finite input cylinder has positive probability and its subsequent output is fixed.

For each state outside *D*, deletion of its diagonal pair supplies two equally long input words with different output words. Pad them when necessary and choose a common length *L* for the finitely many such states. At least one of those two words disagrees with any specified length-*L* target output. Its input probability is $`2^{-L}`$. Hence, from any state outside *D*, the probability of matching a prescribed target block while remaining outside *D* is at most $`1-2^{-L}`$. Repeated conditioning on successive finite blocks gives a bound $`(1-2^{-L})^j`$ for *j* blocks. It tends to zero. Every fixed infinite output therefore has probability zero on runs that never hit *D*.

Since the full atom set is countable, runs avoiding *D* contribute no mass to it. Runs hitting *D* contribute all their mass to atoms, proving both identities. ∎

The adversarial controls distinguish these measure identities from event identities. In the split observer, one exceptional input avoids the deterministic-output hitting set yet still produces the zero stream, which is a positive atom; equality of atomic mass and hitting probability does not assert equality of those input events. Removing avoidance from fixed-output fibre nullity fails for the constant observer, whose fibre has mass one. Removing the zero boundary on non-reaching states permits a nonzero homogeneous harmonic solution. Finally, infinitely many outputs that merely repeat the first input bit still have a two-point carrier and zero diffuse defect: fresh coordinates cannot be replaced by repeated access to one sample. ### 4.3 Exact rational computation

The theorem gives a terminating algorithm on the full finite machine description:

1. Compute *E* by finite relation deletion and extract *D*.
2. In the directed transition graph, find the states *Z* from which *D* is unreachable.
3. Set $`h=1`$ on *D* and $`h=0`$ on *Z*.
4. For every remaining state, solve

```math
h(s)=\tfrac12h(\delta(s,0))+\tfrac12h(\delta(s,1)).
```

5. Return $`1-h(s_0)`$ as the exact defect and compare that rational number with the requested rational threshold.

The remaining linear system is nonsingular. Every remaining state has a finite path to *D*. Finiteness supplies a common finite upper bound on the length of a suitable exit path and a positive lower bound on its probability. The probability of staying forever in the remaining subgraph is therefore zero. Its transition submatrix has powers tending to zero, so $`I-Q`$ is invertible. Rational Gaussian elimination computes the unique solution exactly. This is a decidability result, with no asserted optimal complexity bound.

The finite-horizon computation is separately exact: count the n-bit input words ending in D and divide by 2^n. These increasing probabilities converge to atomic mass, but convergence alone does not prove that the limit is rational. The source's executable infinite-horizon solver computes backward reachability in at most m expansions, then uses Cramer's determinants for the same boundary system, with a proved nonzero denominator. Its rational result is identified with the actual fair-input hitting law; subtracting it from one yields the defect. This is a different implementation of the exact solution from Gaussian elimination, with no complexity guarantee asserted here. [C250-099] [C250-102] [C250-104]

## 5. Compact survivors and finite robust answers

The previous decision theorem obtains strength by restricting the representation. A different positive result restricts the query and states the effective evidence interface explicitly.

**Theorem 5 — Finite witness for an open answer region.** Let $`K_0\supseteq K_1\supseteq\cdots`$ be nonempty compact subsets of a Hausdorff space, and put $`S=\bigcap_nK_n`$. If *U* is open and contains *S*, some finite stage satisfies $`K_N\subseteq U`$.

**Proof.** The nested compact sets have a nonempty intersection. If no $`K_n`$ lies in *U*, then the nonempty sets $`K_n\setminus U`$ are closed subsets of compact $`K_0`$. They are nested, hence have the finite-intersection property and a common point. That point belongs to *S* and lies outside *U*, a contradiction. ∎ [S2, §1]

The theorem applies to the actual finite-extension images at a fixed coordinate, or to the actual images of a fixed finite block of observations. If the declared answer is the same throughout an ambient open neighbourhood of every surviving realization, a finite range warrants that answer for every compatible realization. The realization itself need not be unique.

For a continuous real observable *g*, strict regions $`\{g<\tau\}`$ and $`\{g>\tau\}`$ are open. Equality is not covered merely because it is true on the final survivor. The ambient topology matters: continuity only on *S* does not make the relevant answer region open around *S*.

### 5.1 The effective search and its premises

For an algorithm, assume a computable metric presentation, uniformly supplied upper-compact names for the sets $`K_n`$, and an effectively open name for *U*. Concretely, the compact names must semidecide whether a supplied finite family of basic open balls covers $`K_n`$, and the open name enumerates basic balls making up *U*. These are part of the input, not consequences of set-theoretic compactness. [S2, §1; S3, C17–C18]

Dovetail the containment searches for all *n*. Within each search, enumerate finite subfamilies of balls already listed for *U* and run the cover semidecision for $`K_n`$. If any such check succeeds, output *n* with that finite cover. Soundness follows because the cover lies in *U*. Completeness on the promised robust instances follows from Theorem 5 and compactness: a stage wholly in *U* has a finite subcover drawn from its enumerated balls, and its cover check eventually succeeds. Running the searches by dovetailing is necessary; waiting forever on an earlier false containment would not be a complete search.

If *g* is computable and continuous in the represented sense, its strict rational sublevel and superlevel regions supply the needed effective open names. A separately supplied numerical convergence rate or an advance lower bound on the query gap is unnecessary. The conclusion is termination on the stated promise domain. The search does not decide those promises for arbitrary proposed descriptions. The existing effective-compactness literature gives the same finite-cover interface and computability of an effectively compact singleton; no new abstract compactness principle is claimed here. [P2, §2.6]

The tensor reconstruction theorem already uses an effective compact representing fibre together with uniform moment names and a determinacy promise. Its computed law and its promise conditions retain their own proof. The present theorem explains a related query-level consequence and also covers nonunique survivors when the requested answer is constant on a suitable open neighbourhood. It does not rederive or weaken the moment theorem's input requirements. [C2, §10.1]

## 6. A uniformly computable realization and complete strict certificates

Let *P* be a well-formed unary P02-L1 program, with natural output and the inherited bounded-loop semantics. Define its bit stream and inverse system by

```math
b_P(i)=\mathrm{Eval}(P,i)\bmod2,
\qquad X_i=[0,1],
\qquad f_{P,i}(x)=\frac{x+b_P(i)}2.
```

The evaluation used here is the unary evaluator with argument *i*. A different wrapper with an incompatible arity contract cannot be substituted for it. Every finite evaluation terminates mathematically, although a particular implementation may refuse a resource limit. [S2, §2; S3, C06, C12]

### 6.1 Existence, uniqueness and the exact finite range

**Theorem 6 — A unique computable compatible realization.** The system has the unique realization

```math
x_{P,i}=\sum_{r\ge0}b_P(i+r)2^{-r-1}.
```

Each coordinate is uniformly computable with error at most $`2^{-n}`$ after its first *n* terms. At coordinate zero, the depth-*n* finite-extension image is exactly

```math
K_{0,n}=\left[\frac{V_n}{2^n},\frac{V_n+1}{2^n}\right],
\qquad V_0=0,
\qquad V_{n+1}=2V_n+b_P(n).
```

**Proof.** The series is nonnegative and bounded by one. Splitting off its first term proves compatibility, $`x_{P,i}=(b_P(i)+x_{P,i+1})/2`$. For any compatible realization *z*, unwinding *n* equations gives

```math
z_i=\sum_{r\lt{}n}b_P(i+r)2^{-r-1}+2^{-n}z_{i+n}.
```

Both remaining tail coordinates lie in $`[0,1]`$, so the distance between *z* and the displayed realization at coordinate *i* is at most $`2^{-n}`$ for every *n*. It is therefore zero. The same formula proves the approximation bound and the exact image interval: the finite extension's last free coordinate ranges through all of $`[0,1]`$. Writing the integer prefix value as

```math
V_n=\sum_{k\lt{}n}b_P(k)2^{n-1-k}
```

gives the recurrence. ∎ [S2, §2; S3, §1]

This is inverse composition: adding a depth composes the next map on the right. For bits 0,1, the map is $`f_0(f_1(x))=(1+x)/4`$, not $`(2+x)/4`$. The distinction is detectable by a nonconstant prefix and cannot be checked by all-zero examples alone.

### 6.2 The finite certificate service

Fix a threshold $`\tau=p/d`$ with integer *p* and positive integer *d*. Let $`x_P=x_{P,0}`$. A finite witness consists of a depth *n* and the correctly replayed prefix calculation. The exact integer tests are

```math
\begin{aligned}
\text{Below:}&\quad (V_n+1)d\lt{}p2^n,\\
\text{Above:}&\quad V_nd>p2^n.
\end{aligned}
```

**Theorem 7 — Sound and complete finite witnesses for strict comparisons.** A successful Below test implies $`x_P<\tau`$, and a successful Above test implies $`x_P>\tau`$. Every true strict comparison eventually has its corresponding successful test. At equality neither test ever succeeds.

**Proof.** Soundness follows from Theorem 6's enclosing interval. If $`x_P<\tau`$, choose *n* with $`2^{-n}<\tau-x_P`$. The interval's upper endpoint is at most $`x_P+2^{-n}`$, hence is strictly below *τ*. The Above case follows by the corresponding lower-endpoint bound. At equality the point belongs to every interval, excluding both strict endpoint tests. ∎ [S2, §2; S3, §1]

To search for a strict answer, compute successively $`b_P(0),b_P(1),\ldots`$, update $`V_n`$ and apply the chosen test. The unknown positive gap is used only in the termination proof; it need not be supplied. An implementation that exhausts a resource budget has refused this search. It has not proved equality or disproved the requested strict inequality.

The verifier must also bind the calculation to the independently expected request: the literal program or its explicitly declared identity normal form, threshold, scalar interpretation, model and version, recipient, comparison and governing release rule. It must reject malformed syntax, a zero denominator, inconsistent prefix length, non-bit prefix entries, a claimed *V* different from replay, or a stale bound field. Exact binding proves that the calculation concerns the expected record. It does not prove the record's worldly truth or authority. [S2, §2; S3, C07–C12]

## 7. Complete effective equality certification is obstructed

The preceding realization is computable with a fixed geometric error bound. That does not make exact zero uniformly semidecidable. The target reduction can be written inside the actual bounded-loop program fragment instead of assuming a black-box simulation oracle.

### 7.1 The source machine premise and the admitted AST construction

Use nonempty finite valid two-counter instruction tables. Each instruction is a halt instruction H, an increment $`I(r,t)`$, or a conditional decrement $`D(r,t_{\mathrm{zero}},t_{\mathrm{nonzero}})`$, with $`r\in\{0,1\}`$ and in-range targets. Both counters and the initial program counter start at zero. A stage *t* means the instruction in the configuration after *t* transitions, so an initial H has stage zero. [S3, §2]

The recursion-theoretic premise is the standard one for this source machine class: its halting set is computably enumerable and undecidable. Consequently its nonhalting set is not computably enumerable, since simultaneous enumeration of halting and nonhalting would decide which holds. This premise is inherited computability background; no new formalization of two-counter universality is claimed. The following complete construction establishes the reduction into the target language actually used here.

Use distinct natural-number registers with these roles.

| Register | Role |
|---|---|
| 0 | Unary input *n*, never written |
| 1 | Output bit |
| 2 | Current program counter |
| 3 | Snapshotted program counter |
| 4, 5 | Source counters |
| 6 | Latched halt bit |
| 7 | Bounded-loop index |
| 8 | Previous halt bit |

Construct a finite unary P02-L1 AST with output register 1. Initialize registers 1, 2, 4, 5 and 6 to zero. Execute a bounded loop of length $`n+1`$ using register 7. On each iteration:

1. Copy register 6 into register 8.
2. If register 6 is zero, copy register 2 into register 3 and execute a finite sequence of cases, one for each source instruction index *j*. Every case tests register 3 against the constant *j*.
3. The matching H case sets register 6 to one. An I case increments the selected source counter and assigns its target to the program counter. A D case tests the selected counter: at zero it assigns the zero target; otherwise it subtracts one using truncated natural subtraction and assigns the nonzero target.
4. Assign $`\mathrm{sub}(\text{register }6,\text{register }8)`$ to output register 1.

All operations expand into the existing finite `set`, `seq`, `if`, bounded `loop`, register, constant, addition, comparison and truncated-subtraction constructors. The source table only determines finitely many case branches and numerals. Validity of that table is decidable, and the table-to-AST map is effective. No new primitive instruction, unbounded loop or external execution oracle is introduced. [S3, §2]

**Invariant and first-halting correctness.** Before iteration $`t+1`$, either the halt bit is zero and the program counter and counters are the source configuration after *t* transitions, or the halt bit is one and H has already been reached. In the first case exactly one instruction case runs. Its test uses the unchanged snapshot, so assigning a new program counter cannot activate a second case in the same iteration. In the second case no instruction case runs. The halt bit changes at most once, from zero to one, and the output at the end of the iteration is one exactly when that change occurs.

After $`n+1`$ iterations, the program therefore outputs one exactly when the first H stage is *n*. Initial H produces $`1,0,0,\ldots`$; an initial increment leading to H produces $`0,1,0,\ldots`$; a self-looping increment with no H produces only zeros. These controls fix the indexing and the one-step simulation semantics. Every finite evaluation terminates irrespective of whether the source machine ever halts.

For the resulting admitted unary program $`P_M`$,

```math
x_{P_M}=
\begin{cases}
0,&M\text{ never halts},\\
2^{-t-1},&M\text{ first reaches H at stage }t.
\end{cases}
```

Every one of these inverse systems retains compactness, continuity, unique realization, exact contraction factor $`1/2`$ and the uniform $`2^{-n}`$ approximation bound.

### 7.2 The certificate impossibility and its positive exceptions

**Theorem 8 — No uniformly complete effective finite equality discipline.** Let *C* be any effectively enumerable class of finite certificates, and let $`A(P,c)`$ be computably enumerable acceptance. It is impossible that acceptance is sound for $`x_P=0`$ over every admitted *P* and complete for every true zero instance in the family $`P_M`$.

**Proof.** Given *M*, effectively construct $`P_M`$. Enumerate candidate certificates and dovetail their acceptance computations. Soundness ensures that an acceptance implies $`x_{P_M}=0`$, hence nonhalting. Completeness ensures that a nonhalting machine eventually has an accepted certificate. This semidecides nonhalting, contradicting the stated source-machine premise. ∎ [S2, §3; S3, §§2–3]

The certificate may be an invariant, induction argument, arithmetic derivation or global finite proof. The argument does not restrict it to an observation prefix. A constantly zero program has a direct finite equality proof. A source table with a self-looping increment and no H has a finite nonhalting invariant, also yielding a genuine equality proof. A verifier accepting a finite list of sound exceptional instances is possible but incomplete. An unsupported asserted law is not such a proof; a noncomputable acceptance oracle lies outside the effective premise.

The simpler observer reduction in §2.2 similarly excludes an effective sound finite-certificate discipline complete for zero diffuse defect on the entire admitted observer language. The stronger threshold classification does not require reading this impossibility as a ban on restricted fragments. The original finite invariant certificates remain sound incomplete services at their own stated scope. [S1, §6]

### 8.2 General compactness controls

**C13 — A robust answer without a unique state.** Let $`X_i=\{0,1\}\times[0,1]`$ and $`f_i(c,x)=(c,x/2)`$. There are two compatible realizations, with fixed first coordinate zero or one and second coordinate zero. With observable $`g(c,x)=x`$, depth three gives values in $`[0,1/8]`$ and certifies $`g<1/4`$ for both. This is a general compact-query example, not an input to a scalar-only unary certificate format.

**C14 — One unique coordinate need not make the entire realization unique.** Take $`X_0`$ to be a singleton and $`X_i=\{0,1\}`$ for $`i\ge1`$. Let $`f_0`$ be constant and all later maps be identities. Coordinate zero is fixed, but the full inverse system has two realizations. A coordinate-zero certificate cannot be promoted to full-state uniqueness.

**C15 — Continuity only on survivors is insufficient.** Take $`K_n=[0,2^{-n}]`$, $`S=\{0\}`$, and $`q(x)=1`$ exactly at zero. Its restriction to *S* is continuous. Every finite range also contains positive points, so no such range makes *q* constant. A separate global proof can establish that the survivor is zero; the control excludes the unsupported ambient-open inference.

**C16 — Closedness does not replace compactness.** In $`\mathbb R`$, let $`K_n=\{0\}\cup[n+1,\infty)`$ and $`U=(-1,1)`$. The sets are nonempty, closed and nested, and their intersection is $`\{0\}\subset U`$. None lies inside *U*. The extra points escape to infinity. This is a set-theoretic counterexample, not an effective-search claim.

**C17 — Existence does not supply effective names.** Fix a noncomputable $`\alpha\in[0,1]`$ and make every bonding map the constant *α*. The system is compact, continuous and uniquely realized, and every positive-depth coordinate range is $`\{\alpha\}`$. These existence statements provide no computable name for the map or the point. A purported effective solver using only them would have to compute *α*. This missing-input example differs from §6, where both the maps and the unique state are uniformly computable.

The fixed-point report gives a stronger sampling obstruction for that missing effective input. Take a constant singleton correspondence whose probability is Bernoulli with a noncomputable bias α. Its semantic fixed point is unique and its topological behavior is harmless. Enumerating the disjoint accepting prefixes for each answer gives increasing computable lower bounds on its probability. Almost-sure termination makes the two outcome probabilities sum to one, so either lower approximation supplies an upper approximation for the other; waiting until their remaining gap is below any requested tolerance computes α, a contradiction. ## 9. The effective access distinction

The results supply three concrete positive interfaces with different conclusions.

| Supplied representation and premises | Complete positive service | Remaining boundary |
|---|---|---|
| Full finite synchronous Mealy machine under fair independent inputs | Exact rational diffuse defect and every rational threshold decision | Does not extend to unbounded computable state. |
| Uniform upper-compact ranges, an effective open answer region, and containment of all survivors in that region | A finite containment witness found by dovetailing cover checks | Does not decide validity of the names or the robustness promise. |
| Admitted unary generator, its exact bit interpretation and a fixed strict rational query | A finite replayed dyadic witness for every true strict comparison | Does not certify equality by absence of a strict witness. |

For an arbitrary admitted first-halting generator, evaluating its first three bits may establish 000 without settling whether its source ever halts. That finite prefix nevertheless proves $`x_P\in[0,1/8]`$ and therefore $`x_P<1/4`$. A later first halting bit can make the scalar positive while preserving that conclusion. Under a previously admitted rule requiring precisely this strict bound, the mathematical evidence is sufficient now. A rule demanding exact zero requires an additional genuine global equality proof or continued withholding. These are different fixed queries; changing the rule is not a step of the proof. [S2, §4; S3, §6]

The hierarchy theorem, the finite-state procedure and the compact-query theorem therefore coexist without contradiction. Exact finite observations, a complete source description, effective approximation, robust finite warrant and uniformly complete exact decision are distinct capabilities. The source identity and request-binding controls preserve which capability was actually supplied. No empirical probability, interpretation of harm, collective acquisition advantage, communication-cost improvement or physical intervention permission follows from the scalar construction.

### 9.1 Finite success and an indefinitely continuing policy

The finite-state positive procedure in section 4 and the equality obstruction in section 7 concern different representations. A further distinction appears even when each local admission test is decidable: reaching every finite horizon need not supply one effective policy that continues forever. The *Mathematical Companion*, entries 1–6 and 11, studies this question through a rooted, prefix-closed binary tree $`T\subseteq 2^{<\mathbb N}`$. A node records an already committed history. A finite planner returns some $`H(n)\in T\cap 2^n`$; an irreversible controller must emit one infinite sequence all of whose prefixes belong to $`T`$. The quantifier order changes from a uniformly available finite witness at each requested horizon to compatible witnesses generated by a single continuing computation. [Renewal and certification companion][renewal-companion]

Here a computable controller includes its entire computable support: helper procedures, stored tables and any computable source of advice. It may pause for an arbitrary finite time between commitments. It cannot erase an actual earlier commitment or obtain a noncomputable oracle merely by calling it a supporting service. For a decidable tree, an indefinitely successful controller exists exactly when $`T`$ has a computable infinite path. One direction reads the path's next bit. For the other, simulate the controller until its $`(n+1)`$st commitment; indefinite success makes that computation terminate and computes the $`n`$th bit.

This model does not identify indefinite continuation with physical immortality, a person's identity through replacement, or an irrevocable entitlement to act. Its application to a real process requires an independently supported correspondence between admissible physical histories and the mathematical tree. A finite certificate that verifies a route, local state transfer or a permission condition does not by itself establish that correspondence or the continued availability of the resources on which the next certificate depends.

Finite completion has a separate compactness condition. Fix one policy and a certificate contract, and let U contain its realizable finite prefixes with no checked goal certificate. If U is finitely branching, every admitted complete trace reaches a checked goal certificate in finite time, and every infinite branch of U is itself an admitted trace, then König’s lemma gives a uniform finite resolution depth. Aborts, unresolved failures and permanently blocked runs must remain in the admitted domain and do not count as goal-certificate success. Pointwise success alone is insufficient: in scenario n, sequentially querying for a unique witness at location n and then checking its proof takes n+2 steps. Every admitted scenario resolves, but the all-zero unresolved limit branch has realizable finite prefixes and is excluded from the domain. Realization of unresolved branches, rather than mere local feasibility, is the missing premise. This classical application neither synthesizes the policy nor supplies effective level tests or uniform costs for its steps; almost-sure termination is also weaker than termination on every admitted branch. ### 9.2 An explicit decidable tree with finite planners and no effective lineage

Fix an effective enumeration $`(\varphi_e)`$ of partial computable numerical functions. Put

```math
A=\{e:\varphi_e(e)\downarrow=0\},\qquad
B=\{e:\varphi_e(e)\downarrow=1\}.
```

These disjoint computably enumerable sets have no computable binary separator taking value $`1`$ on $`A`$ and $`0`$ on $`B`$. If $`f`$ were such a separator and $`\varphi_k=f`$, its value at $`k`$ would be required to differ from itself. Outputs other than $`0,1`$ impose no condition.

Let $`A_n,B_n`$ be the bounded-stage approximations obtained by running the relevant computations for $`n`$ steps and retaining indices below $`n`$. Admit a word $`\sigma\in 2^n`$ exactly when

```math
e\in A_n\Rightarrow\sigma(e)=1,
\qquad
e\in B_n\Rightarrow\sigma(e)=0.
```

Membership is decidable by bounded simulation. Earlier-stage requirements are among later-stage requirements, so this is a prefix-closed tree. The finite planner

```math
H(n)(e)=
\begin{cases}1,&e\in A_n,\\0,&e\notin A_n\end{cases}
\qquad(e\lt{}n)
```

always produces an admitted node. A mathematical infinite path exists: the characteristic function of $`A`$ meets every requirement. Every infinite path separates $`A`$ from $`B`$, however, so no such path is computable. Equivalently, if a computable path has index $`k`$, its convergent diagonal computation is eventually visible at a sufficiently large finite level and forces the opposite bit. This supplies an explicit counterexample; the absence of a controller is not inferred from the failure of a bounded search.

The familiar existence of recursive binary trees without recursive paths provides the computability-theoretic background. The present construction also supplies the finite planner and fixes the operational meaning of a committed lineage. Jockusch and Soare's treatment of effectively closed classes and the later accounts of recursively bounded trees distinguish mathematical paths from recursive members; those general antecedents do not turn a local finite planner into a uniform path selector. [Effectively closed classes][renewal-jockusch-soare] [Recursive branches][renewal-gasarch]

There is a concrete transfer interpretation. Let a state be $`(u,v)\in 2^2`$, with transition $`\Delta((u,v),i)=(v,i)`$ and output $`\Lambda(u,v)=u`$. Alternate generations encode this same state by the identity and by componentwise complementation. The transfer between successive encodings is the induced bijection; decoded readout and transitions commute for every input, not just along one sampled trace. Add the actual history tag and require its next committed bit to remain in $`T`$. This lineage is part of the stipulated causal transition history, not an inference from a self-reported string; an independently manufactured lookalike can share the semantic state without sharing that history. Each finite transfer can then be exactly state preserving while the choice of indefinitely many admissible tags has the obstruction just proved. For every requested finite horizon, a computable tag plan works on every always-authorised service-input history, and a mathematical infinite route exists for each such history. The negative controller result already applies to the one fixed history stated below.

After each committed transfer, the product model removes the predecessor instance token from its active configuration. The successor uses the transferred full finite state and history tag, the constructor/checker code, current permission information and the declared common support; no operation reads the retired token. The common platform, memory supply, interpretation of the admission tree and legitimate authority remain explicit support. Token exclusion in this model therefore does not establish physical independence or exclusion of every original failure root.

An independently governed permission condition $`p`$ prospectively permits the active instance to establish one admitted child while $`p=1`$, and expressly permits that child's next use under the same condition. The instance cannot set $`p`$ or enlarge the grant. Tree membership and permission have different roles: membership does not establish normative legitimacy. Revocation requires the specified orderly termination, rather than resistance to withdrawal. The negative example already holds on the fixed authorised branch with permission constantly $`1`$ and service input constantly $`0`$; it does not depend on revocation or an adversarial input stream. A finite state-transfer certificate establishes neither physical authenticity nor the authority represented by the grant. Those remain separate premises of an application.

### 9.3 The positive condition: an effective pruned witness

Call a subtree $`U\subseteq T`$ **rooted and pruned** when it contains the empty word, is prefix closed, and every node has at least one immediate child in $`U`$. For a decidable binary tree $`T`$, the following are equivalent:

1. $`T`$ has a computable infinite path.
2. $`T`$ contains a decidable rooted pruned subtree.
3. $`T`$ contains a computably enumerable rooted pruned subtree.

**Proof.** The prefixes of a computable path form a decidable rooted pruned subtree. A decidable subtree is computably enumerable. Given an enumeration of a rooted pruned $`U`$, start at the empty word and wait until either of the two children of the current word appears. Pruning makes each wait finite. Commit to the first enumerated child and repeat. Prefix closure and $`U\subseteq T`$ make every commitment lawful. This constructs a computable path. $`\square`$

In this construction each search must restart the enumeration from its beginning or consult retained earlier emissions as well as new ones. A computably enumerable subtree need not be enumerated in prefix order. For example, the pruned subtree $`\{0^n:n=0,1,2,\ldots\}`$ can be enumerated without repetition in the order $`\epsilon,00,0,000,0000,\ldots`$. A procedure that selects 0 when it is emitted and then waits only for a newly emitted immediate child misses the already emitted 00 and waits forever. Restarting or retaining output finds that child and preserves the proof's finite-wait conclusion. This clarifies the operation of the existing effective search; it adds no hypothesis of prefix-ordered enumeration. [Collective diagnosis and committed continuation, §4.4][continuation-reassessment]

The procedure is uniform in a supplied valid enumeration. It is not a procedure that discovers such an enumeration from every positive tree, or decides that an arbitrary enumeration has the required properties. In particular the tree of section 9.2 has no such witness despite having an explicit mathematical path and a finite planner.

The natural viability core is

```math
V(T)=\{\sigma\in T:
\forall m\geq |\sigma|\ \exists\tau\in T\cap2^m\ (\sigma\preceq\tau)\}.
```

For a decidable finitely branching tree, nonmembership in this core is computably enumerable: find a finite extension level containing no continuation of $`\sigma`$. Thus $`V(T)`$ is co-computably enumerable. In the diagonal example it is nonempty, rooted and pruned, but cannot also be computably enumerable, since the preceding procedure would compute a path. Knowing the exact local transition law and knowing that some continuation exists at every depth are therefore insufficient to enumerate a viable next-choice service.

For an explicitly given finite graph the situation changes. Delete dead ends until a fixed point is reached, and retain a reachable cycle or a nonempty pruned region. This finite calculation supplies a continuing policy whenever one exists. A finite abstraction of an infinite physical system inherits this positive result only after its soundness and the availability of the corresponding concrete actions have been established. Merely drawing a finite diagram does not discharge that bridge.

### 9.4 Why private randomness has two different boundaries

For the particular diagonal tree of section 9.2, every computable fair-coin committed controller succeeds with probability zero. The statement is stronger than absence of a computable path, and its proof uses the special separator construction.

Let $`S`$ be the measurable event that a machine emits infinitely many bits and all its committed prefixes belong to that tree. Suppose $`\Pr(S)>0`$. Approximate $`S`$ in measure by a finite union of coin cylinders with error less than $`\Pr(S)/5`$. The conditional mass of $`S`$ in that union exceeds $`2/3`$, so at least one constituent cylinder $`[\rho]`$ has

```math
\Pr(S\mid[\rho])>2/3.
```

Hardcode this finite prefix. For each coordinate $`e`$ and bit $`b`$, the event $`E(e,b)`$ that the machine eventually emits $`b`$ there is effectively open: every finite computation that makes that commitment supplies a finite coin cylinder. Its conditional probability has a computable increasing sequence of rational lower bounds. On $`S`$ the coordinate is emitted, so at least one of $`E(e,0),E(e,1)`$ has conditional probability greater than $`1/3`$. Search both lower bounds and output the first bit whose bound exceeds $`1/3`$. This computes a total binary function $`g`$.

If $`\varphi_e(e)\downarrow=b`$, every successful path has bit $`1-b`$ at coordinate $`e`$. Hence $`E(e,b)`$ is disjoint from $`S`$ and has conditional mass less than $`1/3`$. The search cannot output $`b`$. Thus $`g`$ is the forbidden separator, a contradiction. $`\square`$

The proof does not effectively find $`\rho`$ from the program, and supplies no uniform finite time by which failure must be visible. It allows the machine to diverge or stop on failing coin streams. It does not say that every computable tree without a computable path has measure zero, or that randomness cannot ever improve a success probability.

There is also a general boundary at **probability one**. Let $`T`$ be any fixed rooted prefix-closed binary tree, with no effectiveness assumption on its membership. Suppose an effective committed fair-coin machine produces a path through $`T`$ almost surely. For each finite output word $`s`$, let $`E_s`$ be the event that it emits $`s`$ as a prefix, and define

```math
U=\{s:\Pr(E_s)>0\}.
```

An effectively open event has positive measure exactly when its enumeration contains a nonempty cylinder. Therefore $`U`$ is computably enumerable, contains the root and is prefix closed. If $`s\notin T`$ were in $`U`$, a positive-measure cylinder would force failure, contradicting almost-sure success. If $`s\in U`$, almost every tape in $`E_s`$ eventually emits another bit; the two child events cover $`E_s`$ up to a null set, so at least one child has positive measure. Thus $`U`$ is pruned. The child-enumeration procedure of section 9.3 computes a path without querying membership in $`T`$.

Consequently, for this private-coin service,

```math
\text{computable path}
\ \Longleftrightarrow\
\text{almost-sure effective controller}
\ \Longleftrightarrow\
\text{c.e. rooted pruned witness}
\ \Longleftrightarrow\
\text{decidable rooted pruned witness}.
```

This is a promise-based extraction, not a decision procedure for the probability-one premise. The output-support proof also does not claim that arbitrarily chosen finite witnesses to positive output probability are compatible prefixes of a single input tape.

A stronger tape statement can be proved separately. Let $`D_n`$ be the effectively open, full-measure set of tapes on which the original machine emits at least $`n`$ bits. Every nonempty cylinder meets $`D_n`$ in a nonempty cylinder. Starting from $`\rho_0`$, effectively search for an extension $`\rho_{n+1}`$ whose cylinder forces at least $`n+1`$ emissions, and pad its length to at least $`n+1`$. The search terminates by full measure and effective openness. The nested prefixes determine a computable tape on which the original machine emits forever. Every emitted prefix is valid: otherwise its finite computation would force a bad prefix on a positive-measure cylinder. This proves existence of a computable successful tape for the same machine, without a running-time or memory bound. Replacing its private random source is an available intervention only when the actual system permits that replacement; an external agent's choices are not private coins.

### 9.5 Arbitrarily high success below probability one

The last equivalence is sharp. For each integer $`k\geq2`$, enumerate at most one forbidden word for each program index $`e`$: wait until that program has produced its first $`e+k`$ binary outputs, and then enumerate that word $`w_e`$. Put

```math
O_k=\bigcup_e[w_e],\qquad
\mu(O_k)\leq\sum_{e\geq0}2^{-(e+k)}=2^{1-k}.
```

Every computable binary sequence has some index and therefore lies in $`O_k`$. At stage $`n`$, admit a word of length $`n`$ when it has no forbidden prefix enumerated by that stage. The resulting $`T_k`$ is a decidable prefix-closed binary tree: an earlier prefix is checked against an earlier subset of the prohibitions. Its infinite paths are exactly $`2^{\mathbb N}\setminus O_k`$. Thus

```math
\mu([T_k])\geq1-2^{1-k},
\qquad [T_k]\text{ contains no computable sequence}.
```

A machine that simply copies independent fair bits succeeds with this probability. Given any fixed $`r<1`$, choosing sufficiently large $`k`$ yields success above $`r`$ and still no deterministic computable path. This is a different tree from section 9.2. A computable pseudorandom tape belongs to the excluded computable sequences; finite statistical resemblance to fair coin tossing does not change that fact. The construction establishes a mathematical probability threshold, not an empirical diagnosis of physical random generators.

### 9.6 Closed generations, population width and perfect path sets

A population service has a different output object from a single lineage. At stage $`n`$ it must finish and publish a **complete closed** nonempty finite set $`G_n\subseteq T\cap2^n`$. Every member of $`G_{n+1}`$ has its parent in $`G_n`$, and a closed generation is never reopened. For a deterministic computable successful service, $`G=\bigcup_nG_n`$ is decidable and prefix closed. The finite computation publishing generation $`n`$ decides membership at that level.

If $`|G_n|\leq K`$ at every level, $`G`$ has at most $`K`$ infinite paths: $`K+1`$ distinct paths would have distinct prefixes at a sufficiently large common level. A nonempty finite set of paths has an isolated member, selected by a finite prefix that separates it from the others. Above this prefix the tree has a unique infinite path. That path is computable. At each fork, dovetail the searches for a finite empty extension level above each child. The child not on the unique path has only finitely many extensions by finite branching, so its search terminates; choose the other child. Hardcoding the isolating prefix is legitimate for this existence proof, although finding it uniformly from the service is a different problem. This would compute a path in the diagonal tree, which is impossible.

The argument yields more than the exclusion of a fixed width bound. Every successful computable closed-generation service for that tree has **no isolated infinite path**. Its nonempty closed path set is therefore perfect. An elementary binary-splitting construction chooses two incompatible extensions above each selected prefix and repeats indefinitely; nesting maps $`2^{\mathbb N}`$ injectively into $`[G]`$. Thus it has continuum many paths. This is a classical construction, not an effective selector or a computable embedding of the full binary tree.

It also follows that

```math
\forall K\ \exists N\ \forall n\geq N\quad |G_n|>K.
```

Choose $`K+1`$ distinct paths and a level at which their prefixes are distinct; those prefixes remain distinct at all subsequent levels. The widths therefore tend to infinity. They need not increase monotonically, and the argument gives no computable uniform rate. The stronger conclusion concerns the size of completed generations, not instantaneous concurrent hardware, maximum stack size, or a backtracking search's transient occupancy.

There is a corresponding almost-everywhere statement for random population services on the diagonal target. For each finite word $`\sigma`$, define a computable random-tape extractor that waits for the service's closed generations and follows the unique infinite branch above $`\sigma`$ by the dead-child search whenever that search succeeds. It may stall on other tapes. If a successful run has an isolated path, some finite $`\sigma`$ isolates it and the corresponding extractor succeeds. Each extractor has success probability zero by section 9.4; the countable union over finite $`\sigma`$ is still null. Almost every successful run therefore has no isolated path, and its closed path set is perfect with widths tending to infinity. A bound $`K`$ that depends on the tape remains excluded. The random realised tree need not itself be computable; this argument uses countably many effective tape extractors rather than assuming that it is.

There is nevertheless a simple positive population service: publish the entire finite level $`T\cap2^n`$. The finite planner makes each level nonempty, decidability makes it computable, and prefix closure supplies parent coherence. It preserves alternatives with growing completed populations but does not select one effective infinite lineage. An operational implementation of this population service requires prospective permission for both admitted children and the capacity to maintain them; the mathematical tree does not supply those resources or permissions.

### 9.7 Uniform selection, revisable plans and finite lookahead

Nonuniform existence must not be confused with a uniform policy extractor. A useful width-two family makes this distinction explicit. For index $`e`$, admit only constant words $`0^n,1^n`$; the word $`b^n`$ survives exactly while the bounded simulation of $`\varphi_e(e)`$ has not halted with output $`b`$. Each tree has at least one computable constant path. If a total positive-promise selector uniformly returned a path through each such tree, computing its first bit would give a total computable $`f(e)`$ different from $`\varphi_e(e)`$ whenever the latter is binary. At an index of $`f`$ this is impossible. Every instance may have a computable solution without one effective rule selecting solutions across all instances.

The finite planner of section 9.2 also produces revisable approximations

```math
h_n(e)=\begin{cases}H(n)(e),&e\lt{}n,\\0,&e\geq n.
\end{cases}
```

For each $`e`$, these values increase monotonically to $`\mathbf1_A(e)`$. A computable uniform stabilisation modulus would compute that characteristic function, and so cannot exist. Nor can a computable procedure choose unbounded horizons whose returned finite words form one nested chain: their union would be a computable path. Revising a provisional plan is permitted in this construction; revising an already enacted history is not.

Finite lookahead does not remove the obstruction. Let $`h(s)`$ be any total computable natural-valued function of the current finite history, with no fixed bound on its growth. Define

```math
\mathrm{Look}_h(s)\Longleftrightarrow
\exists t\in T\cap2^{|s|+h(s)}\ (s\preceq t),
```

and let $`L_h`$ contain those $`s\in T`$ for which every prefix passes this test. Each test is a finite search, and only finitely many prefixes are tested, so $`L_h`$ is decidable and prefix closed. Moreover

```math
[L_h]=[T].
```

Every path through $`T`$ supplies all the required finite extensions; the reverse inclusion follows from $`L_h\subseteq T`$. On the diagonal target, $`L_h`$ therefore still has nodes at every level, an effective finite planner obtained by finite search, and no computable path. The random zero-success and closed-generation population obstructions depend on its path set and carry over. The witness in a lookahead test is an extension in the original $`T`$, not a recursively assumed witness to all future lookahead tests. Totality of $`h`$ is a premise, not something this procedure decides. The source's implemented search order may differ from a lexicographic mathematical presentation; correctness does not require identical selected words.

### 9.8 The complexity depends on the input language

The companion fixes a decidable syntax of primitive-recursive programs for finite-word predicates. A malformed code denotes the root-only tree; a well-formed code is made rooted and prefix closed by requiring its predicate at every nonempty prefix. Each individual membership predicate is primitive recursive. Universal evaluation over arbitrary primitive-recursive syntax is total computable, but is not itself primitive recursive. That distinction is essential when forming the uniform index sets.

For this numbering write $`\mathrm{INF}(e)`$ for the existence of a mathematical infinite path, $`\mathrm{CP}(e)`$ for a computable path, and $`\mathrm{PATH}(e,p)`$ for the assertion that ordinary program $`p`$ computes a total binary path. Write $`\mathrm{PRUNED}(e,j)`$ when enumeration $`j`$ presents a rooted, sound, prefix-closed, pruned subtree of $`T_e`$. The exact classifications are:

| Property | Complexity in the declared representation | Meaning of the bound |
|---|---|---|
| $`\mathrm{INF}`$ | $`\Pi^0_1`$-complete | Every finite level is nonempty. |
| $`\mathrm{CP}`$ | $`\Sigma^0_3`$-complete | Some ordinary program is a total binary path. |
| $`\mathrm{PATH}`$ | $`\Pi^0_2`$-complete | The supplied program must terminate at every coordinate. |
| Validity of a supplied primitive-recursive total controller | $`\Pi^0_1`$-complete | Totality is already supplied by its syntax. |
| $`\mathrm{PRUNED}`$ | $`\Pi^0_2`$-complete | Enumeration must supply all children and prefixes eventually. |

For $`\mathrm{INF}`$, nonempty finite levels give the $`\Pi^0_1`$ definition. Hardness follows from a tree that retains $`0^n`$ exactly while a chosen computation has not halted within $`n`$ steps. For $`\mathrm{PATH}`$, write

```math
\forall n\ \exists s\quad
\text{the first }n\text{ outputs halt by stage }s,
\text{ are binary, and form a node of }T_e.
```

Totality reduces to this property even for the full binary tree. If the controller is primitive recursive and syntactically total, only the universal finite membership conditions remain; bounded nonhalting gives the matching $`\Pi^0_1`$ lower bound. Quantifying existentially over ordinary program indices gives the $`\Sigma^0_3`$ upper bound for $`\mathrm{CP}`$.

For $`\mathrm{PRUNED}`$, inclusion in $`T_e`$ is universal over finite enumerations, while root occurrence, occurrence of required prefixes and eventual occurrence of a child have a $`\forall\exists`$ form. Conversely, given $`\forall y\exists z\,R(a,y,z)`$ with a decidable bounded witness test, enumerate $`0^k`$ once witnesses have appeared for the first $`k`$ requirements. The resulting enumeration is rooted and sound in the full binary tree; it is pruned exactly when all requirements eventually receive witnesses. This proves the $`\Pi^0_2`$ lower bound. Section 9.3 supplies the further exact identity

```math
\mathrm{CP}(e)\Longleftrightarrow\exists j\,\mathrm{PRUNED}(e,j).
```

### 9.9 A constructive hardness proof that keeps every tree infinite

The lower bound for $`\mathrm{CP}`$ can be proved without hiding a non-effective tree presentation. Fix the primitive-recursive diagonal tree $`K`$ of section 9.2 and its finite planner $`H`$. Let a $`\Sigma^0_3`$ predicate have the form

```math
P(a)\Longleftrightarrow\exists x\ \forall y\ \exists z\ R(a,x,y,z),
```

where the required finite tests are primitive recursive. Define a monotone progress function

```math
\ell(a,x,s)=\max\{k\leq s:
\forall y\lt{}k\ \exists z\leq s\ R(a,x,y,z)\}.
```

It is unbounded exactly when row $`x`$ satisfies its $`\forall\exists`$ condition. Use stage $`0`$ and every stage at which $`\ell`$ strictly increases as block cuts. Define $`U_{a,x}`$ by requiring the word in every block between successive visible cuts, including the last unfinished block, to be in $`K`$. This is a primitive-recursive prefix-closed tree. If there are infinitely many cuts, compute the next cut before filling each block with the finite planner $`H`$ at that block length. This computes a path. If there are only finitely many cuts, every infinite path has a tail through $`K`$, so none is computable. A mathematical path exists in either case.

The existential choice of $`x`$ must be encoded without accidentally creating an easy limiting branch. Attaching the component for row $`x`$ at $`0^x1`$ would always admit the computable no-exit path $`0^\omega`$, regardless of whether any row succeeds. The construction instead uses $`K`$ itself as its skeleton. For a word $`\sigma`$, set $`c(\sigma)=0\sigma(0)\,0\sigma(1)\cdots`$. Build $`S_a`$ from the words $`c(\sigma)`$, their intermediate zero prefixes, and words

```math
c(\sigma)\,1\,\tau,
\qquad \sigma\in K,\quad \tau\in U_{a,|\sigma|}.
```

The first $`1`$ in a marker position is a one-time exit to a row; before that exit, the alternating data positions trace $`K`$. The finite parsing test is primitive recursive and prefix closed. A path that never exits decodes a path through $`K`$, and cannot be computable. A computable path that exits after $`x`$ data bits has a computable tail through $`U_{a,x}`$, so that row has unbounded progress. Conversely, a successful row $`x`$ yields a computable path by prefixing its computable $`U_{a,x}`$ path with $`c(H(x))1`$. Every $`S_a`$ remains infinite, while

```math
S_a\text{ has a computable path}\Longleftrightarrow P(a).
```

In particular the all-zero marker branch is not an unintended computable solution: its alternating data must still form a path through $`K`$. For fixed $`R`$, the bounded parsing and the primitive-recursive $`K`$, $`\ell`$ and $`R`$ operations form a fixed finite membership-program template. Effective substitution of the numerical parameter $`a`$ into that template gives a total computable map $`a\mapsto e(a)`$ into valid primitive-recursive syntax. Since $`S_a`$ is already rooted and prefix closed, the normalisation in section 9.8 leaves it unchanged: $`T_{e(a)}=S_a`$. The reduction therefore supplies actual finite input descriptions, not only an abstract family of decidable trees. This completes the $`\Sigma^0_3`$ hardness proof on an everywhere-infinite family. The broader classification of recursively bounded effectively closed classes is a known computability-theoretic result; the explicit construction here fixes the finite planner, coding and all-positive mathematical-path promise used in the application. [Representation of closed classes][renewal-cenzer-remmel]

### 9.10 What finite checking can and cannot supply

A sound, complete effective system of finite **positive** certificates for $`\mathrm{CP}`$ would enumerate that index set: enumerate all finite certificates and run the checker. Its $`\Sigma^0_3`$ completeness excludes such a system. The same argument excludes complete effective positive certification of arbitrary-program $`\mathrm{PATH}`$ and of $`\mathrm{PRUNED}`$, both $`\Pi^0_2`$-complete. It does not say that a particular finite certificate cannot establish a particular policy, or that every useful restricted class has this obstruction.

Nor can an algorithm decide $`\mathrm{CP}`$, or halt exactly on all positive instances and return a verified policy. A procedure promised only positive inputs is a different claim; section 9.7 supplies its separate width-two obstruction. Relative to actual oracles, $`0'''`$ decides the $`\Sigma^0_3`$ index set, and $`0''`$ can test $`\mathrm{PATH}(e,p)`$ and search for a path program on a positive instance. These are precise recursion-theoretic access statements, not licenses to assume that a physical or institutional oracle is available.

The classifications also change with the representation. Suppose a raw input $`d`$ is arbitrary machine code intended to decide membership of finite binary words. Count malformed descriptions and programs that are non-total, non-Boolean, root-rejecting or not prefix closed as negative. This defines the mathematical question; it does not provide an algorithm that recognises all invalid descriptions.

For mathematical infinitude, let $`D(d,n,s)`$ require that by stage $`s`$ the machine has returned Boolean answers on every word of length at most $`n`$, that those answers describe a rooted prefix-closed finite tree, and that at least one length-$`n`$ word is accepted. This is a finite decidable condition, and

```math
\mathrm{INF}_{\mathrm{raw}}(d)
\Longleftrightarrow\forall n\ \exists s\ D(d,n,s).
```

The right side ensures a valid total decider with a nonempty level at every depth; finite branching then gives an infinite path. Conversely, a valid decider with an infinite path supplies the required finite answers and an accepted length-$`n`$ prefix, so some sufficiently large $`s`$ works. This proves the $`\Pi^0_2`$ upper bound. For hardness, take any predicate $`b\in B\Longleftrightarrow\forall n\exists s\,R_0(b,n,s)`$ with decidable $`R_0`$. On a word of length $`m`$, the constructed program waits until witnesses have been found for every $`n\leq m`$ and then accepts. If $`b\in B`$, this is the total full-tree decider. Otherwise it is non-total and hence invalid. The construction reduces every $`\Pi^0_2`$ set to raw mathematical infinitude, establishing completeness.

For a computable path, conjoin the finite validity checks with termination of the first $`n`$ outputs of a proposed ordinary program $`p`$, their Boolean values and admission of their prefixes by $`d`$, all witnessed by the same sufficiently large finite stage. The resulting decidable predicate $`Q_{\mathrm{raw}}`$ gives

```math
\mathrm{CP}_{\mathrm{raw}}(d)
\Longleftrightarrow\exists p\ \forall n\ \exists s\ Q_{\mathrm{raw}}(d,p,n,s),
```

which is the $`\Sigma^0_3`$ upper bound. For the matching lower bound, compile the syntax-total tree descriptions of section 9.9 into ordinary deciders. Every output of that reduction is valid, and it has a computable path exactly when the original $`\Sigma^0_3`$ predicate holds. Raw computable-path existence is therefore still $`\Sigma^0_3`$-complete, while raw mathematical infinitude is $`\Pi^0_2`$-complete instead of the syntax-total $`\Pi^0_1`$ classification. Input totality is part of the problem. Similarly, an ordinary possibly partial proposed controller has a different validity problem from a primitive-recursive syntactically total one.

The transfer product of section 9.2 preserves both directions of the effective-policy claim. Given a computable path through the supplied $`T_e`$, use its successive bits for renewal choices and the fixed state-transfer and service algorithms for interleaved inputs. This yields one ordinary controller that renews indefinitely on every always-authorised service-input history in the declared product, independently of which service inputs occur. It retains the specified termination branch when permission is revoked. Conversely, any ordinary supported controller guaranteeing such uniform indefinite renewal must succeed on the computable history with permission always present and service input constantly zero. Simulating its successive commitments on that history computes a $`T_e`$-path. Thus existence of this uniform continuing service is equivalent to $`\mathrm{CP}(e)`$.

This equivalence does not automatically classify every population, probabilistic or resource-bounded service built around that product. Conversely, a system whose invariant already includes a warranted effective next-choice rule is not refuted by an example that lacks such a rule. The practical conclusion is to state the actual service—finite horizon, one lineage, closed population, or revisable plan—and to identify the witness that makes its positive continuation claim effective.

#### Exact operational scope of the tree and renewal interfaces

The source-level tree construction and its contracts distinguish a mathematical witness from a request to inspect that witness. `EffectiveTree` supplies primitive-recursive finite admission and finite plans at each depth, together with a mathematical path and the obstruction to a computable path. Its bounded evaluator uses a fuel/value bound; the numeral in that evaluator is not a proved count of physical or Turing-machine steps. `TreeAudit` contains axiom-printing, evaluation and small-example requests. Finite lookahead must check the completed prefix as well as every proper prefix. The independent edge controls exhibit the omitted-boundary error: every proper-prefix check can hold while the last check fails. Conversely, requiring finite lookahead at every prefix still leaves the same infinite path set, as §9.7 proves. `LookaheadAdmissionRequired` and `LookaheadBoundaryRequired` request the corresponding computability, prefix-closure, path-equivalence and pruning-boundary declarations; the requests do not prove them again. The renewal construction makes the operational qualification explicit. A migration changes the generation token and encoding while preserving the modeled service state, but retains the stipulated platform, constructor and authority support. A revoked grant takes the termination branch. Finite plans supply the corresponding finite runs. The obstruction to one computable committed observer already holds on the fixed, constantly authorised zero-input history; it does not assert failure on every possible environment. An environment supplying a noncomputable path as advice can enable a copy-input observer, so the blanket contrary claim is separately rejected. The constructive hardness argument also keeps two quantifiers apart. `ProgressCuts` identifies row totality with unbounded progress cuts and non-totality with eventual stabilisation of the last cut. `SkeletonUnion` then obtains a computable path exactly when **some** row is total. The reset-component implementation supplies the link between progress cuts and a coherent path. At each completed cut, retain the whole ended block; a snapshot has length equal to the last cut, is admitted, and extends earlier snapshots. Unbounded computable cuts therefore yield a computable path. If the last cut instead stabilizes, an infinite component tail would compute a path through the diagonal tree, which is impossible. The resulting equivalence is between a component's computable path and totality of its designated row. Finite slices in this construction have their advertised length even beyond the word by default-false padding; identification with an actual word segment requires the explicit bound b+m≤length. The target finite-word checker is total, and every produced tree has a mathematical infinite path. What varies is computable-path existence. ### 9.11 A full moment name and an indexed law are different outputs

The effective-law theorem in [Tensor Moments, §10.1](tensor-moments-and-corrective-dynamics.md#101-computing-an-actual-determinate-law-from-all-its-moments) computes an unlabelled law under validity and determinacy promises. A countable indexed representation asks for more: approximation in $\ell^1$ of the individual weights attached to a supplied sequence of distinct support points. The capped-countable-recovery guide reports a positive theorem with known injective computable support and effective cap tails, and a failure without equivalent effective tail or total information. Full moment determination and effective recovery in this stronger representation must therefore remain separate. [GUIDE105-G050]

Here is the compactness mechanism under explicit sufficient hypotheses. Suppose $x_i$ is an injective computable sequence in a fixed compact box, and the admissible probability weights satisfy

```math
0\le p_i\le c_i,\qquad \sum_i p_i=1,
```

where the nonnegative caps are computable and their tails have a computable bound tending to zero. The capped box is effectively totally bounded in $\ell^1$: choose $N$ making $\sum_{i>N}c_i$ small, then cover the first $N$ bounded coordinates by a rational grid. It is closed and complete, hence compact. The normalization equation and coordinate inequalities define an effectively closed admissible subset. A nonempty subset is assumed; the argument is not a decision procedure for consistency of arbitrary inputs.

Every polynomial moment is uniformly computable from such a weight vector. On the compact box the polynomial has a computable bound, so truncating the weight sum gives a certified tail error and the finite part can be approximated effectively. Conversely, equality of all polynomial moments identifies the Borel law by compact polynomial approximation. Injectivity of the support sequence then identifies every weight as the law's mass at that particular point. Thus a valid full moment name cuts out a singleton in the compact admissible weight space.

The effective compact-singleton argument used earlier in this work now applies in the indexed space. Enumerate strict violations of the moment equations and of the defining constraints. Search for a finite cover of the ambient capped box by those excluded open sets together with a ball of the desired radius around a rational approximation. A cover certifies that the promised singleton lies in the ball; some such cover exists by compactness. Finite rational probability vectors can be used as approximation centers, for example by truncating and reallocating the small omitted mass. The centers need not satisfy the caps exactly. This proves approximation of the actual indexed law under the stated promises, without deciding validity, giving a running-time estimate or claiming that every arbitrary moment sequence has a representative. The mechanism is standard effective compactness, as in Tensor Moments §10.1, not a new abstract selection principle. [GUIDE105-G050]

The same compactness explains why a finite precision certificate can exist for each requested error without one fixed exact cutoff sufficing. For any $\varepsilon>0$, if no finite set of moment tests with positive tolerances controlled the $\ell^1$ error, there would be pairs of admissible weights at least $\varepsilon$ apart agreeing increasingly closely on increasingly many moments. Compactness supplies convergent subsequences. Their limits would have all moments equal, hence the same weights, contradicting their separation. This proves a finite-test conclusion on the **fixed capped domain**; its effective search uses the supplied effective compactness and computable tests.

The finite-data consequence computes an approximate law, not just a small fibre diameter. For requested ε>0, effective upper compactness of K_c² semidecides covers by {‖p−q‖₁<ε/2} together with finitely many strict moment-separation sets; dovetailing yields a finite degree R and threshold δ>0 uniform over this fixed support and cap. \sum_{n>N}\frac{t^n\mathbb E X^n}{n!}

### 9.13 Residual approximation, uniqueness and selection

The stationary-selection guide distinguishes approximation of a residual, exact computation under uniqueness, and failure of uniform exact selection. It also reports an exact cap-only contraction coefficient and an equivalent universal uniqueness criterion, with strict-gap certificates and error bounds. The guide expressly requires **row domination**, a stronger premise than general envelope invariance, for that cap criterion. Its coefficient formula and general proof are not supplied in the short body, so they are not inferred from the word cap or from the finite control count. [GUIDE105-G062]

The elementary quantitative implication is useful in its own right. If a supplied operator $T$ is a contraction with known $0\le\kappa<1$ and fixed point $x_*$, then

```math
\|x-x_*\|\le\|x-Tx\|+\|Tx-Tx_*\|
\le\|x-Tx\|+\kappa\|x-x_*\|,
```

so $\|x-x_*\|\le\|x-Tx\|/(1-\kappa)$. A small residual gives a certified error only after the operator, norm and strict contraction gap have been supplied. Envelope invariance merely keeps iterates inside a set and does not furnish that estimate. Without a uniqueness or selection premise, several fixed points can have exactly zero residual.

A finite row-dominated model supplies an explicit coefficient behind one part of the cap discussion. Let P be a stochastic matrix, c_j=max_i P_ij and C=Σ_j c_j. For any two rows p,q, Σ_j min(p_j,q_j)=2−Σ_j max(p_j,q_j)≥2−C. Their total-variation distance is therefore at most min(1,C−1). The same bound contracts arbitrary probability inputs: for unequal μ,ν write μ−ν=d(α−β), where d is their total-variation distance and α,β are probabilities obtained from its positive and negative parts. Convexity bounds TV(αP,βP) by the largest distance between two rows. Thus C<2 supplies a strict contraction and, on the finite simplex, a unique stationary law with the corresponding residual certificate. The bound is sharp as a function of the cap total for C=1+ρ∈[1,2]: P has rows (1,0) and (1−ρ,ρ), its maximum row distance is ρ, and the orbit from (0,1) has ℓ¹ distance 2ρ^t from (1,0). This finite argument does not reconstruct the guide’s general countable cap criterion or identify envelope invariance with row domination. The rational controls were read rather than executed.
