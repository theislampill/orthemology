## What is proved

For an infinite action stream taking values in a finite action type:

- Some action recurs infinitely often, so the exact recurrent action set is nonempty
- After some finite time, every action belongs to the recurrent set
- On the event that the recurrent set is exactly U, the set of times at which the action is outside U is literally finite
- Recurrence of each action, exact recurrent-set events, and deterministic-tail events are measurable when each action coordinate of the random stream is measurable
- Under a probability measure, almost-sure eventual membership in G implies that some nonempty U contained in G has a positive-probability exact recurrent-set event
- Any positive-probability exact recurrent-set event contains a positive-probability deterministic-tail event: there is some N after which all actions lie in U

The combined theorem `exists_measurable_positive_recurrent_support` returns a nonempty U contained in G, measurability and positive probability of its exact recurrent-set event, and finiteness of the outside-U action times for every path in that event. No recurrence convergence or query bound is supplied as an assumption.

`tailEvent X U N` is defined as the exact recurrent-set event intersected with the event that every action at time n>=N belongs to U. The formal equality of the exact event with the countable union of these tail events is what licenses selection of a deterministic N. No stopping-time property is assumed or concluded.

## The abstract necessity theorem

`abstract_self_verifying_support` takes:

1. One common action-stream map X and a family of probability laws indexed by models
2. One target action set for each model, with almost-sure eventual target membership under that model's law
3. An explicit relation Agree(theta,eta,U)
4. An explicit transfer premise: whenever Agree(theta,eta,U) holds and a specified `tailEvent X U N` has positive theta probability, it has positive eta probability

It concludes that every model theta has a nonempty U contained in its target such that all models eta agreeing with theta on U accept every action in U.

The relation Agree is not defined as equality of observation kernels in this module. The transfer premise is not derived from a randomized policy, fresh observation laws, or the finite-query evaluator. Instantiating these hypotheses using the original CIRS model remains the semantic bridge. Thus this is the abstract recurrent-support necessity theorem, not a compiled full CIRS necessity theorem.

## Type and verification details

The finite action type is explicit through `Fintype A`. A separate nonempty-action assumption is unnecessary: the supplied total infinite action stream already supplies an action. The probability-law assumption rules out a vacuous zero measure. Targets need not be assumed nonempty; the success hypothesis and conclusion imply the needed nonempty support.

The core positive-partition argument does not require measurability of X; it uses measure subadditivity over its finitely many possible recurrent sets. The combined measurable theorem adds coordinate measurability explicitly and proves the event measurability. This stronger core statement is intentional and does not hide an assumed measurable event.

The finite outside-U conclusion is pointwise on the exact recurrent-set event, not merely almost sure under one model. The deterministic N can depend on the model and the selected U; no deterministic uniform bound across all successful paths or all models is claimed.
