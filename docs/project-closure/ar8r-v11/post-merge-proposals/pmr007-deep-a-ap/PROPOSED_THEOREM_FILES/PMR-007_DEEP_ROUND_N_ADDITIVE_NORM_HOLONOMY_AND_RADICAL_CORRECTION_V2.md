## 1. Frozen declared revision system

Let `G=(V,E)` be a finite, static graph complete for a declared revision scope. Each oriented traversal has a stable registered integer increment

\[

## 2. ANH-1A — componentwise additive-potential criterion

For each connected component `C` of `G`, the following are equivalent:

1. there exists `N_C:C -> Z` such that
   \[
   d(u,v)=N_C(v)-N_C(u)
   \]
   on every edge in `C`;
2. the signed sum of `d` on every closed walk in `C` is zero;
3. the signed sum is zero on every fundamental cycle relative to one spanning tree.

When these conditions hold, `N_C` is unique up to an additive constant on `C`.

### Proof

`1 -> 2` telescopes. `2 -> 3` is immediate. For `3 -> 1`, fix a root and spanning tree, define `N_C(v)` by summing labels on the unique tree path from the root to `v`, and use each fundamental-cycle equation to verify every non-tree edge. Uniqueness follows because the difference of two potentials is constant along every edge and hence on the component.

This is the standard graph-potential/exact-cochain theorem. General mathematical novelty is zero.
