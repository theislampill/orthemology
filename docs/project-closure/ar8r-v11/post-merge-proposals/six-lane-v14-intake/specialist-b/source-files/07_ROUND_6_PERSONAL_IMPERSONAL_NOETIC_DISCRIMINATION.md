## 1. Residual-guided hypothesis

Repeated attempts to infer personality leave the same remainder:

```text

intentional uptake;
same-subject episode ownership;
counterfactual agency and because-of control;
center/lineage stability;

```

Deep AJ already decomposes these as H8a–H8f. Deep BT shows that finite

weaker than intentional uptake and Wisdom.

The question is whether there is a missing **finite behavioural invariant** that
breaks these rivals. Within a model class explicitly closed under
personal/impersonal profile twins, the answer is no.

## 2. Twin-closure theorem schema

Let:

```text
M        model class;
E : M → Profile      complete registered finite experiment/transcript profile;
Pers : M → Bool      target personality coordinate.
```

Assume **twin closure**:

\[
\forall m\in M\;\exists m'\in M:\quad E(m')=E(m)\land Pers(m')\neq Pers(m).
\]

Then `Pers` is not constant on any attained profile fibre, so no decoder from
`E(M)` identifies personality.

This is an immediate application of the existing fibre criterion. It is not a
new theorem and it does not prove that every metaphysically possible experiment
has an impersonal twin. Its force is exactly relative to the declared finite
profile and closure assumption.

The finite checker instantiates all binary response functions on two binary
interventions and duplicates each profile with both personality labels. Every
profile fibre contains both labels.

## 4. Why stronger finite profiles still may fail

Adding more finite observations helps only if the rival class cannot reproduce
them. The following can remain extensional twins:

```text
open-loop responses;
adaptive finite transcripts;
content swaps;
fittingness-labelled signals;
self-report of ownership;
reason-shaped explanations;
error correction;
long but bounded memory;
cross-domain coordination;
common-bearer functional incidence.
```

An impersonal realizer can be defined over the enlarged finite history set
unless the model class excludes it for an independently justified constitutive
reason. Excluding it simply because it lacks personality is target leakage.

Therefore the next discriminator must be one of:

1. an independently justified intensional/constitutive semantic condition;
2. a resource or realization constraint common to all architectures that the
   impersonal twin cannot meet;
3. a causal intervention whose interpretation does not presuppose uptake or
   subjecthood; or
4. an accepted nonidentifiability conclusion for the declared class.

## 5. Countermodels

### SB-CM45 — one-intellect nonpersonal architecture

One nonpersonal intellectual structure represents all content, integrates the
registered functional roles, responds to truth/fittingness signals, and guides
a concrete actualizer. It lacks de se ownership and personal agency under the
intended target semantics while matching the current profiles.

### SB-CM46 — finite-history table

For every registered adaptive history, an impersonal lookup/transition system
returns exactly the personal model’s next output. No finite transcript in the
frozen set distinguishes them.

### SB-CM47 — centered token without subject

A system maintains an `I`-indexed data structure and uses first-person grammar
without any independently established subject. Centered representation is not
centered ownership.

### SB-CM48 — reason-report mimic

A system outputs the reason that causally triggered its selection, but the
trigger is an impersonal transition condition. Accurate reason report does not
establish intentional uptake or normative answerability.

### SB-CM49 — distributed ownership pipeline

One component encodes the center, another evaluates reasons, another selects,
and another executes. The transcript presents one coherent first-person voice,
but no one bearer owns the episode.

### SB-CM50 — source-predicated personality without neutral bridge

An authenticated source predicates personality-like attributes of a revealed
bearer. The neutral experiment’s target is a different candidate unless a
referent/identity bridge is supplied. Source predication is not a neutral
personality discriminator.

### SB-CM51 — resource-bounded split only

A personal implementation is cheaper under one arbitrary cost metric, but the
metric is not common across architectures. Apparent discrimination is an
unjustified resource-unit shift.

### SB-CM52 — constitutive-definition leakage

The intervention defines “genuine response” as one caused by intentional
uptake. Rivals fail by definition, not by independent evidence.

## 6. Proper-function and noetic implications

Likewise, noetic correction can occur in a personal, distributed, or impersonal
representation architecture at the level of the registered formal profile.
Actual uptake/restoration remains a separate target.

## 7. Source and qiyās ceiling

A source may identify a personal bearer and attribute knowledge, will, power,
Wisdom, or Speech. Conditional source acceptance can therefore constrain a
Track-N model. It cannot be smuggled into the common intervention as a neutral
semantic fact. Qiyās al-awlā also presupposes a fixed bearer/source relation;
it does not derive H8a–H8f from finite behavior.
