# Prospective discriminator

Recorded before constructing the finite model or running its checks.

Target: distinguish a local causal-completeness claim from the stronger assertion that a causally sufficient nonmental base excludes reasoning through content. A Boolean transition will be examined at two explicitly specified levels, with a fixed abstraction map. Require the abstraction to commute with the micro-transition on every state, not only one successful run; require intervention tests that remove either premise signal and change the conclusion response. Give an ordinary propositional truth semantics separately and verify conditional truth preservation.

Negative control: preserve the rule and causal implementation but make one accepted premise false of the external situation. The same successful computation must then fail to establish a true conclusion. This tests the external-reference/input boundary without misdescribing formal validity as meaningless symbol shuffling.

Claim ceiling: the result can defeat only an unqualified inference from causal completeness to inability to instantiate a truth-preserving, premise-responsive transition. It will not establish a naturalistic metaphysics, intrinsic intentionality, subjective understanding, an appropriate human belief-forming basis, the origin of a mechanism, or global cognitive warrant. For the stronger incompatibility target, identify the exact additional exclusion premise and whether the source supplies an independent reason for it. No assumption of a distinct extramental bearer for mathematical types or logical laws.

Existing proof machinery: inspect the exact theorem/assurance boundary and attempt a non-mutating imported-kernel recheck. No new whole-package replay claim unless it is actually performed. No predecessor changes.

## Independent pre-construction correction

Acceptance-bit sensitivity alone would not test sensitivity to logical form. The main implementation will therefore contain explicit fixed formula codes for four literals (p, not-p, q, not-q), a first-premise code A, and the antecedent B and consequent C of a second premise B→C. The transition accepts C only when both premises are enabled and A=B. Formula-change interventions hold the acceptance bits fixed. A deliberately faulty implementation dropping the matching check should admit a false conclusion from true accepted premises. This strengthens the implementation claim while retaining the original intrinsic-content/warrant ceiling.
