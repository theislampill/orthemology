## Exact classical transport, with its semantic premise visible

Fix one deterministic adaptive policy, one target/version, and one admitted certificate system. The policy uses only its available finite history. All source, authentication, inferential and scope commitments needed for certificate soundness are established independently of a terminal label. A successful event means an actual finite certificate has been produced and checked, with its cited evidence available and its conclusion in the substantive goal set. Correct output text, an available but unchecked proof, a deferred answer, or an abort is not that event.

Let R be the nonempty set of admissible complete traces of this policy. Pad genuinely completed traces with a fixed dummy event. Unsuccessful aborts may instead be padded with an explicit unresolved-failure event; a permanently blocked run cannot disappear from the domain and thereby count as resolved. Let H be the tree of all finite prefixes of traces in R. Suppose H is finitely branching. This is a condition on fully represented outcomes at each history; arbitrary evidence strings or an unbounded natural-number reply need not satisfy it.

For r in R, let τ(r) be the first discrete step at which its checked goal certificate has been produced, and let τ(r)=∞ if that never occurs. Define the unresolved tree U to contain exactly those h in H with no such event in h. Then

    U has a node at depth n  iff  some r in R has τ(r)>n.

Consequently a uniform finite bound is equivalent to an empty finite level of U. The load-bearing realisation premise is

    Every infinite branch of U is itself a trace in R.

If every r in R resolves finitely and the realisation premise holds, U has no infinite branch. König's lemma makes U finite-height, so some common N bounds τ. Conversely, under finite branching, if every admissible trace resolves but no uniform N exists, König supplies an infinite branch of U outside R. Each of its finite prefixes is witnessed by some admissible trace; no single admissible trace realises all of them. The witnesses cannot be silently exchanged for one global scenario.

For the standard prefix/cylinder topology, [H], the space of infinite paths through H, is compact. Since H is the prefix tree of R, [H] is precisely the closure of R. Thus closedness of R in [H] suffices for branch realisation. Equivalently, the finite terminal cylinders cover a compact R and therefore have a finite subcover. Full closedness is stronger than needed: only unresolved limit branches matter.

A compact underlying state space Ω is also sufficient if each finite-history consistency set C_h⊆Ω is closed, nonempty exactly for realisable histories, and coherent under prefixes. Along an unresolved branch these sets are nested and nonempty, so compactness supplies a state in their intersection. The model must additionally ensure that membership in every C_h means that this state really realises the branch under the fixed policy. Compactness of Ω alone, without closed consistency fibres and this faithful trace interpretation, is not enough.

This is an application of inherited mathematics, not an independent warrant-creation principle. For an external reference to the classical lemma and its direct proof, see Simon Thomas's [Math 461 notes, §16, Lemma 16.6](https://sites.math.rutgers.edu/~sthomas/2006_03_06lecture_konig_lemma.pdf), pages 1–3. Only those relevant passages were used.

## One sharp excluded-limit control

The admissible scenarios are n∈ℕ. At scenario n there is exactly one genuine witness, at location n. Query k returns 0 when k≠n; querying n supplies an authenticated witness e_n establishing P(n). The admitted proof rule is the ordinary finite existential-introduction step from P(n) to G:=∃k P(k), with the source commitment that these authenticated witnesses support their asserted instances. Its support is {e_n}. No negative query supplies that support. The grammar has no axiom deriving G merely from the externally specified scenario class.

The fixed policy queries 0,1,2,… until it obtains e_n, then constructs and checks this finite derivation in a separate final step. The check verifies its cited instance, evidence identity, target/version and rule application; soundness follows from the specified source commitment and existential introduction, rather than being defined by the terminal marker. Hence τ(n)=n+2, counting n+1 inspections and one final check.

Every admissible scenario resolves with a genuine finite certificate. For every N there is a scenario requiring more than N steps. Ignoring the fixed action annotations, the complete traces have form

    0^n, witness(e_n), checked-proof(n), dummy, dummy, …

The tree is finitely branching. The all-zero trace is an unresolved limit branch: any finite zero prefix occurs in a scenario whose witness is farther away. But that all-zero trace is excluded by the scenario domain. Adding it changes the domain to include a scenario with no witness; the same policy and proof system then fail pointwise resolution there. Calling it semantically possible merely because its prefixes are feasible would be an unwarranted model extension.

The target is true throughout the original domain, so an immediate correct output is possible as an extensional label. That is different from producing the specified proof. If a separately warranted exactly-one promise were admitted as an axiom sufficient for G, the certificate contract would change and immediate resolution might become available. The example does not deny that route; it does not grant it for free.

## Guardrails and stopping outcome

- The quantifiers are one fixed policy and all its admissible traces: ∀r∃n. Per-state existence of possibly different policies, ∀r∃σ, does not establish a common successful policy ∃σ∀r. Nothing here synthesises that policy.
- Finite branching is substantive. With a countably branching first reply n followed by a forced finite chain of n unresolved steps and a checked terminal, every branch terminates and the branch domain is closed, yet depths are unbounded. Closedness without the finite-branch/compactness condition does not suffice.
- A discrete history-depth bound is not a wall-time or price bound. A finite prefix tree has finitely many used steps, but converting its depth to a guaranteed execution bound requires finite uniform cost/time bounds for each represented step, including source access, processing, evidence reconstruction and certificate checking. Hidden state-dependent latency is not controlled by a finite observation alphabet.
- If finite unresolved levels can actually be enumerated and decided, an empty-level search eventually finds a bound under the compactness and pointwise-success premises. Semantic realisability is not automatically decidable. No claim of an uncomputable bound is inferred merely from an undecidable general totality problem; the effective empty-level search is already retained in T16.
- Almost-sure termination is weaker than termination on every admissible branch. An excluded or measure-zero endless branch still blocks a worst-case finite bound if it remains admissible.

The exact branch-realisation obligation is available as a scope check if an unbounded completion claim is later proposed. Open research is not guaranteed to terminate.
