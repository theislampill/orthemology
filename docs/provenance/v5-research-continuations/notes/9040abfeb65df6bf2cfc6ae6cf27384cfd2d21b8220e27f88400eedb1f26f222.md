# Action-sufficient disclosure after exact diagnosis

Sixth-tranche mathematical crosswalk supplement. Ordinary proof candidate; no claim of a new general communication theorem, actual source authentication, canonical adoption, or R5 defeat.

## Question and inherited contract

The independently reviewed restoration v1 establishes exact diagnosis of a governing defect without a uniformly safe first intervention. This supplement asks what additional truthful disclosure would suffice, and how much distinguishable message capacity is necessary. It makes disclosure operationally discriminating while leaving the existence, honesty, authority and actual communication of the source as independent questions.

Keep the static destructive-root architecture D. There are n=2f+1 named acquisition/action roots, at most f corrupt roots in one fixed set C, a correctly diagnosed governing rule theta, and an irreversible unsafe state reached upon acting through a corrupt root. Each intact root can perform the adequate theta-repair. The receiver must eventually attempt a repair. No additional observations, safe probes or alternative actions occur before that first attempt. Root identity, action binding, target, authority and version are held fixed.

Condition on a full labelled report view. Let D be its k dissenting roots. These are known to be corrupt. Let U be the n-k agreeing roots and b=f-k the residual fault budget. Every subset B of U of size at most b remains compatible, with C=D union B. The trusted sender has enough actual integrity knowledge to name an intact member of an agreed menu; knowing the whole C is one sufficient source of that ability. A correct message is received without substitution. Authentication of origin alone would not provide this truthfulness premise.

All protocol random seeds are generated after the report view is fixed, or have a common law independent of C conditional on that fixed view. Sender and receiver private seeds are independent, apart from the explicitly declared shared seed. In particular, a report generated using a seed cannot be used to condition that seed into an uncounted integrity channel.

The extra message alphabet has M distinguishable values. The decoded first-root action can depend on the common view, the message, and receiver randomness. Timing, silence, packet identity and any other distinguishable channel are counted as part of the message when they convey information. The bound concerns one complete decision episode, rather than a nominal one-bit packet followed by uncounted communication.

## The exact zero-error capacity result

**Proposition.** Under this contract, a protocol that selects an intact root with probability one in every compatible static corruption scenario exists if and only if M is at least b+1. This remains true with randomized sender/receiver behaviour and pre-shared randomness independent of C. A fixed-length binary channel therefore needs at least ceil(log2(b+1)) bits. For b=0, one message value, requiring zero additional bits, suffices.

### Sufficiency

Agree on b+1 distinct roots in U and their message labels. At most b of them are corrupt, so at least one is intact. The sender identifies an intact menu root and transmits its label. The receiver executes that root's adequate theta-repair. No complete corruption diagnosis, report-vector transmission, or per-root response receipt is needed. The successful action remains conditional on the inherited lawful causal/action contract.

### Necessity for deterministic decoding

Suppose M is at most b. The set T of roots that the receiver might select across all messages has size at most M. A compatible corrupt set can include every member of T: take B=T intersection U, adding arbitrary roots in U if a maximal budget is desired. The roots in T intersection D are already corrupt. Every message then directs the receiver to a corrupt root. Selecting a known-corrupt root in D only makes the failure immediate. Consequently no encoder, even one that knows the whole C, can supply a safe message.

This is a statement about distinguishable actions under messages, not the total number of possible worlds. A sender need not transmit the entire fault pattern, whose number is much larger.

### Necessity with private randomization

Fix the common view. Discard messages that the sender never uses with positive probability in any compatible scenario. Any retained message is used with positive probability somewhere; protocol-level almost-sure eventual action there, together with independence of receiver private randomness, implies almost-sure eventual action conditional on that message. Thus for each retained message m, p_m is a genuine probability distribution of the receiver's first selected root. The number of retained messages is at most M. Choose one root r_m with p_m(r_m)>0. There are finitely many roots, so such a root exists. Put each chosen r_m in C: those already in D cost no residual budget, and there are at most M<=b additional roots in U. This is a compatible static scenario. Every message has strictly positive failure probability in it. A randomized encoder cannot average those finitely many positive failure probabilities down to zero. Thus private randomization cannot achieve the claimed almost-sure safety.

Receiver decisions to wait before choosing a root are already included in p_m when waiting supplies no new information. Permanent refusal violates eventual repair. A stopping rule which learns additional facts is outside this one-message contract.

### Necessity with shared randomness

Let Z be shared randomness independent of C. Suppose a protocol were almost surely safe and eventually acting for every compatible C. There are only finitely many compatible corruption sets. Intersect their probability-one sets of good seeds. For almost every seed z, the protocol is safe and eventually acting for every C simultaneously. Conditional on that z, discard unused messages as above. The preceding finite-message necessity applies, allowing any remaining independent private randomness. It supplies a compatible C on which safety is not almost sure, contradicting membership in that common good-seed set. The finite intersection avoids an illegitimate adversary that sees the realized seed before choosing C.

The conclusion concerns exact probability-one safety. Shared or private randomness can improve a positive-error minimax tradeoff, and nothing here characterizes its optimal curve.

## Relation to the retained quantitative frontier

Without integrity disclosure, the reviewed optimal first-action damage risk is b/(n-k). With one of b+1 correctly chosen message values, it becomes zero under the stronger source/communication contract. At k=f, the ordinary reports have already exhausted the corruption budget and no additional message is needed. At k=0, even unanimous correct diagnosis requires f+1 possible integrity-directed labels for this guaranteed safe-selection protocol.

The size k alone is insufficient to earn this improvement: the receiver must know which roots are excluded, or possess a separately warranted menu/action certificate with the same effect. If a synchronization process retains theta and k but erases D, its possible corruption sets may again include every f-element subset of the full root set. Its effective action problem must be recomputed; it cannot use b=f-k while silently reusing erased identities.

A full provenance transcript is sufficient but is not always the smallest useful transmission. A trustworthy context-bound safe-action certificate can preserve exactly the discrimination required by the decision. Conversely, an unsigned root number, a correctly copied statement about theta, or a message whose authenticity is known but whose truthfulness is not established does not satisfy this theorem's premises.

## Foundational crosswalk

1. **Norm-fixing:** the adequate target and preservation obligations are independently fixed. The sender's preference does not create correctness.
2. **Knowledge:** the source needs integrity knowledge adequate to the menu. Omniscience would be sufficient but is stronger than necessary; the result cannot infer omniscience from successful signalling.
3. **Agency and power:** a source must be able intentionally to select and realize the appropriate distinguishable message, and the recipient must have its action channel. Mere coexistence of information and power does not establish this joint exercise.
4. **Wisdom and truthfulness:** knowing the safe label and being able to send it do not imply that it is sent, that its content is true, or that a purported packet is authoritative. These remain independent source and recipient warrants.
5. **Disclosure:** truthful diagnostic content and truthful action-integrity content have different consequences under the same target and causal architecture. The latter can eliminate an obstruction that the former leaves intact.
6. **Identity and transport:** a new recipient can inherit the safe action without numerical identity with the sender if the referent, source warrant and action contract survive. Copies do not create extra message capacity or independent integrity roots merely by multiplying carriers.
7. **R5:** all of these are typed interface conditions. The theorem does not show that their roles must have one ultimate bearer, establish an actual communicative ultimate source, or defeat the canonical minimal-nonintegration control.

## Deletion and scope controls

- If sender correctness is removed, all labels may point to a corrupt root. Authentic signatures can authenticate that wrong advice.
- If root identity is permuted in transit without a verified remapping, a true safe-root statement can select a different, corrupt actuator.
- If C changes after the message, the selected root can become corrupt; the static-contract proof no longer applies.
- If the sender or a shared enforcement gate is inside the same corruption budget without adequate protection, its reliability must be analysed. Calling the channel trusted is an additional premise, not an independence derivation.
- If corrupt actions are harmless omissions, the reviewed f+1-root batch can restore without this source or message; that is a stronger fault-containment architecture.
- If root action effects, permission, governing-rule identity or target change, the old label need not remain sound. A certificate must bind the relevant context.
- The bit count concerns a pre-agreed menu and coding dictionary. Establishing that dictionary and its root/action bindings can cost additional communication and warrant.
- No lower bound on the size of a real scripture, human language or divine disclosure follows. Those involve different messages, recipients and purposes.
