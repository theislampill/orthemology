# Exact fair-bit runtime bridge: contract and proof boundaries

## Result and its status

The executable `FiniteMealyCompiler.compiled` translates any supplied finite Boolean-input/Boolean-output Mealy table into the retained P02 syntax. Lean proves its literal decoded source output and actual scheduled-stack output equal the supplied machine on every input tape. The proof reconstructs each acquired digit from the retained sentinel word and verifies the generated register loop. This is a compiler correctness theorem, not an assumed whole-law adapter or a test-based inference.

The executable rational finite-controller implementation builds a rejection-sampling micro-machine and a single-output four-bit frame machine. A two-state, two-action, two-model non-dyadic fixture is compiled into two actual P02 programs, one per simulated environment. The action selector is common and depends only on the current observed state. The precise infinite accepted-history probability argument below is an ordinary mathematical proof. The general rational rejection-law equality, almost-sure infinite completion and expected-clock/cost formulas are **not claimed as Lean theorems**. Lean covers the generic P02 compiler, correlated channel substitution, concrete local frame identity, all-tape frame composition, the accepted controller's singleton-menu law specialization, and positive-stutter parity invariance. Current build/review receipts determine which candidate files have passed; no unverified draft is accepted merely by appearing here.

This is a restricted exact bridge to the accepted observed-state controller, together with a generic finite-memory runtime construction. It is not extraction of the full classical unbounded phase controller, a general dependent P01 compiler, or a universal Python/host refinement theorem.

## 1. Three interfaces that cannot be silently identified

1. The retained P02 runtime reads exactly one new fair bit at physical acquisition tick `k`; its input is `(k, sentinel(first k+1 bits))`. A predetermined, successful stack-fuel schedule computes one Boolean output at that tick on **every** tape.
2. A rational feedback controller chooses one action from its acquired observed action/state history, then receives one finite-valued successor with the specified rational row law. Its clock counts completed receipts.
3. A physical implementation can spend several acquisitions waiting for one receipt. These waits are not additional controller observations. The law of the entire accepted history, the observation encoding, and any charges made during waits all need separate treatment.

A source tick is still not a CPU instruction, a native meter step, a wall-clock second or a finite-memory bound on the retained prefix evaluator. The P02 source here recomputes from the whole prefix at each tick. Its finite table does not erase that implementation overhead.

## 2. The actual finite-table compiler

For `M : Mealy (Fin N)` and initial state `s`, `compiled M s` has arity 2 and output register 4. Registers 0 and 1 retain the stage and sentinel word; register 2 is the finite machine state; register 3 is the bounded loop index. A nested source-owned branch table selects the current state. At loop index `i`, the next acquired bit is read as

`word / 2^(stage-i) % 2`.

The selected branch writes the table's output and successor. The loop executes `stage+1` iterations from the literal initial state. No simulator, supplied trace initializer, noncomputable finite enumeration, external row oracle, or future tape cell is used in this source.

The principal exact endpoints are:

- `evaluate_compiled`: actual numeric decoding/execution gives the table's prefix output
- `compiled_source_output`: source observer equals the table's entire output map on all tapes
- `compiled_runtime_output`: the retained successful actual stack schedule equals that same output map
- `compiled_runtime_law`: equality of complete fair-Cantor pushforward laws
- `compiled_runtime_defect`: the retained exact rational finite-Mealy solver applies to this compiled source

`numbered_runtime_output` accepts an explicit finite numbering equivalence. It does not obtain an executable numbering from a classical choice.

If several Boolean channels are used, `runtimeChannels` passes the **same already acquired prefix** to every channel index. `runtime_channels_exact` is joint same-tape equality, retaining all correlations. It does not independently draw a tape per channel. A decoder must be measurable to claim a probability pushforward; the channel module now requires this and proves the resulting measure is a probability measure. Arbitrary substitution equality alone would not suffice.

## 3. Common controller and model-indexed environment

Let `M`, `S`, `A` be finite memory, observed-state and action sets. Supply finite tables

- `act : M × S → A`
- `upd : M × S × S → M`
- initial `(m0,s0)`

and a finite normalized rational kernel family `Pσ(s,a,y)`. The same `act` and `upd` are used for every σ. `act` takes no σ, sample word, rejection count, physical clock or hidden priority argument. Only an accepted receipt updates `(m,s)` to `(upd(m,s,y),y)`.

The **environment simulator** knows σ and supplies the row `Pσ`. The resulting *closed-loop generative program* may therefore have a different numeric P02 index for each σ. This is a simulation family under one common controller, not an autonomous controller that discovers its environment by reading σ. Deployment with an external environment needs an independently specified receipt channel; this bridge does not authenticate sensors or grant knowledge of hidden rows.

### A second, separate impossibility

A single fixed numeric index, fixed initial source state, fixed fair-Cantor input law and fixed decoder has one decoded law. It cannot equal two distinct model-dependent feedback laws. For example, if the initial receipt has probability 1/3 of being true under σ0 and 2/3 under σ1, no such fixed index/decoder can realize both. Equality would force the probability of the same measurable event to be both values.

This obstruction is independent of the earlier dyadic bounded-acquisition obstruction. Removing a worst-case acquisition bound does not create hidden-model-dependent input information. Permissible resolutions include a model-indexed generative environment (used here), an actual externally supplied feedback channel, or a model-dependent input measure explicitly identified as such.

## 4. Exact rational rejection sampler

Take one positive common denominator `D` for **all rows and models**. Write

`wσ(s,a,y)=D Pσ(s,a,y)`, with nonnegative integral weights summing to D.

Choose `L=max(1, ceil(log2 D))` and `B=2^L`. This particular executable construction uses `L=max(1,(D-1).bit_length())`. A row therefore always acquires at least one bit, including denominator-one rows.

The current controller pair `(m,s)` and its action are frozen during sampling. Read L consecutive fair bits as `v∈{0,...,B-1}`. If `v≥D`, reject and begin another L-bit block without updating controller state or logical history. Otherwise choose the unique state interval of length `wσ(s,a,y)` containing v, emit receipt y and update memory/state. Zero-weight intervals are never selected.

The finite microstate is `(m,s,k,v)` with `0≤k<L` and `0≤v<2^k`. At the last bit of an accepted block, the emitted source/action is still the **pre-receipt** pair `(s,act(m,s))`; the updated pair begins on the next interval.

Denominator-one rows deliberately retain the same positive-width rejection construction: with D=1,L=1 they accept bit 0 and reject bit 1. This is not optimal, but it is exact, non-Zeno and covered by the stated formulas.

### Exact infinite history law, proved from cylinders

Fix σ and any deterministic observed-history policy π. It can be the finite table policy, or a mathematical policy for which an executable realization has separately been supplied. For a compatible n-receipt history h with chronological selected pairs `e0,...,e(n-1)` and receipts `y0,...,y(n-1)`, fix rejection counts `r0,...,r(n-1)≥0`.

There are exactly `product_j (B-D)^rj * wσ(ej,yj)` accepted finite sampler words with these data. Each has `L*sum_j(rj+1)` bits and cylinder mass `B^(-sum_j(rj+1))`. The words are prefix-free: each ends at the nth accepted receipt, so no different such terminal word extends another. Their cylinders are disjoint. Summing first over rejected block contents and accepted codes, then over rejection counts, gives

`Pr(H_n=h) = Compatible(π,h) * product_j Pσ(ej,yj)`.

Indeed, each geometric factor sums to

`sum_(r≥0) ((B-D)/B)^r * (w/B) = w/D`.

This proof uses fixed finite cylinders of the original fair tape. It does **not** assume fresh iid observations conditional on an adaptive stopping time or condition on a phase entry without proof.

Summing over the finitely many n-receipt histories gives probability 1. Intersecting these full-measure events over n proves infinitely many receipts almost surely. The event of an infinite rejected suffix is genuine; for D<B it includes the tape constantly equal to one. The physical P02 output continues to exist there, but the next logical receipt never occurs. No timeout is converted to a false receipt.

Histories use the retained newest-first convention after reversing the chronological list above. The displayed cylinder formula is exactly the retained `markov_observed_prefix_mass`/canonical history law with Unit seed, source state reconstructed from the preceding receipt, and the given π. Agreement of all finite history cylinders, including consistency of the reconstructed history path, yields equality on the complete path σ-algebra. This is a derived probability-law equality, not a premise of the bridge.

A total measurable path representation may assign a fixed fallback suffix on tapes with only finitely many receipts, solely to form a total map. This does not tell an implementation to manufacture a receipt. The null exceptional set must remain separately visible in the execution contract.

## 5. Single-Boolean framing and the concrete fixture

The fixture has observed states and actions `{0,1}`, initial observed state 0, and the common selector `a=s`. For model σ∈{0,1}, the true-successor probability is 1/3 when `a=σ` and 2/3 otherwise. All four feedback rows in each model are normalized and have full support. The two environments already differ in their first receipt law.

Each sampler microstep produces exactly one four-bit frame:

`[accepted, pre-receipt observed state, pre-receipt action, receipt-or-reserved-zero]`.

The last bit is interpreted as a receipt **only** when the first bit is true. Waiting fillers are never reports. The receiver waits for the complete frame; a partial final frame is not an observation. State/action duplication is intentional and checked as an integrity condition for this fixture. Receipt histories are built only from complete accepted frames.

At the first physical acquisition in frame n, the core consumes `x(4n)`, computes its output frame and successor, and stores the pending frame. The remaining three physical acquisitions serialize the pending bits and ignore their fresh input bits. The policy does not see those unused bits. Thus the sampled tape is exactly the deterministic subsequence `x(4n)`. Its finite-prefix cylinder masses are fair: each m-bit subsequence word has `2^(3m)` extensions to a 4m-bit physical prefix, each of mass `2^(-4m)`. This proves the fair decimated input law, including arbitrary dependence across outputs.

The reachable frame machine has 36 states for each model. The compiler emits a 1,534-byte P02 program per model. The two frame machines and the exact generated byte/index identities are bound in `fixtures/SOURCE_IDENTITY.json`. `RationalFixture` verifies the finite local four-bit frame correspondence; `FourBitFraming` lifts any such local certificate to every input stream and every frame position. The source compiler then connects that frame stream to the actual indexed stack runtime.

The accepted-receipt decoder is measurable. For a fixed n and finite history h, the event that the nth completion occurs at physical horizon t with history h depends on a finite output prefix, hence is a cylinder union. Its union over t is measurable. The event that no nth completion exists is the complement of the corresponding countable union. Adding the fixed null fallback yields measurable coordinate functions; the complete history map is measurable by the countable product criterion. This argument is ordinary, not a claimed Lean proof of the variable-length decoder.

## 7. Clock, parity, costs and information

Let `R_n` be rejected blocks before receipt n and `T_n=4 L (R_n+1)` the physical acquisitions spent on that logical transition in the framed fixture. For the unframed sampler omit the factor 4.

The cylinder proof gives the stronger factorization

`Pr(H_n=h, R_0=r0,...,R_(n-1)=r(n-1)) = Pr(H_n=h) * product_j p(1-p)^rj`,

where `p=D/B`. Therefore the rejection counts are iid geometric-failure counts independent of the accepted history, with the same timing law under every model because D,L are global. In particular

`E[T_n]=4 L B/D`.

For D=3,L=2 this is **32/3 physical acquisitions per logical receipt**; the unframed sampler needs 8/3 acquisitions. Every completed block is positive and finite almost surely. When D<B, including this D=3 fixture and the deliberate D=1 construction, no deterministic finite worst-case latency exists. When D=B there are no rejections and latency is exactly 4L acquisitions. All-stream P02 tick termination is compatible with failure of all-stream logical completion.

For a nonnegative error charge `cσ(s,a)`:

- If charged only once per logical report, its lifetime law and expected sum are unchanged by the bridge
- If charged on every physical acquisition while holding the pre-receipt action, the pathwise cost is `sum_n T_n cσ(e_n)` and its expectation is exactly `(4LB/D) E[sum_n cσ(e_n)]`, allowing either side to be infinite
- The expectation identity follows from the displayed independence and Tonelli/monotone convergence, not from finite expected sampling time alone
- Stack-fuel, parsing, source recomputation, integer storage and wall-clock charges are outside that acquisition-cost formula

For parity, every physical acquisition is interpreted as holding the current **pre-receipt** state/action priority, including the acceptance frame. On almost every tape this is a positive finite stuttering of the logical priority path. `StutteringClock.parity_exact` proves equality of the accepted minimum-recurrent-priority event. Labeling waits as a fresh odd priority can destroy a coBüchi/parity property and is not licensed by the bridge.

The policy-visible history is only accepted state/action/receipt data. Raw fair bits, pending serialized bits, sampler register state and model index are not policy observations. This is an interface discipline verified by the supplied finite controller update, not a statement that an arbitrary program inspecting the entire simulator has the same information. Global denominators make timing independent of the model in this construction; model-dependent sampling schedules need not. Even model-independent clocks do not make raw randomness harmless: receipt=b and receipt=not b can have the same fair receipt law while the pair (raw bit,receipt) reveals the model. No backward winning-region equivalence for arbitrary physical policies is claimed.
