## 3. Boolean diagnostic stress model

For the complete attained stress class, project each typed tuple to:

```text
U — Core A profile/class uniformity passes;
W — Core B warrant integrity passes;
C — full-key compatibility passes;
A — target-key authority passes;
T — truth-linked coordinate passes;
R — world-target adequacy passes.
```

Assume all `2^6=64` Boolean combinations occur and exact diagnosis must recover
all six coordinates. Then every two states require different diagnostic labels;
64 labels, or 6 fixed-length bits, are necessary and sufficient.

Deleting any coordinate creates a collision. In particular, all four `(U,W)`
quadrants occur, so neither original core refines the other in this stress
class.

This is a conditional information statement. Actual domains may impose
additional dependencies and require fewer labels.

## 4. Release versus diagnosis

The one-bit release gate

```text
Release := U & W & C & A & T & R
```

is exact for **release alone**. It is deliberately lossy for diagnosis: all 63
failure states map to `false`. That loss matters when the runtime must preserve
burden landing, route selection, repair, source revalidation, or explanation of
why release failed.

Thus the correct distinction is:

```text
binary release sufficiency:
  possible at the declared release-only scope;

lossless burden diagnosis:
  requires the richer typed/coordinate object.
```
