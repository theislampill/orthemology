## 5. SDIG-1B — derivational connectedness/common-bearer independence

A role realization assigns bearers to attribute and action coordinates.  In the
declared predicate-dependency semantics, local support satisfaction records the
instantiation of the typed implication/relation but does not add equality among
role bearers.

Therefore every bearer partition, including an injective plural assignment,
can realize the same connected support graph unless a co-reference/equality
constraint is added.


a) connected source-dependency topology does not entail one bearer; and

b) one bearer does not by itself entail source-dependency topology, because a
carrier-boxing model can place all labels on one bearer while deleting every
cross-role relation.

## 6. SDIG-1C — textual co-reference and source-relative restriction

necessary existence, unity, knowledge, ability, life, volition, speech,

true, while later repairing or criticizing particular arguments.

Call this source proposition `TEXTUAL_COREFERENCE`.  If `PROP`, `ACCEPT`, and
`IDENT` are admitted in a Track-N model, a plural bearer assignment that denies
that co-reference is source-incompatible at the selected scope.

This is not a new neutral unity theorem.  It is source-relative model-class
restriction by an explicit source proposition.

The commentary's lines 481–495 additionally criticize the particular proof
that shared abstract necessity plus individuation forces constitution and then
one necessary being.  Deep AH therefore does not use that criticized proof to
migrate `TEXTUAL_COREFERENCE` into Track T.
