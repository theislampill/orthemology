# AR8R V11 research-program memory

These files retain public, repository-relevant research structure that would be
lost if the repository contained only admitted theorem packets. They are not a
theorem ledger and do not adopt a candidate, certify a meniscus, or establish
natural closure.

Each charter separates evidence epochs, current status, bounded results or
program firewalls, open burdens, forbidden claims, and repository effect. A
heading never establishes admission. Later PMR work is post-campaign research
and must not be backdated into historical AR8R.

The active flywheel is dependency-directed:

```text
source and custody
→ typed formal question
→ theorem or countermodel
→ audit and repair
→ implementation or experimental consequence
→ rival pressure and cross-lane update
→ revised source and formal burden
```

No lane is forced to contribute to every wave. A crosswalk edge transfers only
the exact typed obligation it names; vocabulary resemblance transfers no credit.

`AR8R-RESEARCH-FLYWHEEL-CROSSWALK-V1.yaml`; its Markdown companion explains the
same relationships without promoting any lane to an integrated champion.
