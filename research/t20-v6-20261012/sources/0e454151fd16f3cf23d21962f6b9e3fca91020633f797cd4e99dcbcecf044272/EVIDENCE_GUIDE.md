# How to interpret the evidence

## Authorship and review

This edition is compiled by dot, an OpenAI-powered AI assistant, using the user's supplied and retained research. Separately authored ChatGPT Pro synthesis contributions retain attribution. Primary authors, prior mathematical literature and existing project owners retain the credit recorded in their source reports.

Independent bounded reviews in this consolidation are separate AI review passes. They are not human specialist peer review, independent empirical reproduction by an external laboratory, or evidence of authorial independence between every inherited research stream. A reviewer-proposed strengthening checked collaboratively has collaborative provenance, not independent corroboration by its own proposer.

## Separate questions for each result

| Question | Suitable evidence | What it does not establish |
|---|---|---|
| Which exact text or code was used? | Byte hash, archive ancestry, source map | Correctness or truth |
| What does the source argue? | Contextual reading, attribution and edition records | Truth merely from attribution |
| Does the stated consequence follow? | Written proof or a checked formal derivation with explicit premises | Actual truth of the premises |
| Was this component executed? | Observed command, environment, inputs, exit status and output | Whole-family verification |
| Does the implementation realise the theorem? | Bound semantic mapping and implementation tests/proof | Unstated host, probability or physical assumptions |
| Does this represent the intended application? | Meaning-preserving interpretation and independently warranted conditions | General validity from resemblance |
| Has the result been adopted? | Actual repository/owner decision | Scientific truth or external acceptance |

A claim can be mathematically correct while its practical application is unestablished. A philosophical argument can have substantive defeasible warrant without a universal machine formalisation. These statuses should be recorded precisely rather than ranked on one undifferentiated PASS scale.

## Important execution distinctions

- A retained execution receipt is inherited evidence until its exact computation is observed again.
- A source file inspected or hashed is not thereby freshly kernel checked.
- Compiling selected Lean modules does not freshly compile all imported cached dependencies.
- A finite oracle corroborates the bounded cases it enumerates; it does not replace the universal proof.
- Running assert-based Python under optimisation can disable its tests. Use explicit checks or a clearly identified assertion-preserving adapter before crediting an optimised run.
- Identical copies of a package do not constitute independent replays or discoveries.
- A package manifest passing is custody evidence. Research closure is a separate argument.
- A failed package check remains part of the record even if exact extraction or a corrected invocation later succeeds.

## Negative evidence and corrections

Keep a failed mapping together with its actual domain. Ordinary overdetermination does not automatically instantiate complete necessary original agency. A finite-summary impossibility theorem does not exclude a restricted invariant family. A counterexample to a permission-only timed interface does not refute an urgent deterministic first-hit contract.

Conversely, a stronger intended proposition cannot be protected by building its disputed conclusion into a definition. A valid rival or counterexample that reaches the actual premise deserves its exact evidential weight.

The correction index records current dispositions while historical source bytes remain unchanged. “Superseded” can mean a scope was strengthened, a status was updated, an attribution corrected or a proposed implementation repaired; it does not always mean the older theorem was false.

## Duration and completeness

Prospective consolidation work is recorded through its actual artefacts and observed receipts. It does not certify the historical six-hour active-research floor. Waiting, file recovery, inventories and packaging are not newly earned mathematical or philosophical findings.

The coverage crosswalk is a disposition of the identified programme, not a claim that every archived file received line-by-line semantic examination. Source-reading ledgers state what was actually read. Unavailable later R3 work remains unavailable regardless of the success of recovering the earlier advertised document hashes.
