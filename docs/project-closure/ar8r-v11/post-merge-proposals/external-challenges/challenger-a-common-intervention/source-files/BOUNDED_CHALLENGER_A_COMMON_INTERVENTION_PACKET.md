### Bounded nonidentifiability result

Let

- `M = M_U ∪ M_I ∪ M_P` be the registered unified-personal, impersonal-powers, and plural implementations;
- `Q(m) ∈ {U,I,P}` be the architecture coordinate;
- `J` be any frozen finite family of eligible common interventions;
- `E_J(m)` be the complete law of all declared observations, actions, reports, certificates, provenance records, externally metered resources, failures, and timeouts under all declared candidate-independent adaptive policies.

Architecture identification requires `Q` to be constant on every profile fibre:

```text
E_J(m) = E_J(m')  =>  Q(m) = Q(m').
```

For finite horizons and finite intervention/output alphabets, any admissible interface kernel can be realised by an impersonal complete-history-state controller:

```text
state at t = complete declared history through t;
next-output law = the original kernel conditioned on that history and next intervention;
next state = old history concatenated with the intervention and sampled output.
```

If the impersonal model class permits that realisation under the same operational guards, then for any registered unified-personal implementation `u` there is an impersonal implementation `i_u` such that

```text
E_J(u) = E_J(i_u),     while     Q(u) != Q(i_u).
```

Hence the architecture coordinate does not factor through the complete finite-interface profile. One unified-personal/impersonal collision is already sufficient to defeat three-way class-wide identification; a further collision with the plural class is unnecessary for that negative result.

This is bounded in four ways:

- it is relative to the frozen finite interface and declared model class;
- it does not assert that the impersonal history-state realiser is physically efficient;
- it does not cover a separately justified resource, locality, noncopyability, or implementability bound that the realiser cannot meet;
- it does not establish metaphysical equivalence, actuality, or truth—only equality of the declared profiles.

Thus the packet can produce strong **implementation-level partitions**, but not a neutral finite observational proof of unified-personal, impersonal-powers, or plural metaphysical truth.

## 3. Eligibility contract for the common factorial

### Declared intervention class

An intervention is eligible only when all of the following are frozen before results are inspected:

- finite horizon and typed finite intervention/output alphabets;
- an abstract intervention denotation independent of the target architecture;
- a total architecture-specific implementation map for every architecture under comparison;
- a common output schema and common semantic decoder;
- source, version, authorisation, capability, feasibility, and resource guards;
- candidate-independent deterministic policies, with randomisation supplied externally when used;
- complete profiles rather than selected success outputs;
- no direct query for personality, intentional uptake, bearer unity, divine-source correctness, or another target-loaded predicate.

### Target-independence test

The abstract label and scoring rule may not mention `unified-personal`, `impersonal`, `plural`, `self`, `intentional uptake`, `one bearer`, or a favoured source-world predicate. Each architecture-specific implementation map must be fixed ex ante and justified by the common denotation, not chosen after observing the target label or desired result.

### Semantics-preservation test

For every intervention factor:

1. **Type:** the architecture-specific operation has the declared input, opportunity, and output types.
2. **Denotation:** it performs the same abstract operation, not an architecture-specific surrogate with a different meaning.
3. **Round trip:** implementation followed by the common decoder returns the same abstract intervention label and output-field meanings.
4. **Renaming invariance:** architecture-neutral relabelling does not change the score.
5. **No target leakage:** the implementation, adaptive policy, compiler, budget, and decoder receive no hidden architecture label.
6. **Equal opportunity:** absent a declared causal effect, each implementation receives the same task, evidence, timing, authority object, and resource opportunity.

This is a commuting **semantic** condition, not a requirement that architectures yield equal response laws.

### Complete experiment-profile map

For model `m`, intervention cell `j`, and candidate-independent policy `π`, record the full joint law of

```text
inputs and interventions;
intermediate observations and state-exposed events;
actions and revisions;
reports, reasons, and declared certificates;
authority/version decisions;
provenance-root use and writeback;
latency, memory, communication, locality, energy, and other external meters;
errors, refusals, recovery behaviour, and timeouts.
```

The full profile is

```text
E*(m) = { Law_m(full transcript | j, π) : j in the complete declared factorial,
                                           π in the declared policy family }.
```

Its fibre relation is

```text
m ~* m'  iff  E*(m) = E*(m').
```

Coordinate fibres for causal cuts, norm conflict, form/content, authority/version, provenance, and resource curves form partitions whose common refinement is `~*`. Duplicated or definitionally recoverable coordinates do not add independent refinement.

## 5. Pairwise discrimination versus class-wide identification

For each registered pair `(m,m')`, define its disagreement set

```text
D(m,m') = { j : the complete profile under j differs }.
```

A nonadaptive identifying basis must hit every relevant disagreement set; an adaptive tree must eventually reach a distinguishing continuation for every live pair. If `D(m,m')` is empty, no experiment assembled from the declared class distinguishes that pair.

The complete-history impersonal collision makes at least one unified-personal/impersonal disagreement set empty whenever the model class is history-realisation closed. Therefore:

- individual cuts, conflicts, crossings, rotations, provenance attacks, and budget tests may refine the registered implementation partition;
- a finite suite may separate every member of one small, non-closed registry;
- that finite success still does not identify the metaphysical class unless the registry restriction and its exclusion of profile-equivalent rivals are independently justified;
- finite samples can support observational separation, but cannot by themselves establish equality of full laws or metaphysical truth.

When the full factorial is too costly, choose the next cell by **maximin rival-partition gain** or a weighted hitting-set objective over still-live pairs, with penalties for cost and guard fragility. Initial plausibility is not the selection criterion.

## 6. Deletion and hidden-anchor countermodels

### Deletion countermodels

1. **Delete one factorial cell:** make that cell the sole point of divergence; every retained result agrees.
2. **Delete trajectories and retain endpoints:** two mechanisms reach the same endpoint by different causal or corrective paths.
3. **Delete the independent truth/fittingness certificate:** a target-relative controller and truth-linked controller become observationally interchangeable.
4. **Delete version or authorisation custody:** valid, stale, revoked, and unauthorised messages share the same visible content.
5. **Delete root authentication:** copies of one source masquerade as independent convergence.
6. **Delete timeouts/off-support cells:** one architecture hides its difference by nonresponse or unreachable cases.
7. **Delete external resource metering:** a self-reporting implementation conceals cost or an architecture-specific harness imposes the deficit.
8. **Delete case pairing/common causal design:** independent samples confound task difficulty with architecture effect.
9. **Delete TAC/SAC distinctions:** carrier, episode, type, state, function, lineage, copy, root, path, and evidential independence collapse into a false unity or multiplicity claim.

### Hidden-anchor countermodels

- Add a hidden output bit called `personal`, `intentional uptake`, `owned reason`, or `one bearer` only to the favoured implementation.
- Let the adaptive policy, compiler, role decomposition, or budget inspect the candidate label.
- Treat a source-relative predicate—such as actual divine address or source-world personality—as a neutral score.
- Let an architecture-specific internal role count as the “same” channel without an independent crosswalk.
- Count copied records, carriers, or paths as independent roots.
- Treat cryptographic authority as metaphysical truth or valid receipt as warranted adoption.
- Use a candidate-specific semantic paraphrase, then attribute the induced difference to architecture.

Every such construction can manufacture separation, but none is an independently operationalisable common intervention.

## 9. Exhaustion boundary and successor hypothesis

Every materially distinct proposal examined lands in one of four buckets:

1. **Finite neutral interface manipulation:** included in or refined by the complete factorial; bounded by the profile-fibre collision.
2. **Constitutional, centred, or source-world predicate:** potentially relevant, but not a target-independent neutral intervention unless independently operationalised.
3. **Resource, locality, or noncopyability restriction:** potentially discriminative, but only after an independent representation-invariant bound is supplied.
4. **Infinite-horizon, unbounded open-ended, or direct constitutional access:** outside the declared intervention class and current platform.

That is the genuine platform boundary for the declared class.

### Weak, high-information successor

Do not add another personality-like probe. Test a **representation-invariant realisation-budget correction parameter**.

For a complete profile `E`, define descriptively

```text
B_imp(E) = inf Cost(r)
           over impersonal realisers r that reproduce E exactly
           under a fixed external machine, compiler, locality, and provenance contract.
```

Use a cost vector such as

```text
(memory, communication depth, locality radius, latency, energy,
 authenticated independent roots, noncopyable bottlenecks).
```

Before comparison, quotient away architecture-neutral renaming, state splitting/merging, redundant copies, definitional interface duplication, and common downstream postprocessing.

The weak hypothesis is:

> Some complete causal-cut profile has an externally certified budget below the minimum attainable by every impersonal realiser in a separately justified, representation-invariant impersonal class.

A successful lower-bound argument could exclude that bounded impersonal class; it would still not by itself prove unified personality, and the plural class would require its own bound. Failure to obtain such a bound is informative: it says that no remaining finite neutral intervention in the declared class has class-wide rival-partition power.
