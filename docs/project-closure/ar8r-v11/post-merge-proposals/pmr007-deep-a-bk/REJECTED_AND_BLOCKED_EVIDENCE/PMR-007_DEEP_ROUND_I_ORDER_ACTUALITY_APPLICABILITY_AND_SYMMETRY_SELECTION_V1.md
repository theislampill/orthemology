## 2. Typed finite setting

Let a finite neutral structure be

\[
\mathcal M=(O,X,\operatorname{Applies},\operatorname{Actualizes},\Sigma),
\]

where:

- `O` is a sort of modal/semantic/normative orders;
- `X` is a sort of candidate concrete realizers;
- `Applies(o,x)` means that `x` is an admissible application or exemplification site for `o`;
- `Actualizes(o,x)` means that `x` concretely realizes or makes efficacious the relevant order;
- `Σ` contains only the declared neutral relations and predicates;
- `Aut(M,o)` is the automorphism group of the full declared neutral structure fixing `o`.

For a fixed order `o`, define the eligible realizer fibre

\[
C_o=\{x\in X: Applies(o,x)\wedge Actualizes(o,x)\}.
\]

A selector `s` is **neutral-structure equivariant** when for every isomorphism `h:M→M'` preserving the declared signature and every fixed input order `o`,

\[
h(s(M,o))=s(M',h(o)).
\]

In particular, for each `γ∈Aut(M,o)`, an equivariant output must satisfy `γ(s(M,o))=s(M,o)`.

## 3. Candidate OAS-1A — applicability nonentailment

The existence, underivability, or necessity of an order does not entail that its concrete-realizer fibre is nonempty:

\[
Necessary(o)\wedge Underived(o)\not\models \exists x\, C_o(x).
\]

A one-order/zero-realizer structure is a countermodel. Thus an applicability, exemplification, truthmaker, powers, or actualization bridge is independently required.

## 4. Candidate OAS-1B — symmetry nonselection

Let `Γ=Aut(M,o)` act on `C_o`. If this action has no globally fixed point, then there is no neutral-structure-equivariant selector choosing exactly one member of `C_o`.

### Proof

Suppose `s(M,o)=x∈C_o` were equivariant. Every `γ∈Γ` is an automorphism fixing `o`, so equivariance requires `γ(x)=x`. Hence `x` is a globally fixed point, contrary to hypothesis. QED.

### Transitive corollary

If `Γ` acts transitively on `C_o` and `|C_o|>1`, then no neutral-structure-equivariant unique selector exists.

## 5. Candidate OAS-1C — positive fixed-point condition

If `C_o` contains exactly one element fixed by every member of `Aut(M,o)`, then that element is the unique neutral-invariant candidate for selection.

This condition is proposed only as a selection-eligibility criterion. It does not yet show that the fixed point is definable by a bounded formula, causally efficacious, metaphysically necessary, personal, or source-identified.

## 6. Required models

### I-CM1 — abstract order with no concrete application

`O={o}`, `X=∅`, and `o` is stipulated necessary and underived. This defeats order-to-actuality without an application bridge.

### I-CM2 — symmetric plural actualizers

`O={o}`, `X={x0,x1}`, and both candidates satisfy `Applies` and `Actualizes`. Swapping `x0,x1` is an automorphism. The fibre is nonempty but no neutral unique selector exists.

### I-CM3 — powers field with many equivalent loci

A concrete powers field contains several loci with isomorphic causal roles. The neutral structure constrains actuality and modal profiles but is transitive on the loci. Concrete efficacy does not identify one bearer.

### I-CM4 — primitive coupling pair

Two numerically distinct concrete actualizers are coupled to the same order by one primitive symmetric relation. Genuine order–actuality coordination is present, but unity is absent.

### I-CM5 — source-conditioned asymmetric predicate

Add a predicate `NamedByAuthenticatedSource(x0)` selecting `x0`. The automorphism is broken and a selector exists. The selection is Track-N/source-conditioned unless the predicate receives an independent neutral bridge.

### I-CM6 — hidden haecceity

A primitive identity tag selects `x0` while making no causal, semantic, normative, or explanatory difference. This shows that symmetry breaking alone is not explanatory unification.
