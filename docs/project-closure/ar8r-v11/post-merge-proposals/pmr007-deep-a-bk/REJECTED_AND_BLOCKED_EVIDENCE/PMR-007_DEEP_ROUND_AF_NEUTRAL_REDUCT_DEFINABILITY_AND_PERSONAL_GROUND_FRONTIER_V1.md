## Candidate claim

Let `L0` contain every neutral structural, causal, semantic-anchor, norm,
articulability, provenance, and implementation coordinate currently admitted.
Let `P` be a personal or intentional predicate.  For a declared model class
`K`, call `P` reduct-determined when any two models in `K` with the same `L0`
reduct agree on `P`.

The candidate asserts:

1. `P` is exactly recoverable from the complete neutral reduct iff it is
   reduct-determined on `K`;
2. if personal and impersonal expansions of one reduct both lie in `K`, no
   neutral theorem can entail `P`;
3. if no such twins exist, `P` is explicitly definable in the neutral language;
4. therefore every future neutral personal-ground proof must remove all
   personal/impersonal reduct twins.

The intended contribution is to consolidate the repeated parity results into
one theorem-strength frontier rather than producing another local profile
nonimplication.
