# Review of the finite-query route to CIRS necessity

Verdict: **the proposed reduction is valid at the stated finite, memoryless, full-support statistical-control model.** A common independent seed and a fresh finite-alphabet row oracle give an exact realization of the original interaction. Positive probability of an incompatible recurrent tail then transfers to the actual rival law on the finite-query event. This is an ordinary proof and a formalization obligation map, not a claim that CIRS necessity has been compiled.

The existing orthability and block-review seals are preserved. Source copies and a receipt identify the materials read. Both the existing Boolean evaluator and the new generic-alphabet evaluator sources were inspected. The generic interface matches the needed row instantiation; no independent compilation was performed in this review. Its statements alone do not discharge the action-policy reduction below.

## 1. Exact model and required conclusion

Let the action alphabet A and feedback alphabet Y be finite and nonempty. At every natural-number time the controller selects exactly one action and receives exactly one observation. A fixed hidden model eta supplies probability vectors P_eta,a on Y. Their entries are strictly positive. Conditional on the actual observable interaction history and the selected action, feedback is a fresh sample from that vector; private policy randomness is independent of feedback randomness. There is no additional physical state, history-dependent observation law, changing action menu, or model-dependent initial private information.

The same causal controller is used in every model. It may retain the full history, have arbitrary private memory, and reuse its private randomness. For a target set G_eta, success means that actions outside G_eta occur only finitely often, almost surely.

Fix a true model theta under which the controller succeeds. We must exhibit a nonempty U contained in G_theta such that every rival lambda with P_lambda,a=P_theta,a for all a in U also accepts every member of U. The proof may select U using theta and the law of the complete run. This analytical selection does not supply U to the controller.

## 2. Recurrence and deterministic-tail selection

On the action-path space A^N, define

    Rec(a) = intersection_m union_(t>=m) {path : action_t=a}.

Every cylinder in this expression is measurable. Thus Rec(a), its complement, and every specified recurrent-set event are measurable. Because the controller acts forever and A is finite, every path has a nonempty recurrent action set.

Let E_U be the event that its recurrent set is exactly U. Success under theta implies that, with probability one, E_U holds for one of the finitely many nonempty subsets U of G_theta. Consequently at least one such U has positive probability.

On E_U, each action outside U occurs finitely often. Since there are only finitely many of them, some finite time follows all their occurrences. Therefore

    E_U = union_N F(U,N),
    F(U,N) = {all actions at times t>=N belong to U}
             intersect {every a in U recurs infinitely often}.

Each F(U,N) is measurable. If E_U has positive probability, at least one deterministic N has positive F(U,N) probability. This uses only the fact that a countable union of null events is null. Neither the last outside-U action nor N selected by this existence argument is treated as a stopping time.

The fixed N is optional once finite-query domination is available: E_U itself is contained in the finite-query event. It is useful if the generic primitive first establishes domination for a deterministic query bound. On F(U,N), at most N outside-U actions occur, since only times 0 through N-1 can contribute.

## 3. A faithful common-seed realization

Fix a rival lambda whose observation laws agree with theta on U. For the moment represent private policy randomness by an arbitrary measurable seed R with probability law rho_R, shared across models. Write the deterministic causal action rule as pi(r,h), where h is a finite action/observation transcript. The rule is measurable and has no access to feedback that has not appeared in h. Arbitrary private memory can be replayed from the initial random seed and the transcript.

Independently pre-sample feedback stacks X_(a,j), for a in U and j in N, with each action's entries iid according to P_theta,a. The stacks are independent of each other and of R. Their laws are also P_lambda,a because the two models agree on U. These stacks and R form one common seed with law rho. This common law is required for the pair theta/lambda only; it need not be common to models that disagree on U.

Use the finite oracle alphabet E=Y^A. In model eta, one row z in E has law

    Q_eta(z) = product_(a in A) P_eta,a(z(a)).

Rows are iid and independent of the common seed. This artificial joint distribution of counterfactual observations is permissible because only the chosen coordinate is read. It is not an assertion that unchosen action outcomes are physically sampled in the original model. Every row has positive mass, and every finite row word w of length K has mass product_(j<K) Q_eta(w_j)>0.

The evaluator state is (r,X,h). The generic evaluator additionally maintains its outside-U query counter j. Define its operations as follows:

1. Compute a=pi(r,h), without consulting X except for feedback already included in h, and without consulting any oracle row
2. Set ask=true exactly when a is outside U
3. If ask=true, request the next unused row z_j and append only (a,z_j(a)) to h
4. If ask=false, append (a,X_(a,n_a(h))) to h, where n_a(h) counts the previous uses of a; ignore the generic primitive's dummy row

Keep the seed unchanged. Increment the row counter exactly in step 3. No unused row coordinate is stored in the history or controller memory. Although U determines the simulator's allocation of feedback sources, pi itself remains the original shared controller. The simulator gives no extra information to that controller.

## 4. The law-equivalence calculation

Let h=((a_0,y_0),...,(a_(m-1),y_(m-1))) be any finite transcript. Let h_t denote its prefix of length t and let

    K_h = {r : pi(r,h_t)=a_t for every t<m}.

This is a measurable private-seed event. For every measurable D in the private-seed space, the simulator satisfies

    Prob_eta(R in D and transcript prefix=h)
      = rho_R(D intersect K_h) product_(t<m) P_eta,a_t(y_t).       (1)

Indeed, the transcript specifies which U-stack entries are used and which outside-U row coordinate is read at each query. These are distinct fresh entries or rows. Their specified values have exactly the displayed product probability. Unused row coordinates and unused stack entries integrate to one. The remaining restrictions on the private seed are precisely K_h.

The original causal policy with independent fresh feedback satisfies the same identity. Hence the laws agree on all finite transcript cylinders, and therefore on the countable-product action/observation path sigma-algebra. In particular, they agree on recurrence, eventual-target and finite-outside-U events.

Equation (1) also resolves randomized-policy realization. On a possible history h, the conditional law of R is rho_R restricted to K_h and normalized. The model-dependent feedback product cancels. Thus the behavioral action probabilities after h are the same in both models, even when the seed is reused and private memory persists. Histories with rho_R(K_h)=0 have zero probability under every full-support model and may receive an arbitrary common action rule. Conversely, a shared behavioral policy on the countable set of finite histories can be realized by independent uniform private draws and a fixed finite-action cumulative-probability ordering.

Do not claim that feedback has law P_eta,a conditional on the evaluator's enlarged state (r,X,h). That state contains pre-sampled future U feedback, so its conditional feedback is deterministic there. Freshness is asserted for the original observable interaction, and is proved by (1), not by incorrectly conditioning on the entire simulator state.

## 5. Measurability and finite-query transfer

The space of finite histories is countable and discrete. Membership in U, the action counts n_a(h), the history append operation, and evaluation of a stack at the count n_a(h) are measurable. With measurable pi, the evaluator's ask function and each row-indexed next-state function are measurable. Time is the length of h, so no external clock or model-dependent schedule is required.

The generic row evaluator must supply the following result: if both runs have the same initial-state law rho, and the reference oracle assigns positive mass to every finite row word, then the actual trace law restricted to bounded-query traces is absolutely continuous with respect to the reference trace law on that same event. Its countable-union version supplies the analogous assertion on finite-query traces.

Instantiate the actual oracle with the iid Q_theta row law and the reference oracle with the iid Q_lambda row law. The full-support product calculation above discharges the reference-prefix hypothesis. The resulting domination is between the theta and lambda trace laws themselves.

It is insufficient to show that both worlds are dominated by a third artificial fair reference. Two mutually singular measures may both be dominated by a common measure. Positive-event transfer requires domination by the actual rival trace law (or an independently justified equivalent law).

Under the embedding, the query counter is exactly the number of outside-U actions already executed. Thus F(U,N) is a measurable trace event contained in the bound-N event. If its theta probability is positive, domination implies that its lambda probability is positive. The same argument directly applies to E_U using finite-query domination.

For a fixed bound, the finite alphabet even gives a quantitative version. Put c=min_z Q_lambda(z)/Q_theta(z)>0. Every length-N row word has rival probability at least c^N times its theta probability. The common-seed product and bounded-prefix factorization therefore give Prob_lambda(F)>=c^N Prob_theta(F) for every measurable trace event F contained in boundedTrace N. No equivalence of the infinite iid oracle laws is asserted; those laws may be mutually singular. Nor is there necessarily one positive lower-bound constant for the union over all finite N.

If some a in U is outside G_lambda, every path in F(U,N) contains infinitely many lambda-bad actions. Its positive lambda probability contradicts almost-sure success under lambda. Consequently every rival agreeing with theta on U accepts all of U, proving the required self-verifying support.

## 7. Deletion controls and scope

- If the initial private seed encodes the hidden model, disjoint targets can be chosen correctly without informative observations. There is then no common seed law, so the transfer proof does not apply
- If the action rule can inspect an unused oracle row, it can select actions using information not charged to the query counter. Prefix locality no longer models that policy
- If the action is selected after seeing its row, the selected coordinate need not have law P_eta,a conditional on that action. For example, selecting action q only when its row coordinate is 1 makes its observed outcome deterministically 1
- If feedback shares hidden dependence with private policy randomness, equal public feedback marginals do not suffice. The private seed plus feedback may reveal the model. Independence or an equivalent complete conditional-kernel contract is essential
- If feedback copies one initial hidden bit instead of being freshly sampled, the displayed product law and cylinder identity fail
- If action laws depend on an unmodeled physical state or history, agreement of static vectors on U does not establish equality of future U-feedback laws
- If A is infinite, the recurrent action set may be empty and there may be no deterministic time after all outside-U actions. If play may simply terminate, the nonempty recurrent-set argument also needs an explicit absorbing-action convention
- A zero-probability rival feedback symbol can destroy finite-prefix domination. Full support is stronger than necessary, but any weaker replacement must still justify the required direction of absolute continuity

Within the stated finite model these controls do not reveal a gap. The remaining burden is the explicit semantic realization and its formal verification, not a missing stopping-time theorem or a countable-intersection argument about tail probabilities.
