# Round 18 theorem-family and prior-art note

```text
purpose: authority ceiling, not novelty promotion
```

1. **Set Cover.**  The explicit decision problem `rho_H(C) <= k` is literally
   Set Cover after taking states as the universe and certificate-object supports
   as the listed subsets.  Karp's 1972 NP-completeness result therefore supplies
   the complexity classification.  No new complexity result is claimed.

2. **Witsenhausen zero-error side information.**  Zero-error transmission where
   a decoder has correlated side information is classically tied to graph
   coloring.  Round 18 is a finite one-shot relation-selection specialization
   with typed certificate objects; it does not claim a new characteristic-graph
   theory or asymptotic rate theorem.

3. **Orlitsky–Roche coding for computing.**  Functional compression with side
   information is established ancestry for transmitting only what a decoder
   needs to compute a target function.  Round 18's ambiguity-intersection
   theorem is a finite relation-valued analogue.  No graph-entropy or asymptotic
   coding theorem is claimed.

4. **AR2/AR3 and PMR family.**  The substantive orthemological contribution is
   the separation of surface action from complete warrant/custody object, and
   its integration with target-local transport, temporal model binding, and
   version invalidators.  It is a strict specialization/application of the
   existing reason-preserving transport architecture.
