## The essential refinement distinction

A frontend syntactic result is not an admitted semantic theorem. Finite replay
binds a real canonical Checked object to its exact Term and TypeCode. Dependent
replay binds a real intrinsic Tm to its polynomial/contextual type. A refusal
contains no proof. This gives a sound partial admission architecture independent
of trusting a frontend status string. It does NOT mechanically verify the Python
interpreter or claim that every JSON dependent term has a total intrinsic export.
The total literal export claim is refuted by typed Id/Sigma cases.
