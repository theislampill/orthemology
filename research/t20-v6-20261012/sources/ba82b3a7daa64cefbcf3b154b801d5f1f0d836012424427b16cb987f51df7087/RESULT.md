## 2. Exact finite counting theorem

Let S be a nonempty finite set with an injective natural-pair code s↦(z_s,k_s), O a nonempty finite set with injective natural codes, and E⊆S×A the enabled state/action pairs. For each (s,a)∈E let

    K_a(s,o,t) ∈ Q≥0,       sum_(o,t) K_a(s,o,t) = 1.

Repeated input entries for the same joint atom are aggregated first. Zero-probability atoms receive no seeds. Choose a **positive** integer D divisible by every reduced denominator of every aggregated K entry in the finitely many enabled rows; D=1 works when there are no enabled rows (no transition law is then asserted). Let

    n_(s,a,o,t) = D K_a(s,o,t) ∈ N.

Fix one joint-atom ordering. For each enabled row partition {0,…,D−1} into consecutive blocks of these sizes and send a seed in the (o,t) block to the entire triple `(code(o), z_t, k_t)`. Call this deterministic lookup f_(s,a). The blocks partition the seed set because their nonnegative sizes sum to D. Therefore

    |{u<D : f_(s,a)(u)=(code(o),z_t,k_t)}| = D K_a(s,o,t),

and under a uniform seed U,

    P(f_(s,a)(U)=(code(o),z_t,k_t)) = K_a(s,o,t).

This is a **joint** equality. The three output coordinates use the same seed and same input state.

Conversely, every deterministic map from a fixed D-element uniform seed set has atom probabilities n/D. Hence such a lookup exists for all rows at that D iff every D K entry is integral. The least common seed size is the least common multiple of the reduced denominators of the aggregated nonzero entries (empty family convention 1). Finite arbitrary real kernels with an irrational entry are excluded by this finite-uniform architecture. This is not an impossibility theorem about unbounded random-bit computation, nonuniform external seed laws, or other real representations.

Finite closure and outcome coding are part of this construction: every allocated seed returns a listed outcome and listed successor. Empty rectangular code cells and disabled pairs may be filled by the explicit source fallback. They have **no** claimed application interpretation or authorization. The logical source carriers are N, not Fin.

## 4. Conditional seed law and finite histories

Let H_t contain the relevant operating history through time t, including the current represented state and the previous declared joint replies. Let the policy select an enabled action A_t from that history, possibly using its own randomization. The action is selected before the new sampling seed; if the implementation exposes that seed to action selection, conditioning on the chosen action may bias it and must still satisfy the following premise.

A sufficient external semantic premise is that at every positive-probability operating history/action pair,

    P(U_t=u | H_t=h, A_t=a) = 1/D,    for every u<D.

One may condition on a richer host history, including previous seeds, when available; the stronger premise remains sufficient by averaging. No independence from all unobserved reality is asserted or required. This conditional law is not derived from source typing, source authenticity, per-time empirical frequencies, or unconditional uniform marginals.

Given h with current state s and chosen action a, exact deterministic source adequacy and finite summation give

    P((O_t,S_(t+1))=(o,t') | h,a)
      = sum_(u:f_(s,a)(u)=(code(o),code(t'))) P(U_t=u | h,a)
      = K_a(s,o,t').

If π_t(a|h) is the policy distribution, induction yields the joint cylinder law, for a fixed initial state,

    P(a_0,o_0,s_1,…,a_(n−1),o_(n−1),s_n)
      = product_(j<n) π_j(a_j|h_j) K_(a_j)(s_j,o_j,s_(j+1)).

Include the initial-law factor and sum as usual for an initial distribution. The induction is: multiply the probability of the prefix by the conditional action probability and the displayed conditional joint reply probability. Zero-probability histories require no conditional assignment; their cylinders remain zero. Thus all finite histories, not merely one-time marginals, agree with the declared controlled kernel process.

### Sharp fibre-mass criterion

Uniformity is stronger than necessary. For a positive-probability declared history/action pair, the correct one-step joint conditional law holds **iff** each joint-reply fibre has total conditional seed mass K_a(s,o,t'). This is the first equality above without replacing every seed mass by 1/D. Applied to every positive declared prefix, this condition is necessary and sufficient for the specified finite-history law under the given action policy and initial law. Necessity is relative to that declared history filtration: imposing the same property after conditioning on additional hidden host details can be stronger than observational law preservation.

The control with D=4 has two seeds per output. On the first step it uses only seeds 0 and 2 with masses 1/2 each; on later steps it picks within each output fibre according to past outputs. This is nonuniform and history-dependent at seed level while every output history has the desired fair-emitter law.

### Failure controls

- A one-state emitter with U_1=U_0 uniform on {0,1} has uniform branch marginals at both times. Its history is only 00 or 11, each with probability 1/2. Fresh fair seeds give all four histories probability 1/4. The repetition event has probability 1 versus 1/2. Even conditioning only on the constant current state cannot repair the missing history premise.
- A joint row with mass 1/2 on (outcome,next)=(0,0) and (1,1) has fair marginals. Independent sampling of these marginals assigns total probability 1/2 to the forbidden off-diagonal outcomes. Joint preservation is essential.

Both are standard finite probability facts used as discriminating interface controls, not field-novel results.
