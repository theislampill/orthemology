## 1. Frozen finite layer

Let `X` be finite and nonempty. Let

\[
r:X\to R
\]

be a declared deterministic representation and

\[
f:X\to Y
\]

an **independently supplied** target with an explicit semantic, source,
authority, version, and world-status contract. None of those statuses follows
from the theorem.

`f` is exactly recoverable from `r` when there is a decoder

\[
d:r(X)\to Y
\]

with `f=d∘r`.

## 2. TQDC-1A — exact deterministic descent

\[
\boxed{
f=d\circ r\text{ for a decoder on }r(X)
\iff
\ker(r)\subseteq\ker(f)
}
\]

Equivalently, `f` is constant on every attained `r`-fibre. The decoder is
unique on `r(X)`.

### Proof

If `f=d∘r`, equal representation values have equal target values. Conversely,
when `f` is constant on each attained fibre, define `d(r(x))=f(x)`; fibre
constancy makes this well defined. Uniqueness holds because every element of
`r(X)` has a preimage. ∎

## 3. TQDC-1B — canonical target quotient

The quotient `Q_f=X/ker(f)` is the unique minimal finite attained
representation of `f`, up to a bijection of representation values. Every exact
`r` admits a unique surjection

\[
\bar r:r(X)\twoheadrightarrow Q_f,
\qquad
\bar r(r(x))=[x]_f,
\]

and therefore

\[
|r(X)|\ge |Q_f|.
\]

This is an extensional target quotient, not a causal, algebraic, source, or
metaphysical quotient unless those structures are separately preserved.

## 4. TQDC-1C — typed finite families

For independently typed targets `f_i:X→Y_i`, let `F=(f_i)_i`. Then

\[
\ker(F)=\bigcap_i\ker(f_i).
\]

The attained joint image `F(X)` is subdirect in the product of the attained
coordinate images. It is the full product exactly when every attained-value
tuple has a joint realizer in `X`.

A proper joint image is a genuine extensional restriction. It is not by itself
causation, derivation, explanation, one subject, or one bearer. The full product
is not a warranted null model merely because it is mathematically available.

## 5. TQDC-1D — deterministic coarsening noncreation

If `r'=c∘r`, then

\[
\ker(r)\subseteq\ker(r').
\]

Hence exact recoverability from `r'` implies exact recoverability from `r`, and
failure from `r` persists under every deterministic coarsening.

This is not the full stochastic data-processing or Blackwell theorem. It has no
probability kernel, prior, loss function, or decision value.

## 7. Substantive-reduction criterion

Encoding the answer to any finite problem as a target label makes it a formal
TQDC instance. That is not a substantive reduction.

For BA–BI family credit, a reduction must preserve without answer-oracle
encoding:

```text
the native typed objects;
the admissible maps or transformations;
the load-bearing invariant;
and the native failure/countermodel class.
```

Under this test, TQDC is a common deterministic extensional **layer**, not a
complete common calculus.

### BJ-AU2 — latent orientation

### BJ-AU3 — joint interaction

### BJ-AU4 — convex latent complexity

support and different real nonnegative ranks.

### BJ-AU5 — path holonomy

obstruction is not computed by a vertex partition alone.

### BJ-AU6 — algebraic congruence

equivalence need not be an algebra congruence.
