# Readable dependency and authority map

The machine-readable graph is in `DEPENDENCY_GRAPH.json`; each edge lists the actual Lean import and each node binds its exact source digest. `SOURCE_OWNERS.json` identifies the authoritative archive member or seal-bound author source for every staged source.

- Original recovered P01 checkpoint → repaired qualified-shadow source → recursive Curry/effect successor → raw-index dependent successor
- Original recovered P02 checkpoint and original predecessor → repaired P02 base → Q8 measure/compiler → LOOP renaming/PR → Sigma2 → actual candidate/source-layout compilation → explicit structural PR-derivation compiler
- P02 measure/Q8 sources → root measure classification → tagged-row/Pi3 bridge → tagged productive-prefix successor
- Finite PER/refinement/block-mismatch sources plus P02 MeasureCore/Q8Measure → Mealy actual law → stage2 rational solver
- Original P03 checkpoint → repaired graph/VCT; exact canonical Python/Lean source bases → modeled source/native checker and constructor export
- Original P14 input and earlier completed P14 research → new control/restoration bundle, which supplies the explicit missing `restoration.py` sibling for the preserved P14 probe
- Original P15 input → P15 disclosure work → polytope/accuracy successors → source/norm-fixing bundle
- Canonical repository snapshot → recorded source identities for all source-level comparisons; the package does not modify or adopt into that repository

Each suite compiles an isolated custom closure. Where the same module name has a different historical/source identity, those identities are deliberately kept in separate suites. Overlap in source imports, target names, historical receipts or theorem counts is not double-counted as new research.

Missing external replay inputs are limited to the explicitly pinned official Lean/Mathlib toolchain and package build artifacts described in `PREREQUISITES.md`. Historical local absolute paths remain in preserved records as evidence only; the new wrapper requires explicit paths and never resolves those historical defaults.
