# Exact theorem and control map

Names below are in namespace `VeracityBoundary`; finite results add `.Controls`.

## Generic declarations

1. `controlled_token_true`: K/D/N/P/ExerciseBridge plus local owned/A/C facts entail the exact contextual content. This is primary. No global A/C or knowledge factivity is consumed.
2. `veracity_of_coverage`: additionally supplies A/C universally over the represented occasion domain.
3. `counterfeit_iff_false_under_coverage`: at an owned token, K/A/C and Factive identify counterfeit with false content. No D/N/P is used.
4. `veracity_iff_no_counterfeit`: global leaf-equivalence under K/A/C/Factive. No metaphysical premise is proved by this equivalence.
5. `false_excludes_package`: a false owned assertion contradicts the conjunction of K/A/C/D/N/P/ExerciseBridge. The proof is constructive and has no failed-premise disjunction assumption.
6. `strong_awareness`: A is a projection for `informedOwnership`.
7. `strong_control`: C is a projection for `informedOwnership`.
8. `strong_veracity`: the primary controlled theorem gives universal truth for that stronger assertion extension, with K/D/N/P/ExerciseBridge.
9. `strong_equals_base_iff_coverage`: equality of strong/base assertion extensions for g is equivalent to A/C coverage. Establishing that stronger interpretation as faithful is separate from naming it.

The proof-term readback shows each displayed positive input being consumed. Common Creatorhood, numerical uniqueness, graph LocalCover/CND, general benevolence, essential independence and every-end truthful-substitute claims are absent. Independence and pure perfection can matter to the philosophical warrant for N/P without becoming unused mathematical parameters.

## Six scoped removals

Each declaration checks the five other K/A/C/D/N/P conditions, ExerciseBridge, Factive, failure of the selected condition, an explicit false owned token, and failure of Veracity.

- `deletion_K`: epistemic fragment missing; not perfect knowledge.
- `weak_stress_A`: exact-content awareness missing only in the weak signature; not a genuine full-profile counterexample.
- `weak_stress_C`: actual deliberate presentation missing only in the weak signature; bare capacity/weak attribution is not the full source profile.
- `deletion_D`: descriptive knowing counterfeit without its normative shortcoming classification.
- `deletion_N`: shortcoming and fitting exercise coexist; preserves D and P, isolates the rescue/overriding-good question.
- `deletion_P`: known controlled unfitting exercise; does not retain substantive practical perfection.

## Positive and boundary controls

- `positive_package`: the full package, factivity, source truth, and classification for the distinct false speaker.
- `positive_nonvacuity`: real source-owned true token, extra fitting exercise, false other-speaker counterfeit/shortcoming, and nonoccurrence at the other occasion.
- `created_false_is_not_source_owned`: supplied false creature speech without source assertion ownership.
- `truthful_not_conforming`: source truth alongside an actual unfitting nondeclarative exercise; blocks the converse to P.
- `local_global_separation`: locally controlled truthful assertion plus a separate weak false assertion; all displayed K/C/D/N/P/exercise/factivity conditions hold but A and global Veracity fail.
- `strong_ownership_noncollapse`: strong truth, failure of weak universal truth, and a nonempty strong assertion extension in that two-occasion fixture.
- `strong_ownership_not_truth_by_definition`: a genuinely nonempty informed-ownership extension still contains a known false assertion in the N-removal structure. Strong A/C does not smuggle truth into ownership.
- `positive_equivalence_instance`: instantiates the generic no-counterfeit equivalence on the positive model.

## Expected rejected claims

The eight files in `tests/rejected/` try to claim T0 for each of the six removal structures, weak T0 for the local/global structure, and P for the truthful-nonconforming structure. Replay accepts only false-proposition `decide` rejections. Import errors, typeclass failures and missing declarations do not count as successful controls.
