## What is proved

A parametric finite-history kernel has two exact specialisations. Inverse state
translations and event correspondence up to timestamp erasure recover all finite
histories of the accepted original binary-table model, including damaged states
and arbitrary allowed events. The original model has no event timestamps; the
common model's arbitrary annotations are erased, and a chosen lift uses zero.
The typed specialisation uses the unchanged imported criterion functions and
preserves ordered full-envelope identity, full successors, separate install and
repair grants, and non-idempotent audit histories. Its interface laws are proved
from the actual source definitions.

A stronger alignment binds the whole authentic effective policy, thresholds,
fixed lifetime taint, root memories and complete certificate history. With an
explicit raw-epoch base, finite sequences of actual aggregate preparation,
attempt, source-bound owner certification, delivery and cancellation refine
common primitive histories. Failed preparations and cancellations retain their
actual partial effects. A true cancellation reply yields a cumulative common
certificate and durable exclusion of the exact envelope; neither converse is
asserted. Duplicate cross-call tombstone-list entries remain possible.

The separately named monotone reference-clock class adds a NEW set-now operation,
absent from the accepted service. Arbitrary set-now preserves structural
alignment; only nondecreasing updates belong to the new trace class. Exact grant
predicates imply rejection at a fixed command's lease end. Monotonicity then
preserves expiry across all later finite traces. Rollback can resurrect an
unlanded, uncancelled envelope, as an explicit control demonstrates. Actor
observations remain separate and unchanged. Equal-time stalling and unbounded
forward jumps are permitted, so numerical monotonicity supplies no clock progress
or deadline. A fresh longer-lease command may admit after the original expires.
Expired preparation can still retain a dishonest commitment; the honest live
gates prevent its landing.

The 3013-byte accepted native fixture is retained exactly, with raw epochs 2→3,
n=4, B=1 and q=r=3. A time-advancing installation-to-repair trace has the exact
expected final plant and audit increments. The intact path is a chosen existence
witness, not a strategy that discovers the fault set.

## Portable replay

Supply Python 3, the exact official Lean 4.19.0 Linux compiler and the pinned
Mathlib source tree with existing dependency caches:

    python -B /path/to/checkpoint/replay.py --lean /path/to/lean-4.19.0-linux/bin/lean --mathlib /path/to/mathlib-c44e0c8 --output /path/to/new-absent-output

The caller's working directory is irrelevant. Every compiler stage has an
explicit source root and runs with the checkpoint as its working directory.
All generated modules, logs and receipts go only to the separate absent output
path. Source and dependency trees cannot be selected as output. Existing output
is rejected without altering it.

Replay verifies the exact regular-file inventory, pinned scientific lineage,
independent receipts, compiler digest, and all 6816 pinned Mathlib source files.
It clears inherited Lean source-path settings and uses only a fresh custom build
plus the supplied dependency caches named by the pinned Lake manifest; unrelated
extra package directories are not added to the import path. The exact seven required cache-bearing packages are named in replay.py and must
all be present. The inherited Cli package is deliberately excluded from this
proof import closure; its actual absence is recorded. Any missing required
transitive object still fails compilation. Distribution-only correction details are in DISTRIBUTION_CORRECTION_V1.md.
Each stage is single-threaded, with a
65536 KiB thread stack and a default 300-second timeout (maximum 600 seconds).
Failures retain available diagnostics and cannot produce a PASS receipt.
All custom modules and reviewer challenges are built freshly; all scientific
and reviewer theorem closures are checked against Lean's standard propext,
Classical.choice and Quot.sound axioms. Source identity is rechecked afterwards.

Dependencies are neither installed nor rebuilt. The official compiler binary and
supplied dependency compiled caches are the trusted toolchain boundary; this
package does not independently reproduce those caches or verify hardware.
Historical command paths in reviewer receipts are evidence, not replay inputs.

Run lightweight fail-closed wrapper controls without compiling Lean:

    python -B /path/to/checkpoint/test_replay.py
