- Exact original bytes and all pre-publication omissions remain available only inside the private delivery archive. Public redactions/formatting are not independent scientific evidence.

- Public Git navigation is not the live T20 research ledger. Dot should cite the merged commit and the specific checkpoint document; future checkpoints extend this index **additively**, after separate integration.
