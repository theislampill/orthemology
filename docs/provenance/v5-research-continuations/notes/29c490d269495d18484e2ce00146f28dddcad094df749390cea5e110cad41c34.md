# Independent executable-certificate boundary

The finite-table compiler and natural-state compiler are genuine source-level results when their finite data or local P02 programs/certificates are supplied. They do not prove that an arbitrary mathematically specified observed-history function has such a source program.

A concrete cardinality control makes the real-tolerance issue precise. Fix one binary row with probability 1/2, one used row index, phase gate zero, and consider the literal empirical rejection test with any tolerance epsilon in (0,1/2). For every rational r in (0,1/2), there is a finite acquired history at that row with empirical frequency 1/2+r. Its rejection value is exactly the truth of epsilon<=r. If epsilon1<epsilon2, choose rational r strictly between them; the two tests give different values on that same finite history. Hence this fixed finite rational-row input admits uncountably many distinct tolerance-indexed history predicates.

The histories can also be made feasible observed-state histories: use a two-state, sole-action chain whose row at state 0 is the fair binary row and whose row at state 1 returns deterministically to state 0. Insert that return after each sampled successor 1. Arbitrary finite words are then acquired at row 0 with positive probability, while the interleaved return row has zero empirical deviation. The same threshold separation holds on these feasible histories.

There are only countably many numeric P02 programs. Consequently finite rational rows plus an arbitrary admissible real tolerance cannot, on their own, give executable source for every exact empirical test. An explicit effective tolerance or an additional implementation certificate is a substantive obligation.

This does not prove that the particular retained Classical.choose tolerance is noncomputable. It establishes that computability cannot be inferred from the loose admissibility specification alone. Nor does it rule out choosing another explicit rational tolerance and proving a corresponding successful controller. That would be a supplied effective witness, and equality of its full action law with the separately chosen mathematical record would remain a distinct claim.

Likewise, the source-certified unbounded counter demonstrates genuinely unbounded stored natural state, but its Boolean output may still have a finite observational quotient. Neither statement establishes that the complete accepted phase controller has been instantiated by the natural-state compiler. Its local Implements certificates remain the exact remaining boundary.
