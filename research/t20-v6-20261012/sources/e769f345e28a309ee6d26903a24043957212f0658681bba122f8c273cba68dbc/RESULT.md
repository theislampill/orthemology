# T20 constructive result: certificate memory across withdrawal and guarded revision

## Result first

A current proof-completion summary can forget distinctions that become decisive after an evidence withdrawal. The CP23 acquisition-only frontier is correct under its stated contract; it is not an updateable state for an enlarged grant/withdraw contract.

The constructive repair is exact in the declared finite Boolean model. Start with every status bit that can affect any scoped terminal certificate's least checking cost. Then repeatedly add each bit that can influence a retained bit through an admitted revision action. If independent set/clear actions are available for every bit, retaining exactly this backward dependency closure is both sufficient and necessary. It gives a complete updating state with exactly 2^k distinguishable states, or k bits of fixed-width binary memory. The report does not assert k real-valued coordinates, physical RAM, or a deployment lower bound.

For positive fixed-catalogue certificates, the starting bits are precisely the union of globally undominated full proof supports. Thus the procedure connects an actual finite certificate catalogue to revision-safe state requirements. For guarded revisions, that starting support set can be too small: a bit absent from every terminal proof can still control whether another bit is withdrawn. This is a future certificate-status dependency, not a proof of the source's truth or of human knowledge.

## A worked, source-faithful discriminator

Two admitted Q-proofs cost 1: one uses token a, the other token b. Inventories {a} and {a,b} have the same CP23 normalized residual frontier: an empty missing set at cost 1. Both may retain the same actual a-proof behind that frontier. Every acquisition-only continuation gives the same least cost.

After named withdrawal of a, the first inventory has no eligible proof; the second still has the b-proof at cost 1. A one-valued frontier summary cannot determine both results. The needed distinction is alternative currently held support, not a new metaphysical fact, a new proof of Q, or an authenticated claim that Q became false.

The safe pruning distinction is exact:

- Global domination based on full supports and costs remains valid at every inventory under the fixed catalogue.
- Domination created only by subtracting the current inventory can erase support needed after later withdrawals.
- A guarded status-changing action can introduce dependencies outside all current certificate supports. For h=a and action a←a AND NOT b, the value of b must also survive. Repeating this construction yields a transitive dependency chain.

The result is therefore more specific than the familiar instruction to keep provenance. It characterizes which finite state distinctions are forced by the declared intervention alphabet and which are irrelevant.

## What the procedure constructs

1. Fix the scoped output vector and complete finite admissible catalogue.
2. Compute semantic essentiality of each output; positive support/cost catalogues admit the global-antichain shortcut proved in Theorem 3.
3. Compute the least backward closure through the semantic coordinate functions of the admitted actions.
4. Store those coordinates. To update, fill forgotten coordinates arbitrarily, apply the action model, and project back; the theorem proves fill-independence.
5. Retain a separate recoverable proof/evidence channel and perform the current terminal check. Eligibility is not a completed check or a reusable authorization.

This constructs an exact finite mathematical state reducer. It is not an efficient general compiler: determining semantic essentiality from succinct guards can require substantial work, and the finite controls use explicit tables.

## Exact restrictions

The necessity theorem assumes the whole Boolean cube, all independent set/clear operations, fixed output meaning, total deterministic actions, and unrestricted common action words. Without those assumptions the exact memory can be smaller or require a different representation. Acquisition-only OR has two continuation classes rather than four; correlated states, partial permissions, observable refusals and irreversible histories need their own state model.

Actual version-bound revocation is especially important. [The existing operational contract](https://github.com/theislampill/orthemology/blob/7efc6217c090b92d65f2c4cb8b011c18eb96bf7c/experiments/orthemology-v5/source/OPERATIONAL_CONTRACT.md) explicitly prevents ABA from reviving an old licence. [T08 cancellation](https://github.com/theislampill/orthemology/blob/7efc6217c090b92d65f2c4cb8b011c18eb96bf7c/experiments/orthemology-v5-successors/source-store/485083cfa8c0510ca3af177abd23d6e51835bf0c91074797c9d9fc4a0920fc69/CANCELLATION_ARGUMENT.md) is scoped to exact commands and authenticated histories, with partial effects even on some false replies. Those are richer operational facts. No mapping of those runtimes onto freely resettable bits has been proved.

Authentication, source truth, normative authority, premise defeat, artifact availability, psychological retention and present human basing remain distinct. A zero eligibility bit does not prove falsehood or erase a person's knowledge. The [dynamic orthability companion, §8.1](https://github.com/theislampill/orthemology/blob/7efc6217c090b92d65f2c4cb8b011c18eb96bf7c/companion/dynamic-orthing-noetic-learning-and-orthability.md) already distinguishes objective corrigibility from access, discoverability and guaranteed learning. This operation maintains a specified certificate-state relation; it does not cross those epistemological bridges by changing a Boolean.
