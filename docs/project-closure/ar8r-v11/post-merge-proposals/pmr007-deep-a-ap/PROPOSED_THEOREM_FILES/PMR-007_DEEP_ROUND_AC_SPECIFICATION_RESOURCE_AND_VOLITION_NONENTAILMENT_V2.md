## 2. SRVN-1A — invariant-resource nonselection

If `e` is fixed by all of `G`, then `F(e)` is fixed by all of `G`.  Therefore,
if the action on `A` has **no global fixed point**, there is no total
deterministic `G`-equivariant selector defined at a `G`-fixed resource state.

### Proof

For every `g in G`,

\[
g\cdot F(e)=F(g\cdot e)=F(e).
\]

Thus `F(e)` is global fixed.  The no-fixed-point assumption yields the
contradiction. ∎

Transitivity on a non-singleton alternative set is one sufficient condition
for the absence of a global fixed point.  It is not required by the general
statement.
