# Effective rational cluster witness: restricted design contract

This executable successor is separate from the frozen mathematical width packet. It uses the RATIONAL support a_i=2^(-(i+1)^2), not the real exp(-(i+1)^2) example. The mathematical prior weights are a_i/Z; the program does not replace its infinite normalizer by a finite one, and does not need to compute Z.

For r_i=a_(i+1)/a_i, compute m_i=ceil(log2(1/r_i)) exactly by integer shifts/comparisons; here m_i=2i+3. Define rational boundaries

    b_i=a_i min(3/4,max(3r_i/2,1/(128m_i))).

The policy uses x=max(k/n,1/n), takes the first i with x>b_i, and issues the corresponding report. It searches at most ceil(log2 n)+1 candidate indices: half separation gives b_i<=3*2^(-i-3), so the last certified index has b_i<1/n. No real logarithm, exact comparison of computable reals, Bayes score oracle or numerical normalizer is called.

Two declared modes:

- strict_width: rational0<epsilon<=1/4, rational0<=delta<epsilon and delta<=1/16; arbitrary component probability laws inside the relative delta intervals. If selected a_i>(epsilon-delta)/(2epsilon), use the empirical report. Otherwise use1/2+epsilon a_i(1-delta epsilon)

The component-law promises are mathematical input assumptions. The runtime cannot infer or validate them from a finite receipt word. In particular uniform_critical cannot be silently used for the edge-strip counterexample.

The uncapped core API is decide_word_unbounded for an actual finite nonempty binary word and decide_counts_unbounded for a truthful integer(n,k) prefix summary. These core functions impose NO preset word-length, integer-bit-length, or rational-bit-length ceiling.
