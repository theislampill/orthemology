# Action-relevant integrity after exact diagnosis

Sixth-tranche working candidate. New bounded synthesis; no canonical edit, adoption,
status promotion, historical identity, or claim of new general mathematics.

## Finding in one paragraph

Even exact corruption-robust diagnosis of a hidden governing rule, a completely
specified objective target, fully shared reason packets, and a provenance cutset
with more root-distinct blockers than the corruption budget do not suffice for a
lawful safe restoration policy. The diagnosis can identify the rule without
identifying which intervention roots are intact. When a faulty intervention is
irreversibly damaging, every candidate repair can remain unsafe in a scenario
compatible with the same complete transcript. In contrast, independently
established fail-silent non-destructive trials can restore safely without identifying
all root faults. The missing object is an action-relevant integrity and causal
contract over the recipient's surviving scenarios, not more copies, consensus,
a unique target label, or an assertion of a metaphysically unified source.

## 2. A concrete whole-rule repair semantics

Use a runtime with input z in {0,1}, an independently calibrated intended output
T(z)=z, and a defective upstream representation that reports one constant sign.
Two modules operate in series. Each intact module transmits its input unchanged;
one hidden module theta in {0,1} instead emits constant1. Thus both possible
initial configurations implement the same outward function [0,1] -> [1,1]. Installing the
repair for module theta replaces the relevant upstream rule with the identity
rule and disables every path from the defective module to the output. Installing
the wrong module's repair does not establish restoration. This gives two hidden
governing structures with the same present output, and a fixed objective target
that does not vary with which module is faulty.

The possible modules, target, input class, path completeness, and effects here
are stipulated finite engineering semantics, not a claim about a person, school,
fiṭrah, or an actual source. There is a genuine operation/no-operation contrast:
without the correct repair, input 0 continues to yield the erroneous constant
1; after correct repair, both inputs are handled correctly forever. Holding at
the initial configuration is safe but never restorative; holding after repair
preserves the restored rule.

There are n=2f+1 authenticated acquisition/maintenance roots R, f>=1. Root identity
is already externally settled: copies, aliases, and source unity cannot change
R. A single static C subset R, |C|<=f, marks roots whose full integrity cannot be
relied on during this episode. Correct roots report theta. Corrupt roots may
report either bit, including the truth. Each recipient can receive the complete
root-labelled report vector and the same correct target, version, and authority
contract. We grant these unusually strong epistemic conditions to isolate the
remaining obstruction.

Each root i offers a module-specific action repair(i,b). If i is intact and b=theta,
the action establishes the identity rule, preserves every hard obligation, and
leads to an absorbing restored state G. Holding keeps G. The root supports for
all correct-module blockers are singleton sets {i}. The static causal path
registry has one error-effective path, cut by any intact correct-module action.

## 3. Destructive-root architecture: exact separation theorem

Architecture D adds one causal fact: attempting repair through a root in C enters
an absorbing unsafe state X outside the persistent target set. The state target
is G, defined by the repaired rule on the entire input class, rather than success
on the particular next input. This is not merely a transient bad output. No later
intervention in the registered menu can undo X. A wrong module choice also fails
to restore; it cannot improve the safe-recovery claim. The controller may hold,
request/retransmit any already available report, or attempt one root repair. All
communication-only actions leave C hidden. The fault set is static and selected
before any private random seed, not adaptively after commitment.

### D1: exact governor diagnosis and support robustness both hold

The uncorrupted report codewords, suppressing fixed root/version/attribution
coordinates, are 0^n and 1^n, at Hamming distance n=2f+1.
Majority therefore identifies theta under every permitted substitution pattern,
by AW's actual code contract. This does not identify C: actual altered reports
are only a subset of possibly corrupt roots.

For the correct-module repair portfolio the blocker hypergraph consists of all
n singleton root supports. Its transversal number is n, so kappa=n>f. PRRC's
static support certificate is true. It asserts that an intact blocker exists,
not that attempted corrupt blockers are safe.

### D2: no common safe and restorative policy exists

Consider the admissible transcript y=theta^n. It occurs for every possible C,
because corrupt roots may report theta. Before a first repair attempt, every
allowed communication or hold history is compatible with every C. Any policy
that restores must eventually attempt a repair. If its first attempted root is
i, choose an admissible static C containing i. That same pre-attempt history is
still possible, and the attempt enters X. Thus no deterministic history policy
can guarantee both safety and eventual restoration for all C. Waiting forever
preserves safety and fails restoration.

Randomization does not recover almost-sure safety and liveness. Under y=theta^n,
a policy with almost-sure eventual attempt induces a distribution p on the first
attempted root. Choose the f roots with greatest p mass as the static C. Their
mass is at least f/n, hence unsafe failure probability is at least f/n in that
scenario. Uniformly choosing one correct-module root attains failure f/n for
|C|=f. Thus the minimax failure probability among policies that eventually
attempt is exactly f/n. No probabilistic source-independence or iid assumption
has been introduced; this is a finite averaging argument over action choices.

The contradiction persists after granting every recipient warranted adoption
of theta, and even common knowledge of theta and the entire disclosed contract.
It is not a failure to pool information. What remains unknown is which repair
root is safe to exercise.

### D3: why stronger foundations do not silently solve it

Fixing the objectively correct target strengthens what G means. A source/world
argument may justify theta or the standard governing which outcomes count as
restoration. Neither fact implies i notin C, makes a corrupt intervention
non-destructive, or gives a recipient an action it can safely execute. One may
expand every scenario with the same defended account of objective normativity,
source unity, Knowledge, or a correct standard without altering this proof,
provided that account does not independently entail those missing causal and
integrity facts. The exact missing bridge is exposed, not denied in principle.

### D4: exact integrity frontier after a non-unanimous report

For an observed vector y, first majority-decode theta. Define the mismatch set
E(y)={i : y_i != theta} and k=|E(y)|. Every compatible corruption set contains E
and has size at most f. Conversely every such C is compatible: its remaining
corrupt roots simply reported the truth.

Thus the roots certainly intact after y are exactly:

- R\E if k=f
- the empty set if k<f

For k=f, no corruption budget remains for an agreeing root. For k<f, each
agreeing root i belongs to the compatible set E union {i}, while mismatching
roots are already known corrupt. This proves the characterization directly
from the causal/report contract, rather than introducing an opaque verdict set.

Among policies that attempt a repair almost surely after y and use only the
specified harmless pre-attempt observations, the exact minimax unsafe probability
is (f-k)/(n-k). Never select a known mismatching root; uniform selection among
the n-k agreeing roots attains the bound. Conversely the adversary can put its
remaining f-k corrupt roots on the largest choice masses among those roots. Any
mass q assigned to known corrupt roots gives risk at least
q + (1-q)(f-k)/(n-k), which is no smaller than the displayed bound. Holding forever is
excluded from this minimax class because it fails restoration.

For f=1,n=3, y=(0,0,1) entails C={3}, so repair through root1 or root2 is safe.
But y=(0,0,0) is compatible with each singleton C and supplies no certainly safe
repair. Both vectors exactly identify the same governor. Unanimity about the
right diagnosis can coexist with less action-relevant integrity information.
This is not a general claim that disagreement is good; the conclusion depends
on the specific shared fault budget and source-to-actuator integrity coupling.

## 4. Fail-silent architecture: a substantive positive contrast

Architecture S changes only the root-failure transition. Let R_theta be the
semantically adequate idempotent repair map: it takes the initial defective
configuration to G and preserves G. Each actual root action is

F_i,C = R_theta if i is intact, and Id if i is corrupt.

This means a corrupt-root attempt is genuinely inert: it neither damages the
governor nor consumes other routes nor undoes a preceding successful repair.
The controller majority-decodes theta and executes any f+1 distinct actual roots.
At least one action is R_theta. The maps commute and R_theta is idempotent, so
their composition is R_theta regardless of order. G is reached within f+1
attempts and retained thereafter. No integrity diagnosis and no trusted SUCCESS
or FAIL receipt is needed for this fixed-length batch. It can finish with no
knowledge of which root did the work. A sound receipt would permit early stopping
but is an additional convenience, not a concealed oracle premise of the result.

The semantic requirements are strong and independently testable:

1. A failed action is the identity map on all safety and repair-relevant state,
   including available future routes; a mere returned label FAIL does not prove it
2. An intact action performs the same target-adequate repair map and preserves G;
   correct-module action must be idempotent and introduce no new error path
3. Actions complete in the declared discrete steps, and the fault budget/root
   identities/version epoch remain fixed through the sequence
4. The corrected rule handles the entire target input class and preserves the
   custody/reread obligations; a one-case output clamp does not qualify
5. Distinct recipient actions are authorized and feasible. Root-distinctness is
   authenticated; f+1 aliases of one actual root are insufficient

The positive theorem applies a real causal redundancy architecture. It is not
derived from a response label, source count, metaphysical property, or code
distance alone. It is the coverage variant of the commuting/idempotent repair
criterion being developed in the norm-fixing sibling argument: some local maps
can be identity and thus need not individually repair anything, but the bounded
fault budget guarantees that the composition contains one adequate repair.

### S1: the new resource is fault containment, not a free actuation assumption

S does not solve D with the original unrestricted destructive faults. It changes
what a compromised action root can causally do. The report channel can still be
Byzantine while its actuation channel must be confined to the certified repair
or omission. Two possible justifications have different trust costs:

- Independently established omission-only actuation faults. The actual mechanism
  permits a root to withhold the correct action but not substitute an arbitrary
  state-changing action. Here {R_theta,Id} is a substantiated failure-class
  restriction. Corruption of the plant's transition mechanism is outside scope.
- A separately enforced actuation envelope accepts only the certified R_theta
  operation and otherwise leaves state unchanged. Its semantic validation,
  non-bypassability, atomicity and preservation of future routes need independent
  evidence. An API signature, returned FAIL, proof file, or common source label
  does not establish those physical/implementation facts.

If one common enforcer g supplies this envelope and its integrity is part of the
same root-fault budget, each repair has actual required-root support {g,i}.
Then {g} intersects every blocker support: actual kappa=1, despite n distinct
report/maintenance roots. For f>=1, corrupting g defeats the positive guarantee.
A gate that silently shares origin with an already faulty root cannot be counted
as a new independent protection either. The executable common-gate control
computes this transversal and demonstrates a failed batch after gate corruption.

One may instead declare g trusted and outside the corruption class, but that is
an additional trusted-base premise, not a result. Source or norm correctness does
not discharge it. Distributed or replicated enforcement may reduce the common
bottleneck only after a fresh causal/dependency analysis shows fault containment,
actual root separation, and no ability for one bad enforcer to undo good repair.
No such architecture is claimed here. The positive result therefore identifies
an exact useful new resource and its price: independently warranted containment
of faulty actions, alongside coverage by at least one adequate repair.

## 5. Loss and controller boundary

In D, a one-off indicator of a damaging act has total loss at most one. That does
not establish restoration: after X, the target rule is wrong forever and the
literal total non-target-visit count is infinite. Counting incident messages,
failed attempts, or correct diagnoses silently changes the objective.

In S, after the report-acquisition stage, non-target action visits before G are
at most f+1. Thus every finite moment of that count is bounded by (f+1)^d. This
bound comes from the deterministic static-fault architecture. It is not an
application of the sixth-tranche empirical-controller theorem.

The actual controller-cost theorem [S25–S26] has a finite rational static hidden-model
family, fully observed physical states, declared lawful menus, exact coBuchi
bad-pair loss, source-specific row tests and winning-region membership. D's
initial state is outside the common safe-recovery region. Its theorem does not
manufacture missing safe actions. If a representation hides X or replaces the
literal target loss with the single damage-event loss, its hypotheses no longer
refer to this task. The separate literal-loss observation obstruction [S27] likewise
forbids substituting a convenient observed-symbol score for a latent target
failure without a valid loss representation. No countable-prior or generic
prediction bound is imported here.

## 6. Copying, synchronisation, and identity

### Copies preserve the root-level obstruction

Suppose actual root i has m_i>0 report/agent/actuator-interface copies. Copies are
numerically distinct tokens, but every copy inherits that root's report and
actuation fault. Pooled root decoding, the actual singleton-support hypergraph,
and the live C family are unchanged. A copy-level first-choice policy induces
root probability p_i by summing its choices over copies of i. Its worst-case
failure on the unanimous transcript is the sum of the largest f root masses,
which is at least f/n. Optimizing over copies therefore cannot improve the
root-level f/n value.

For f=1 and three roots, uniform selection over one copy of each root gives
failure 1/3. If root1 is represented forty times and the other roots once each,
uniform selection among the forty-two carriers gives worst-case failure
40/42=20/21. Choosing uniformly over authenticated roots restores 1/3. Copying
can worsen a naive selection procedure; it cannot create resilient integrity.
In S, f+1 distinct carriers do not guarantee success if they are all copies of
one corrupt actual root. The constructive guarantee counts actual distinct roots.

### A correct conclusion is not a repair-sufficient synchronization

For f=1,n=3, full y=(0,0,1) identifies root3 as the unique corrupt root and permits
safe destructive repair through root1. Replace the packet by only its correct
majority conclusion theta=0. The same received summary now also represents
(0,0,0), where every root may be corrupt. Any policy seeing only that summary
must use the same choice in these scenarios and cannot guarantee safe recovery.
The synchronization preserves exact diagnosis of the governing rule but loses
action-relevant integrity. Retaining the multiset {0,0,1} without binding each
report to its actual root also fails: permutations leave each root possibly the
mismatching/corrupt one. Source-to-content binding is load-bearing here.

This is compatible with AR's common-channel data-processing result. It does not
claim that AU's linear root-span rank is a complete nonlinear information or
control invariant. AU explicitly leaves operational repair capacity open. The
example must not be presented as an application of its matrix theorem to an
unregistered nonlinear summary.

A faithful copy of the full labelled report and valid recipient action contract
can preserve this safe policy despite creating a new numerical token. A copy of
just the true diagnosed proposition need not. Same physical carrier, same
computational type, numerical identity, source lineage, and possession of an
action-relevant warrant remain distinct coordinates.

### Local adoption and authorization are additional, explicit premises

The base theorem supplies pooled exact identification inside the finite report
model. To call an actual recipient warranted in adopting theta requires a valid
recipient-local reason route: actual authenticated roots, correctly attributed
content, credible fault-bound/model completeness, current applicability and
closed defeaters. Having the mathematical decoder or all messages somewhere in
the collective is not that route. We can grant every recipient that route and
common knowledge of theta; D2 still holds. Authorized exercise of repair is yet
another predicate, held fixed and permissive in D. It does not imply causal
safety. The stronger root-integrity warrant i notin C, when obtained at k=f, is
what changes safe executability, not shared conviction about theta.

## 7. What changed, and what did not

This construction gives an explicit joint counterexample to the proposed
composition of robust governor diagnosis + root-resilient support + collective
agreement into safe lasting repair. The same roots occupy evidence and action
roles; truth-preserving corruption masks the action-relevant uncertainty. A
matched repair architecture alters that causal failure semantics and supplies
a bounded constructive recovery policy, without requiring full structural or
integrity identification.

It changes the operational reading of four avenues simultaneously:
unknown-structure restoration must track action-relevant hidden structure;
provenance resilience must distinguish surviving support from safely selectable
support; collective warrant must specify what proposition is warranted; and
synchronization must preserve the policy's causal and root-indexed memory
interface rather than treating copy count or numerical identity as sufficient.

The foundational lanes contribute only through explicit premises about target
adequacy, actual source/world correspondence, and lawful action. No new proof of
objective norm-fixing, Necessary Being, a divine attribute, or revelational
identification is claimed. The operational theorem is deliberately compatible
with rival metaphysical accounts that satisfy the same stated premises.

## 8. Guard-deletion controls and exact remaining obligations

The conditional k=f result does not survive separating report faults from
actuator faults. With three roots, report (0,0,1) exhausts a one-sensor-fault
budget at root3, while a separately faulty actuator1 can still fail destructively.
One must actually warrant the common fault-unit model: every intact root reports
correctly and actuates correctly, and all relevant failures belong to the same
at-most-f set. Root identity, truth of one report, actuation integrity, and
conditional statistical independence are not interchangeable.

The finite controls also change C after each attempt: one mobile fault follows
root1, then root2, and defeats the f+1 fail-silent batch. This is deliberately
outside the static theorem. A root-alias control gives two copies of one false
report plus one true independent report; carrier-majority is wrong even with
only one actual corrupt root. A false SUCCESS receipt can cause premature
stopping while the fixed distinct-root batch still succeeds.

Before applying this construction to an actual multi-agent runtime, the following
remain empirical/engineering obligations rather than theorem outputs:

- independently establish the correct target/input class and the meaning of a
  persistent restored rule; inspect current correctness, reliable route, warrant
  for route reliability, and general metaphysical claims separately
- identify actual acquisition/actuation fault units and justify their coupling,
  budget, static epoch, and coverage of all relevant failure modes
- preserve root-to-content binding, including verified dissent exclusions and
  versions, rather than transmitting only a majority conclusion
- demonstrate intended intervention effects, fail-silent or damaging failure
  semantics, and preservation of future options and all hard obligations
- establish recipient-local reasons and permission separately from an aggregate
  model calculation; a source cognition is not automatically a recipient warrant
- test source-world applicability and truth if a theological or proper-function
  source restricts the candidate standards; capacity for truthful disclosure
  does not establish this disclosure occurrence or this route's integrity
- model omitted paths, dynamic bypass, member churn, and version drift if claimed;
  otherwise retain the bounded episode and reject stronger persistence claims

A direct implementation test should send the same full labelled vector through
three modes: original custody, majority-only synchronization, and labels-unbound
multiset synchronization. It should compare the actual permitted integrity-safe
repair roots, not just classification accuracy. A second test should inject a
root fault that truthfully diagnoses theta but fails on actuation. A third should
verify that the allegedly fail-silent action preserves the entire subsequent
route set. These tests can falsify the proposed application rather than merely
replay a renamed decision table.

## 9. Prior-art and contribution ceiling

Diagnosis and safe control have long been distinct research problems. Paoli and
Lafortune’s 2005 publisher abstract introduces safe fault diagnosis, while Paoli,
Sartini and Lafortune’s 2011 publisher abstract/section excerpts distinguish safe
controllability and continued fault-tolerant operation. These are prior-art
anchors, not freshly verified full proofs in this packet.

Fawzi, Tabuada and Diggavi’s author text fixes hidden attack sets over time and
studies secure linear-system estimation. Section III-F extends estimation to
actuator attacks. The positive estimation/control separation in Section IV uses
sensor attacks and an intact actuation equation; it explicitly notes that
actuator attacks preclude general stabilizing control. Our destructive-root
construction therefore does not refute that separation theorem. It is outside
its actuation contract.

Sources: [Paoli–Lafortune 2005](https://www.sciencedirect.com/science/article/pii/S0005109805001111),
[Paoli–Sartini–Lafortune 2011](https://www.sciencedirect.com/science/article/pii/S0005109811000227),
[Fawzi–Tabuada–Diggavi author version, §IV](https://arxiv.org/html/1205.5073v1).

No novelty is claimed for the general distinction, Hamming codes, hypergraph
transversals, indistinguishability arguments, randomized finite minimax bounds,
or idempotent redundancy. The scoped contribution is the explicit joint
AW+PRRC+FRLA integration test, the action-integrity frontier and its
synchronization/copy controls, a genuinely causal positive comparison, and the
exact boundary on importing foundation/controller claims. The original
R5-minimal-nonintegration control [S08] remains untouched: every result here can
