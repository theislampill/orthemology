# Printed-source collation

The [1920 print (p.20)](https://oll-resources.s3.us-east-2.amazonaws.com/oll3/store/titles/1979/0961-01_Bk.pdf#page=66) matches [New Advent’s](https://www.newadvent.org/summa/1002.htm#article1) negative concession. [Leonine 1888 (p.27)](https://archive.org/download/operaomniaiussui04thom/operaomniaiussui04thom.pdf#page=45) prints the positive reading but records a negative variant. The discrepancy therefore predates the website; the English translators’ Latin base and production responsibility remain unestablished.
