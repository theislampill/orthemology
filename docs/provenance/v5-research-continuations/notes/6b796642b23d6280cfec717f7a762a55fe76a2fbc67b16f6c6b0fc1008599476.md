# A terminating exact-rational witness on dyadic-square centres

Ordinary constructive theorem and separately scoped reference implementation. Version1,2026-10-01. This is not an implementation of the non-rational exp-square prior, a Lean extraction theorem, or a physical-clock guarantee.

## 1. Rational boundaries replace real logarithms

For a uniformly computable exact-rational support0<a_(i+1)<=a_i/2 with a_0<=1/2, define r_i=a_(i+1)/a_i and let m_i be the least integer m>=1 satisfying2^m r_i>=1. It is computed exactly using integer shifts. Equivalently,

    2^(-m_i)<=r_i<2^(-(m_i-1)).

For L_i=log(1/r_i), the elementary bounds1/2<=log2<=1 give

    L_i<=m_i<=4L_i.

Set

    b_i=a_i min(3/4,max(3r_i/2,1/(128m_i))).             (R)

Every boundary is rational and satisfies(3/2)a_(i+1)<=b_i<=(3/4)a_i. Thus all index-selection, MGF and report-shape arguments in the frozen width successor continue to apply. The normalizer is neither approximated nor truncated; the policy never needs it.

## 3. Terminating selector from a finite prefix

Given a nonempty word of length n with k ones, form x=max(k/n,1/n) and take the first i with x>b_i. Let B=ceil(log2 n), implemented exactly as(n-1).bit_length(). Since a_i<=2^(-i-1),

    b_B<=(3/4)a_B<=3/(8*2^B)<=3/(8n)<1/n<=x.

Thus the bounded loop over i=0,...,B must find an index. It never requires an exact comparison of arbitrary computable reals. Equality x=b_i moves to the next cluster; equality of the empirical frequency with a selected critical centre chooses the left local report. Both rules are explicit and tested.

All arithmetic operations on rational integers terminate. The dyadic-rank calculation uses numerator/denominator bit lengths followed by exact shifts/comparisons. Its final inequalities certify the integer rank, rather than a floating approximation to a logarithm. The normalizer and infinite prior support are not replaced by a finite prior: the finite loop is proved sufficient for THIS decision from the whole infinite family.

## 5. Exact input/output and costs

The functions decide_word, decide_counts and the CLI retain the finite limits in DESIGN_AND_CONTRACT.md. Those guarded adapters are bounded restrictions, NOT an infinite compulsory-report family. Both interfaces accept an actual binary word or a truthful integer(n,k) summary. A summary does not supply or certify n observations; it is a data representation whose statistical provenance is an external promise. The word and summary interfaces agree exactly.

The index search checks at most ceil(log2 n)+1 candidates. Reading a word still requires linear work in its length. Each support denominator considered has at most O((log n)^2) bits under the general certified search bound, and arithmetic also depends on the bit lengths of epsilon and delta. Induction over the blocks proves exact input interpretation, including leading zeros and a single sign. Output uses the inverse base-10^9 decomposition. No float, real logarithm, random seed, network action, code evaluation, or approximate posterior is used.
