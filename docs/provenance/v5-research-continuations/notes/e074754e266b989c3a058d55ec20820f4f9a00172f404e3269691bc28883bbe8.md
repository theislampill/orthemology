## Constant and cutoff audit

Using `q = |State × Action|`, `m = |B₀|`, `D = |State| |Action|^|State|`, define:

- `α = q + 2m`
- `β = q(m−1) + 2m²`
- `c = (min(η,1))²/2`
- `A = 2q|State|/(1−exp(−c))`
- `λ = log(2/(2−p^D))`

Model membership gives `m > 0`, so natural subtraction is handled correctly in the exact identity `J_N = αN + β`. Nonempty states and the fallback action give `D > 0`; the derived bounds give `c > 0`, `A ≥ 1`, and `λ > 0`.

The affine optimizer chooses:

`B = (D/λ) [ (α(1 + log(2A)/c) + β)log 2 + log 2 ]`

`V = (D/λ) [ α log 2 / c + 1 ]`
