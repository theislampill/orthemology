# Exact potential controls

Status: APPROVED CONTROL SPECIFICATIONS; execution status is recorded separately in validation receipts. These are relative interpretations of explicit contracts. None is a certification of a metaphysically possible imperfect Necessary Being or a refutation of T17's cumulative appraisal.

## Shared convention

For each one-premise deletion use a nonempty source domain containing g, a context c, an owned assertion t of false proposition p, and its own actual exercise e. The assertion-to-exercise bridge holds. A true proposition q is also available. Unless changed below, g knows p false, is aware that t asserts p, deliberately presents t as an assertion, and thus descriptively counterfeits; D/N/P follow their displayed implications. DeliberatePresentation has no content argument, so its occurrence-level control is distinguished from Aware's exact contextual-content awareness. Unmentioned relations are false or restricted to the displayed witnesses. Full definitions and truth tables would be required before execution.

The source's upstream originality/necessity labels may remain uninterpreted supplied background, but the models must not call g practically perfect after dropping the premise that supplies actual practical conformance. Retaining such a label does not establish its intended interpretation.

## Deletion controls

### V-K — epistemic scope missing

Set KnowsFalse(p) false while Assert/Aware/DeliberatePresentation are true. KnowingCounterfeit and DeclarativeShortcoming are false; Fitting(e) true. D, N, P, A, C and factivity hold; K fails; T0 fails. This is an epistemically limited false assertion, not a counterexample preserving perfect knowledge. A separate knowledge-of-q witness can prevent cognition from being wholly empty.

### V-A — contextual awareness missing

Set KnowsFalse(p) true, Aware(t,p) false, DeliberatePresentation(t) true; D/N/P hold with no counterfeit/shortcoming and Fitting(e) true. K and C hold; A fails; T0 fails. Add an erroneous intended-content assignment to distinct true q: the source deliberately presents t but misidentifies its contextual content. This tests a weak ownership interpretation; it does NOT establish that T17's intended genuine ownership permits this configuration. Under a strengthened semantics where genuine ownership already entails A, this control is unavailable and A is redundant: record that definitional dependency rather than fake an independent deletion.

### V-C — controlled adoption missing

Set KnowsFalse(p) and Aware(t,p) true, but DeliberatePresentation(t) false; set expressive capacity true. D/N/P hold with no counterfeit/shortcoming and Fitting(e) true. K and A hold; C fails; T0 fails. This distinguishes power from actual controlled adoption and exposes an accidental/slipped presentation interface. If genuine ownership is defended as entailing C, prove/state that semantic bridge; do not just rename ownership to make the control disappear.

### V-D — descriptive counterfeit alone has no normative conclusion

Set KnowsFalse, Aware, DeliberatePresentation and KnowingCounterfeit true; DeclarativeShortcoming false; Fitting(e) true. K/A/C/N/P hold, D fails, T0 fails. The finite valuation shows that descriptive knowing falsity and normative defect have different types. It is not an objection to the independently defended defect classification.

### V-N — respect-specific shortcoming does not settle overall fittingness

Keep KnowsFalse/Aware/DeliberatePresentation, KnowingCounterfeit and DeclarativeShortcoming true; set Fitting(e) true. K/A/C/D/P hold, N fails, T0 fails. This is the precise relative structure of the rescue/overriding-good challenge: admitting counterfeit as a respect-specific shortcoming does not by itself exclude a fitting overall act. It does not establish that the same configuration is available to the qualified original source. That is the continuing philosophical dispute over N.

### V-P — knowing practical nonconformance

Keep KnowsFalse/Aware/DeliberatePresentation, KnowingCounterfeit and DeclarativeShortcoming true; set Fitting(e) false. K/A/C/D/N hold, P fails, T0 fails. This is the fully informed controlled liar. Mere knowledge, power and independence do not supply fitting exercise. Do not describe the model as retaining substantive practical perfection.

## Definitional dependency review before deletion claims

The A/C controls deliberately force an honest choice about speech-act semantics. A defensible reading of deliberate adoption under the exact known content may entail awareness; a defensible reading of genuine owned assertion may entail a form of adoption. If so, factor the semantic coverage bridge accordingly and remove the impossible independent fixture. Source claim, semantic definition and theorem premise are different entries in the ledger. The point is to expose the real bridge, not maximize the number of nominally independent premises.

Likewise, if `Perfect` is defined as all acts fitting, then `Perfect -> P` is a projection, not new attribute reasoning. If it is defined as all declarations true, reject the design. If `KnowingCounterfeit` already contains a defect predicate, reject V-D as rigged. If `Fitting` is merely whatever g does, reject the normative interpretation.

## Positive inhabited interpretation

Use two contexts c0/c1, two sources g/h and at least two occurrences. At c0 g genuinely owns a true assertion q, knows q, is aware of its content, deliberately adopts it, and performs its fitting exercise. At c1 that token does not occur. The source has another fitting nondeclarative exercise, so P has more than a single assertion instance. No fixed total history or universal occurrence follows.

At c0 h owns a false p-assertion with knowledge, awareness and controlled adoption; it has a declarative shortcoming. Original productive provision of h's occurrence by g is true, while g's assertion ownership of that occurrence is false. Generic D is exercised nonvacuously by h; N/P are imposed only on g. This inhabits the source-side contract while preserving a false created speaker and separating production from assertion ownership. The target source's own no-counterfeit implication is necessarily untriggered in a full T0 model; do not disguise that as a limitation peculiar to this fixture.

An optional standing ability to produce the physical false-token event can remain true while g never owns it as a false assertion. Distinguish the physical event from the complete source-profile-relative voluntary act. This is consistency bookkeeping, not a new metaphysical power result.

## Additional diagnostic controls

1. **Truthful yet not generically conforming:** retain g's true owned assertion and add an actual nondeclarative exercise u with Fitting(u) false. T0 holds; P fails. This prevents reverse inference from veracity to general practical perfection.
2. **Local/global separation:** two contexts; retain all controlled-token hypotheses at c0 but remove A or C at c1 and place the false assertion there. The local result holds while global T0 fails. An actual-token theorem does not supply essential universal scope.
3. **Leaf-equivalence check:** under K/A/C and factive KnowsFalse, prove both directions between T0 and no KnowingCounterfeit. Display exact prerequisites rather than calling no-counterfeit a newly independent weaker principle.
4. **Unused-premise readback:** the positive theorem must not consume numerical uniqueness, graph LocalCover, common creation, capacity for every end, or a recipient-knowledge purpose. If these appear only as unused arguments, remove them and report the redundancy.
5. **Ownership preservation:** quotation/fiction and h's false assertion may be caused by g without being asserted as g's own account. Assert must stay distinct from Produces. This is an integration guard consistent with T19 and existing attestation work, not new discovery credit.
