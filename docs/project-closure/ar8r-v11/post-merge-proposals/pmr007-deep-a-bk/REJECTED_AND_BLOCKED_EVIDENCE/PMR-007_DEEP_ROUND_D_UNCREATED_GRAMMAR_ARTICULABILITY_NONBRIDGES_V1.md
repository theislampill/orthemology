## 2. UGEN-1 — equivariant nonorigination theorem

Let a group `G` act on source states `X` and possible determinate assignments
`Y`.  Let `x0 in X` be wholly invariant under the declared symmetry:

```text
g.x0 = x0 for every g in G.
```

Let `F:X->Y` be wholly internal and symmetry-respecting:

```text
F(g.x) = g.F(x).
```

Then `F(x0)` is fixed by every `g in G`.

### Proof

For every `g`, equivariance and invariance give

```text
g.F(x0) = F(g.x0) = F(x0).
```

Thus `F(x0)` lies in `Fix_G(Y)`.  If a target assignment `y*` has a nontrivial
orbit and therefore is not fixed by `G`, no such `F` maps `x0` to `y*`. QED.

This is a standard group-action fact.  Its AR8R contribution is the exact
placement of the asymmetry burden, not general mathematical novelty.

> A non-fixed, nontrivial determinate assignment cannot originate from that

## 4. Sharp controls

### D-CM1 — asymmetric source

Let `X=Y` with the same nontrivial action and `F` be identity.  `F` is
equivariant and gives a determinate output because the selected input already
has a nontrivial orbit.  The distinction is source-carried.

### D-CM2 — asymmetric operation

A constant function chooses one distinguished `y*`.  It succeeds but is not
`G`-equivariant; the selector is built into the operation.

### D-CM3 — external selector parameter

Extend the source to `<x0,s>` with `s in Y` and define `F(x0,s)=s`.  The
parameter carries the missing distinction.  It is not generated from `x0`
alone.

### D-CM4 — spontaneous/random symmetry breaking

An invariant probability distribution can yield a non-invariant realized
sample.  The theorem concerns the realized deterministic assignment.  The
sample/seed is the selector; symmetry of the distribution is not identity of
the outcome.

### D-CM5 — fixed target

If `Y` has a `G`-fixed element, an equivariant map can return it.  The theorem
rules out only a target whose orbit is nontrivial relative to the declared
symmetry.  “Invariant” is not synonymous with “empty” or “meaningless.”
