## 1. Typed finite modal bundle

Fix a finite nonempty declared modal index set `W` with actual index `w0`.
For each `w`, let `O_w` be a finite set of local occurrences. Let `G` be a
separate global-bearer sort and

\[
\iota_w:O_w\to G
\]

an independently supplied occurrence-to-global-bearer map. It represents the
chosen `B_ID` semantics and is not derived here.

Keep separate:

```text
EXISTS(w,o);
ROOT_ROLE(w,o);
UNDERIVED_IN_GRAPH(w,o);
CONCRETE(w,o);
ABSTRACT_ORDER(w,a) on a separate abstract-order sort;
TRANSPORT_{wv}(o)=o';
GLOBAL_BEARER identity through iota_w;
metaphysical necessity beyond the declared frame.
```

Define

\[
R(w,o)=EXISTS(w,o)\land ROOT\_ROLE(w,o)\land UNDERIVED\_IN\_GRAPH(w,o).
\]

## 2. NCBD-1A — actual-root nonpersistence

\[
\exists o\in O_{w_0}\;R(w_0,o)
\]

does not entail a root at every declared world and does not entail one global
bearer represented at every world.

## 3. NCBD-1B — worldwise unique-root quantifier firewall

\[
\forall w\;\exists!o\in O_w\;R(w,o)
\]

does not entail a `g in G` such that every selected root occurrence maps to
`g`. Distinct local roots can occupy distinct global-bearer classes.

## 4. NCBD-1C — coherent lineage remains weaker than B_ID

A section `s(w) in O_w` can be preserved by every declared transport while

\[
\iota_w(s(w))\ne\iota_v(s(v)).
\]

Such a section is one coherent role/lineage section, not one numerical bearer.

## 5. NCBD-1D — abstract-order/concrete-bearer firewall

A separate abstract object can satisfy `ABSTRACT_ORDER(w,a)` for every `w`
while no local occurrence satisfies `R and CONCRETE`. Necessary abstract or
modal order therefore does not entail concrete instantiation under the typed
language.

## 6. NCBD-1E — scoped sufficient bearer package

Suppose there are a section `s` and global bearer `g` such that:

```text
COVERAGE:
  for every w, s(w) exists and satisfies ROOT_ROLE and UNDERIVED_IN_GRAPH;

B_ID:
  for every w, iota_w(s(w)) = g;

CONCRETE_EXEMPLIFICATION:
  for every w, CONCRETE(w,s(w));

FRAME_SCOPE:
  W is the declared modal scope of the conclusion.
```

Then `g` has a concrete underived-root occurrence at every `w` in the declared
frame. Call this

```text
DECLARED_FRAME_PERSISTENT_CONCRETE_ROOT(g).
```

If transport is part of the model, add:

```text
COHERENCE:
  TRANSPORT_{wv}(s(w))=s(v), and transport preserves iota.
```

This certifies compatibility of the same-bearer package with the modal role
bundle. It is not needed to manufacture `B_ID`; it presupposes the identity map
that transport must preserve.

The conclusion becomes metaphysical necessity only under an independently
warranted modal semantics and frame-completeness premise.
