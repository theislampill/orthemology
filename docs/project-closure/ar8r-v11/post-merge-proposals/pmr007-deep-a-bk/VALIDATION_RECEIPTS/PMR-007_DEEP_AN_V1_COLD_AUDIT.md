## Blocking findings

### AN-F01 — primitive count was treated as likelihood evidence

Fewer named primitives or derivational patterns is not itself an observation
likelihood.  Candidate G P6 requires a bridge from explanatory economy to
truth-conduciveness.

### AN-F02 — no canonical prior was supplied

If current likelihoods are equal, posterior odds remain the prior odds.  A
source, theological, or owner preference cannot be relabelled as neutral
empirical evidence.

### AN-F03 — description language was not independently fixed

Finite prefix-code rankings can be reversed by changing the code.  Code length
is evidential only relative to a warranted representation and coding policy.

### AN-F04 — sequence likelihood silently assumed iid sampling

The product likelihood used by the executable check is valid only under the
frozen iid model.  Dependence, intervention, adaptive sampling, and selection
bias require separate likelihoods.

### AN-F05 — support restriction may be target import

A proper subset of profiles is explanatory only if independently motivated and
fixed before held-out evaluation.  Removing unwanted cases by definition is
not predictive success.

### AN-F06 — zero probabilities overstate finite evidence

A zero-likelihood model is eliminated only relative to the frozen exact model.
Model misspecification, measurement noise, and unregistered states must remain
open.

### AN-F07 — predictive advantage was overread as metaphysical truth

A Bayes factor or held-out prediction does not by itself establish a personal
realizer, Necessary Being, source identity, or world-complete architecture.

### AN-F08 — evidence completeness was not typed

Equal likelihood on the current registered evidence does not imply global
observational equivalence.  It establishes only no update from that evidence.

### AN-F09 — Bitter-Lesson and representation dependence were omitted

Hand-authored explanandum coordinates, priors, and codes can relocate owner
assumptions.  Matched information, compute, and preregistered held-out tests are
required before empirical architecture comparison.

### AN-F10 — theorem-family and novelty ceiling were omitted

Bayes odds, finite total-variation discriminability, and prefix-code controls
are standard.  General mathematical novelty is zero; the value is a precise
Candidate-G P6 evidential gate.
