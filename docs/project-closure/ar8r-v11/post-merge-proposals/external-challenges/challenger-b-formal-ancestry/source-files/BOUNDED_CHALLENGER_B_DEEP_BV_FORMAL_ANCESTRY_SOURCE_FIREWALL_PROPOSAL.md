## 2. Typed repaired statement

### 2.1 Pure quotient theorem

Let:

- `M` be any type of candidate models;
- `Profile` be any type of complete registered experiment profiles;
- `QVal` be any target-label type;
- `E : M → Profile` be the frozen experiment-profile map;
- `Q : M → QVal` be an independently specified target coordinate.

Define profile equivalence:

\[
m \sim_E m' \quad\Longleftrightarrow\quad E(m)=E(m').
\]

Define fibre constancy:

\[
\operatorname{FC}(E,Q)
:\Longleftrightarrow
\forall m,m'\in M,
E(m)=E(m')\Rightarrow Q(m)=Q(m').
\]

Let `π_E : M → M/∼E` be the quotient map. Define exact quotient identifiability:

\[
\operatorname{QI}(E,Q)
:\Longleftrightarrow
\exists d:M/{\sim_E}\to QVal,
\quad Q=d\circ\pi_E.
\]

Then:

\[
\boxed{
\operatorname{QI}(E,Q)
\iff
\operatorname{FC}(E,Q)
}
\]

and the quotient decoder `d` is unique.

### 2.2 Exact assumptions

The equivalence above requires only:

```text
well-typed total maps E and Q;
equality on profile and target values;
the quotient by profile equality.
```

It does **not** logically require:

```text
finiteness;
probabilities;
causal semantics;
source authority;
world truth;
proper function;
personality;
mentality;
Wisdom;
Speech;
revelation;
a Necessary Being;
resource feasibility;
a real experiment.
```

Finiteness is useful for enumeration, finite certificates, and the repository’s scoped experiment owners, but it is not load-bearing in the quotient proof.

### 2.3 Attained image versus full profile codomain

The safest statement factors through the quotient or attained image `E(M)`. The phrase “`Q` factors through `E`” is ambiguous if it is read as requiring a decoder on the entire declared codomain `Profile`:

\[
\exists d:Profile\to QVal,
\quad Q=d\circ E.
\]

Fibre constancy always yields a decoder on `E(M)` or `M/∼E`. Extending it to profile values never attained by any model additionally requires an off-range value in `QVal`, a surjectivity condition, or an equivalent extension premise.

Deletion countermodel:

```text

Profile = singleton
QVal    = empty
```

Both `E` and `Q` exist as empty-domain maps and fibre constancy is vacuous, but no function `Profile → QVal` exists. Deep BV should therefore say **quotient/attained-image factorization**, or add an explicit nonemptiness/extension guard.

## 3. Proof and exact nonidentifiability witness

### 3.1 Factorization implies fibre constancy

Assume `Q=d∘π_E`. If `E(m)=E(m')`, then `π_E(m)=π_E(m')`. Therefore:

\[
Q(m)=d(\pi_E(m))=d(\pi_E(m'))=Q(m').
\]

### 3.2 Fibre constancy implies factorization

Assume `Q` is constant on every `E`-fibre. Define:

\[
d([m]_E)=Q(m).
\]

If `[m]_E=[m']_E`, then `E(m)=E(m')`; fibre constancy gives `Q(m)=Q(m')`. Thus `d` is well-defined and `Q=d∘π_E`.

### 3.3 Decoder uniqueness

Every quotient element has the form `[m]_E`. Any decoder satisfying the factorization must map `[m]_E` to `Q(m)`. Hence two such decoders agree everywhere.

### 3.4 Nonidentifiability

The exact negative witness is:

\[
\exists m,m'\in M:
E(m)=E(m')
\quad\text{and}\quad
Q(m)\ne Q(m').
\]

This does not say that the models are identical, that all possible experiments fail, or that `Q` is meaningless. It says only that the frozen registered profile does not determine `Q` over the declared model class.

### CM-BVB-09 — finite-history impersonal realizer

### CM-BVB-10 — formal intervention without eligibility

### CM-BVB-11 — full-codomain empty edge

## 7. Dependency and noncircularity audit

### 7.1 Core theorem

The core theorem is noncircular when `E` and `Q` are independently supplied maps. It says nothing about whether either map is scientifically or metaphysically adequate.

### 7.2 Main circularity hazards

A purported Deep BV application is circular or target-dependent when any of the following occurs:

1. **Answer-oracle implementation:** `impl(m,j)` reads `Q(m)` or a synonymous preferred-architecture predicate.
2. **Answer-oracle output encoding:** `κ_a` inserts the target label into the comparison output.
3. **Architecture-asymmetric strengthening:** the preferred architecture receives a constitution-rich operation while rivals receive a surface simulation under the same label.
4. **Conclusion-selected model class:** rivals are excluded because they fail the desired conclusion rather than an independent admissibility rule.
5. **Source migration:** source authority, intended divine predication, or revelation is treated as neutral evidence without an independently accepted source/world bridge.
6. **Proper-function self-certification:** the intervention is called “properly functioning” using the same function status the experiment is meant to identify.
7. **Uncreated-grammar self-certification:** an operation counts as common only if the rival already instantiates the preferred uncreated/mental/Speech ontology.
8. **Transcendental model pruning:** the positive ground or Necessary Being conclusion is assumed in the admissible model definition.
9. **Protocol drift:** results from one-shot tests are reinterpreted as complete adaptive profiles.
10. **Tolerance drift:** equality of exact laws is replaced after inspection by an undeclared statistical tolerance or test.
11. **Resource drift:** an impossible or unauthorized intervention remains in `J` only for the rival that would otherwise survive.
12. **Version drift:** different source or implementation versions are compared without recording that the action menu and semantics changed.

### 7.3 Recommended freeze order

```text
(1) declare target question and Q semantics;
(2) declare model class M and independent admissibility rules;
(3) declare abstract intervention type J;
(4) construct architecture implementations without per-model Q access;
(5) audit semantic preservation and output comparability;
(6) freeze protocol, version, source, authorization, resource, and physical guards;
(7) freeze E_J and equality/tolerance semantics;
(8) only then evaluate fibres and Q constancy;
(9) preserve every surviving collision model.
```

Global experiment design may be informed by the already declared question, but steps 3–7 may not use the hidden answer labels or eliminate a rival by definition.

## 9. Can proper-function, uncreated-grammar, or transcendental premises constrain a common intervention?

### 9.1 Proper function

**Legitimate uses**

A proper-function premise can constrain an intervention when:

1. the intervention instrument must satisfy an independently certified function-fixing relation unrelated to the target architecture coordinate; or
2. the experiment explicitly targets a supplied function-status coordinate and includes the independent history/design/authority/truth/environment evidence needed by that account.

Examples include a separately verified selected-effect history, an authenticated design specification, or an independently fixed institutional authority. These may restrict the eligible implementation class or enrich the profile.

**Illegitimate uses**

It is question-begging when:

```text
the preferred architecture is declared properly functioning because it gives the preferred answer;
the rival is denied the “same” intervention because it lacks the proper function being tested;
current success is treated as selected effect, design, Plantingian warrant, fitrah, intellect, personality, or Wisdom;
source-relative fitrah purpose is imported as a neutral function-fixing fact.
```

The repository’s proper-function matrix correctly requires account-specific function-fixing evidence and gives equal-success/different-history countermodels.

### 9.2 Uncreated grammar and articulability

**Legitimate uses**

Neutral linguistic facts—exact tokens, morphology, syntax, declared composition, or a formal grammar—can define a common operation if they are implemented and interpreted uniformly. A school-relative uncreated-Speech premise can also define a source-conditioned branch, provided the conditioning remains explicit.

**Illegitimate uses**

It is target-dependent when:

```text
“same intervention” means participation in an uncreated or mental grammar;
articulability is assumed to require mentality or Speech;
a created linguistic implementation is disqualified because it lacks the desired metaphysical ground;
source disclosure is treated as actual uncreated Speech without the separate bridges.
```

The uncreated-grammar owner explicitly keeps local grammar, modal orthability, underived ground, necessity, unity, mentality, agency, Wisdom, Speech, and revelation separate. Deep BV cannot collapse them.

### 9.3 Transcendental premises

**Legitimate uses**

A formal or transcendental premise may restrict the candidate class when its exact hard premise is independently defended, the formal/world reflection map is explicit, and the restriction is not merely the desired conclusion restated. The resulting experiment remains conditional on those premises.

**Illegitimate uses**

A common-intervention profile cannot infer or presuppose:

```text
positive further ground from non-generation without H2;
underived terminal from further ground without H3;
necessity from underivability without H4;
concrete being from necessary ground without H5;
one bearer from roles without H6;
intellect from content without H7;
personality from intellect without H8;
Wisdom without H11;
actual Speech without H15;
Allah as revealed without H16.
```

The bridge ledger marks these hard premises as required but not established. A factorization theorem cannot discharge them.

### 9.4 Result

Proper-function, uncreated-grammar, and transcendental materials can constrain `J`, `M`, or the output semantics only in one of two honest forms:

```text
(A) independently established target-neutral eligibility guard; or
(B) explicitly source-/school-/theory-relative conditional experiment.
```

Any other use is either target leakage, model-class question-begging, or source-track migration.
