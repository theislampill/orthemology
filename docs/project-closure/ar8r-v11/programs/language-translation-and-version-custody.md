# Language, translation, occurrence meaning, and version custody

## Historical boundary and later-program split

The language program separates signal, token, syntax, morphology, composition,
reference, semantic content, pragmatic force, intention, uptake, evidence,
warrant, authority, convention, and world-directed truth. It records that a
translation fibre can preserve a selected proposition while losing other
structure, and that token type alone need not decide occurrence meaning. Exact
historical predecessors are AR8R-T89, which separates source provenance from
translation truth, and AR8R-T244, which exposes a nonconservative bridge when a
new old-language consequence appears. Query-relative fibre and version-custody
characterizations are later PMR descendants, not historical AR8R payloads.

## Bounded results by epoch

- later PMR result: a target query factors through a translation exactly when it is constant on
  every attained translation fibre;
- preserving one query does not preserve morphology, syntax, ambiguity,
  discourse force, authority, evidential status, authorization, or execution;
- later PMR result: same bytes do not entail same applicability when version, dependency,
  authority, invalidator, or target obligations differ;
- PMR-007 `PMR-007-VCT-1` makes that version-custody transport and action-menu
  eligibility boundary explicit in a finite scoped proposal;
- PMR-007 `PMR-007-ORTC-V4` measures complete certificate-object refinement under
  declared observation and channel assumptions, without upgrading source truth,
  common knowledge, or authorization;
- program boundary: lexical availability is not complete occurrence meaning;
  no exact historical definition of `occurrence meaning` is assigned here.

## Forbidden claims

- shared form or grammar entails shared meaning or truth;
- translation is complete because one proposition survives;
- same bytes imply same applicability;
- linguistic convergence establishes unique or divine grammar;
- secondary translation establishes Arabic-primary wording.

## Repository effect

Preserve the layered language model and version-custody guards. No source or
theological conclusion is promoted beyond its exact verification status.

The V11 compatibility and TAC/SAC registries keep token type separate from occurrence meaning, source provenance separate from translation truth, and equal bytes/profile separate from version eligibility.
