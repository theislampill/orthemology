## 1. Central question

Can one coherent ground of cross-system articulability create genuine formal unification while remaining impersonal and non-speaking? If yes, then genuine derivational unity and total articulability still do not by themselves establish mentality or Speech.

## 2. Formal construction

Let `C` be a finite nontrivial content set. For every language or representational system `i` in a finite nonempty index set `I`, let

\[
e_i:C\to \Sigma_i
\]

be a bijective encoding. Define canonical translation

\[
\tau_{ij}=e_j\circ e_i^{-1}:\Sigma_i\to\Sigma_j.
\]

Then:

\[
\tau_{ii}=id,\qquad \tau_{ji}=\tau_{ij}^{-1},\qquad
\tau_{jk}\circ\tau_{ij}=\tau_{ik}.
\]

Thus the representational systems and canonical translations form a connected groupoid. Every content is expressible in every system, and every predicate on `C` transports exactly along the translations.

## 3. TAGI-1A — formal articulability unification

The shared content object `C` and the family `{e_i}` derive all pairwise translations from fewer primitives than a theory taking every translation table independently. The groupoid laws exclude arbitrary translation combinations and impose cross-system counterfactual constraints.

This satisfies Candidate G's **formal** conditions for non-carrier-boxing unification:

```text
shared derivation;
cross-profile restriction;
cross-system counterfactual dependence;
primitive reduction;
novel excluded translation configurations.
```

## 4. TAGI-1B — mentality and Speech nonentailment

Expand the construction with predicates:

```text
MENT: intrinsic mentality or understanding;
AGENT: agency;
CAP: agentive expression capacity;
UTTER: actual speech occurrence;
ATTR_N: Track-N source-attributed Speech;
UNCR_N: Track-N uncreated status.
```

There is an impersonal expansion in which the complete groupoid construction holds and all six predicates are false. There is also a personal expansion with the same groupoid reduct and some or all predicates true. Therefore formal total articulability, canonical translation, and genuine formal unification do not entail mentality, agency, Speech, or uncreated Speech over a model class containing both expansions.

## 5. UG-T4 and prior distinction

A wholly undifferentiated source with no distinguished content, selector, operation-carried asymmetry, or fixed point cannot equivariantly select a nontrivial label from a fixed-point-free orbit. The groupoid construction avoids this failure because `C`, the encodings, and their relations already contain distinguishing structure.

The result therefore supports only:

```text
nontrivial determinate articulation requires prior distinction or asymmetry at the declared formal scope.
```

It does not identify that prior structure as mental, personal, necessary, concrete, or divine.

## 6. Concrete impersonal realization

For each `tau_ij`, a deterministic finite transducer can realize the translation table. The abstract content/translation order plus these concrete transducers gives an `abstract order + concrete impersonal actualizer` model of exact expression and translation.

No claim is made that this finite actualizer is an ultimate metaphysical actualizer.
