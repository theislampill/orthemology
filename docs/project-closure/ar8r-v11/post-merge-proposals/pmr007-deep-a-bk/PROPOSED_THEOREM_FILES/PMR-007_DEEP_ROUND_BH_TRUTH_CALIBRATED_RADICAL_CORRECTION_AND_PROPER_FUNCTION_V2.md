## 1. Typed setting and authority assumptions

Let `G=(V,E)` be a finite undirected **declared revision registry**. For every
oriented edge, let

\[

Choose one spanning forest `T`, with one tree per connected component.

## 2. TCRPF-1A — componentwise finite truth-calibration certificate

The following are equivalent:

```text
A. For every oriented edge (u,v), d(u,v)=L(u)-L(v).

B. On every oriented forest edge, d(u,v)=L(u)-L(v), and the signed sum of d
   around every fundamental cycle determined by T is zero.

C. On each connected component there is a potential N, unique up to one
   additive constant for that component, such that
   d(u,v)=N(v)-N(u) and N(v)=C_component-L(v).
```

### Proof

`A -> B`: truth-loss differences telescope around every cycle.

`B -> C`: root each tree and define `N` by path integration of `d`. Forest-edge
calibration gives `N=C_component-L` on the tree. Each nonforest edge closes one
fundamental cycle; zero cycle sum forces that edge to equal the potential
difference. Componentwise uniqueness follows from connectedness.

`C -> A`: substitute `N=C_component-L`.

## 3. TCRPF-1B — additive versus ordinal correction

If every declared improvement edge has strictly positive exact increment, the
directed improvement relation is acyclic. Conversely, any finite acyclic
improvement relation admits some topological rank. But a topological rank need
not reproduce the supplied additive increments or truth-loss differences.

Thus:

```text
additive truth calibration
=> ordinal corrigibility

ordinal corrigibility
!=> additive truth calibration.
```
