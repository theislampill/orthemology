# Source custody and ancestry ledger

Access date for web-checked material: **2026-08-09**.

This ledger distinguishes what a source says from whether the source is true,
whether a translation is exact, whether the predicate is instantiated in the
actual world, whether it applies to a proposed bearer, whether a recipient is
warranted, and whether any repository owner adopts the claim.

## Source/world ladder

```text
S0 exact source bytes and locus
S1 edition/version custody
S2 translation
S3 morphology
S4 syntax
S5 occurrence meaning and discourse force
S6 formal predicate
S7 world truth
S8 bearer/referent applicability
S9 recipient warrant
S10 authority
S11 revelation
```

No arrow is automatic. `S10` and `S11` are not neutral experiment semantics.
