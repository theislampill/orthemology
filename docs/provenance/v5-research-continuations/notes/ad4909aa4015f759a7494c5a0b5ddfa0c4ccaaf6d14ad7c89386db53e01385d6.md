## Semantic findings

1. `prefixLength blocks N` is the length of the first N actual finite blocks. It is monotone, with the expected successor recurrence.
2. `Unbounded` requires every physical time t to be crossed by some finite cumulative length. `blockIndex` chooses the LEAST such crossing. Its proved lower and upper bounds make the offset valid, and `flatten` selects the actual List.get element. Empty blocks are skipped without creating a filler action.
3. `eventually_flatten_good` transfers eventual goodness of every action in each sufficiently late executed block to eventual goodness at physical action times. The cutoff is exactly the cumulative length of the finite prefix of potentially bad blocks. Individual block lengths need no uniform bound.
4. Nonempty blocks imply Unbounded. Eventually nonempty blocks also imply it. Those are sufficient conditions, not necessary ones: infinitely recurring empty blocks can still have unbounded cumulative length, and the main theorem handles them through its direct hypothesis.
5. Under EVERY-block nonemptiness, physical time t lies in a block with index at most t. The least-crossing index depends only on the first t+1 blocks, as the precise `blockIndex_prefix_local` type states. The theorem is about index locality; no unprinted stochastic measurability theorem is inferred.
6. All-empty blocks make eventual block goodness vacuous, but fail Unbounded. The main theorem therefore does not manufacture an infinite good physical execution from empty plans. The same caveat applies whenever only finitely many actions are actually executed.
