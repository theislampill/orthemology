# A computable deterministic scheduler for the recovered Markov theorem

This is a fresh successor source after the workspace reset. It strengthens the policy-existence conclusion of the byte-exact recovered `SUPPORT_CHANGING_MARKOV_THEOREM.md`. No lost review seal is attached to it.

Replace the recovered proof's uniform private action choices by deterministic per-state round-robin lists. Retain each local counter throughout its navigation or operating stage, resetting only at a new stage. The same region criterion then admits a computable deterministic history policy with finite expected total bad actions. The expectation concerns the Markov transitions, which remain random.

This ordinary proof is supplied for fresh independent review. It is not a new Lean theorem. The original definitions, empirical-row tests, false-rejection estimates and support-budget induction remain in force. The new obligation is a physical-time bound for this deterministic scheduler.

## 1. Effective scheduler

At navigation, order every nonempty allowed menu A_B,W(s). If its size is k_s, keep c_s in {0,…,k_s−1}. When at s, choose action number c_s, increment that counter modulo k_s and leave every other counter unchanged. At operation use the same rule on the selected component menus U(s).

Start fresh rotor counters and statistical counters at each stage entry. Keep rotor progress across repeated visits, tests and first returns to any anchor. The mismatch milestones in the main proof are analysis devices depending on a fixed actual model; the controller does not know or reset at those milestones.

The policy uses only finite rational input, graph calculations, observed history and integer counters. It can ignore any externally supplied seed, including a Dirac seed. It needs neither private coins nor an uncounted external clock.

The rotor itself has finite memory. The full learner retains unbounded sample counts and therefore is not an autonomous stationary finite-state controller. The earlier finite-memory obstruction is unaffected.

## 2. Augmented-state closure lemma

For one fixed stage, augment the observed physical state with the entire rotor vector:

    z=(s,(c_v)_v).

With n physical states and at most a actions per state, the augmented chain has at most

    Z_stage = n product_v k_v ≤ n a^n

states. Counter updates are deterministic. Every positive augmented transition probability is at least p, the least positive probability in the supplied physical transition rows. If several physical outcomes are combined into an absorbing event, its positive probability is also at least p.

Let D be a closed strongly connected class of the augmented chain, and C its physical-state projection. For any s in C, choose an augmented vertex over s and a positive directed cycle through it. Such a nonempty cycle exists because the finite class is closed and its stochastic rows are nonempty. Returning to the same rotor vector requires a positive multiple of k_s departures from s. Every rotor value and hence every prescribed action at s occurs on that cycle.

Closure of D then makes every supported successor of all those actions remain in D. Consequently C is closed under every prescribed action at each state of C. This is the key projection property. The physical state by itself need not be Markov under round-robin, and the augmented chain need not be irreducible.

## 3. Navigation reaches an event from every rotor vector

Fix live support B, its nonempty region W_B, candidate φ and actual θ. Let H be the fixed set of navigation pairs whose full θ and φ rows differ. Consider the auxiliary augmented chain killed on a completed H-row sample, entry into the candidate target, or a proper support exit. Statistical rejection can terminate the actual attempt earlier.

Suppose a closed nonabsorbing class D existed. Its projected set C avoids the target. By the closure lemma it uses every allowed action at each state in C. Avoiding the H event says that all those rows agree under θ and φ. Avoiding exits says qθ=0 there, and row equality gives qφ=0. Their internal successors remain in C.

Thus no state in C can reach the candidate target or a φ-positive exit in the allowed internal graph. This contradicts the fixed-point condition. Every active augmented state therefore has a path to an absorbing event.

Use the global constants

    N=|S|,    a=|A|,    Z=N a^N,    L_rr=Z/p^Z.

A shortest absorbing path takes at most Z transitions, each of probability at least p. Hence from every augmented state an event occurs within Z steps with conditional probability at least p^Z. Geometric blocks give a conditional mean wait at most L_rr.

The bound is uniform over all rotor vectors, including vectors accumulated at previous milestones. Merely choosing a physical path and assuming that its desired action is next would not justify this estimate. The augmented-chain argument supplies the missing control over action order.

## 4. Operation reaches an exit or a specified row

Fix a selected component with strongly connected common internal U-graph.

If the actual model has a positive support exit on any U-pair, a closed augmented class avoiding exits would project to a nonempty set closed under all U internal edges. Strong connectivity forces its projection to be the whole component. It would then use the exit-bearing pair and have a positive exit, contradicting closure. Thus an exit occurs in conditional mean time at most L_rr, unless a test stops the attempt sooner.

If no actual exit is possible, fix any used pair e and kill the chain on its next completed sample. A closed class avoiding e would again project to the entire component and use every U-action there, including e. This is impossible. The conditional mean wait to the next completed sample of any prescribed used pair is therefore at most L_rr from every augmented history.

For a mismatching candidate, define its selected coordinate's auxiliary rejection count K on the uninterrupted round-robin chain, ignoring all tests. Per-row sample tapes are still iid with their actual row laws. The main proof's E[K]≤Jop is unchanged. The survival event for the k-th sample is known after sample k−1, so the conditional stopped-sum argument gives mean rejection time at most L_rr Jop. A different test can only stop the actual stage sooner.

For matching full rows, self-verification still makes every operated pair good. The false-rejection estimate is unchanged, and an infinite matching stage has zero bad cost.

## 5. Constructive finite-cost conclusion

The main proof's Δ, r, n0, ε, Jnav and Jop depend on row laws and deterministic-count concentration bounds. They do not require randomized action selection. Replace L by L_rr in its completed-event waiting bound, operating bound, candidate-cycle argument and strict-support induction. This yields

    H_B^rr ≤ |B|(|B|+1) L_rr (Jnav+Jop) / [2(1−ε)].

All quantities are finite and computable from the supplied finite rational system. The bound can be very large; this is not a polynomial learning-time claim. The policy need not construct the whole augmented state graph during execution: the graph supplies the proof, while execution maintains local counters and empirical counts.

Consequently the equivalent existence statements can include a computable deterministic history policy with finite expected bad count. A prescribed external seed may be ignored. This strengthens existence and construction; it does not infer intrinsic understanding or any metaphysical property from correct control.

## 6. Reset boundary

Resetting a rotor after every action always chooses the first action and may permanently starve a required second action. Resetting at every first return to an anchor has the same defect at that anchor. Neither is the scheduler proved here.

For example, let the first action self-loop without revealing a mismatch and let the second action be the informative pair. Retained round-robin selects the second on the second visit. Repeated reset stays on the first forever. If the underlying prescribed-action graph is strongly connected through that second action, the reset process violates the projection lemma because it no longer cycles through local actions.

Tests should retain the complete counter vector and check every counter state, rather than only the all-zero initial vector. The fresh independent audit is responsible for those controls; no vanished audit result is being counted.

## 7. Self-contained target-pruning justification

For a fixed B,W,θ restrict to allowed θ-good pairs with zero θ-exit probability. Their θ rows are normalized on internal successors. Compute current maximal end components and delete any pair rejected by a model in B that agrees on every full row of that component. Recompute after every deletion round.

Every original valid self-verifying subcomponent E remains. It lies in some current MEC D; a model matching all of D also matches E and therefore accepts every pair of E. Such a model cannot cause an E-pair to be removed. Pairs outside all MECs cannot belong to E either. This is the preservation invariant.

At termination every returned MEC is good and self-verifying. The invariant places every original valid component inside a returned one. If a returned component had a larger valid extension, that extension would survive and contradict current maximality. The outputs are therefore exactly the maximal valid components. At most the finite number of pairs can be deleted.

The union of intersecting valid components is valid: a model matching the union matches both pieces. Maximal valid components consequently have disjoint state sets. This justifies selecting a component at target entry and supplies the finite algorithm's proof without relying on an unrecovered prose packet.

## 8. Common-support special case and almost-sure reachability

When no support can shrink, the recovered operator is the common-support graph operator R. Let F instead use per-model almost-sure reachability to each self-verifying target. Pointwise F(W) is contained in R(W), so its greatest fixed point is contained in that of R.

At a graph fixed point every state has an allowed path to every model's target. Uniformly sampling safe actions reaches each target with a geometric bound; alternatively the round-robin argument above applies with no exits. Thus that graph fixed point is also an F-fixed point. Their greatest fixed points are equal. Their intermediate iterates need not coincide: a forced branch to a target or a bad trap has a target graph path but not almost-sure target reachability before viability pruning.
