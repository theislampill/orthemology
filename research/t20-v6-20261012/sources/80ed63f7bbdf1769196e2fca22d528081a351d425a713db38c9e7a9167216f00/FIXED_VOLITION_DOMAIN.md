# Fixed particular-volition admissibility: a bounded code-contract audit

8 October 2026 UTC. This adapter reads the current reactive model without altering it. It introduces no new cooperation law, original-agent metaphysics, or definition of complete volition.

## Result

**Represented intention-success can hold throughout the independently policy-defined ordinary domain while individual whole original provision still fails.** That is the current model's actual situation. The ordinary domain is generated by the supplied policies, not selected by testing whether the output happens to be Q.

This earns a noncircular **formal-domain** result. It does not establish metaphysical admissibility, the wisdom of the supplied q or policy, or the identification of a recorded Exercise with the source's fully complete particular willing. Restricting the domain to ordinary(q,q) also does not repair the actual two-root original-provision problem.

The small new control distinguishes that construction from the circular alternative “admit exactly the profiles whose output is Q.” When the observed output function is perturbed, the policy-defined domain stays fixed and its success claim fails; the success-filtered domain moves and keeps success true by construction. The perturbation is a definition-dependency control only, not a proposed wise world or a new production model.

Let C_A(Q,w) stand for the source-level claim that A's particular willing of Q is fully determinate and complete in the relevant original operative respect. The source-motivated requirement is that C_A(Q,w), in a genuinely admissible comparison, entails Q's occurrence. This report does **not** define C_A by any of the following:

- membership in the standing repertoire;
- possession of TargetCode(q) or SettingCode(q);
- passing the interpreter's output-equality check;
- membership in the ordinary or success-filtered domain.

The old program has no independently warranted implementation of this source-level predicate. Its goal, setting, own-activity end, policy and actual support are available for comparison with that predicate; they must not be promoted to it by renaming.

The Majmu8 particular-reason control, already directly read in the preceding audit, adds that a supplied particular selection needs adequate warrant. It does not require a unique mathematical optimizer or authorize reasonless selection merely because a policy is executable. The present audit adds no new full-source reading credit for that earlier work.

## 2. Four domains that must not be interchanged

Fix a supplied positive target Qq, the same bearer-owned repertoires, and the current unchanged law. Goal and operative setting remain different semantic fields.

### A. Ordinary policy domain

The adapter first calls the old intrinsic policies:

- A issues goal q, setting q
- B issues goal q, setting q

Only then does it evaluate a forecast or output. The domain contains this one profile. Its definition never asks whether F(profile)=Qq. The policies use the supplied q and their respective original's owned repertoire; neither takes the peer's actual execution as input.

For each of the three q contexts, direct execution verifies:

- created output is exactly Qq;
- both represented complete-target intentions and own-activity ends hold;
- the reason-derived full forecast agrees with the run;
- every created event has actual support {A,B};
- every event's individual entire-provider set is empty.

Thus satisfying the output-success arm on this domain does not supply the source's independent actual whole-production arm. No failed opposite-intention profile is needed to expose that remaining issue.

The domain's procedural independence from output is not an independent metaphysical argument for its admissibility. The fitting q, the own-full-target policy and the primitive joint law remain the model's disclosed hypotheses.

### B. Full API-compatible diagnostic inputs

For the same intended q, each present actor can be assigned any of its three available settings; either exercise can instead be absent. This gives16 accepted input profiles. These are compatible with the program's input types and total evaluator. They are not therefore all wise, possible, fully original, or compatible with the same complete particular volitions.

Five of those profiles happen to produce Qq: three coactive solutions of the shared-goal response equation and two solo profiles. Only one of the five is the ordinary policy profile; only that one matches the full ordinary forecast. The two off-diagonal coactive successes retain both represented goals q but replace the stipulated own-full-target policies with different means. The two solo successes override one policy-required exercise.

The old tests already solve the simultaneous equations and distinguish these profiles. The adapter makes their domain relationship explicit; it does not newly count them as metaphysically admissible alternatives.

### C. Suppression preserving the A record

Take the ordinary pair(a_q,b_q) and evaluate(a_q,None). The identical A Exercise object is reused. Its represented goal and setting are unchanged, Qq still occurs, and A's own-activity end remains true. Actual support becomes {A}.

But the resulting profile does not conform to B's unchanged ordinary policy, which calls for b_q. **The suppression overrides B's policy-required exercise; it does not silently compute a new intrinsic B policy.** The frozen full forecast is false of that altered run because the peer act, support and associated records differ, despite output Qq remaining correct.

A truthful description can be assigned to the changed diagnostic context. That is not the same as holding the full ordinary forecast and all policy premises fixed. Nor does reusing the A record prove that source-level C_A remains complete under every peer intervention. The earlier numerical-act audit explains why local record identity and source-level numerical identity must remain distinct.

### D. Outcome-success-filtered domain

Define D_success(Qq) as the compatible profiles p for which F(p)=Qq. Then “every admitted p produces Qq” is true by the definition of admission. It supplies no independent reason to exclude the other profiles.

This domain is not the old ordinary domain: it has five profiles instead of one, includes suppression, and includes nonordinary coactive plans. Four of its five profiles fail the ordinary policy condition, and four fail the full ordinary forecast.

Calling this domain “the complete-will domain” would hide precisely the conclusion the source-motivated test is supposed to examine. This adapter uses it only as an explicitly circular comparator.

## 3. The new discriminating operation

The current law and all its source files are unchanged. For a negative control, the adapter supplies a second **observed-output function** that shifts each positive output label cyclically, leaving the empty output empty. It is not proposed as a metaphysical or wisely chosen alternative law; there is no second causal ontology, policy story or source warrant attached to it.

The comparison shows, for every q:

1. The ordinary policy profile remains(q,q).
2. That profile succeeds under the actual law but fails its represented goal under the shifted output function.
3. The original success-filtered domain and the shifted success-filtered domain are different nonempty sets, each containing five profiles.
4. Each success-filtered domain still passes “all admitted profiles succeed” against the function used to define it.
5. No shifted success-filtered profile conforms to the original ordinary policy.

This is useful because it rules out the claim that ordinary-domain success is merely a hidden output filter. It equally rules out treating success-filtering as admissibility evidence. It does not show that either altered-law or nonordinary profile preserves the source's complete willing and wisdom. The original ordinary success is a genuine conditional property of the stated policy/law pair, not an independently grounded explanation of why that pair characterizes perfected originals.

## 4. Exact boundary for “fixed complete particular volition”

There are two unestablished applications:

- **Record-to-volition:** Why does retaining this goal/setting/Exercise record retain the source's complete particular volition and its actually sufficient original determination? The source's completion cannot be defined by success, and the adapter provides no such definition.
- **Profile-to-world:** Why is a changed peer profile admissible for the same proposed originals with the relevant wise reasons and knowledge preserved? API acceptance and a standing response constructor do not prove that possibility.

The independently policy-defined ordinary domain addresses a narrower question: what runs follow the currently supplied policies? It gives one coherent ordinary run per supplied q and correct forecasts at that signature. The source-grounded original-agent possibility of those runs is still not demonstrated.

Conversely, arbitrary fixed-setting failure in the diagnostic domain is not an unconditional counterexample to the source's effect-by-complete-willing principle. It may alter or override the conditions relevant to particular willing, wisdom and knowledge. An affirmative argument using such a failure must justify the fixed-volition and admissibility premises. A rival cannot escape that task merely by deleting failed cells and naming the survivors admissible.

## 6. Particular reasons and end content

`own_policy(original,q)` supplies a deterministic formal selector. It does not compute why this particular q is wise: q is an input, and the worth of the own-full-target policy is a separate hypothesis. `forecast(c,q)` derives the run conditional on those inputs; correct forecasting does not provide the missing particular practical rationale.

Holding q and those policies fixed leaves only(q,q). Changing the policy or selecting another response-pair while retaining the label “reason-context q” is not evidence that all complete wise reasons stayed fixed. The model's context index must not stand in for an unmodelled exhaustive reason-state.

The current own-activity end is also deliberately **not a peer-valuing end**. It requires Qq and the bearer's own participation. A's version survives peer suppression. If a later defense values the actual joint relation or the other original's participation as part of A's end, that is a richer end: suppression may preserve Qq while failing the very end intended. The existing UNION `test_global_participation_end_is_not_individual_end` already establishes this distinction. No new psychological claim or permission to combine the two motives is inferred here.

## 7. Disposition

The available discriminating operation has been executed rather than postponed. Ordinary-domain output success is genuine at the declared signature, the circular comparator is exposed, and the actual original-provision failure remains visible in the same ordinary run.

No tested domain supplies an independent metaphysical admissibility warrant. No setting, target label, object reuse, forecast or successful profile is defined to be the source's complete particular volition. The strongest source package remains unpreserved at actual whole original efficacy; the independent justification and application of that norm remain philosophical obligations. This is a bounded contract clarification, not a new model, source refutation or T20 closure.
