## Mathematical premises

- **L1 Domain:** For arbitrary nonempty I, each represented-state domain S_i contains an absence value 0_i. Its product therefore includes simultaneous absence.
- **L2 Displayed rules:** Each F_i is defined on the declared inputs. The realization requirement is x_i = F_i(x) for every i.
- **L3 Null preservation:** Every F_i returns absence on all-absent supplier inputs.
- **L4 Target:** The claimed unique realization includes at least one positive existential coordinate.
- **L5 Relational variant:** If deterministic functions are replaced by local constraint relations, the all-absent input-output tuple is admitted by every displayed rule. L5 replaces L2–L3 for that variant.

L1–L4 contradict unique nonempty realization under the displayed equations. No premise says simultaneous absence is a metaphysically accessible world. If the intended admissible class is smaller than the full product, its restriction is a further premise.

## Productive application premises

- **A1 Real reception:** A receipt through an exercise requires an actual supplier. This is positively warranted at the admitted local productive scope. It does not make the receiver passive.
- **A2 Existential outputs:** The represented output is the bearer's in-scope existential actuality, not only a property's value or an acquired exercise. This requires target-specific justification.
- **A3 Complete resource typing:** All relevant suppliers and independent positive resources are represented or explicitly retained as outside inputs. A machine creating a new object is not an absent donor merely because no earlier object is present.
- **A4 Domain and admissibility:** The rules' defined domain and the joint admissibility constraints are included. A1 alone does not prove null admissibility or exhaustive law representation. B-DOMAIN is an explicit warning against ignoring this premise.
- **A5 Law-only explanatory claim:** The proposed explanation claims that the included laws and admissibility conditions, without an added actual token configuration, determine the target. Only explanations making this claim are tested by EE10-2/3.

These premises are not all automatically true about the whole actual cosmos. The source application is grounded in the inspected model's actual stated resource placement. An uninstantiated state variable is not evidence for A2–A5.

## Positive controls

- Infinite subordinate ancestry with a warranted outside original contributor: permitted.
- Several original contributors supplying a receiving subinventory: permitted; no common-bearer inference.
- Necessary bearer with contingent exercise when P inventories contingent substances: permitted; acts are not silently added to P.
- Contingent original contributor inside an exhaustive contingent inventory: its own existence remains to be explained; no free closure.
- Noncausal existential law excluding null: remains a distinct explanatory candidate, requiring its own warrant.
- Necessarily occupied role with varying contingent occupant: can exclude global emptiness without de re necessity of any one bearer.
- Actual Q offered as non-law-only causal explanation: not excluded by this paper's lemma.
