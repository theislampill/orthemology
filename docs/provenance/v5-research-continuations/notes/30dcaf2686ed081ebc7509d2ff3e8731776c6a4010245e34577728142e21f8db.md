# Phase-source successor replay

The source-only successor includes every unchanged v5 custom Lean source and
all additive Boolean phase-controller sources. It contains no compiled Lean
objects. Its manifest and runner reject changed, missing, and unmanifested
files. Keep all result paths outside the frozen packet.

## Lean

Use the same pinned Lean 4.19.0 executable and Mathlib revision as v5. To compile
all custom modules, use:

```
python PACKET/tests/replay.py --root PACKET --out ABSENT_RESULT \
  --lean PINNED_LEAN --mathlib PINNED_MATHLIB
```

A focused replay additionally supplies the adjacent exact-qualified predecessor
mapping with `--qualified candidate-v6-qualified.json`. Each predecessor source
and object hash is rechecked before reuse. Only additive modules are freshly
compiled in that mode. The source-only packet has the full dependency closure
for a cold replay; the mapping is an optional local acceleration, not a hidden
source dependency.
