## 1. Typed setting

Let `B` be a finite Boolean algebra of registered contents. A created token
algebra `T` has token-forming operations `and_T`, `or_T`, and `not_T`. A semantic
map

\[
\sigma:T\to B
\]

is compositional when it preserves those operations.

Call `T` totally articulating **relative to B** when `sigma` is surjective.
This is a declared-domain notion, not absolute articulability.

## 2. Candidate theorem

### FTASA-1A — finite impersonal total-articulability construction

Every finite Boolean content algebra has a finite created token algebra with a
surjective compositional semantic map. The construction can be implemented as
an impersonal algebraic system with no mentality, speaker, intention, agency,
Wisdom, or Speech predicate.

### FTASA-1B — semantic quotient characterization

For any compositional `sigma`, define

\[
t\sim_\sigma u\iff\sigma(t)=\sigma(u).
\]

Then `~_sigma` is a congruence and

\[
T/{\sim_\sigma}\cong\operatorname{im}(\sigma).
\]

If `sigma` is surjective, the quotient is isomorphic to `B`.

### FTASA-1C — world/reference and source nontransfer

The same token algebra and semantic quotient can be combined with different
world-interpretation maps, source-authority assignments, versions, recipient
warrants, and personal/impersonal expansions. Therefore the algebraic structure
does not determine actual-world reference, source truth, authority,
applicability, mentality, or Speech.
